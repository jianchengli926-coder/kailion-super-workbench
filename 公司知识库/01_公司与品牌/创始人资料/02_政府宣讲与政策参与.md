## 一、阳东区纪念长征胜利90周年主题宣讲（"金色答案"）

| 字段 | 内容 |
|---|---|
| 时间 | 2026年9月（长征胜利90周年；PPT文件日期约2026-09-10至09-22） |
| 场合/活动 | 阳东区"纪念中国工农红军长征胜利90周年"主题活动——"长征精神·身边答案"系列主题宣讲 |
| 主题/标题 | 《长征精神，身边答案——一个00后阳江青年的"金色长征"》 |
| 角色定位 | "身边答案"矩阵中的**"金色答案"**（红色=淬炼初心 / 蓝色=向海图强 / 绿色=生态担当 / 金色=五金刀剪产业转型升级与青年创新创业） |
| 受众类型 | 区领导、党员干部、青年代表 |
| 形式 | 现场主题宣讲（完整版预估14-15分钟；另有约5-6分钟精简版） |

### 核心内容要点
1. **为什么返乡**：在广州10个月做了三份工作，摸透阿里、亚马逊、速卖通、Temu、Facebook等主流平台；反向选择带着新能力回阳东，2026年初用3万元积蓄创办公司，以创始人主导、AI辅助的精益模式运营。
2. **一个人的长征**：金融专业零基础自学AI编程、独立站与SEO；一个多月跑遍阳东几十家工厂，归档36家合作工厂资料；自2025-07-05起每天录20分钟自我复盘视频，坚持460多天。
3. **创业方式"三位一体"**：AI工具链（提效70%、人力成本降80%）+ 海外独立站kailioncrafts.com（Google SEO，四年成本5000元，流量客户100%自有）+ 本地供应链（约7成订单资金回流本地工厂）。
4. **从"租流量"到"造资产"**：对比传统平台五金品类年投入30万元 vs 独立站四年5000元；强调"租来的流量建立不起品牌"。
5. **工厂走出去、人才留下来**：直接带动就业20多人，赋能50多家工厂数字化升级；给青年三条建议（先找家乡优势产业切入 / 带着新能力回来而非降低要求 / 长期坚持把大目标拆成小任务）。

### 关键金句/数据
- "每一代人有每一代人的长征路，每一代人都要走好自己的长征路。"（开场引述）
- "租来的流量建立不起品牌，只有自己的阵地才能把制造能力沉淀成长期资产。"
- "返乡不是退路，而是把新能力带回家，在家门口创造机会。"
- 数据：阳江刀剪全产业链550亿+、经营主体8500家、从业约20万、产量占全国75%、出口占85%、远销160+国家、2025年出口41.3亿元。
- 案例：2026年7月一篇英文文章《Why 70% of the World's Cutlery Comes From Yangjiang, China》被北美采购商看到，成交2万美元定制订单，净利率约25%。

## 二、2027年度阳江市十件民生实事意见书（书面建议）

| 字段 | 内容 |
|---|---|
| 时间 | 2026年8月25日（完整版落款） |
| 场合/活动 | 2027年度阳江市十件民生实事意见建议征集（致阳江市人民政府办公室） |
| 主题/标题 | 《关于实施"工厂走出去、人才留下来"阳江刀剪数字化品牌出海与青年创业赋能行动的建议》 |
| 建议人身份 | 阳江市锴利国际贸易有限公司创始人兼总经理、KaiLionCrafts品牌创始人、阳江市五金刀剪行业协会会员、阳东返乡青年创业者 |
| 受众类型 | 市政府办公室、人社/商务/工信/团委等部门 |
| 形式 | 书面建议书（3000字简介版 + 完整版） |

### 核心内容要点
1. **两大民生痛点**：①中小工厂"制造能力强但品牌与海外连接能力不足"，困于低价内卷；②青年"有能力但缺少与家乡产业连接的机会"，形成"青年缺产业机会、企业缺数字化人才"的结构性矛盾。
2. **总体思路**：政府引导、协会协同、企业参与、青年实践、市场化运作、公共服务赋能；不新建大型硬件平台，依托现有协会/园区/孵化载体/职业院校。
3. **五项实施内容**：①建立"阳江刀剪数字化出海公益赋能机制"（能力诊断+资料标准化+AI数字外贸公益培训+推广自有数字资产）；②开展"青年返乡数字外贸实训计划"（培训+工厂参观+真实项目+企业实践）；③依托现有载体打造"青年数字外贸实践专区"；④建立"青年人才库+工厂需求库"双向匹配；⑤开展"雁归阳江"青年返乡创业宣传行动（含校园宣讲）。
4. **2027三阶段安排**：Q1启动试点建库 → Q2-Q3培训实践形成案例 → Q4复制总结、沉淀《阳江刀剪数字化出海基础SOP》。
5. **量化目标**：公益培训≥6场、参与100-200人次、服务企业30-50家、深度试点≥10家、青年实践岗位≥20个、供需对接≥2场、返乡宣传2-3场、SOP 1套、典型案例5-10个。

### 关键金句/数据
- "阳江不缺制造能力，缺的是让好产品'被世界看见'的能力；阳江也不缺优秀青年，缺的是让青年愿意回来、能够留下、真正干成事的产业土壤。"
- 已有实践基础：36家合作工厂归档、128条标准化产品主数据、kailioncrafts.com独立站、AI综合提效约70%/人力成本降约80%、北美2万美元订单验证闭环。
- 本人愿以返乡青年实践者身份提供已验证的经验、培训内容、基础SOP和案例。
