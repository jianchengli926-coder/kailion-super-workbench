## 第一章：跨境网络（新增细节）

### 1.1 自建跨境网络 vs 普通梯子
- 普通梯子/共享V*N痛点：机房IP、多人共享、频繁跳IP、平台风控
- 自建独享静态住宅IP优势：真实家庭宽带属性、100%独享、固定IP不变
- **关键认知**：稳定长期一致的网络环境可减少因网络频繁变化产生的额外风控因素，但**不能保证平台永不验证或永不封号**
- 平台风控综合因素：IP + 设备 + 账号行为 + 登录位置 + 系统时区 + 使用语言 + 浏览器环境 + Cookie + 手机号 + 支付信息 + 账号历史 + 平台规则

### 1.2 网络组成架构
- 工作设备 → v2rayN/小火箭(客户端空壳) → 美国VPS(远程中转站) → x-ui面板+Xray引擎 → 静态住宅IP(固定出口) → 海外平台
- **关键认知**：节点是"门"，IP是"地址"。一台VPS只有1个IP，可以开N个节点，但多节点仍共享同一出口IP
- VPS只做中转站，不跑浏览器/剪辑，2G内核够用

### 1.3 软路由进阶
- 软路由是TK运营标准配置：断网不跳IP（最关键）
- 连WiFi就自动有跨境网络；SK5分流，一机一IP
- TK标准配置：手机刷机→关定位→语言时区调目标国→对应国家IP→软路由WiFi→注册运营

### 1.4 IP纯净度检测
- pingip.cn实测：风控分100，风险值8%越低越纯净
- IP类型需为 `<双ISP> <家庭宽带IP> <原生IP>` 才是静态住宅IP
- 浏览器指纹检测：IP/时区/语言/系统/CPU/内存/屏幕分辨率/WebGL全能被检测
- 需自备苹果美区ID，不要租美区ID下载软件

## 第二章：AI赋能（新增细节）

### 2.1 多模型交叉验证法
- 同一项目同时交给Claude/ChatGPT/Gemini/Grok/豆包/DeepSeek/智谱/文心等产生10个答案
- AI互相评分，多数AI认可的方向=重点检查对象，人最终判断
- "就像10个好学生做同一道选择题，大家都选A，A不一定100%正确，但一定值得重点检查"

### 2.2 AI使用两大基石
1. **知识库=喂给AI的资料**：公司产品目录、规格参数、价格体系、生产工艺、质量标准、历史项目、客户案例
2. **提示词=给AI的指令**：角色设定+任务目标+输入素材+输出格式+约束条件
- 核心逻辑：AI越用越聪明，不是因为AI变了，而是知识库变厚了、提示词变准了

### 2.3 企业AI落地安全指南
- **外置SSD部署**：AI Agent运行工作区放外置SSD（雷电/USB4 40Gbps），保护本地硬盘
- 知识库隔离：多Agent独立副本，避免上下文污染
- **独立站防毁**：严禁AI直连生产环境，本地测试后人工上线
- 定期全站备份，数据多重保险
- **四条铁律**：①独立站不能直接交给AI接入（曾做坏过）；②智能体项目放外置SSD跑；③公司知识库复制多份一份AI一套；④文件优先Markdown格式

### 2.4 八大专属AI效率工具
| # | 工具 | 功能 | 形式 |
|---|------|------|------|
| 01 | 场景图提示词反推 | 白底图+参考图→生成提示词 | HTML本地离线 |
| 02 | 刀剪场景词库 | 4大品类预设场景+一键翻译 | HTML本地离线 |
| 03 | 白平衡校正 | 批量一键校正成白底+滤镜 | HTML本地离线 |
| 04 | 白底主图视觉矫正 | 独立站白底图统一角度方向 | HTML本地离线 |
| 05 | SKU批量命名工具 | 内置国际标准SKU命名库 | HTML本地离线 |
| 06 | 混元3D+自研多角度3D | 2分钟出3D效果图 | 在线+本地 |
| 07 | updrama作图中转站 | 聚合多模型约¥0.07/张 | 在线 |
| 08 | Codex自动化剪辑流水线 | 抓爆款→拆镜头→素材匹配→自动出片 | 工作流 |

### 2.5 通用AI到企业AI完整工作流
收集→整理→定义→分析→验证→执行→决策→沉淀→再利用
- 每一次循环，企业知识库都在增长，AI都在变得更懂企业

### 2.6 AI工具选型
- 国内：豆包(日常文档/PPT)、DeepSeek(中文推理)、智谱清言(Agent)、文心一言(综合办公)
- 国外：Claude(编程/长文本/重要项目)、ChatGPT(全能主力)、Gemini(视觉生图免费额度高)、Grok(内容创作)
- Agent：Codex(重要开发/跨聊天共同记忆)、WorkBuddy(性价比中文任务)、豆包桌面版(国内文档PPT)
- **结论**：重要项目用Codex，简单中文任务用WorkBuddy省钱，国内文档PPT用豆包

## 第三章：独立站与SEO（新增细节）

### 3.1 平台 vs 独立站核心对比
| 维度 | 平台 | 独立站+Google SEO |
|------|------|-------------------|
| 流量来源 | 年费+P4P买曝光 | 谷歌自然搜索+社媒引流 |
| 见效速度 | 快(本月入驻下月出单) | 慢(1-3月认识你，6月稳定给量) |
| 客户归属 | 归平台 | 100%自有 |
| 停投后果 | 流量询盘归零 | 排名稳定后持续来量 |
| 成本结构 | 年费+广告费逐年叠加 | 一次性建站+低额年运维 |

### 3.2 WordPress vs Shopify九维对比结论
- 快速测品/不想碰技术→Shopify；做品牌/做SEO/做B2B询盘/长期资产→WordPress
- **WordPress服务器四年成本约3000元**
- 技术栈：WordPress+WooCommerce + Elementor+Astra主题 + Hostinger VPS + Rank Math + Fluent Forms + FluentSMTP

### 3.3 域名命名原则
- 不要只用公司拼音，国外没有记忆点
- KaiLionCrafts = KaiLi(锴利拼音) + Lion(狮子座Leo) + Crafts(手工艺品/五金刀剪)
- 让外国客户一看域名就知道公司做什么

### 3.4 代码免费实现的功能
- CSS一行fixed实现页眉固定（不开会员）
- CSS强制调换描述与SEO信息位置
- JS手风琴实现FAQ折叠/区块动效
- JS改造购物车为一键询盘表单（B2B核心）

### 3.5 图片SEO四要素
| 要素 | 说明 | 错误示范 |
|------|------|---------|
| 文件名 | SEO友好命名，英文小写+连字符 | IMG_20240101.jpg |
| Alt文本 | 关键词描述图片内容 | 留空或"product" |
| Title标题 | 关键词标题，鼠标悬停显示 | 留空 |
| Description | 一句话描述补充Alt | 留空 |

### 3.6 关键词体系与内容三层金字塔
- 四类关键词：产品词(wholesale kitchen knives)、行业词(Yangjiang knife manufacturer)、解决方案词(private label kitchen knives)、内容词(How are kitchen knives made?)
- 三层金字塔：流量层(科普内容社媒曝光) → 专业层(深度内容SEO长期流量) → 成交层(采购意向内容直接询盘)

### 3.7 Cloudflare独立站防护（9步部署）
1. 备份现有DNS配置
2. 注册Cloudflare+切换Nameserver
3. 核对DNS记录（尤其MX邮件记录）
4. 修改Nameserver
5. 等待生效+验证(15-30分钟)
6. 开启Bot Fight Mode
7. 配置Rate Limiting（同IP 10秒超20-30次弹验证码）
8. 最终确认+观察1-2周
- **成本0元（Free Plan）**，部署30-60分钟

### 3.8 服务器与CDN布局
- 主节点：美国洛杉矶
- CDN缓存：立陶宛(欧洲)、新加坡(东南亚)
- 视频上传YouTube→代码嵌回产品页（利用YouTube全球CDN零卡顿）
- 视频需延迟加载+图片覆盖，客户点击才播放

### 3.9 首页优化实测数据
- 首屏改静态图片+WebP格式+避免延迟加载
- 桌面端FCP 1.1秒，LCP 1.5秒
- 海外客户基本4G网络较慢，首页必须做静态快速加载

## 第四章：本地供应链拍摄剪辑（新增细节）

### 4.1 24道工序全链路（厨房刀样本）
1.工厂外观 2.办公室 3.车间全景 4.钢板 5.塑料 6.激光切割 7.人工开料 8.调直校正 9.自动成形 10.数控冲压 11.菜刀炉淬火 12.氮化炉强化 13.回火处理 14.HRC硬度测试 15.打背/粗磨 16.水磨开刃 17.镜面抛光 18.过镭射光 19.开利口 20.倒角/拉披锋 21.全自动清洗 22.印字/Logo 23.手柄装配 24.品检分级

### 4.2 必拍高帧率镜头（120fps+）
- 激光切割火花 ★★★★★
- 红热刀胚出炉（热处理，全片视觉巅峰）★★★★★
- 打背逆光火花
- 焊接弧光（ND64减光镜防过曝）
- 镜面抛光反光
- 印字激光雕刻

### 4.3 五段式镜头法（每个工序必拍）
1. 远景：厂房大门/车间门头（建立实力）
2. 中景：整条生产线/车间整体（看产能）
3. 过程景：生产加工/焊接/打磨（看工艺）
4. 特写：产品细节/材质/质检（看品质）
5. 收尾：成品/打包/发货（看交付）

### 4.4 三段式镜头法（每个工序内部）
1. 进去特写：物料进入设备瞬间
2. 中间全景：设备整体运作
3. 出来特写+手持展示：工序完成后半成品

### 4.5 六种基础运镜
固定镜头、缓慢平移、推进镜头、拉远镜头、俯拍、特写微距

### 4.6 剪辑四件套
- 转场：匹配剪辑为主，横移方向一致，颜色匹配
- 音效：现场环境音是灵魂（火花/磨削/激光声），工业风BGM做底
- 调色：工业写实——冷灰底+暖橙高光，金属质感强化
- 字幕：大号字体+高对比度+关键数据弹窗+中英双语

### 4.7 一套素材多平台版本化
| 平台 | 画幅 | 时长 | 内容类型 |
|------|------|------|---------|
| YouTube | 16:9横屏 | 4-5分钟 | 完整流程/工厂纪录片 |
| TikTok | 9:16竖屏 | 15-30秒 | 极致测试/工艺快剪 |
| Instagram | 1:1+Reels | 精修图+短视频 | 白底产品图/场景美学 |
| Facebook | 16:9/1:1 | 30-60秒 | 工厂全景/质检/发货（B2B转化最高） |

### 4.8 爆款内容公式
视觉钩子(淬火火花/削纸瞬间) → 工艺展示(怎么做的) → 性能证明(测试数据) → 信任建立(工厂实力/客户见证) → 行动引导(访问独立站/提交询盘)

### 4.9 6大内容选题类
工艺锻造类、极限测试类、应用场景类、工厂实力类、行业知识类、客户见证类

## 第五章：海外社媒矩阵（新增细节）

### 5.1 双圈流量闭环
- **外环（社媒引流层）**：FB/IG/TikTok/YouTube/Pinterest/X → 短链接 → 独立站
- **内环（独立站转化层）**：SEO自然流量 + 80%B2B询盘(Form/WA/Email) + 20%B2C海外仓现货
- 核心逻辑：社媒是外环负责引流，独立站是内环负责承接

### 5.2 Facebook B2B广告6步走
1. **选目标**：初期用流量(Traffic)→后期切转化(Conversions)→线索收集(Leads)
2. **定受众**：35-55岁、美国/欧洲/中东、兴趣(厨房用具/户外装备/烹饪)、职位(Owner/Manager/Buyer)
3. **做素材**：15-30秒工艺视频+白底产品图+痛点钩子→产品价值→CTA，3-5套A/B测试
4. **设预算**：测试期$10-20/天跑3-5天→优化期$30-50/天跑7-14天→放量期$100+/天
5. **装像素**：FB Pixel安装全站，标准事件PageView/ViewContent/Lead，转化API回传
6. **监测优化**：CPM/CPC/CTR/询盘成本，每周复盘每月大优化

### 5.3 出价方式对比
| 方式 | 适用场景 | B2B建议 |
|------|---------|---------|
| CPC | 引流到独立站 | 新手首选 |
| CPM | 品牌曝光/再营销 | 已有品牌认知后 |
| CPA | 表单提交 | 需50+转化数据后 |
| oCPM | 智能优化转化 | 有数据积累后最好 |

- 健康指标：CTR 1.5%-3%正常，CPC $0.5-$2合理，转化率5%-10%优秀

### 5.4 养号四阶段
- 第1周：只浏览点赞，完善资料，绑2FA，每天15-30分钟
- 第2周：加3-5好友/天，加入2-3行业群，发2-3条生活动态
- 第3周：发行业价值内容(70%价值+20%生活+10%产品)，创建公共主页
- 第4周：主页持续发内容，建BM，低预算广告测试$5-10/天

### 5.5 赛马机制三阶段
1. 自然流量测试：发原创内容观察播放互动
2. 低预算加码：自然播放达1,000-10,000且互动良好时开启付费
3. 极速测试收询盘：$10-100测试欧美/中东市场

### 5.6 90天行动路径
- **第1月**：素材库搭建（拍摄单+授权+命名，集中拍摄2-3次，素材库100+条）
- **第2月**：稳定发布（FB/IG每周3-4条，YT每周1条，TK每周5-7条，记录数据）
- **第3月**：热度验证转化（自然破1k-10k再投，FB $10-100测试，跑通内容→投流→询盘）

### 5.7 社媒外链三条红线
1. 禁止在社媒放联系方式（WA号/邮箱/电话）
2. 禁止在社媒标价格
3. 禁止短链接跳转（用独立站原始域名链接）

### 5.8 五大概规红线
1. 引流红线：评论区/私信直接留电话报价 → 引导独立站短链接
2. 网络红线：动态机房IP频繁切换 → 固定静态住宅IP一机一号
3. 代码红线：剪映原视频直接传海外 → CapCut二渲（注：PPT后续纠偏——真正决定流量的是内容质量/账号权重/受众匹配）
4. 账号红线：个人主页直接跑广告 → BM+企业公共主页
5. 投放红线：视频一发就砸钱投广告 → 等自然播放1k-10k再赛马
