# LinkedIn运营全案

> 定位：B2B获客主阵地。**LinkedIn个人Profile触达是公司页的2.75倍**——主理人本人Profile做主力获客，公司页做背书。这是80% B2B社媒线索的来源。

## 一、平台规范速查

| 字段 | 规范 |
|------|------|
| Display Name | 真名（如 Leo Li），不写品类 |
| Headline | **≤220字符**（不是原来以为的120） |
| About | ≤2,600字符 |
| Profile URL | linkedin.com/in/xxx |
| 头像 | 300×300（真人职业照） |
| 背景图Banner | 1128×191（扁平横幅） |
| Website字段 | Contact info里最多3条 |

## 二、双账号策略

### L3 个人Profile（主力获客）
- 用真实英文名（Leo Li / Jason Li / Owen Li / Julia Zhong）
- Headline写"品类 + 供应商身份"
- 发工厂实拍、行业洞察、采购知识
- @公司页做背书

### L1 公司页（品牌背书）
- 名称：KaiLionCrafts
- 只放品牌官网+招聘+About
- 每2–3天1条
- 不做主力获客

## 五、链接放置规则（关键）

| 位置 | 可点击性 | 说明 |
|------|---------|------|
| Contact info → Websites | ✅ 最多3条 | 品类页+OEM页+联系页 |
| 帖子正文 | ❌ 外链降权20–60% | 发完后自己第一条评论补链接 |
| About底部 | ✅ 可写URL | |
| 置顶帖 | ✅ 评论区可放链接 | |

**铁律**：帖子正文不要放外链——正文带外链会被限流20–60%。发完后自己第一条评论补链接。

## 六、运营节奏

- 个人Profile每周2–3条
- 公司页每2–3天1条
- 内容方向：工厂实拍、行业洞察、采购知识、QC知识
- 每天花15分钟刷Feed、评论同行帖子
- 主动连接：每天≤15个目标客户（海外刀具批发商、进口商、品牌买手）

## 七、运营注意

- 员工个人页是公司页触达放大器
- 公司页只放品牌官网+招聘+About
- 个人Profile发内容时@公司页背书
- 头像必须真人职业照（深色衬衫、浅灰/深蓝纯色背景、胸像）

## 八、改名限制
- Display Name：较宽松
- 自定义URL：有次数限制
- Headline/Bio：分多次小改，不要一次性大改Profile
- 一次性大改Profile会被判定异常

## 九、内容方向
| 品类 | 内容主线 |
|------|---------|
| Outdoor | 工厂/工艺、钢材与热处理、刀型与用途、OEM/ODM、采购清单（避免战斗/攻击） |
| Kitchen | 钢材与研磨、Chef/Cleaver/Santoku、热处理、套装、QC |
| Scissors | 刀片对齐、张力、材质、应用场景、激光刻字 |
| Accessories | 砧板、硅胶厨具、BBQ工具、食品接触材料、零售包装 |
