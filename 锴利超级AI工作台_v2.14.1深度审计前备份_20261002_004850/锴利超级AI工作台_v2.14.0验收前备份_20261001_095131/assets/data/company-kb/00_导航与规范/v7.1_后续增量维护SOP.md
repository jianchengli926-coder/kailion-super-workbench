# v7.1 后续增量维护 SOP

> 版本 v7.1 ｜ 供 Leo 后续新增内容时遵守。

## 一、新增文件必做

1. 在对应一级目录创建 Markdown。
2. 顶部写 YAML frontmatter，**必须包含 `sensitivity: public|internal|confidential`**。
3. 凡含价格/成本/出厂价/利润/供应商真名 → `confidential`。
4. 凡含管制刀型、仿牌品牌、冲突SKU、内部决策 → `internal`。
5. 纯对外、无价格、无供应商真名、无管制术语 → 才可 `public`。
6. 同步更新 `01_知识库文件全清单.md` 与 README 计数。

## 二、新增 SKU 入库流程（恢复后）

1. 先在 `02_产品知识库/SKU数据提取/` 核对来源。
2. 排除管制 13、仿牌 6、冲突 3 个 SKU。
3. 价格字段不写入 public，仅标 [CONFIDENTIAL]。
4. 入 `SKU正式库/`，frontmatter `sensitivity:public`。
5. 更新 SKU 状态统计与本目录图表数据。

## 三、外部知识更新

- 每条必须带 source_url / source_name / publish_date 或 fetch_date / confidence。
- 各国法规类须加"以官方最新法规为准，对外报价与合同前二次核实"。
- 到期按 `外部知识过期日历.md` 复核。

## 四、发布前检查（每次）

- public 层 grep：`$数字|建议售价|出厂价|批发价|天澳|广和|汇达|犀瑞|OTF|弹簧刀|Gerber|SOG|Microtech|Strider|KL-OD-HC-006|KL-OD-HC-005|KL-KN-DS-001`，命中=0（除已登记合规例外）。
- 重新生成统计 JSON/CSV 与两个 HTML，数字须一致。
- 重新打 public_safe 与 internal_full 两个 zip 并更新 SHA-256。

- 不得把供应商真名写入 public。
- 不得在 public 写我方产品价格。
- 不得自行导入 161 个剩余待入库 SKU（候选总数181，已入库20）<!-- v7.1.1勘误 -->（等 Leo 决策）。
