# 亚马逊Listing优化全流程

## 一、Listing优化整体框架

Listing优化是证据驱动的结构化工作流，分为三个阶段：**诊断→优化→执行**。

### 诊断层
1. **Listing健康诊断**：内容表达、关键词与自然流量、买家顾虑、属性完整性、竞品差距、生命周期、资产保护
2. **Alexa收录诊断**：AI如何理解产品，五问测试，COSMO关系覆盖

### 优化层
3. **Listing文案优化**：Title、五点、描述、Search Terms
4. **主图副图工作流**：6-8张图的规划、生成、排版、QA
5. **A+图片工作流**：Basic A+ / Premium A+模块规划与生成

### 执行层
6. **综合优化**：合并诊断JSON，生成分阶段执行方案

## 二、Title优化规范

### 两种标题形式
1. **SEO标题候选**：自然、关键词前置、人类可读
2. **新规产品名**：最多75字符（含空格）

### 新规Product Highlights（新品Listing）
- 3-5行简短事实性描述
- 覆盖最高信号的已确认属性（包装数量、单单位电池容量、充电接口、尺寸/材质、控制方式、包含配件）
- 与五点描述保持区分

### 标题优化原则
- 关键词前置但自然可读
- 不堆砌关键词
- 不使用促销性词语
- 不使用竞品商标
- 75字符限制内包含核心词+关键属性

## 三、Bullet Points（五点描述）

### 输出要求
- 恰好一个五点对应一个copy block
- 包含英文copy和中文理由
- 明确买家意图、使用场景、顾虑和边界
- 五点数量：固定5条

### 写法要点
1. **第一点**：核心卖点+产品定义，必须包含核心关键词
2. **第二点**：关键功能/性能优势，用数据支撑
3. **第三点**：使用场景+适用性
4. **第四点**：材质/工艺/耐用性
5. **第五点**：包装内容+售后/保障

### 禁止事项
- 不写未经证实的声明（保修、续航、防水、认证、医疗功效、兼容性、安装时间、USB充电行为）
- 不确定的标记为`待确认`
- 不使用"claims"作为英文标签，用"宣传性承诺或声明"并标注状态

## 四、Product Description与Search Terms

### Description
- 补充五点未覆盖的细节
- 讲述品牌故事
- 详细使用说明和护理指南

### Search Terms（后台搜索词）
- **最大字节数**：249 bytes
- 禁止：竞品商标、促销性声明、过度重复、不支持的属性
- 策略：补充前台未覆盖的同义词、拼写变体、相关词

## 五、主图与副图规范

### 图片集合（6-8张）
| 图片 | 类型 | 要求 |
|------|------|------|
| 图1 | 白底主图 | 无文字、无道具、无水印、无徽章、无未售物品 |
| 图2 | 信息图 | 核心卖点可视化，文字排版 |
| 图3 | 功能图 | 展示关键功能/机制 |
| 图4 | 场景图 | 真实使用场景 |
| 图5 | 细节图 | 材质/工艺细节 |
| 图6 | 尺寸图 | 尺寸对比/比例示意 |
| 图7 | 包装图 | 包装内容展示 |
| 图8 | 对比图 | 与竞品/旧款对比 |

### 图片技术规范
- 最终尺寸：1600 x 1600 px（不拉伸产品）
- 主图：纯白背景RGB 255,255,255
- 文字：最多2种字体族、3种字重
- 标题1-2行，辅助文字1-3行
- 文字安全区：远离产品、面部、手部、控件、证据细节

### 字体排版规则
- 优先使用品牌授权字体
- 否则使用开源/系统字体并记录路径
- 精确层级、文本框边界、对齐、行数限制、最小字号
- 溢出、缺失字形、字体回退、弱对比、断行、不一致间距、400px缩略图不可读均视为失败

### 不可违反规则
- 保留真实产品形状、颜色、比例、可见部件、材质纹理、包装内容
- 不发明配件、包装、认证、徽章、Logo、声明、接口、按钮、手柄或功能
- 图1无文字、道具、水印、徽章或未售物品
- 副图必须像完成的Amazon转化图，不是普通照片或拼贴

## 六、A+内容规范

### Basic A+
- 默认5个模块
- 图片优先设计，标题/正文文字放在图片外
- 仅短标签、图标或简单声明使用文字叠加

### Premium A+
- 默认不超过7个模块
- 桌面和移动资产分别生成（移动优先构图，不依赖裁剪桌面图）
- 更强的品牌叙事和交互模块仅在服务产品卖点逻辑时使用

### A+工作流
1. 收集输入（产品图、Listing copy、主副图、目标站点和类目）
2. 检查参考产品链接
3. 输出2-3个A+布局推荐（不写图片提示词）
4. 用户确认布局后生成完整内容计划
5. 创建模块图片提示词
6. 生成所有模块图片
7. QA检查

## 七、Listing健康诊断体系

### 诊断维度（5个维度100分）
1. **内容表达**：标题、五点、描述、属性的完整性和准确性
2. **关键词与自然流量**：关键词覆盖、排名、流量结构
3. **买家顾虑与评论**：好评/差评主题、未回答问题
4. **竞品差距**：与竞品的内容和关键词差距
5. **生命周期与资产保护**：上架时间、修改强度、保护等级

### 生命周期判断
- 上架时间优先使用`available_date`，再与Keepa最早历史核对
- 时间冲突标记为推测，不伪造精确日期
- 不因链接年龄高就自动禁止修改，也不因年龄低就忽略已有流量资产

### 资产保护等级
- **高/极高保护**：禁止同时替换标题、五点和Search Terms
- **保守分阶段**：没有健康诊断时默认
- 每阶段至少观察14天，定义继续、停止和回滚条件

### 诊断输出格式
每个重要问题必须包含6要素：
1. 现在的问题
2. 证据
3. 会造成什么影响
4. 建议修改位置与内容方向
5. 为什么这样改
6. 如何验收

## 八、Alexa/Rufus/GEO收录诊断

### 五问测试
通过5个英文问题测试Alexa如何理解产品：
1. What is [product]?
2. Who is [product] for?
3. What problem does [product] solve?
4. How is [product] different?
5. Where can I use [product]?

### 四层证据分离
- 卖家意图
- 当前Listing表达
- Alexa理解
- 已确认产品事实

### 证据状态（5级）
- `confirmed`：多源确认
- `single_source`：单源
- `conflict`：证据冲突
- `inferred`：推断
- `missing`：缺失

**禁止**：将conflict、inferred、missing事实作为确认事实进入修复方案。

### COSMO关系覆盖
固定输出15行COSMO关系行，检查Listing是否覆盖了Amazon语义理解所需的关系。

### 复测模式
Listing修改后，用相同5个问题再次采集，对比分类为：`改善`、`无变化`、`新增冲突`。问题措辞在基线和复测间不得改变。

### 硬边界
- 仅使用"Alexa"作为用户语言
- 不输出数字Alexa评分
- 不声称Amazon内部已索引或推荐产品
- 不输出完整替换Listing copy
- 不添加复制按钮

## 九、综合优化执行规则

### 模块动作分级
每个模块标记为以下之一：
- `保留`：现状良好，无需修改
- `局部修补`：小范围调整
- `替换候选`：需要重写
- `暂缓发布`：数据不足或风险高

### 修改强度约束
- 高或极高保护链接：禁止同时替换标题、五点和Search Terms
- 没有健康诊断：默认保守分阶段
- conflict、inferred、missing、不可公开事实和竞品商标不得进入成稿
- 每阶段至少观察14天

### 输出物
- HTML报告（固定12章）
- 版本化JSON
- Excel执行表（7个分表）

## 十、刀剪品类Listing案例参考

### 关键词布局策略（基于B0G8HTRKQG数据）
- **标题**：knife set + kitchen knife set + knife block set + 关键属性
- **核心优先词**：knife set（搜索量581,301）、kitchen（294,917）、kitchen knife set（162,982）、knife block set（82,985）
- **重要补充词**：knife set with block（购买率2.96%）、knife set wood、knife set 3
- **场景词**：kitchen gifts、rv essentials、home kitchen
- **否定词**：所有拼写错误（nife set等）、竞品品牌（Farberware、Granitestone、MasterChef）

### 竞品Listing结构参考
| 产品 | 价格 | 评分 | 核心结构 |
|------|------|------|----------|
| Astercook 15件 | $59.99 | 4.7 | 15件+刀座+磨刀器 |
| McCook 15件 | $59.98 | 4.6 | 15件+full tang+礼盒 |
| Astercook Cream White | $59.99 | 4.7 | 浅色15件+防锈涂层 |
| Martha Stewart 14件 | $59.99 | 4.5 | 14件+acacia block |
| Home Hero 16件 | $29.99 | 4.7 | 透明刀座+量大评论 |

### Listing优化关键洞察
- $57.98-$59.99是15件自磨刀座礼品线的核心价格带
- 颜色审美是$60档的明显差异点（Cream White、Crystal Pink）
- 防锈/洗碗机安全承诺是最大VOC痛点，必须打样测试
- 刀座结构创新（透明、磁吸、紧凑）是差异化方向
