# 社交媒体运营SOP (Social Media Operations SOP)

> **用途**：把 KaiLionCrafts 48账号矩阵的日常运营拆成"几点几分做什么"的标准动作，覆盖每日/每周/每月流程、各平台要点、内容创作全流程、危机处理、团队分工、工具。
> **使用方式**：运营人每天上班照本 SOP 走；每周一对照本周内容日历排期；每月末对照 KPI 复盘。
> **核心原则**：60% 教育/信任 + 20% 幕后/社区 + 20% 产品/转化；卖什么偏不说什么，说解决什么问题；点赞是虚荣指标，B2B 要的是询盘。
> **与其他文件关系**：[`社媒内容日历执行版.md`](执行与防封/社媒内容日历执行版.md) 管每周发什么主题；[`社媒矩阵总控/01_社媒矩阵总控策略.md`](./社媒矩阵总控/01_社媒矩阵总控策略.md) 管账号架构；[`执行与防封/02_刀具内容合规红线.md`](./执行与防封/02_刀具内容合规红线.md) 管不能发什么。

## 〇、基础架构速览（新接手人必读）

- **4 品类 × 12 平台 = 48 账号**，一台手机 = 一个品类 = 一个真人负责人 = 一套洛杉矶静态住宅 IP。详见 [`社媒矩阵总控/03_48账号矩阵清单.md`](./社媒矩阵总控/03_48账号矩阵清单.md)。
- **三层账号**：L1 公司主号 KaiLionCrafts（广告主体）/ L2 品类品牌号（垂直获客）/ L3 负责人个人号（LinkedIn 信任获客）。
- **4 台手机错峰窗口**（洛杉矶 PST 时间）：
  - Phone 1 · Outdoor · Leo Li：09:00–12:00 PST（北京时间次日 01:00–04:00）
  - Phone 2 · Kitchen · Jason Li：13:00–16:00 PST（北京时间次日 05:00–08:00）
  - Phone 3 · Scissors · Owen Li：17:00–20:00 PST（北京时间次日 09:00–12:00）
  - Phone 4 · Accessories · Julia Zhong：21:00–23:00 PST（北京时间次日 13:00–15:00）

## 一、每日运营流程（Daily Routine）

> 以下为阳江（北京时间）1人统筹 4 个品类号的标准日程。若为 4 人分工，每人只负责自己手机窗口内的动作。

### 08:30–09:00 早间：巡检 + 回复（30 分钟）

- [ ] **08:30** 打开 4 台手机，依次检查每台手机上的 App 通知（按 Phone1→Phone2→Phone3→Phone4 顺序，每台 5 分钟）
- [ ] **08:35** 回复所有未读 DM / WhatsApp Business / Messenger（B2B 询盘必须在工作时间 2 小时内首响，24 小时内正式回复）
- [ ] **08:45** 回复所有评论（点赞 + 有价值的评论手写回复；负面评论按第六节危机 SOP 处理）
- [ ] **08:55** 记录昨日数据：各平台粉丝增量、爆款视频播放量、DM 询盘数（填入周日数据表）

### 09:00–10:00 上午：发布 + 互动（60 分钟）

- [ ] **09:00** 按本周内容日历，发布今天该发的内容（见第二节周排期表）
- [ ] **09:15** 发布后 15 分钟内：自己用另一个号或让同事在评论区留 1 条引导性评论（如 "What's the MOQ for this one?"），提升初始互动
- [ ] **09:20** 互动时间：在同行账号（同类刀剪/厨具/户外品牌）下点赞 10–15 个、评论 3–5 条、关注 2–3 个目标客户（采购商/品牌方/行业 KOL）
  - 单平台每日主动关注 ≤15 人、点赞 ≤30、评论 ≤5 条，超过即触发 spam 风控
- [ ] **09:45** LinkedIn 个人号（L3）花 15 分钟浏览 feed，对行业帖子做有质量的评论（不要"great post"，要写 2–3 句真实见解）

### 10:00–12:00 中午：内容创作（120 分钟）

- [ ] **10:00** 拍摄/整理素材：按本周脚本清单拍 1–2 条原始视频（工厂工艺、产品演示、装柜发货）
- [ ] **11:00** 剪辑：CapCut 粗剪 + 加字幕 + 换比例（9:16 / 1:1 / 16:9）
- [ ] **11:45** 写文案：按内容日历模板写英文 caption + 8–12 个 hashtag（见第三节）
- [ ] **12:00** 排期：把明天/后天要发的内容在各平台后台排好（不要当天临时拍当天发）

### 14:00–15:30 下午：询盘处理 + 客户跟进（90 分钟）

- [ ] **14:00** 处理 WhatsApp Business / Messenger 里的高意向询盘：报价、寄样、发目录 PDF
- [ ] **14:30** 给已读不回的沉睡客户发跟进消息（分步发：先发 1 条工厂新视频 → 2 天后再问需求）
- [ ] **15:00** 把当天询盘录入 CRM / 表格（客户名、国家、品类意向、数量、来源平台、跟进状态）
- [ ] **15:20** 处理 YouTube 评论 / 邮件咨询（Gmail/Outlook/Zoho 三邮箱）

### 15:30–16:30 下午晚些：内容二剪 + Pinterest（60 分钟）

- [ ] **15:30** 把上午剪好的母内容，按平台拆成不同版本（TikTok 9:16 / IG Reels 9:16 / YT Shorts 9:16 / LinkedIn 1:1 或 16:9 / FB 16:9）
- [ ] **16:00** Pinterest 发 3–5 个 Pin（产品图 + 信息图，Alt 用 kitchen/camping/outdoor 词，不要用 tactical/knife 直搜词）

### 21:00–21:30 晚间：数据记录 + 次日准备（30 分钟，对齐美东早高峰）

- [ ] **21:00** 发布 Facebook / LinkedIn 深度帖（美东早 9:00 = 北京 21:00，是 B2B 决策人刷 LinkedIn 的高峰）
- [ ] **21:15** 记录今日数据到周报表（粉丝增量、播放量、互动率、DM 数、询盘数）
- [ ] **21:25** 检查明天要发的内容是否已排期、文案是否合规（对照第六节红线词表）

> **养号期（前 14 天）特殊规则**：每天登录 1 次、在线 20–40 分钟，只刷同 niche 内容、点赞 5–10 个、关注 2–3 个，**不发内容、不改资料**。详见 [`执行与防封/01_养号与防封总策略.md`](./执行与防封/01_养号与防封总策略.md)。

## 二、每周运营流程（Weekly Routine）

> 标准周产出：**TikTok 4 条 + Instagram 3–4 条 + Facebook 2–3 条 + LinkedIn 1–2 条 + YouTube 1 条 = 约 12–14 条/周**。旺季（10–11 月 BFCM）TikTok/IG/FB 频率上浮 50%。

### 周一：内容策划日

- [ ] **W-Mon-1** 打开 [`社媒内容日历执行版.md`](执行与防封/社媒内容日历执行版.md)，确认本周周主题（如 1月W2 = Knife Steel Deep Dive；5月W2 = Poultry Shears Boom）
- [ ] **W-Mon-2** 列出本周 12–14 条内容清单：每条写清楚 平台 / 发布时间 / 形式 / 时长 / 脚本要点 / CTA / 落地页链接
- [ ] **W-Mon-3** 排本周拍摄清单：哪几条要去车间拍（锻造/淬火/打磨/装柜），哪几条用已有素材二剪
- [ ] **W-Mon-4** LinkedIn 长文 Post 今天 22:00 发（行业洞察，150–300 词）

### 周二–周三：拍摄 + 剪辑日

- [ ] **W-Tue-1** 去车间拍素材（手机横拍/竖拍都要拍，方便后期裁比例）；每个镜头拍 2–3 条备选
- [ ] **W-Tue-2** 必拍镜头库：锻打火光 / 淬火火花 / 砂轮磨刃 / 微距钢材纹理 / 激光雕刻 / 成品开箱 / 装柜发货 / QC 检测 / 创始人出镜讲解
- [ ] **W-Tue-3** IG Feed Carousel / 单图今天 21:00 发（5–7 张产品图或知识图文）
- [ ] **W-Wed-1** CapCut 批量剪辑：母视频 → 各平台原生版（加 0.5% 缩放、1 帧黑场、换 BGM、改 EXIF，不要机械改文件）
- [ ] **W-Wed-2** TikTok 工艺/科普短视频今天 10:00 发（45–60s）
- [ ] **W-Wed-3** 写好本周所有英文 caption + hashtag，存入内容库

### 周四：审核 + 排期日

- [ ] **W-Thu-1** 合规自检：逐条对照 [`执行与防封/02_刀具内容合规红线.md`](./执行与防封/02_刀具内容合规红线.md) 禁用词表（weapon/tactical/combat/attack/kill/self-defense/dagger 等），户外刀品类尤其严查
- [ ] **W-Thu-2** 检查画面：刀刃不能指向镜头/人；不能刺向物体（除切食物/绳子/木头）；不能与枪支同框；弹簧刀/蝴蝶刀连展示都不要
- [ ] **W-Thu-3** IG Reels 今天 15:00 发（15–30s 产品特写）
- [ ] **W-Thu-4** FB Page 帖今天 21:00 发（工厂实力/行业观点）
- [ ] **W-Thu-5** LinkedIn 短帖/文档今天 22:00 发（公司动态/展会/认证）
- [ ] **W-Thu-6** 把周五–周日要发的内容全部在各平台后台排好定时发布

### 周五：发布 + 互动日

- [ ] **W-Fri-1** TikTok 工厂幕后/装柜今天 10:00 发（30–45s）
- [ ] **W-Fri-2** YouTube 长视频 5–10min 或 Shorts 今天 20:00 发（工厂 tour / 产品评测 / 展会 vlog / 工艺全流程）
- [ ] **W-Fri-3** 主动互动：在 knife/chef/BBQ 相关 Facebook Group、Reddit subreddit 回答问题（90/10 规则，自荐内容 ≤10%，不在评论区挂链接）
- [ ] **W-Fri-4** 给本周新关注的目标客户发一条友好的问候（不要硬广）

### 周六–周日：轻量运营 + 数据记录

- [ ] **W-Sat-1** TikTok 互动/轻松内容今天 15:00 发（15–30s：投票选题、"猜钢材"、客户问答）
- [ ] **W-Sat-2** IG Story 轮播 3–5 帧今天 12:00 发，加投票贴纸（"Which handle wins? Pakkawood vs G10"）
- [ ] **W-Sat-3** 周末只做轻量互动（30 分钟）：回复评论、DM，不主动发新内容
- [ ] **W-Sun-1** Pinterest 补 5–10 个 Pin
- [ ] **W-Sun-2** 周日晚：把 4 台手机上每个账号的 Handle、Bio、已发内容截图、粉丝数、网站链接字段截图归档到云文件夹（防封备份，详见 [`执行与防封/01_养号与防封总策略.md`](./执行与防封/01_养号与防封总策略.md) 第七节）

### 周日晚：周复盘（30 分钟）

- [ ] **W-Review-1** 本周数据填表：
  - 各平台粉丝增量：TikTok ___ / IG ___ / FB ___ / LinkedIn ___ / YT ___ / Pinterest ___
  - 本周发布条数：TikTok ___ / IG ___ / FB ___ / LI ___ / YT ___
  - 爆款视频（播放 > 均值 2 倍）：哪条？为什么爆？
  - DM 询盘数：___ 条（其中高意向 ___ 条）
  - 社媒 → 独立站点击（UTM 追踪）：___ 次
- [ ] **W-Review-2** 本周哪条内容互动最好？下周复制这个方向
- [ ] **W-Review-3** 本周哪条内容被限流/掉播放？检查是否踩了合规红线
- [ ] **W-Review-4** 把复盘笔记存档，作为下周选题依据

## 三、每月运营流程（Monthly Routine）

> 每月最后一个工作日做月度复盘。

### 3.1 数据分析（第 4 周周五，2 小时）

- [ ] **M-1** 导出各平台后台数据：粉丝总量、净增、总播放、总互动率、主页访问、链接点击
- [ ] **M-2** GA4 看社媒带来的独立站流量（按 `utm_source` 拆分：tiktok / instagram / facebook / linkedin / youtube / pinterest）
- [ ] **M-3** 统计月度询盘数：从 WhatsApp/Messenger/Email/表单进来的询盘，按来源平台拆分
- [ ] **M-4** 计算关键转化率：
  - 粉丝 → 主页访问：___%
  - 主页访问 → 独立站点击：___%
  - 独立站点击 → 询盘：___%
- [ ] **M-5** 对比上月：哪个平台涨得最快？哪个平台 ROI 最高？

### 3.2 策略调整

- [ ] **M-6** 投入分配调整：把 60% 精力放在 ROI 最高的 1–2 个平台（B2B 刀剪推荐 YouTube + LinkedIn 优先）
- [ ] **M-7** 内容方向调整：数据好的内容类型加量，数据差的砍掉
- [ ] **M-8** 下月主题对齐 [`社媒内容日历执行版.md`](执行与防封/社媒内容日历执行版.md) 和 [`全年季节性营销日历.md`](./全年季节性营销日历.md)，节日提前 2–4 周备料

### 3.3 竞品监控

- [ ] **M-9** 找 3–5 个同行账号（同类刀剪工厂/品牌），记录他们本月爆款内容、粉丝增量、发布频率
- [ ] **M-10** 记录他们在哪些平台投广告（Meta Ad Library 查 FB/IG 广告）
- [ ] **M-11** 找 1–2 个可借鉴的内容形式，下月测试

### 3.4 下月内容规划

- [ ] **M-12** 列出下月每周主题（对齐内容日历）
- [ ] **M-13** 列出下月拍摄计划（哪些要去车间、哪些要拍产品特写、哪些要创始人出镜）
- [ ] **M-14** 列出下月节日/节点（情人节/母亲节/广交会/BFCM/圣诞等），提前 2 周备料
- [ ] **M-15** 更新网红/KOL 外联清单（参考 [`刀具品类网红资源地图.md`](网红营销/刀具品类网红资源地图.md)）

## 四、各平台运营要点（TikTok / Instagram / Facebook / LinkedIn / YouTube）

> 平台优先级：**第一层（核心 60% 精力）= YouTube + LinkedIn**；**第二层（25%）= Pinterest + Instagram**；**第三层（15%）= X + Facebook + TikTok**。不要全面铺开。

### 4.1 TikTok

| 项目 | 要点 |
|------|------|
| **定位** | 短视频破圈，工厂过程化展示；B2B 获客辅助 |
| **最佳发布时间（北京时间）** | 周一/三/五 10:00、周三/六 15:00（对应美东早间/午间） |
| **频率** | 每周 4 条，15–60s |
| **内容形式** | 9:16 竖屏；前 3 秒 Hook（视觉冲击：火花/慢动作切物/大字字幕提问）；字幕跟随；CTA "DM CATALOG" |
| **算法特点** | 完播率 > 点赞；前 3 秒决定生死；新号有流量扶持但前 7 天不发内容只养号 |
| **互动策略** | 发布后 15 分钟内置顶引导评论；回复每条评论；用竞品热门音频但内容自制 |
| **合规红线** | ❌ 禁投广告；❌ weapon/tactical/self-defense 词；❌ 刀刃指镜头/人；✅ 框定为 kitchen/household 锋利工具 |
| **Bio 链接** | Profile Website field（需 1000 粉以上开通）；否则放 Linktree 或引导 "DM for catalog" |

### 4.2 Instagram

| 项目 | 要点 |
|------|------|
| **定位** | 视觉品牌，产品图鉴；B2B 品牌门面 |
| **最佳发布时间** | 周二 21:00（Feed）、周四 15:00（Reels）、周六 12:00（Story） |
| **频率** | 每周 Feed 30% / Reels 40% / Story 30%，共 3–4 条 + 若干 Story |
| **内容形式** | Feed Carousel 5–7 张；Reels 15–30s；Story 轮播加投票/问答/倒计时贴纸 |
| **算法特点** | Reels 是流量主力；Story 提升粘性；账号前 7 天不改 Bio/头像 |
| **互动策略** | 每周至少 1 次投票贴纸、1 次问答贴纸；节日周用倒计时贴纸 |
| **合规红线** | 厨刀可投广告；Outdoor 不投；食品接触材料只说适用 SKU，不写全 SKU 统一认证 |
| **Bio 链接** | Profile Links 最多 5 条；每个品类号链对应品类落地页（不是首页） |

### 4.3 Facebook

| 项目 | 要点 |
|------|------|
| **定位** | 品牌证据 + WA 引流；广告投放主力（厨刀/剪刀/厨房用品可投） |
| **最佳发布时间** | 周二/四 21:00（美东早 9:00） |
| **频率** | 每周 2–4 条 Page 自然帖；旺季加广告 |
| **内容形式** | 1–3 张图，50–120 词；工厂实力/行业观点/痛点解决；在 knife/chef group 回答问题 |
| **算法特点** | 自然 reach 低，需广告放大；Group 参与比 Page 发帖有效 |
| **互动策略** | 加入 5–10 个厨师/BBQ/刀具爱好者 Group，每周回答 2–3 个问题（不硬广） |
| **合规红线** | 厨刀广告可投；Outdoor/猎刀/战术刀禁投；禁买卖撮合；禁刀指镜头/人 |
| **转化路径** | Click-to-WhatsApp 广告走 Meta BM → Ads Manager → Engagement → WhatsApp |

### 4.4 LinkedIn（B2B 主阵地）

| 项目 | 要点 |
|------|------|

| **合规红线** | 武器图禁投广告；B2B 制造/OEM 内容完全可行；个人资料必须真实姓名+可验证职位 |

- [ ] **CS-4** 内容配比自检：本周内容是否 60% 教育 + 20% 幕后 + 20% 产品？

### 5.2 脚本（拍摄前 1 天写好）

**15–30 秒快闪脚本（TikTok/Reels）：**

| 段落 | 时长 | 要求 |
|------|------|------|
| Hook | 0–3s | 视觉冲击：火花/慢动作切物/大字字幕提问（"3 mistakes when buying knives"） |
| Demo | 3–22s | 单一动作演示，无废话，字幕跟随 |
| CTA | 22–30s | Logo + "DM CATALOG" / link in bio |

**30–60 秒标准科普脚本：**

| 段落 | 时长 | 要求 |
|------|------|------|
| Hook | 0–3s | 痛点提问 |
| 知识点 1 | 3–18s | 一个要点 + 画面演示 |
| 知识点 2 | 18–35s | 第二个要点 |
| 知识点 3 | 35–50s | 第三个要点 |
| CTA | 50–60s | "We send spec sheets with every quote. DM us." |

**2 分钟+ 长视频（YouTube）：**
开场 15s 介绍主题 → 主体每段有小标题 → 最后 20s 总结 + 订阅 + 询盘链接。

## 六、危机处理 SOP（Crisis Management）

### 6.1 负面评论处理（分级）

| 级别 | 场景 | 响应时间 | 处理动作 |
|------|------|----------|----------|
| **L1 轻微** | 对产品/价格/发货的正常疑问 | 4 小时内 | 公开回复 + 引导 DM；提供事实信息（MOQ/lead time/certification） |
| **L2 中等** | 抱怨质量/发货慢/沟通差 | 2 小时内 | 公开道歉 + 立即转 DM；24 小时内给出解决方案 |
| **L3 严重** | 指控欺诈/质量问题扩散/法律威胁 | 30 分钟内 | 不公开争吵；立即转 DM；通知 Leo；保留截图证据；48 小时内书面回复 |
| **L4 危机** | 负面内容被大量转发/媒体关注 | 立即 | 停止发布新内容；启动应急群；Leo 亲自出面；24 小时内发官方声明 |

**回复模板（L1/L2）：**
```
Hi [Name], thanks for reaching out. We're sorry to hear about [issue].
We take quality very seriously — could you DM us your order number and
photos? Our QC team will resolve this within 48 hours.
```

**升级流程：**
L1 运营人自己处理 → L2 通知品类负责人 → L3 通知 Leo → L4 全团队应急。

### 6.2 账号被封 / 限流应对

- [ ] **CR-1** 发现账号被封/限流后，**不要在同一台手机、同一个 IP 下立刻重开新号**；至少换设备、换 IP、冷却 2–4 周
- [ ] **CR-2** 立即截图保存：账号 Handle、粉丝数、已发内容、违规通知
- [ ] **CR-3** 按平台申诉渠道提交申诉（见 [`执行与防封/01_养号与防封总策略.md`](./执行与防封/01_养号与防封总策略.md) 第七节）：
  - TikTok：App 内申诉；7 天内勿重复提交，间隔 10 天
  - Facebook：Help Center → "My account is disabled"；附护照/驾照 + 英文申诉信
  - Instagram：与 FB 联动申诉
  - YouTube：Studio 内申诉（三级警告制，90 天滚动清除）
- [ ] **CR-4** 申诉信用公司营业执照 + 独立站 + 强调"合法 B2B 出口企业，展示制造工艺，不推广武器"
- [ ] **CR-5** 同时把该账号粉丝导到备份账号（其他品类号 / LinkedIn 个人号 / 邮件列表）
- [ ] **CR-6** 内容迁移：把被封账号的爆款视频重新剪辑后发到其他平台账号（不要原封不动重发）

### 6.3 内容被删 / 被标记

- [ ] **CR-7** 收到内容被删/被标记通知后，先看原因（违规词？画面？版权？）
- [ ] **CR-8** 若误判（户外刀被误判暴力）：走 craftsmanship 路线申诉，强调合法户外工具制造展示
- [ ] **CR-9** 若确实违规：删除相关内容；记录违禁词；更新内容创作 checklist
- [ ] **CR-10** 同类型内容 24 小时内不要再发（避免连坐）

### 6.4 客户投诉处理

- [ ] **CR-11** 所有投诉先记录：客户名/订单号/问题/截图
- [ ] **CR-12** 质量问题：24 小时内回复 + 48 小时内给方案（补发/退款/折扣）
- [ ] **CR-13** 物流问题：提供 tracking 号 + 联系货代；不甩锅给物流
- [ ] **CR-14** 沟通问题：创始人亲自打电话/WhatsApp 跟进（B2B 信任优先）
- [ ] **CR-15** 投诉解决后 1 周回访，确认客户满意；满意客户可邀请留评价
