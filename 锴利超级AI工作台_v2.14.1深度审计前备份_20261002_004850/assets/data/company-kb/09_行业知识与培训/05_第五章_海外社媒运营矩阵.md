## 3. 方法与步骤

### 3.1 双圈流量闭环模型（P12-P13）

**外环：社媒流量矩阵（引流层）**
- 平台：Facebook / Instagram / TikTok / YouTube / Pinterest / X
- 任务：建立信任+引流，禁止直接交易
- 规则：平台严禁私留联系方式与私下报价，通过品牌短域名安全导流

**内环：独立站承接中心（转化层）**
- 全球CDN加速：洛杉矶主节点+立陶宛/新加坡缓存
- 极简移动端UI：Mobile-First排版，询盘按钮醒目
- 统一白底图：PS精修+精准参数+专业询盘表单
- 多渠道承接：Form / WhatsApp / Email无缝接入
- 结构：80% B2B批发询盘 + 20% B2C海外仓现货

### 3.2 网络基建：一机一号一IP（P5-P7, P15, P21）

**核心规则**：
- 每台设备 = 一个账号 = 一个固定出口IP
- 用静态住宅IP，对应目标市场（投美国就用美区住宅IP）
- 拔掉国内SIM卡
- 用whoer.net / ipip.net检查出口IP
- 虚拟定位/GPS、时区、语言与目标国一致
- 不频繁切换线路

**IP类型风险等级**（P7, P21）：
- 住宅IP(ISP)：最安全，首选，约$5-15/月/个
- 商业IP(Business)：中等风险
- 机房IP(Hosting)：风险最高，避免使用

**多账号管理**：指纹浏览器隔离（AdsPower、RoxyBrowser等），每个账号独立IP+独立浏览器指纹（P7）

### 3.3 养号SOP：1人4机（P9, P22-P24）

**四阶段（周期1-6个月）**：

| 阶段 | 时间 | 动作 |
|------|------|------|
| 第1周 基础建设 | 前3天只浏览点赞；完善头像封面资料；绑定邮箱手机+2FA；每天登录15-30分钟；禁止加好友发广告 | P9 |
| 第2周 轻度互动 | 每天加3-5个好友；加入2-3个行业群组；每周发2-3条生活动态；关注5-10个行业主页 | P9 |
| 第3周 内容沉淀 | 发行业价值内容（70%价值+20%生活+10%产品）；群组参与讨论；创建公共主页 | P9 |
| 第4周 商业准备 | 主页持续发布积粉丝；创建BM；低预算广告测试$5-10/天 | P9 |

**1人4机配置**（P23）：4台二手手机+4个静态住宅IP+4个独立邮箱；每日分时段刷同类目视频；4台设备账号间互发测试邮件增加社交活跃度。

### 3.6 Facebook公共主页搭建（P17）

- **命名**：公司英文名+品类+B端词（如 Yangjiang KaiLionCrafts — Kitchen Knife Factory）
- **头像/封面**：Logo（1:1，≥320px）；封面用工厂实拍/团队
- **简介**：2-3句讲清谁、做什么、服务谁；留下独立站网址
- **CTA**：Send Message / Visit Website / WhatsApp
- **开广告前门槛**：发布≥5条内容、自然赞≥20、评论≥3、运营≥14天

### 3.7 广告投放：赛马机制三阶段（P37-P38）

**第一阶段：自然流量测试**
- 发布原创图文/视频贴，观察自然播放与互动
- 验证标准：自然播放1,000~10,000且互动良好
- 禁忌：视频一发布就立刻砸钱投广告

**第二阶段：低预算加码投放**
- 对验证成功的爆款开启广告
- 预算：$10-$100低预算测试
- 目标市场：欧洲、美洲、中东
- 通过公共主页+BM安全投放

**第三阶段：放大与优化**
- 对高转化广告持续加码
- A/B测试素材与受众
- AI工具筛选优质询盘

### 3.8 Facebook广告6步实操（P45）

1. **选择广告目标**：初期用流量(Traffic)→独立站；后期切转化(Conversions)
2. **定义目标受众**：35-55岁，美国/欧洲/中东，兴趣=厨房用具/户外装备/烹饪，职位=Owner/Manager/Buyer/Procurement
3. **制作广告素材**：15-30秒工艺/测试视频+白底产品图，3-5套素材A/B测试
4. **设置预算排期**：测试期$10-20/天跑3-5天；优化期$30-50/天跑7-14天；放量期$100+/天
5. **安装像素追踪**：Facebook Pixel装独立站所有页面；标准事件PageView/ViewContent/Lead
6. **数据监测优化**：CPM/CPC/CTR/询盘成本；每周复盘一次

### 3.9 B2B广告精准获客5招（P41）

1. **文案设门槛**：用MOQ、行业术语（OEM/ODM/BSCI/HRC）过滤散户
2. **受众锁定决策人**：定向采购经理/进口商/批发商；用竞品主页截获同行客户；1%相似受众转化率是普通定向3-5倍
3. **CTWA跳转WhatsApp**：WhatsApp代替表单，转化率比表单高40%
4. **素材用工厂实拍**：2026年Meta"仙女座算法"——素材即定向，工厂实拍让系统识别B2B人群
5. **落地页表单再筛选**：增设采购等级/所属行业/大致采购量问题

### 3.10 出价与预算节奏（P43）

| 出价方式 | 适用场景 | 建议 |
|---------|---------|------|
| CPC | 引流到独立站/表单 | 新手首选 |
| CPM | 品牌曝光、再营销 | 有品牌认知后用 |
| CPA | 表单提交转化 | 需积累50+转化数据后 |
| oCPM | 智能优化转化 | 有数据积累后效果最好 |

**健康指标**：CTR 1.5%-3%正常（低于1%有问题）；CPC $0.5-$2合理（超$3需优化）；转化率5%-10%优秀。

### 3.11 AI询盘背调与客户分级（P42, P53）

**AI背调四步**：
1. 输入客户信息（姓名/公司名/邮箱）
2. AI全网检索（LinkedIn/Facebook/公司官网/注册信息）
3. 智能分析评级（公司规模/采购历史/决策人职位/预算能力）
4. 分级跟进

| 等级 | 识别特征 | 跟进策略 |
|------|---------|---------|
| A级 大买家 | 品牌商/进口商/大型批发商，公司5年+/员工50人+/年采购百万级 | 24小时内专人跟进，CEO亲自对接 |
| B级 潜力客户 | 中小型批发商/电商卖家，1-5年/员工10-50人 | 48小时内回复，发目录报价，提供样品 |
| C级 普通散客 | 个人消费者/小批量采购 | 自动化模板回复，引导B2C下单 |
| 无效询盘 | 公司信息查无此人/邮箱异常/同行 | 直接过滤，加入黑名单 |

### 3.12 YouTube视频托管与CDN加速（P34, P51-P52）

- 产品视频上传YouTube，再以代码嵌回独立站产品页
- 好处：不占独立站服务器带宽，全球CDN加速，客户看视频零卡顿
- 独立站服务器：洛杉矶主节点+立陶宛(欧洲)/新加坡(东南亚)/纽约(北美)CDN缓存
- 独立站加载慢1秒流失30%客户

### 3.13 五大合规红线（P48, P55）

1. **引流红线**：社媒评论区/私信不留电话/报价 → 引导至独立站短链接
2. **网络红线**：不用动态机房IP频繁切换 → 固定静态住宅IP一机一号
3. **代码红线**：不直接用剪映原视频上传 → CapCut海外版二次渲染
4. **账号红线**：不用个人主页跑付费广告 → BM+企业公共主页
5. **投放红线**：不一发布就砸钱 → 等自然播放1k-10k验证后再投

### 3.14 三阶段路线图（P56, P62）

**第一阶段（第1-2月）基础建设期**：独立站搭建+CDN+白底图+询盘表单；4台手机+静态住宅IP+养号；FB公共主页+BM搭建
**第二阶段（第3-4月）内容与测试期**：工厂拍素材建立素材库；剪映初剪+CapCut本地化；四平台矩阵发布；自然流量测试
**第三阶段（第5月起）放大与团队期**：FB赛马广告投放；AI审单分级跟进；招募摄影/剪辑师打造内容流水线
