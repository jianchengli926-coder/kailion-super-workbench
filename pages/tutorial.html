STEP BY STEP

① 四步上手，先出一张图

前两步是「必须做」，不做后面一定失败；第三、四步是「跑一次就会」。全程不用写代码。

1

下载安装

必做

Windows 10 及以上，安装包 10MB 级，本地原生运行，不需要浏览器。

  • 安装完双击桌面图标即可
  • 首次启动停在「工作台首页」
  • 想自己搭流程则切到「经典画布」
2

配置供应商

必做

没有算力等于没有电。这是新手失败率最高的一步。

  • 右上角菜单栏→ 供应商管理
  • 导入开发者的config配置文件，输入加密密码，即可配置供应商
  • 用哪个生成节点，就要配对应的那条线（默认开发者配置好了，直接使用即可）
3

跑出第一张图

跑一次就会

只需要两个节点。拖进画布、连上线、点运行。

  • 节点库拖入提示词节点
  • 右侧拖入Banana Pro节点
  • 把两个节点的小圆点拖在一起完成连线
  • 写提示词 → 点节点上的运行
4

把成果留下来

跑一次就会

生成完的东西不会自己消失，但要主动归档才好复用。

  • 图片自动进入素材库
  • 整套流程存进工作流库，下次直接加载
  • 重复性任务可转成定时任务

第一张图的提示词，照抄就能用

好提示词 = 主体 + 场景 + 光线 + 风格 + 画质。缺哪补哪，别只写一个词。

一只戴圆框眼镜的柴犬，坐在木质书桌前敲笔记本电脑，
暖色台灯从左前方打光，背景是洒满便签的软木板，
电影级人像摄影风格，浅景深，高清细节

对应关系：主体=柴犬 / 场景=书桌+软木板 / 光线=暖色台灯左前 / 风格=电影级人像 / 画质=高清细节。这个五段结构适用于一切出图场景。

UI TOUR

② 界面六个区域，各管一件事

第一次打开会被满屏按钮吓到。其实只有六块区域，认全了就不会迷路。

主视图切换
工作台首页 / 经典画布。工作台是「说一句话自动干活」，经典画布是「自己拖节点」。两者可随时切换，画布始终挂载不会丢数据。
左侧菜单
资源库入口：画布、节点库、工作流、素材、技能、知识库、提示词 默认显示；专家、数字人、选题、风格、角色、场景、品牌、商品 出厂默认隐藏，可在菜单的「管理」里开自定义模式勾上。
节点库
所有可拖拽的 AI 能力。出厂只显示 30 个，点顶部的「管理」打开自定义模式可放出剩余节点。按分类折叠，支持搜索。
中间画布
搭流程的地方。滚轮缩放、中键或右键拖拽平移。支持撤销重做、复制粘贴、框选多选、一键自动布局。
右侧参数面板
选中节点后在这里改参数。所有参数改动都是即时的，改完直接点运行，不需要保存。
右下 AI 助手
小锴助手。可以问「怎么配供应商」「帮我生成一条详情页工作流」，也能让它调用技能、搜索资源库、拆解并执行任务。它默认知道当前画布状态，不用手动粘贴上下文。

智能工作台的三块东西

顶部胶囊
决定下方「能力标签」显示范围。不选胶囊就显示全部能力标签。
能力标签
点一下会把「分类名：描述」直接写进输入框，当作自然语言的起点。新手最快的用法是：点标签 → 改掉里面的具体内容 → 回车。
输入框
Enter 立即运行；Shift+Enter 换行；@文件名 引用已上传文件；/技能名 调用内置技能。
历史面板
页面下方保留最近运行记录，点一下能回到当时的画布。执行完还能一键把当前工作流转成定时任务。
RECIPES

③ 小白常见工作流：照着搭就行

以下 10 组是新手最常用、最容易跑通的链路。每组都写了「链路 / 参数要点 / 常见坑」，按顺序从第 1 组往后做。

1

出一张图（最好上手的起点）

★ 最容易
提示词→Banana Pro
怎么做
拖两个节点、连一条线、写提示词、点运行。就这么点事。
参数要点
画幅比例和分辨率档位必须同属一套协议。Banana 系吃「1K/2K/4K」，GPT Image 系吃「2160x3840」这种像素串 —— 配错会被服务端按协议改回去，你会以为设置不生效。
常见坑
① 两个节点之间没连线，提示词传不过去；② 供应商管理里没配图像线路。
2

图生图 / 换风格（手上有张图，想变成别的样子）

★ 最容易
图片→Banana Pro＋提示词
怎么做
图片节点接进生成节点的图像输入口，提示词只写「要变成什么」，不要再去描述原图长什么样。
参数要点
写「改成 XX 风格，保持构图不变」比写一长串风格词有效得多。风格越短越准。
常见坑
产品图被改形。要在提示词里明确加一句：严格保持产品外形、颜色、logo 不变，只替换背景与光线。
3

电商详情页（跨境 / 国内电商最常用）

★★ 中等
图片（产品图）→详情页生成→素材库
怎么做
上传清晰的产品正面图，接进「详情页生成」。节点会反推品类、材质、人群，按品类套用详情页模块组合（首屏卖点 → 场景 → 细节 → 参数 → 服务承诺），逐屏出图。也可以先用「详情页解析」粘贴商品链接抓数据再喂过去。
参数要点
模块组合默认按品类给一套，不需要的模块直接取消勾选，别生成完再删。跨境场景要分别设「提示词语言」和「画面语言」，别把中文大字铺到英文站点。
常见坑
① 图里中文字不一定写准，上架前必须人工复核；② 多 SKU 批量前先跑 1 个验证画幅，验证完再放大，否则整批白烧钱。
4

图文笔记（小红书 / 朋友圈九宫格）

★ 最容易
图文生成（一个主题）→文案 + N 屏配图
怎么做
一个节点搞定文案和配图。内置五套平台预设：小红书图文 / 电商种草 / 朋友圈九宫格 / 公众号图文 / 抖音图文，选中后自动匹配画幅、屏数与平台写法约束。
参数要点
结构是「第 k 段正文天然对应第 k 张图」，所以屏数改了要重跑配图，否则图文对不上。单屏可以全屏编辑，改完实时写回。
常见坑
文案改了但配图没重跑 —— 这是最常见的不一致来源。改文案后统一重新生成。
5

短视频 / 漫剧（从一句灵感到成片）

★★ 中等
提示词→视频大纲→视频分镜→Seedance→视频组装
怎么做
先出大纲定结构，再用「视频分镜」把每个镜头拆成脚本 + 画面提示词，然后逐个镜头交给 Seedance 出片段，最后「视频组装」预览并导出。
参数要点
控制总时长：单镜头时长 × 镜头数 = 总时长。先跑通 1 个镜头确认风格，再整批跑。
常见坑
① 视频线路没配就点运行；② 单镜头时长超过该模型上限（多数是 5s / 10s）；③ 一次性全跑导致中途想改风格，前面的钱白花。
6

带货脚本（把一件商品编译成脚本矩阵）

★★ 中等
图片（商品图）→带货脚本→分镜提示词→Seedance
怎么做
只连一张商品图，节点会自动反推名称、描述、卖点、人群、场景；再按功能 / 效果 / 情绪 / 信任 / 差异化 / 转化六维拆解卖点并绑定证据，最后用「视频模板 × 前三秒钩子」正交枚举出多个变体。每个变体自带完整分镜：时长、景别、运镜、口播、字幕。
参数要点
变体数量先设小（比如 2~3 个），文字部分筛出满意的大纲，再拿它的提示词去出视频。
常见坑
变体开太多，逐个生成视频成本失控。策略是「先穷尽脚本，再精选生成」。
7

办公四件套（Word / Excel / PPT / HTML）

★ 最容易
提示词→Word / Excel / PPT / HTML
怎么做
四个独立节点，各自负责生成对应格式的文件。做完可以在工作区预览，也能直接下载。
参数要点
一定要说清结构和规模：「8 页 PPT，每页 3 个要点」比「做个 PPT」结果好十倍。要可编辑的 PPT 走「PPT内容 → PPT组装」这条线，能导出 PPTX 和讲稿。
常见坑
格式不对或打不开时，用文档转换节点做兼容转换（支持 DOCX / PDF / HTML / RTF / CSV / JSON / XML / TXT / MD / PPTX / XLSX / EPUB 十二种格式双向转换）。
8

一句话让 AI 干活（不想学节点就用这个）

★ 最容易
工作台输入一句话→自动建画布→自动执行
怎么做
在工作台首页输入自然语言需求，比如「生成 3 张小红书风格的九宫格图文，主题是新中式茶具」。系统会解析意图、自动搭好工作流并执行，执行完可以跳到画布看它到底搭了什么。
参数要点
需求里带上产出物 + 数量 + 风格三要素。信息不够时它会主动反问澄清（比如「要横屏还是竖屏」），这时认真回答，比它猜错重跑便宜得多。
常见坑
描述太含糊（「做几张图」），产出完全不可控。宁可多写十个字。
9

多角色出方案（需要专业视角时）

★★ 中等
提示词（主题）→专家讨论 / 专家协作
怎么做
「专家讨论」是让多位专家围绕同一主题各说各话、互相碰撞；「专家协作」是按阶段分工，各产出自己那一段。还有「数字人协作」走顺序 / 并行 / 讨论 / 混合四种模式。
参数要点
把主题和最终产出物都写清楚。只说「帮我做营销方案」，出来的一定是泛泛而谈。
常见坑
参与了太多专家导致内容冗长重复。先选 2~3 位最相关的。
10

跨境选品到上架（涉及真实外呼，务必先读）

★★★ 需前置条件
云牛顿·找品→云牛顿·批量询盘→妙手·货源采集→妙手·编辑详情→妙手·多平台发布
怎么做
这条链路在节点库里默认隐藏，需要先在节点库「管理」里打开展示。用 1688 云牛顿按文字或链接找品，拿到候选商品后批量发起询价/议价/交期询盘，再用妙手 ERP 把货源采集到公共采集箱，AI 生成标题描述图片后回写，最后一个节点发布到 TikTok / Shopee / TEMU / OZON / 美客多。
前置条件
妙手功能需要你自己的妙手开放平台 AppKey / AppSecret 并配置 IP 白名单；云牛顿需要你的 1688 采购账号完成授权。
常见坑
① 询盘是真实外呼，默认带人工确认闸门，需要你点确认才会发出去；② 按次扣点的服务（如店雷达选品榜）失败也不退点数，且系统不会自动重试，别反复点；③ 采集类操作不要把在途的真实外呼强行掐断，否则会留下孤儿任务。
NODE CATALOG

④ 节点库全景：68 个节点，出厂只显示 30 个

下面的清单与软件内节点库一一对应。带可见的是开箱就显示的；带需开启的要去节点库「管理」→ 自定义模式里勾出来。支持搜索与分类筛选。

两个关于「找不到节点」的事实

1）属于权限禁用的节点，可见性设为显示也不会出现。权限禁用优先级高于可见性设置，所以如果你在自定义模式下勾了却依然看不到，多半是这条被禁用了。

2）节点库分组里还有「分析阶段 / 策划阶段 / 执行阶段 / 优化阶段」四个分组，是给分阶段协作预留的，目前只有「优化阶段」下有数字人协作与创意灵感两个节点。上面清单把这两个归入了「协同与优化」分类，方便阅读。

WORKFLOW LIBRARY

⑤ 工作流库速查：20 个分类该挑哪个

软件自带一整套预设工作流，不需要从零搭。左侧菜单 → 工作流库 → 选中 → 加载到画布。新手建议先跑「快速入门」那一区。

先跑这 8 条（快速入门区）

图片
最简单图片生成 / 最简单图生图 / 最简单头像生成
视频
最简单视频生成
文本
一句话文案 / 最简单文章写作 / 最简单翻译
结构
最简单大纲生成

建议顺序：图片生成 → 图生图 → 一句话文案 → 视频生成。前三条各花 3 分钟，第四条开始真正理解「异步任务」是什么感觉。

分类什么时候用它

加载模板后必做三件事

① 换成自己的素材。模板里的示例提示词、示例图全部替换掉，别直接跑。

② 确认模型。点开生成节点的模型下拉，确认指向你已经配好的那一档。

③ 先小规模试跑。把数量类参数改成 1，跑通了再放大。

LIBRARIES

⑥ 资源库与素材：东西存在哪，去哪找

所有创作资产都留在本机，不上传服务器，断网也能打开软件。只有你主动调用 AI 接口时才联网。

出厂显示的库

画布、节点库、工作流、素材、技能、知识库、提示词。这七个开箱就在左侧菜单里。

默认隐藏的库

专家、数字人、选题、风格、角色、场景、品牌、商品。在菜单「管理」里打开自定义模式即可显示。

自动沉淀

生成的图片会自动存入素材库；创意灵感节点里的结果图可以一键收藏进素材库，而且会连着「实际发送的那条提示词」一起带走。

备份与迁移

设置 → 数据备份，可导出/导入资源库与画布数据，换电脑时用它搬家。

长文本怎么填

节点里只放一个点击式预览卡，点开是独立编辑器（带提示词库、语义库、模型切换、AI 优化）。这是刻意设计 —— 节点内滚动会跟画布缩放打架。

滚动不跟手？

画布的滚轮缩放优先级最高。把鼠标移到内容区内部再滚；最稳的方式是直接拖滚动条。

TROUBLESHOOTING

⑦ 报错自查 / 常见问题

90% 的「生成失败」都不是软件坏了。按下面的顺序逐条排查，绝大多数问题能自己解决。

SHORTCUTS

⑧ 快捷键（Windows 上 Ctrl，macOS 上 Cmd）

记住撤销、复制、自动布局这三个就够日常用了。

编辑

Delete / Backspace删除选中的节点或连线
Ctrl+C / Ctrl+V复制 / 粘贴节点
Ctrl+D创建选中节点的副本
Ctrl+A全选所有节点
Esc取消选择

撤销与布局

Ctrl+Z撤销上一步操作
Ctrl+Shift+Z重做
Ctrl+O自动整理节点布局

多选

Ctrl+ 单击 / Shift+ 单击添加或移除节点到选区
拖拽框选框选多个节点

画布导航

鼠标滚轮缩放画布
鼠标中键拖拽 / 右键拖拽平移画布
