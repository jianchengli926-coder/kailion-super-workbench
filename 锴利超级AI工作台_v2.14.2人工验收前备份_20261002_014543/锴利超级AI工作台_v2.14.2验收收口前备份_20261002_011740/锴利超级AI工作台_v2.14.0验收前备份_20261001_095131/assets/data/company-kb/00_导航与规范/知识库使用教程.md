> 本教程面向两类读者：①**第一次打开知识库的人**（3 分钟上手）；②**要把知识库接到 Dify / Cursor / 自研工作台的 AI 工程师**（照着配就能跑）。

## 一、快速入门（3 分钟了解）

### 1.1 这是什么

`公司知识库/` 是 KaiLionCrafts（阳江市锴利国际贸易有限公司）从 33 个核心文件夹、20 万+ 原始资料中提炼出的 **AI 可读版业务中枢**。历经 v2.0 → v3.6 共九轮建设，当前规模：

| 指标 | 数值 |
|------|------|
| Markdown 文件 | **292 个**（+1 个可折叠 HTML 思维导图） |
| 一级分类 | **12 个**（00–11）+ 1 个原始资料索引区（99） |
| 覆盖市场 | **45 个国家 / 地区** |
| 产品 SKU | **204 个** 全量参数（厨刀 46+套装 35 / 剪刀 26 / 户外 77 / 厨房用品 20） |
| SEO 关键词 | **903 个**（厨刀 372 / 户外 367 / 剪刀 135 / 厨房用品 29） |
| 产品 FAQ | **103 条**英文标准答案 |
| 对外 PDF | 5 份（产品目录 / Lite 版 / Company Profile / 证书合集 / 证书 Clean 版） |

### 3.2 Dify 接入（推荐生产环境）

**步骤：**

1. **创建知识库** → 导入已有文本 → 批量上传 `公司知识库/` 下所有 `.md`（约 292 个）。
2. **分块策略**：
   - 通用默认：**分段 500 tokens，重叠 50 tokens**。
   - 邮件模板：单封为一块，重叠 0%。
   - 国家指南：按国家切分，600–800 tokens。
   - SKU 参数表：300–500 tokens，按产品组分块。
   - 术语库：200–300 tokens，按术语组分块。
3. **Embedding 模型**：双语内容用 **`bge-m3`**（多语言，1024 维）；纯中文用 `bge-large-zh`；纯英文用 `text-embedding-3-small`。
4. **元数据**：把 YAML frontmatter 的 `title / category / subcategory / tags / region / type / status` 全部解析为元数据字段，启用 metadata filtering。
5. **混合检索**：BM25（关键词）+ 向量（Embedding），权重 **50:50**。
6. **重排模型**：`rerank-multilingual-v3.0`（Cohere），**top_k=8，score_threshold=0.5**，最终取 Top-5 注入上下文。
7. **LLM 选择**：
   - 日常起草/翻译：本地 `qwen2.5:7b`（temperature 0.08–0.1，max_tokens 2048–4096）。
   - 复杂商务写作：`glm-4.6` / DeepSeek / Claude。
8. **🚫 隔离**：`10_项目路演与政府材料/` 和 `11_订单与财务/` **单独建私有 dataset**，不与面向客户的问答工作流挂接。

## 四、常用检索路径和关键词

### 4.1 通用检索三步法

```
第 1 步：先查索引（00_README 第七节"快速链接" + 04_多级分类体系.md）
   ↓
第 2 步：再查分类（按任务路由到 02/03/04/05/06/07 对应一级目录）
   ↓
第 3 步：最后查具体文件（目录内 `00_总览` → `02_索引` → `04_参数表`）
```

### 4.2 按场景的检索关键词建议

| 想做什么 | 在 RAG 中输入这些词 |
|----------|---------------------|
| 写德国客户开发信 | `Germany importer development email Yangjiang LFGB chef knife` |
| 客户问 440C 钢材 | `440C stainless steel HRC edge retention outdoor knife FAQ` |
| 算 FOB 报价 | `FOB price MOQ tier kitchen knife 500 pieces Yangjiang` |
| 户外刀能不能发德州 | `Texas knife import law switchblade fixed blade federal 19 CFR` |
| 写 TikTok 脚本 | `TikTok hook kitchen knife cooking viral script` |
| 给产品页写 Title | `RankMath focus keyword SEO title meta description kitchen knife` |
| 海外仓现货 | `US warehouse ready stock 1-3 day delivery kitchen outdoor` |
| 客户要资料包 | `company profile product catalog certifications FDA LFGB package` |
| 被压价怎么回 | `negotiation price objection B2B knife buyer response` |
| 新人培训 | `Yangjiang knife industry history steel grade training onboarding` |

### 4.3 高效检索技巧

1. **先按 `region` 元数据过滤**：开发德国客户先过滤 `region=欧洲`，再做向量检索。
2. **查询改写**：用户输入"客户要报价"先经 LLM 改写为 `"quotation PI payment terms FOB CIF MOQ tier price"` 再检索。
3. **不要一次问太泛**：把"帮我做营销"拆成"TikTok 厨刀脚本"、"LinkedIn B2B 文章"、"FB 广告素材"三次独立检索。
4. **命中 0 结果时**：去掉修饰词，用更短的核心词（如"厨房刀不锈钢厨师刀"→"chef knife"）。
5. **结果矛盾时**：按权威优先级裁决（见 5.2）。

## 五、维护更新

> 完整规范见 [`07_知识库维护与更新规范.md`](./07_知识库维护与更新规范.md)。本节为操作摘要。

### 5.1 新增资料 6 步 SOP

```
① 分类判定 → ② 通读原文 → ③ 提炼要点 → ④ 生成 .md → ⑤ 更新索引 → ⑥ 更新映射表
```

| 步骤 | 动作 | 要点 |
|------|------|------|
| ① 分类 | 对照 [`04_多级分类体系.md`](./04_多级分类体系.md) | 拿不准时按"它最常被哪个业务场景调用"归类；**禁止另起无主题新目录** |
| ② 读取 | 完整通读原文 | PDF/xlsx 先转文本；原图走图片描述库 |
| ③ 提炼 | 只留"AI 能直接调用"的结构化知识 | 砍寒暄/过程稿；保留结论、参数、阈值、SKU 号、认证名、日期 |
| ④ 生成文件 | 命名 `两位数字_主题.md`，写 YAML 7 必填字段 | 落到对应二级目录；正文用表格/清单，不要大段散文 |
| ⑤ 更新索引 | 同步三处导航 | (a) `00_README` 第七节快速链接追加；(b) 新增 SKU 同步品类总览+SKU 索引；(c) 结构性增删更新 [`04_多级分类体系.md`](./04_多级分类体系.md) 和思维导图 HTML |
| ⑥ 更新映射表 | 在 [`../99_原始资料索引与映射/02_原始资料→知识库映射表.md`](../99_原始资料索引与映射/02_原始资料→知识库映射表.md) 追加一行 | 记录：原始文件 → 新知识库文件 → 一句话说明。**无此步 = 资料等于没入库** |

> ⏱️ 常规资料 24 小时内走完 6 步；影响对外报价/发货/合规的资料（新认证、新法规、新价格）**当天处理**并在文件顶部标 `🚨 紧急：生效日期 YYYY-MM-DD`。

### 5.2 版本冲突处理

两个文件说法不一致时，按此优先级裁决（不要各说各话）：

### 5.3 定期审计周期

| 周期 | 时间点 | 审计内容 |
|------|--------|----------|
| **月度（轻量）** | 每月最后一个周日 | 新增/修改文件 YAML 齐全性、死链、draft 超 30 天文件 |

### 5.4 废弃内容处理（不删除）

## 六、使用红线（必须遵守）

1. **AI 只出草稿，人做决策**：发邮件/上架/社媒发帖/报价/样品单，AI 只生成草稿，Leo 人工确认后执行。
2. **敏感信息不对外**：统一社会信用代码、法人/创始人手机号、股权比例、财务预测、BSCI C 评级、客户订单数据——不得出现在任何对外输出。
3. **禁止编造**：客户名、成交记录、认证编号、SKU 参数——知识库没有的写"待 Leo 确认"，不要猜。
4. **户外刀合规**：不推自动刀/OTF/蝴蝶刀/Zombie/品牌仿款（Gerber/SOG/Microtech），即使目标国法律允许。
5. **对外称呼工厂**：用 "We hold equity in 4 specialized family factories"，不说 "our own factory"。
