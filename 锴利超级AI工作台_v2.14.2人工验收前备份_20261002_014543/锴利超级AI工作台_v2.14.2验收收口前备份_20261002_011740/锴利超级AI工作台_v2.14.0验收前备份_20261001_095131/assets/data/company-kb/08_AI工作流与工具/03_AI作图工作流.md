## 三、关键设计模式（整合地基）

### 3.1 技能库是数据不是代码（Claude 工作台）
```js
{id:"hero_main", name:"高端商品主图", need_image:true,
 template:"保持{product}的外形、材质、颜色和logo完全不变，背景为{background}，光线为{lighting}…",
 vars:{ product:{type:"text",default:"厨房刀具"},
        background:{type:"select",options:["纯白背景","浅灰渐变","深色大理石台面"]},
        lighting:{type:"select",options:["柔和棚拍光","侧逆光突出刀刃反光"]} }}
```
加技能 = 加一个 JSON 对象，不改渲染逻辑；`{变量}` + `type:text|select` 让非技术用户产出专业提示词。

### 3.2 模型能力位分流
```js
doubao:    { base_url:"https://ark.cn-beijing.volces.com/api/v3", model:"doubao-seedream-4-0-250828",
             supports_image_input:true, supports_sequential:true }   // 豆包一次出多图
gpt_relay: { base_url:"https://中转域名/v1", model:"gpt-image-1", supports_sequential:false }
vision:    { base_url:"http://127.0.0.1:8000/v1", model:"Qwen/Qwen2.5-VL-7B-Instruct" }
```
用 `supports_sequential` 能力位分流，而非 if 模型名硬编码。

### 3.3 其他精华
- **两阶段「规划→批量出图」**：先生成画面指令规划可编辑，再批量执行，避免一次批量出 6 张废图烧钱。
- **canvas 本地工具箱**：卷积/尺寸标注/加文字/撤销重做，本地处理不耗 API。
- **图片压缩** `shrinkDataURL(dataURL, 1600, 0.9)`：上传前压到 1600px 防接口超时。
- **IndexedDB 存图**（不进 localStorage）+ 资产库跨页选取。
- **两段式风格基因解析**（智谱）：第一段视觉模型输出结构化风格基因（构图/配色/版式/光影），第二段拼进生成指令；三档复刻强度（高度复刻/构图复刻/配色复刻）。
- **安全模型**（GPT 工作台）：浏览器只存 provider 选择，真 Key 在服务端环境变量。

## 七、注意事项（优先级铁律）

**真实素材 > 已确认素材处理 > AI 生成素材。**

- AI 不得虚构工厂/生产线/客户/认证/产品参数/材料/工艺/海外仓/现场人物。
- 产品图命名遵循三模式分流（product-image / hero-banner / factory-image）。
- 白底主图优先（无文字），信息图副图配套；电商工具建议浅底/白底以真实判断商品颜色。
- 整合时分别提取原型的信息架构与真应用的调用链路，不混用。

## 八、产品图生成提示词模板（v3.4 深化）

> 以下模板来自 Claude 工作台 SKILLS JSON 结构 + 智谱工作台场景提示词 + 文心一言 14 项功能地图。

### 8.1 白底主图（Amazon 图1 / WooCommerce 主图）

```
纯白色背景电商主图，商品居中，柔和影棚布光，轻微地面阴影，
高清商业产品摄影，突出商品细节与质感。
保持{product}的外形、材质、颜色和logo完全不变。
```

变量：
- `product`：产品名（如 "8-inch chef knife with pakkawood handle"）
- `background`：纯白背景 / 浅灰渐变 / 深色大理石台面
- `lighting`：柔和棚拍光 / 侧逆光突出刀刃反光

### 8.2 场景图（Instagram / 社媒 / 独立站 Banner）

```
{scene_setting}，{product}放在前景，自然光线，浅景深，
生活方式摄影风格，高清，8K。
```

场景预设（来自 DeepSeek 18 个电商场景库）：
- 北欧厨房台面（木质砧板 + 窗边自然光）
- 专业厨师操作台（不锈钢台面 + 铜锅背景虚化）
- 户外露营桌面（篝火/野餐布 + 暖色调）
- 礼盒开箱场景（丝带 + 木纹桌面 + 顶光）

### 8.3 信息图副图（Amazon A+ / 五点配图）

```
{product}产品信息图，{feature_callout}文字排版在右侧，
浅灰背景，专业电商设计，清晰无歧义。
```

约束：最多 2 个字体族、3 个字重；文字用 FontTools 审计 + Fabric.js 排版。

### 8.4 风格基因复刻（智谱两段式）

**第一段：视觉模型分析参考图**
```
分析这张电商爆款图的：构图 / 主体位置、占比、留白 /
配色方案（主色、辅色、对比度）/ 版式结构（文字层级、装饰元素布局）/
视觉风格调性 / 光影处理。用简洁中文列出。
```

**第二段：拼入生成指令**
```
严格复刻以下风格基因重新构图。要求：商品主体形态、品牌标识完全不变；
重构背景、版式、光影；预留卖点文案排版空间。
```

三档复刻强度：高度复刻（构图+配色+版式几乎一致）/ 构图复刻（借鉴布局）/ 配色复刻（只迁色调）。

### 8.5 三段式工作流（codex 工作台产品洞察）

> "先填事实 → 再选构图 → 生成 Prompt → 再调用图片模型"

让用户填结构化事实（产品名/真实卖点/使用场景/视觉风格/画面语言/目标渠道），再让模型组织成提示词。
