# 订单全流程 SOP（从询盘到售后）

> 团队 4 人：**Leo / Jason / Owen / Julia**。订单按"负责人"区分。
> 状态机：`询价 → 报价 → 确认 → 生产 → 出运 → 完成`

---

## 全流程总览

```
① 询盘 Inquiry
   ↓ 1 个工作日内首响
② 报价 Quotation（Proforma Invoice）
   ↓ 客户确认 + 签回 PI
③ 订单确认 Order Confirmation（收 30% 定金）
   ↓ 定金到账 + 规格书面批准
④ 采购下单 Purchase Order（向关联工厂）
   ↓
⑤ 生产 Production & In-Line QC（每日更新）
   ↓ 样品 10–15 天 / 大货 30–45 天
⑥ 包装贴标 Packaging & Labelling
   ↓
⑦ 出货前验货 Pre-Shipment Inspection（视频确认）
   ↓ 客户书面批准 + 收 70% 尾款
⑧ 出口报关 Export & Logistics（单证齐全）
   ↓ 海运 20–35 天 / 海外仓 1–3 天
⑨ 交付 Delivery & 售后 After-Sales
```

---

## 节点 ①：询盘 Inquiry

| 项目 | 内容 |
|------|------|
| **触发来源** | 独立站 RFQ / Fluent Forms 询盘表单 / WhatsApp / 邮件 / 社媒私信 |
| **标准操作** | 1. 接收询盘，记录客户公司名、国家、需求产品、数量<br>2. 判断客户等级（ABCD 分级）<br>3. 1 个工作日内首次响应（确认收到 + 初步需求澄清） |
| **时间标准** | **1 个工作日内**首次响应 |
| **责任人** | Leo / 值班销售 |
| **输出物** | 询盘登记（客户名、国家、产品、数量、来源渠道） |
| **注意事项** | 用报价反筛法（3 反问）过滤比价党；A 类客户 24h 内必回 |

---

## 节点 ②：报价 Quotation

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 确认客户需求（产品规格、数量、定制要求、目的港）<br>2. 核算成本（产品成本 + 国内费用 + 运费 + 利润）<br>3. 出具 PI（Proforma Invoice）PDF<br>4. 邮件发送 PI + 产品图/规格表/认证资料 |
| **时间标准** | 确认需求后 **1–2 天**出 PI |
| **责任人** | Leo |
| **输出物** | PI 形式发票（含产品/数量/单价/总额/付款条款/交货期/银行信息） |
| **注意事项** | 报价有效期 15–30 天；按客户等级差异化定价；分项报价显透明 |

---

## 节点 ③：订单确认 Order Confirmation

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 客户签回 PI（邮件回复确认）<br>2. 客户支付 30% 定金<br>3. 确认规格书面批准（产品图/材质/包装/Logo 稿确认）<br>4. 工作台新建销售订单（order_no 自动 KL-2026-001） |
| **时间标准** | 收到定金 + 规格批准后当天 |
| **责任人** | Leo |
| **输出物** | 签回的 PI + 定金到账凭证 + 销售订单记录 |
| **铁律** | **收到 30% 定金 + 规格书面批准**才开工生产，缺一不可 |
| **工作台状态** | 询价 → 报价 → **确认** |

---

## 节点 ④：采购下单 Purchase Order

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 根据销售订单需求，向对应家族工厂/合作工厂下采购 PO<br>2. 确认工厂交期、价格、QC 标准<br>3. 工作台新建采购订单（po_no，关联销售订单号） |
| **时间标准** | 收定金后 **1–2 个工作日**内下 PO |
| **责任人** | Leo + 工厂对接人 |
| **输出物** | 工厂采购 PO + 工作台采购订单记录 |
| **对应工厂** | Amber（厨刀/大马士革）、YeYu（amfori BSCI）、Homeful（FSC）、Keenhope 铿浩（大马士革/RoHS）等 36 家 |
| **工作台状态** | 确认 → **生产** |

---

## 节点 ⑤：生产 Production & In-Line QC

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 工厂按订单生产（8 步流程：冲压→焊接→抛光→研磨→质检→激光打标→清洗→包装）<br>2. **来料检验**（钢材/材料核对，不合格 100% 拒收）<br>3. **过程检验**（HRC 硬度/尺寸/外观巡检）<br>4. 每日向客户发送生产更新（照片/视频） |
| **时间标准** | 样品 **10–15 天** / 大货 **30–45 天**（轻定制约 15 天） |
| **责任人** | Leo + 工厂 QC |
| **输出物** | 生产日报（照片/视频）+ 过程检验记录 |
| **QC 节点** | ① 来料检验（工厂 QC）<br>② 过程检验（HRC 硬度/尺寸/外观，Leo + 工厂） |
| **注意事项** | Leo 几小时内可到现场（30 分钟供应链半径）；每日生产更新 |

---

## 节点 ⑥：包装贴标 Packaging & Labelling

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 按客户要求贴标、包装（Logo/条码/说明书）<br>2. 核对外箱唛头（Shipping Mark）<br>3. 清点数量、称重、量尺寸 |
| **时间标准** | 生产完成后 **1–2 天** |
| **责任人** | 工厂 |
| **输出物** | 包装好的成品 + 装箱单草稿（件数/重量/体积） |
| **注意事项** | 核对客户指定的包装方式、标签语言、说明书版本 |

---

## 节点 ⑦：出货前验货 Pre-Shipment Inspection

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 拍摄验货视频/照片（产品外观/功能/包装/数量）<br>2. 发送视频给客户书面确认<br>3. 客户书面批准后，通知客户付 70% 尾款<br>4. 收到尾款 → Leo 本人签字放行 |
| **时间标准** | 出货前 **2–3 天** |
| **责任人** | **Leo 本人签字** |
| **输出物** | 验货视频/照片 + 客户书面确认 + 尾款到账凭证 |
| **铁律** | **视频验货 + 客户书面批准 + 尾款到账**，三者齐备才放货 |
| **工作台状态** | 生产 → **出运** |

---

## 节点 ⑧：出口报关 Export & Logistics

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 准备全套单证（商业发票/装箱单/合同/报关单）<br>2. 刀具 PSB 公安局备案<br>3. 报关行申报海关<br>4. 海关放行 / 装船 / 装机<br>5. 寄送正本单证或电放提单 |
| **时间标准** | 尾款到账后 **3–5 天**内完成报关出运 |
| **责任人** | Leo |
| **输出物** | 提单 B/L + 商业发票 + 装箱单 + 原产地证 COO + 合规证书 |
| **物流时效** | 海运 20–35 天 / 空运 7–15 天 / 快递 3–7 天 / 海外仓 1–3 天 |
| **注意事项** | Every Document, Every Time, Zero Delays |

---

## 节点 ⑨：交付 Delivery & 售后 After-Sales

| 项目 | 内容 |
|------|------|
| **标准操作** | 1. 货物到港/到门，客户签收<br>2. 跟进客户收货反馈<br>3. 如有质量问题，启动售后/索赔流程<br>4. 工作台订单状态改为"完成" |
| **时间标准** | 海运到港后跟进；售后 **24h 内响应** |
| **责任人** | Leo |
| **输出物** | 客户签收确认 + 售后记录 |
| **质保体系** | 终身质保（材料/工艺缺陷）/ 10 年刃口保持 / 2 年装配 / 整批不合格 100% 退换 |
| **工作台状态** | 出运 → **完成** |

## 关键节点铁律（不可逾越）

1. ✅ 收到 **30% 定金 + 规格书面批准** 才开工。
2. ✅ 出货前必须 **视频验货 + 客户书面批准**。
3. ✅ 收到 **70% 尾款** 才放货 / 放提单。
4. ✅ 每批出货 **Leo 本人签字放行**。
5. ✅ 所有收付款在工作台 payments 表登记。
