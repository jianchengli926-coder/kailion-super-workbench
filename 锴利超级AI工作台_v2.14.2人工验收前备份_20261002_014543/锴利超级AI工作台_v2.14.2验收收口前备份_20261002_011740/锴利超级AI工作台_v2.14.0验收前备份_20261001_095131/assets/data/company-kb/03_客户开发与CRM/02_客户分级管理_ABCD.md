# 客户分级管理（ABCD分级标准）

> 核心逻辑：**20%客户贡献80%利润**。A类客户5%-15%贡献60%-80%利润。
> 目的：把有限精力集中在高价值客户上，差异化跟进。

---

## 一、ABCD分级总表

| 等级 | 定义 | 数量占比 | 利润贡献 | 年采购额参考 |
|---|---|---|---|---|
| **A类（核心/KA）** | 已稳定下单、复购强、金额大、付款靠谱；或高意向+高匹配+高紧迫 | 5%-15% | 60%-80% | 年订单≥50万美元 |
| **B类（潜在/成长）** | 有需求但不急、信息不全、正在比价；回复慢但不完全失联 | 20%-30% | 15%-30% | 年订单10-50万美元 |
| **C类（一次性/低意向）** | 一次性询盘、无具体规格、未索样、信息模糊 | 50%+ | <5% | 年订单<10万美元 |
| **D类（无效/风险）** | 索要免费样品不留真实公司、价格离谱、付款条件苛刻、骗子嫌疑 | — | — | 无 |

## 二、各级客户详细特征

### A类客户（核心/KA）特征
- **已下单客户**：复购2次以上，订单金额稳定，付款准时
- **高意向新客户**：
  - 有具体图纸/技术参数
  - 主动问交期、认证、付款条款
  - 问"你们工厂在哪里""能不能验厂"
  - 索要样品后主动反馈
- **公司规模**：进口商、品牌商、大型连锁零售商
- **关注点**：稳定供货、一致性、认证齐全、验厂、独家代理、OEM/ODM
- **决策链**：长，多部门（采购+QC+管理层）

### B类客户（潜在/成长）特征
- 有需求但不急，说"please send catalog and price list"
- 正在比价中，同时联系多家供应商
- 回复邮件但很慢（3-5天回一次）
- 有具体品类兴趣但无明确数量
- 样品已寄但未确认反馈
- **转化潜力**：培育3-6个月可升A类

### C类客户（一次性/低意向）特征
- 群发询盘，无具体规格
- 只问"what's your best price"
- 不留真实公司名和网站
- 要免费样品不留收件信息
- 问完价就消失

### D类客户（无效/风险）特征
- 价格离谱（比市场价低50%以上）
- 要求100% OA赊销
- 域名注册<1年，无真实办公地址
- 索要大量免费样品不付运费
- 邮件语法怪异、附件可疑
- 疑似骗子/洗钱/诈骗

## 三、差异化跟进策略

### A类客户（24小时响应）
| 维度 | 策略 |
|---|---|
| 响应时间 | **24小时内必回**，紧急问题4小时内 |
| 跟进频率 | 每周至少1次主动沟通；节假日/季前主动问候 |
| 服务配置 | 最强业务员一对一；老板亲自盯；定期视频会议 |
| 报价方式 | 年度框架价 + 阶梯价；强调TCO（总成本） |
| 样品 | 付费样品 + 正式样品单；附完整检测报告 |
| 付款 | T/T 30%定金+70%见提单副本；信用极好可谈L/C |
| 资料包 | 公司PPT + 工厂视频 + BSCI/Sedex报告 + FDA/LFGB证书 + 产能表 |
| 关系维护 | 节日祝福、新品优先通知、年度回访、展会面谈 |

### B类客户（5-7天跟进）
| 维度 | 策略 |
|---|---|
| 响应时间 | 48小时内回复 |
| 跟进频率 | **每5-7天联系一次**；定期给新信息/案例 |
| 服务配置 | 标准化跟进流程；业务员轮值 |
| 报价方式 | FOB单价 + MOQ；给阶梯价引导加量 |
| 样品 | 低价/样品费可抵大货；快速寄样 |
| 付款 | T/T定金+尾款；不轻易给OA |
| 资料包 | 产品目录 + 报价单 + 主营品类认证 |
| 培育目标 | 3-6个月内升级为A类；定期推送新品/案例/行业资讯 |

### C类客户（季度维护）
| 维度 | 策略 |
|---|---|
| 响应时间 | 可2-3天回 |
| 跟进频率 | **季度触达一次**；邮件列表群发维护 |
| 服务配置 | 最低成本维护；自动邮件序列 |
| 报价方式 | 标准报价表群发；不单独定制 |
| 样品 | 不主动免费寄样 |
| 资料包 | 通用产品目录PDF |
| 转化触发 | 客户主动回复升级为B类后再重点跟进 |

### D类客户（放弃/最低维护）
| 维度 | 策略 |
|---|---|
| 响应时间 | 不主动跟进 |
| 跟进频率 | 不跟进 |
| 服务配置 | 放弃或最低成本维护 |
| 风险控制 | 不发任何敏感资料；不寄免费样品；不接受任何高风险付款条款 |
| 触发升级 | 仅在客户主动提供真实公司信息+大额订单意向时重新评估 |

## 四、客户升降级机制

### 升级触发条件
- **C→B**：客户主动回复并询问具体产品/价格/样品
- **B→A**：客户下首单 ≥10万美元，或连续2次复购
- **A→B**：连续6个月无订单，且回复率显著下降

### 降级触发条件
- **A→B**：连续3个月无新订单；延迟付款超过2次
- **B→C**：连续2个月无回复；样品后无反馈
- **C→D**：发现骗子特征（可疑邮件/附件/价格离谱）

### 定期评审
- **每月**：业务主管评审A类客户状态
- **每季度**：全员评审B/C类客户升降级
- **每年**：全面梳理客户档案，更新分级

## 五、KaiLionCrafts客户分级实操要点

1. **五金刀剪行业特点**：
   - 欧美品牌商/进口商 → 目标A类（年采购额大、复购稳）
   - 亚马逊大卖/独立站品牌 → 目标A/B类（量中等但稳定）
   - 小批发商/新店 → B/C类（小批量试单起步）
2. **初判快速法**：收到询盘后先看：
   - 有没有具体产品型号？→ 有=B类以上
   - 有没有问交期/认证/MOQ？→ 有=A类潜力
   - 只问"price list"？→ C类
3. **A类客户老板亲自盯**：作为创业公司，前10个A类客户必须创始人Leo亲自对接
