# 客户跟进记录表模板（CRM Follow-up Log）

> **使用说明**：每跟进一次客户，在表中追加一行。所有字段用英文填写（B2B外贸场景），本表为可直接复制到 Excel / 飞书多维表格 / CRM 系统的标准格式。
> 字段顺序固定：Customer → Country → Category → Status → Hotness → Last Follow-up → Next Follow-up → Notes → Next Action。

---

## 二、字段定义（Field Definitions）

| Field 字段 | Type | 是否必填 | 填写规范 |
|---|---|---|---|
| **Customer Name** | Text | 必填 | 客户公司法定全称，不写简称；个人采购写联系人+公司 |
| **Country** | Text | 必填 | 英文国家名（Germany / United States / Australia…），用标准名 |
| **Category / Product** | Text | 必填 | 客户当前关注的品类/SKU，如 "Kitchen Shears, PEELER-01" |
| **Status** | Enum | 必填 | 见下方状态定义表，**只能选固定枚举值** |
| **Hotness** | Enum | 必填 | `Hot` / `Warm` / `Cold` / `Dead`，见下文 |
| **Last Follow-up** | Date | 必填 | 最近一次沟通日期，格式 `YYYY-MM-DD` |
| **Next Follow-up** | Date | 必填 | 下次计划跟进日期，格式 `YYYY-MM-DD`，CRM据此提醒 |
| **Follow-up Notes** | Text | 必填 | 本次沟通要点、客户反馈、异议（英文简要记录） |
| **Next Action** | Text | 必填 | 下一步具体动作+负责人+deadline，如 "Send sample PI by 09-30" |

### Hotness 热力度定义
| Value | 含义 | 跟进节奏 |
|---|---|---|
| **Hot** | 有明确需求+预算+时间计划，1个月内有望成交 | 每周跟 |
| **Warm** | 有兴趣但不急/在比价，3个月内可能成交 | 每两周跟 |
| **Cold** | 回复慢/信息模糊/仅索取目录 | 每月跟 |
| **Dead** | 连续30+天无回复或明确无需求 | 转Win-back序列（见《18_客户流失预警与挽回》） |

## 三、跟进状态定义（Status Pipeline Stages）

**中文说明**：客户在任何时刻必须落在且仅落在一个状态上。状态即销售漏斗阶段，用于统计转化率。

| Status 状态 | 英文定义 | 进入条件 | 下一步 |
|---|---|---|---|
| **New Inquiry** | 新询盘刚到，尚未回复 | 收到独立站/B2B平台/邮件询盘 | 24h内首回并需求确认 |
| **Replied** | 已首次回复，等待客户回应 | 发出第一封回复 | 按响应时效二次跟进 |
| **Quoted** | 已发正式报价单 | 发出PI/Quotation | 跟进报价反馈 |
| **Sampled** | 已寄样，等待样品测试反馈 | 样品寄出/签收 | 样品送达后3天问反馈 |
| **Negotiating** | 价格/条款谈判中 | 客户还价或提异议 | 按谈判话术推进 |
| **Won / Closed-Won** | 已成交，定金到账 | 收到deposit | 转订单流程+复购培育 |
| **Dormant** | 沉睡：曾沟通但90天+无订单无回复 | 超过一个季度无动静 | 唤醒邮件序列 |
| **Lost / Closed-Lost** | 已流失：选了竞品或明确放弃 | 客户明确拒绝/转竞品 | 录入流失原因，进Win-back |

> **状态流转规则**：Won 之后若再次询价，重新进入 Replied / Quoted，不计入新线索；Lost 客户90天后可重新激活为 New Inquiry。

## 四、单次跟进记录卡（Per-Contact Log）

**中文说明**：每个客户每次沟通，除了主表一行，重要客户另存以下记录卡，便于复盘。

```
[Contact Log]
Customer: ___________________________
Date: _______________________________
Channel:  [ ] Email  [ ] WhatsApp  [ ] Call  [ ] Zoom  [ ] Trade Show

1. What the customer said / asked:
   ______________________________________________________________

2. What we promised / sent:
   ______________________________________________________________

3. Open issues / objections:
   ______________________________________________________________

4. Hotness change:  [ ] Hot  [ ] Warm  [ ] Cold  [ ] Dead
   Status change:   New Inquiry / Replied / Quoted / Sampled / Negotiating / Won / Dormant / Lost

5. Next action & deadline:
   ______________________________________________________________
```

## 五、使用纪律

1. **每次沟通当天**必须更新 Last Follow-up 和 Next Follow-up，不允许"记在脑子里"。
2. Next Follow-up 到期当天必须动作，否则 Hotness 自动降一档。
3. 每周一上午花15分钟过一遍 Next Follow-up = 本周日期的客户清单。
4. 状态只能用枚举值，禁止自由发挥同义词（如 "waiting" "pending" 统一归 Dormant/Negotiating）。
