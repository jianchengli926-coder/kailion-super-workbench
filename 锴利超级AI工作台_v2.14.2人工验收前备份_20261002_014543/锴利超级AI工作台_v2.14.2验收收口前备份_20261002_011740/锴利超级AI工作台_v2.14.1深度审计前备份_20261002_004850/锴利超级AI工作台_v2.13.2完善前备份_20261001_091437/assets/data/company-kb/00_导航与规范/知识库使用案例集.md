# 知识库使用案例集

> **用途**：给AI工作台使用者（Leo/新员工/AI工程师）展示"遇到具体业务问题时，AI应该查哪些文件、怎么串起来、输出什么"。
> **读法**：每个案例都是一个完整的业务动作——从客户/用户的问题出发，看AI如何在292个知识库文件中精准定位、提取、组合，输出可直接使用的业务结果。
> **所有文件路径均为真实存在路径**，可直接点开验证。

## 案例1：开发一个美国户外刀批发商

### 场景描述

> Leo在LinkedIn上找到一家美国户外用品批发商——"OutdoorGear USA"（假设名），总部在丹佛，年采购额估计$200万-$500万，主营户外刀、露营工具。Leo需要在30分钟内完成：客户背调报告 + 定制开发信 + 初步报价区间 + 美国仓现货推荐。

### AI提取了什么关键信息

1. **国家层面**：
   - 美国西部最佳发信时间=北京时间00:00-09:00（定时发送，不用熬夜）
   - 美国客户效率至上、24小时必回、直来直去
   - FDA 21 CFR食品接触合规、加州Prop65警告
   - 🚨 **红线**：自动刀/弹簧刀（switchblade/auto knife）有法律限制，只推手动折刀和固定刃

2. **客户画像**：匹配Persona 2（Wholesaler批发商）——阶梯价、现货、混批灵活；直接发年度框架价表

3. **产品匹配**：从户外刀77个SKU中筛选——推荐固定直刀和手动折刀（不碰自动刀），钢材8Cr13MoV/9Cr18MoV，B2B价$15-50区间

4. **报价区间**：FOB公式 = EXW + 国内运费 + 报关 + 港杂；批发商给阶梯价（500-999pcs ×0.8-0.88；≥1000pcs ×0.75-0.85）

5. **美国仓卖点**：1-3天本地发货——这是对批发商最大的吸引力（不用等30天船期）

### 最终输出结果

```
📋 客户背调报告 + 开发信 + 报价区间 + 现货推荐（一整套，30分钟完成）

1. 客户背调清单（13步Checklist）：
   - 公司官网/LinkedIn/Amazon店铺 → 确认主营品类和规模
   - 进口记录（ImportYeti/Panjiva）→ 看现有供应商是谁
   - 信用评估（Dun & Bradstreet）→ 付款风险
   - [具体查询动作列成清单]

2. 开发信草稿（英文，200词）：
   - 主题：Yangjiang Cutlery Manufacturer → OutdoorGear USA (Fixed Blade + EDC)
   - 开头：提到对方官网/LinkedIn的具体产品
   - 价值点：①美国仓现货1-3天发 ②MOQ 50pcs起 ③FDA合规 ④三道QC
   - CTA：邀约15分钟Zoom，附产品目录
   - [标注：草稿待Leo确认后发送]

3. 初步报价区间（FOB Shenzhen）：
   - 入门固定直刀：$15-25/pc（500pcs）
   - 中端EDC折刀：$25-45/pc（500pcs）
   - 高端S35VN折刀：$45-60/pc（500pcs）
   - 现货（美国仓）：比FOB价高30-40%但3天到货

4. 合规提醒：不推OTF/自动刀/蝴蝶刀/Zombie款
```

## 案例2：处理德国客户的厨刀询盘

### 场景描述

> 德国汉堡的一家厨刀进口商"Hamburg Messer KG"发来询盘，要求：①推荐适合德国市场的主厨刀 ②报价 ③提供认证文件 ④询问LFGB合规。客户邮件很正式，附了公司WEEE注册号。

### AI查询了哪些知识库文件

| 步骤 | 查询的文件路径 | 为什么查 |
|------|--------------|---------|
| ① 德国商务特点 | [`04_国家地区开发指南/02_欧洲_德英法意西荷.md`](../04_国家地区开发指南/02_欧洲_德英法意西荷.md) | 德国人严谨、逐字审合同、最看重检测报告、LFGB比FDA更严 |
| ② 认证清单 | [`01_公司与品牌/资质认证/01_资质证书总览.md`](../01_公司与品牌/资质认证/01_资质证书总览.md) | 我们有哪些认证可发给客户 |
| ③ 认证详解 | [`01_公司与品牌/资质认证/02_产品认证详解.md`](../01_公司与品牌/资质认证/02_产品认证详解.md) | LFGB/CE/RoHS具体覆盖哪些SKU |
| ④ 厨刀SKU参数 | [`02_产品知识库/厨刀SKU深度参数与应用场景.md`](../02_产品知识库/厨房刀具/厨刀SKU深度参数与应用场景.md) | 选适合德国市场的主厨刀（钢材/硬度/尺寸） |
| ⑤ 厨刀FAQ | [`02_产品知识库/产品FAQ库/01_厨房刀FAQ.md`](../02_产品知识库/产品FAQ库/01_厨房刀FAQ.md) | 德国客户常问的技术问题标准答案 |
| ⑥ 报价策略 | [`11_订单与财务/04_报价体系与价格策略.md`](../11_订单与财务/04_报价体系与价格策略.md) | 德国客户付款偏好（T/T或L/C，首单建议L/C） |
| ⑦ PI模板 | [`11_订单与财务/07_PI形式发票模板.md`](../11_订单与财务/07_PI形式发票模板.md) | 直接套英文PI模板 |
| ⑧ 背调工具 | [`03_客户开发与CRM/03_客户背景调查SOP与工具.md`](../03_客户开发与CRM/03_客户背景调查SOP与工具.md) | 德国客户背调用Creditreform |

### AI提取了什么关键信息

1. **德国客户特点**：
   - 严谨到极致，规则大于一切，会逐字审核合同
   - 最看重检测报告和稳定交货——准备"超详细资料包"
   - 承诺交期必须做到，延迟提前7天告知并给补偿
   - 邮件标题规范（公司+产品+事项），附件命名清晰
   - 付款：T/T或L/C，首单建议L/C

2. **认证匹配**：
   - LFGB ✅（德国食品接触材料标准，最严）
   - CE ✅（全欧盟通用）
   - RoHS ✅（有害物质限制）
   - FDA（美国认证，德国客户也认可作为质量参考）
   - BSCI（社会责任审计——但C评级不主动展示）

3. **产品推荐方向**：
   - 德国市场偏好：德国钢对标款（X50CrMoV15同级别）、锻造刀、传统三德刀/主厨刀
   - 推荐9Cr18MoV/VG10 Damascus主厨刀——对标Wüsthof $155-170，我方B2B价$20-40

### 最终输出结果

```
📦 德国客户询盘回复包（30分钟内完成）

1. 产品推荐（3款）：
   - KL-KN-SS-011 木纹柄不锈钢主厨刀（9Cr18MoV, HRC56-58）——对标Wüsthof Classic
   - KL-KN-DS-008 Damascus纹理主厨刀（VG10芯材, HRC58-60）——高端线
   - KL-KN-SS-014 空心边三德刀（5Cr15MoV）——德国家庭常用三德刀

2. 报价（FOB Shenzhen, 500pcs）：
   | SKU | 单价 | MOQ | 交期 |
   |-----|------|-----|------|
   | KL-KN-SS-011 | $5.60 | 500 | 25天 |
   | KL-KN-DS-008 | $9.60 | 500 | 30天 |
   | KL-KN-SS-014 | $6.40 | 500 | 25天 |
   报价有效期：15天

3. 认证文件清单（打包发客户）：
   - LFGB证书（SGS测试报告）
   - CE符合性声明
   - RoHS测试报告
   - FDA 21 CFR测试报告（作为补充）
   - 钢材材质证明（MTC）

4. 德语区注意事项（写邮件时遵守）：
   - 邮件标题：[KaiLionCrafts] Chef Knife Quotation for Hamburg Messer KG
   - 附件命名：KLC_HamburgMesser_Quotation_20260928.pdf
   - 不主动提BSCI C评级
   - 交期承诺要保守（说25天就确保25天）
   - 首单建议T/T 30%+70%，如客户坚持可谈L/C

5. 背调提醒：用Creditreform查对方信用
```

| 维度 | 人工完成 | AI完成 | 提升 |
|------|---------|--------|------|
| 查德国商务禁忌 | 翻国家指南+背调SOP约20分钟 | 10秒 | 120× |

### AI提取了什么关键信息

1. **四档报价公式**：
   ```
   EXW = 产品出厂价 + 内包装费 + 厂内装卸费
   FOB = EXW + 国内运费（工厂→盐田港）+ 报关费 + 港杂费 + 文件费
   CIF = FOB + 海运费 + 货运保险（货值×110%×保险费率）
   DDP = CIF + 目的港清关费 + 进口关税 + 目的国内陆运输
   ```

2. **阶梯价**：500pcs = 标准价×0.8-0.88（取0.85）

3. **汇率缓冲**：报价用汇率比当日中间价低2-3%（如中间价6.75，按6.60核算）

4. **德国客户**：首单建议T/T 30%+70%见提单副本；信用好可谈L/C
