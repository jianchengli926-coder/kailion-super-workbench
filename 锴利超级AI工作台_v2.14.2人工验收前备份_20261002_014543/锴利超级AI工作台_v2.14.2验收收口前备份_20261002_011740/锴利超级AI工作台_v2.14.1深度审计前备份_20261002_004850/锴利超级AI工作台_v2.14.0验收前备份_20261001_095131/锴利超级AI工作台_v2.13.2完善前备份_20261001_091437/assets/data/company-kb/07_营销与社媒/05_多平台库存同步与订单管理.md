# Multichannel Inventory Sync & Order Management / 多平台库存同步与订单管理

> 说明（中文）：KaiLionCrafts 同步运营 Amazon FBA + eBay + Walmart + Shopify 独立站时，最大的运营风险是**超卖 (oversell)** 和**库存账实不符**。本文件定义同步策略、订单流、工具选型与退货流程。

---

## 1. Inventory Sync Strategy / 多平台库存同步策略

### 1.1 Core Principle: Single Source of Truth (SSOT)

- **Total available inventory = physical stock at US warehouse** (or FBA in-transit + FBA on-hand).
- Do NOT sum stock across platforms. All platforms draw from a **central pool**.
- Apply a **safety buffer** (e.g., hold back 5-10% of stock) to prevent oversell during sync lag.

### 1.2 Allocation Rules / 库存分配规则

Example allocation for 100 units of a kitchen knife SKU:

| Channel | Allocated Qty | Rationale |
|---------|---------------|-----------|
| Amazon FBA | 60 (already at FBA) | Prime demand, fast mover |
| Shopify DTC | 20 (at US 3PL) | Highest margin |
| eBay | 10 (at US 3PL) | Supplemental |
| Walmart WFS | 10 (at WFS) | New channel |
| **Safety buffer** | **Reserve 5 units** | Buffer for returns/exchanges |

- Re-allocate weekly based on sell-through velocity.
- Use **reorder point** = (avg daily sales × lead time in days) + safety stock. For 阳江→US sea freight ~45 days, plan replenishment early.

### 1.3 Preventing Oversell

- Real-time API sync on each sale (not batch cron).
- When any channel sells 1 unit, decrement central pool and push new available qty to all other channels within 15 minutes.
- Hard cap: never show more than (pool - safety) to any channel.
- If sync fails: auto-decrement listings to 0 across secondary channels until resolved.

## 2. Order Management Flow / 订单管理流程

```
[Customer places order]
        │
        ▼
[Platform webhook → OMS central queue]
        │
        ├── Amazon FBA order      → Amazon fulfills directly (no action)
        ├── Walmart WFS order     → Walmart fulfills directly (no action)
        ├── Shopify / eBay / self-fulfilled
        │       │
        │       ▼
        │   [OMS routes to US 3PL warehouse]
        │       │
        │       ▼
        │   [3PL picks/packs/prints label]
        │       │
        │       ▼
        │   [Tracking number pushed back to platform]
        │       │
        │       ▼
        │   [Customer notified with tracking]
        │
        ▼
[Post-purchase: review request, follow-up email in 7 days]
```

### 2.1 SLA Targets

- Order received → warehouse notification: <15 min.
- Warehouse ship-by: ≤2 business days (Walmart requires 2 days).
- Tracking uploaded: same day as ship.
- Customer message response: <24h (Walmart requirement).

## 4. US Warehouse Allocation / 美国仓多平台发货分配

### 4.1 Inventory Placement

| Warehouse Type | Used For | Stock Kept There |
|----------------|----------|------------------|
| Amazon FBA | Amazon Prime orders | Fast-moving hero SKUs (top 20%) |
| Walmart WFS | Walmart orders | Walmart-approved SKUs |
| US 3PL (e.g., ShipBob/Deliverr/洋码头海外仓) | Shopify + eBay + B2B | Long-tail SKUs, case packs, returns |

### 4.2 Replenishment Cadence

- Sea freight from阳江 → US West Coast: ~35-45 days.
- Air freight: 7-10 days, premium cost for top SKUs stockouts.
- Reorder trigger: when US 3PL on-hand < (7-day forecast + 45-day sea lead buffer).

## 5. Returns Processing / 退货处理流程

### 5.1 Platform-specific Returns

- **Amazon FBA**: Amazon handles all returns; unsellable inventory disposed or returned to you.
- **Walmart**: 30-day return window; WFS handles.
- **eBay**: Buyer can open "Not as Described" case; seller must respond within 3 business days.
- **Shopify DTC**: Your policy (recommend 30-day return).

### 5.2 Knife-Specific Returns

- Inspect returned blade immediately:
  - **Resellable**: blade guard intact, no use marks, original packaging → restock.
  - **Unsellable**: edge used, packaging damaged → liquidate (e.g., eBay outlet) or dispose.
- **Never** restock a knife that has been used — liability risk.
- Photograph every return for dispute evidence.

### 5.3 Return Addresses

- Each platform requires a US return address. Use the 3PL address; do NOT use your China factory address.
