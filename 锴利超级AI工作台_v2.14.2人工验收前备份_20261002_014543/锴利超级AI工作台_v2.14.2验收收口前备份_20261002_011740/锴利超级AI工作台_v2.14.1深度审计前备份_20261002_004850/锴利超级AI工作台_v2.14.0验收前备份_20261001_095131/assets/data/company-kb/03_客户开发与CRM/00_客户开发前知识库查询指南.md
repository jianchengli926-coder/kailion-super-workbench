# 客户开发前知识库查询指南

> **用途**：AI 在给任何海外客户开发、回复询盘、发送资料前，必须按本指南的顺序查询知识库，
> 杜绝凭记忆乱说、报错价、错发证书、触犯进口法规。
> **路径口径**：`NN/文件名` 中 `NN` 指一级目录编号；PDF 交付物位于公司根目录（非 .md 库内），文件名见文末清单。

---

## 〇、启动前置（每次对话先做）

- [ ] 读 `00/00_README_知识库总导航.md` 确认版本与权威口径
- [ ] 读 `00/02_公司核心事实速查表.md`（公司全称/品牌/主营/所在地）
- [ ] 遇到任何数字、材质、认证、条款，**以知识库文件为准，不臆造**
- [ ] 区分"可对外发"与"内部敏感"：发客户前对照 `99/03_敏感信息与待补充清单.md`

---

## 一、按国家开发时的查询顺序

> 顺序原则：**国别法规 → 区域打法 → 通用SOP → 产品 → 话术模板**。

| 目标国家/地区 | ① 先查国别指南 | ② 再查法规/专项（按需） | ③ 通用SOP | ④ 话术/模板 |
|---|---|---|---|---|
| 🇺🇸 美国 | `04/01_北美_美国加拿大.md` | 推户外刀必查 `04/11_户外刀各国进口法规专项.md` | `03/01 开发SOP` → `03/02 ABCD分级` | `03/邮件模板/01 开发信` |
| 🇨🇦 加拿大 | `04/01_北美_美国加拿大.md` | 户外刀同查法规专项 | 同上 | 同上 |
| 🇩🇪🇬🇧🇫🇷🇮🇹🇪🇸🇳🇱 欧洲 | `04/02_欧洲_德英法意西荷.md` | 户外刀具查法规专项（刀刃长度/携带限制） | `03/01` → `03/03 背调SOP` | `03/邮件模板/01` |
| 🇯🇵🇰🇷 日韩 | `04/03_东亚_日韩.md` | 刀具进口合规查法规专项 | `03/01` | `03/邮件模板/01` |
| 🇸🇬🇲🇾🇹🇭🇻🇳🇮🇩🇵🇭 东南亚 | `04/04_东南亚…md` | — | `03/01` → `03/05 小客户/跨境电商策略` | `03/邮件模板/01` |
| 🇦🇪🇸🇦 中东 | `04/05_中东_阿联酋沙特.md` | 刀具/文化禁忌注意 | `03/01` → `03/04 大客户策略` | `03/邮件模板/01` |
| 🇧🇷🇲🇽 拉美 | `04/06_拉美_巴西墨西哥.md` | 关税/单证复杂，加查 `06/05 出口流程与单证` | `03/01` | `03/邮件模板/01` |
| 🇷🇺 俄/独联体 | `04/07_俄罗斯与CIS.md` | 付款/结算查 `06/04 付款条款` | `03/01` | `03/邮件模板/01` |
| 🇦🇺🇳🇿 澳新 | `04/08_澳洲与新西兰.md` | 户外刀法规专项 | `03/01` | `03/邮件模板/01` |
| 🇮🇳 印度/南亚 | `04/09_印度与南亚.md` | 价格敏感，加查 `03/06 谈判异议处理` | `03/01` → `03/05` | `03/邮件模板/03 询盘回复` |
| ⏰ 任意国家发邮件前 | `04/10_全球时区与最佳联系时间速查表.md` | 选最佳发送时段 | — | `03/邮件模板/02 跟进序列` |

**美国客户开发标准链路（示例闭环）：**
1. `04/01 北美指南` → 摸清采购习惯、热门品类、渠道
2. 若推户外刀 → `04/11 户外刀各国进口法规`（刃长/合法性/标签）
3. `03/01 开发SOP` + `03/02 ABCD分级` 判定客户级别
4. `03/03 背调SOP` 做客户背景调查
5. `02/对应品类` 确认要推的 SKU 与卖点
6. `03/邮件模板/01 首次开发信` 落笔

## 三、按客户类型的查询路径

### A. 大客户 / 品牌商 / 进口商（A 类）
- [ ] `03/04_大客户开发策略.md`
- [ ] `03/03_客户背景调查SOP与工具.md`（务必背调：规模、渠道、竞品）
- [ ] `03/07_客户资料包标准清单.md`（按清单打包全套资料）
- [ ] `01/工厂与供应链/03_OEM_ODM定制能力` + `01/资质认证`（验厂/认证是硬门槛）
- [ ] `03/06_谈判话术与异议处理.md`（账期、独家、贴牌谈判）
- [ ] `10/04_社会效益与产业链升级.md`（政府/产业背书可作加分）

### B. 小客户 / 跨境电商卖家 / 独立站卖家（C/D 类）
- [ ] `03/05_小客户与跨境电商开发策略.md`
- [ ] `06/02_美国仓现货体系` + `06/07_美国仓现货SKU库存清单`（推小批量现货/一件代发）
- [ ] `02/对应品类/02_SKU索引`（轻量化选品，不甩整套参数表）
- [ ] `03/邮件模板/03_询盘回复模板.md`（快速报价、低门槛 MOQ）

### C. 新客户首次接触（不分大小）
- [ ] `03/01_客户开发全流程SOP.md` 走标准动作
- [ ] `03/02_客户分级管理_ABCD.md` 当场定级
- [ ] `03/邮件模板/01_首次开发信模板`
- [ ] `04/10_时区速查` 选发送时间

### D. 已报价未成交客户（跟进阶段）
- [ ] `03/邮件模板/02_跟进序列_Day0_3_7_14_21_30.md`
- [ ] `03/06_谈判话术与异议处理.md`（价格/交期/MOQ 异议）
- [ ] `03/08_实战案例集.md`（用同类成交案例背书）

## 四、发送前终检 Checklist（对外动作前必过）

- [ ] 客户所在国法规已核对（尤其户外刀具刃长/进口限制）
- [ ] 报价 MOQ、规格、付款条款来自知识库，非记忆
- [ ] 公司名称用权威口径：阳江市锴利国际贸易 / Yangjiang Kaili International Trading Co., Ltd.
- [ ] 品牌名统一 KaiLionCrafts，不混用拼写
- [ ] 未泄露 `99/03_敏感信息` 中标注为内部的内容（底价、成本、工厂股权细节）
- [ ] 附件为三份标准 PDF：Company_Profile / Product_Catalog / Certifications
- [ ] 发送时段符合 `04/10_时区速查`
