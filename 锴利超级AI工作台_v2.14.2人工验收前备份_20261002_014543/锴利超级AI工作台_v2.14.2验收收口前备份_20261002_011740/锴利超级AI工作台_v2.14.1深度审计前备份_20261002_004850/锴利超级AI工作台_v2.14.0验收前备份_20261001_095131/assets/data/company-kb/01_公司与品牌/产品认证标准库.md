# 产品认证标准库（Product Certification Standard Library）

> 本文件汇总四大品类（厨房刀/专业剪刀/户外刀/厨房用品）在各主要市场的认证要求，供业务、跟单、合规团队快速查阅。
> ⚠️ 认证费用为2025-2026年市场参考区间，实际以检测机构报价为准。法规更新频繁，发货前须与目的国报关行/清关代理确认。
> 已有23组合作工厂认证清单见本目录 `04_产品合规认证体系.md` 第四节。

## 二、食品接触材料认证详解

### 2.1 FDA 21 CFR（美国食品接触）

| 项目 | 内容 |
|---|---|
| 法规依据 | 21 CFR Part 170-199（食品接触材料法规） |
| 适用范围 | 所有预期与食品接触的材料：不锈钢厨刀、厨房剪、削皮器、夹铲等 |
| 核心原则 | FDA**不认证品牌**，而是规定允许接触食品的材料化学组成；制造商自行合规 |
| 测试项目 | ①不锈钢成分合规（耐腐蚀性、无毒）；②铅迁移（21 CFR 109.6，限值<0.005 µg/mL）；③重金属溶出 |
| 费用区间 | $500-2,000/材质（SGS/Intertek实验室报价） |
| 周期 | 1-2周 |
| 发证机构 | FDA不发证书；由第三方实验室出具测试报告（SGS/BV/Intertek等） |
| 有效期 | 无固定有效期；材料/工艺变更需重测 |
| KaiLionCrafts状态 | ✅ 已通过（cert-14：6重复样铅迁移均<0.005 µg/mL） |
| 官方来源 | https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfcfr/cfrsearch.cfm （检索日期：2026-09-28） |

### 2.2 LFGB（德国食品和饲料法典）

| 项目 | 内容 |
|---|---|
| 法规依据 | Lebensmittel- und Futtermittelgesetzbuch (LFGB)；BfR Recommendations |
| 适用范围 | 德国市场销售的所有食品接触材料；比欧盟1935/2004更严格 |
| 测试项目 | ①感官测试（DIN 10955：气味/味道迁移）；②迁移测试；③重金属溶出（铅/镉/铬/镍）；④不锈钢成分合规 |
| 费用区间 | $1,500-4,000/材质（SGS/TÜV报价） |
| 周期 | 3-5周 |
| 发证机构 | SGS/TÜV Rheinland/TÜV SÜD等第三方实验室 |
| 有效期 | 无固定有效期；材料变更需重测；欧盟认可度高 |
| KaiLionCrafts状态 | ✅ 已通过（cert-07：SGS LFGB DMS-052双项PASS，2026-07-28）；cert-10：感官测试DIN 10955 PASS |
| 官方来源 | https://www.bfr.bund.de/en/service/databases/bfr-recommendations-on-food-contact-materials/ （检索日期：2026-09-28） |

### 2.3 欧盟 Regulation (EC) 1935/2004

| 项目 | 内容 |
|---|---|
| 法规依据 | Regulation (EC) No 1935/2004 框架法规；Regulation (EC) No 2023/2006（GMP） |
| 适用范围 | 所有预期与食品接触的材料和制品 |
| 核心要求 | ①不向食品释放危害健康的成分；②不导致食品组成不可接受变化；③不损害食品感官特性 |
| 测试项目 | 总迁移量测试（10 dm²接触面）；特定重金属迁移 |
| 费用区间 | $1,000-3,000/材质 |
| 周期 | 2-4周 |
| 发证机构 | 欧盟公告机构（Notified Body）出具测试报告；制造商自行DoC |
| 有效期 | 无固定有效期；标准更新需重评 |
| 官方来源 | https://food.ec.europa.eu/safety/chemical-safety/food-contact-materials/legislation_en （检索日期：2026-09-28） |

## 三、化学品与环保合规认证

### 3.1 CE标志（欧盟符合性标志）

| 项目 | 内容 |
|---|---|
| 法规依据 | 各欧盟指令/法规（如GPSD通用产品安全指令、机械指令2006/42/EC） |
| 适用范围 | ⚠️ **纯手动刀剪（无电子部件、无机械驱动）在欧盟不强制CE**；含电子磨刀器/电动切片器等需CE |
| 测试项目 | 视适用指令而定；手动刀剪主要受GPSD一般产品安全管辖 |
| 费用区间 | $500-3,000（视是否需公告机构介入） |
| 周期 | 2-6周 |
| 发证机构 | 制造商自行声明（DoC）；高风险产品需公告机构 |
| 有效期 | 无固定有效期；协调标准更新需重新评估 |
| KaiLionCrafts状态 | ✅ cert-06：CE自我声明（DMS-249，HX检测） |
| 官方来源 | https://single-market-economy.ec.europa.eu/single-market/ce-marking_en （检索日期：2026-09-28） |

### 3.2 RoHS（限制有害物质指令）

| 项目 | 内容 |
|---|---|
| 法规依据 | Directive 2011/65/EU + (EU) 2015/863 |
| 限制物质 | 铅/汞/镉/六价铬/PBB/PBDE/DEHP/BBP/DBP/DIBP（共10项） |
| 适用范围 | ⚠️ **电子电气设备（EEE）**；纯手动刀剪不适用。电动磨刀器/电动切片器适用 |
| 测试项目 | IEC 62321方法测试10项有害物质 |
| 费用区间 | $300-1,000/材质 |
| 周期 | 1-2周 |
| 发证机构 | SGS/Intertek/华讯检测等第三方实验室 |
| 有效期 | 无固定有效期；材料变更需重测 |
| KaiLionCrafts状态 | ✅ cert-02（RoHS九项HX检测）、cert-17（CTB RoHS大马士革）——可作为材料安全佐证，非市场准入强制 |
| 官方来源 | https://environment.ec.europa.eu/topics/waste-and-recycling/rohs-directive_en （检索日期：2026-09-28） |

### 3.3 REACH（欧盟化学品注册评估授权）

| 项目 | 内容 |
|---|---|
| 法规依据 | Regulation (EC) No 1907/2006 |
| 适用范围 | 所有出口欧盟的产品（不论是否电子） |
| 核心要求 | 若产品中SVHC（高度关注物质）含量>0.1%（w/w），须向接收方/消费者通报 |
| 重点关注 | 金属刀具：镍（致敏）、铬、铅；塑料手柄：邻苯二甲酸酯 |
| 测试项目 | SVHC清单筛查（目前240+项，持续更新） |
| 费用区间 | $500-2,000 |
| 周期 | 2-4周 |
| 发证机构 | 第三方实验室出具测试报告；ECHA维护SVHC清单 |
| 有效期 | SVHC清单更新后需复测新增物质 |
| KaiLionCrafts状态 | ⚠️ 待确认（现有RoHS报告不完全覆盖REACH SVHC） |
| 官方来源 | https://echa.europa.eu/candidate-list-table （检索日期：2026-09-28） |

### 3.4 加州 Proposition 65

| 项目 | 内容 |
|---|---|
| 法规依据 | California Safe Drinking Water and Toxic Enforcement Act of 1986 |
| 适用范围 | 所有在加州销售的产品 |
| 核心要求 | 企业在"明知且故意"使人接触列管化学物质前，须提供"清晰合理"警告 |
| 刀剪相关物质 | 铅、镉（黄铜手柄/焊接点）、镍（不锈钢析出） |
| 测试项目 | 铅/镉溶出测试；总含量测试 |
| 费用区间 | $300-1,500/材质 |
| 周期 | 1-2周 |
| 发证机构 | 第三方实验室测试报告；警告标签自行加贴 |
| 有效期 | 无固定有效期；新物质列入需重评 |
| 执法特点 | **私人执法**（bounty hunter律所），和解金通常$2,500-$50,000+ |
| KaiLionCrafts状态 | ⚠️ 待确认（FDA铅迁移测试可部分参考，建议做Prop 65专项） |
| 官方来源 | https://www.p65warnings.ca.gov/ （检索日期：2026-09-28） |

### 3.5 CPSIA（美国消费品安全改进法）

| 项目 | 内容 |
|---|---|
| 法规依据 | Consumer Product Safety Improvement Act 2008 |
| 适用范围 | **12岁以下儿童产品**；成人厨刀/户外刀不适用 |
| 核心要求 | 铅含量限值（表面涂层≤90ppm、基材≤100ppm）；邻苯二甲酸酯≤0.1%；CPSC认可第三方实验室测试；儿童产品证书(CPC) |
| 费用区间 | $1,000-3,000 |
| 周期 | 3-5周 |
| 发证机构 | CPSC认可第三方实验室 |
| 有效期 | 无固定有效期；材料变更需重测 |
| 对刀剪影响 | 成人刀剪不适用；但若产品包装/营销针对儿童（如儿童安全剪刀），可能触发 |
| 官方来源 | https://www.cpsc.gov/Regulations-Laws--Standards/CPSIA （检索日期：2026-09-28） |

|---|---|

### 4.6 SONCAP（尼日利亚符合性评估）

| 项目 | 内容 |

## 八、认证维护规则

1. **材料变更必重测**：换钢材等级、换手柄材料（POM/G10/木材/Micarta）、换表面处理工艺，必须重新做食品接触迁移测试。
2. **新工厂导入必重测**：新合作工厂须重新做全套食品接触测试（TÜV/SGS）。
3. **证书到期预警**：FSC至2029-04、BSCI至2027-04，到期前60天启动续证。
4. **SVHC清单跟踪**：ECHA每半年更新SVHC清单（目前240+项），出口欧盟产品需持续关注。
5. **证书归属**：工厂认证证书对外展示需工厂授权；KaiLionCrafts自有测试报告可自由使用。
