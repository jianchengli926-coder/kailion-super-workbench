### 1.2 设计原则

1. **本地优先，云端兜底**：隐私数据 / 重复任务走本地 Ollama；复杂推理 / 高质量生成走云端 API。
2. **知识库是底座**：所有 AI 工作台都从同一个知识库读事实，避免口径不一致。
3. **人在回路**：AI 出草稿，Leo 审核后才对外发送。
4. **模块化**：每个工作台独立，坏一个不影响其他。
5. **成本可控**：模型调用走"便宜模型先试，贵模型只在必要时用"。

## 二、硬件需求（M4 Mac mini 16G 基线）

### 2.1 M4 Mac mini 16G 能跑什么（建议方案，需根据实际环境调整）

| 任务 | 模型 | 内存占用 | 能否跑 | 速度感受 |
|------|------|---------|--------|---------|
| 翻译 / 简单问答 | qwen2.5:7b (Q4 量化) | ~5GB | ✅ 流畅 | 10-30 token/s |
| 嵌入索引 | bge-m3 | ~1.2GB | ✅ 流畅 | 30-80ms/条 |
| 长文生成 | qwen2.5:14b (Q4) | ~9GB | ⚠️ 勉强 | 5-10 token/s，占满内存 |
| 复杂推理 | deepseek-r1:7b | ~5GB | ✅ | 比 qwen 慢但推理强 |
| 大模型 70B+ | 任何 70B | >40GB | ❌ 跑不动 | — |
| 同时跑工作台 + Ollama + 浏览器 | — | 16G 吃紧 | ⚠️ | 建议关不用的工作台 |

### 2.2 硬件升级建议（未来 12 个月）

| 升级项 | 什么时候升 | 预算 | 收益 |
|--------|-----------|------|------|
| 内存加到 24G / 32G | 当 14b 模型频繁 OOM | ~$300-600 | 能跑更大模型 |
| 外接 SSD（已有 1TB） | 知识库 / 模型文件膨胀 | 已配 | ✅ |
| 云服务器（VPS） | 需要 24 小时不关机跑 Dify/CRM | $10-30/月 | 不依赖 Mac mini 开机 |
| 独立 GPU 工作站 | 想本地跑 70B 模型 / 批量嵌入 | $2000+ | 暂不建议，云端更划算 |

> **当前结论**：M4 Mac mini 16G 跑 7b 模型 + bge-m3 + 所有工作台**够用**。瓶颈不是硬件，是工作流和提示词。

## 三、模型选型（本地 vs 云端成本性能对比）

### 3.1 模型路由表（建议方案，需根据实际环境调整）

| 任务 | 首选 | 备选 | 理由 |
|------|------|------|------|
| 日常翻译 / 术语一致性 | **本地 qwen2.5:7b** | Dify 翻译工作流 | 免费、隐私、temperature 0.08 稳定 |
| 知识库问答（双语） | **本地 qwen2.5:7b** | DeepSeek | 走 RAG，本地够 |
| 客户开发信 / 营销文案 | **GPT-4o** | Claude | 语气自然，英文地道 |
| 长文档 / 合同审查 / 竞品分析 | **Claude 3.5 Sonnet** | GPT-4o | 长上下文、逻辑强 |
| 代码 / Cursor / Codex | **Claude / GPT-4o** | DeepSeek-Coder | 代码能力 |
| 嵌入（向量索引） | **本地 bge-m3** | text-embedding-3 | 免费、多语言 |
| 重排序 | **Cohere rerank-multilingual** | bge-reranker-v2-m3 本地 | 现有已接 Cohere |
| 快速草稿 / 简单润色 | **豆包 / DeepSeek 免费额度** | GPT-4o mini | 便宜 |

### 3.2 成本对比（按月估算，建议方案，需根据实际环境调整）

假设：每天 50 次 AI 调用，其中 30 次简单（本地/便宜），20 次复杂（云端）。

| 方案 | 月成本 | 质量 | 隐私 |
|------|--------|------|------|
| 全本地（Ollama qwen2.5:7b） | ~$0（电费） | 中（简单任务够，复杂任务弱） | 最好 |
| 全云端 GPT-4o | ~$60-120 | 高 | 数据出域 |
| **混合方案（推荐）** | **$20-50** | 高 | 敏感本地 + 复杂云端 |
| 全云端 Claude | ~$50-100 | 高（长文最强） | 数据出域 |

### 3.3 推荐路由策略

```
用户提问
  ↓
是否涉及敏感数据（客户隐私 / 价格 / 未发布产品 / 内部财务）？
  ├─ 是 → 走本地 Ollama（qwen2.5:7b）
  └─ 否 → 是否复杂任务（长文 / 代码 / 高质量文案）？
        ├─ 是 → 走云端（Claude / GPT-4o）
        └─ 否 → 走便宜云端（GPT-4o mini / DeepSeek / 豆包）
```

## 四、数据安全与隐私

### 4.1 数据分级（建议方案，需根据实际环境调整）

| 级别 | 数据类型 | 处理方式 |
|------|---------|---------|
| 🔴 绝密 | 客户银行账号、PI 金额、合同条款、员工工资、供应商底价 | **只走本地 / 飞书本地**，绝不喂云端 AI |
| 🟡 内部 | 客户名单、询盘内容、未发布产品、内部 SOP | 优先本地 AI；云端调用前脱敏 |
| 🟢 公开 | 官网产品介绍、公开博客、公开社媒文案 | 随便用云端 AI |

### 4.2 敏感数据处理规则

1. **银行账号 / 密码 / API Key**：永远不贴进 AI 对话框。用环境变量 / `.env` 文件。
2. **客户隐私**：客户邮箱 / 电话 / 公司名，在喂云端 AI 前打码（如 `***@xxx.com`），或用本地模型。
3. **未发布产品**：新品定价 / 未上线 SKU，先本地处理，公开前不走云端。
4. **云端 API 数据保留**：OpenAI / Claude 默认不保留训练数据（企业版），但仍要知道数据发出去了。
5. **本地 Ollama 是兜底**：网络断了 / 敏感任务，切本地。

### 4.3 访问控制

- 工作台公网密码 441723（后续建议改成强密码 + IP 白名单）。
- 飞书机器人 / Webhook 不公开。
- Cloudflare Tunnel 加 Access 策略（邮箱验证）。
- 仓库 / 知识库不 push 到公开 GitHub。

## 五、日常运维

### 5.1 知识库更新 SOP（建议方案，需根据实际环境调整）

| 频率 | 动作 | 负责 |
|------|------|------|
| 每周 | 新增产品 / 新询盘模板 / 新市场资料 → 更新 `公司知识库/` | Leo |
| 每周 | 更新后重新索引 Dify 知识库（新增文件单独索引，不全量重建） | Leo |
| 每月 | 跑一次 RAG 测试集（20 个问题），检查召回率 | Leo |
| 每月 | 清理过时文件（旧版设定、废弃 codex-AGENTS.md） | Leo |
| 每季度 | 知识库目录结构审计（参考 `00_导航与规范/07_知识库维护与更新规范.md`） | Leo |

### 5.2 模型更新

```bash
# 每周检查 Ollama 模型更新
ollama list
ollama pull qwen2.5:7b     # 有新版才拉
ollama pull bge-m3

# 云端 API：每月看一次账单（OpenAI / Claude / Cohere）
# 注意 Cohere rerank 是按量计费，超量会停
```

- 本地模型不要追新版本太勤，**稳定 > 最新**。
- 换模型后必须跑测试集回归，确认质量不下降。

### 5.3 性能监控

| 监控项 | 工具 | 告警阈值 |
|--------|------|---------|
| Mac mini 内存 | Activity Monitor | 持续 >80% → 关不用的工作台 |
| 磁盘 | df -h | 剩余 <20G → 清理模型 / 备份 |
| 工作台进程 | `ps aux | grep streamlit` | 崩了自动重启（写 launchd 脚本） |
| Cloudflare Tunnel | 子域名能否访问 | 打不开 → 查 tunnel 状态 |
| API 调用量 | OpenAI / Claude 后台 | 接近月预算 80% 时告警 |
| RAG 召回率 | 每月测试集 | <80% → 排查分块 / 模型 |

### 5.4 成本控制

1. **便宜模型兜底**：简单任务用 GPT-4o mini / DeepSeek，不要事事 GPT-4o。
2. **批量任务本地跑**：批量翻译 / 嵌入用 Ollama，不烧云端 token。
3. **缓存**：相同问题不要重复调 API，工作台加 5 分钟缓存（V75 已做）。
4. **每月看账单**：OpenAI Usage / Claude Console / Cohere Dashboard，找出最贵的调用场景。
5. **设置预算告警**：OpenAI 后台设 $50/月 hard limit，超了自动停。

## 九、故障应急

| 故障 | 应急 |
|------|------|
| Ollama 挂了 | 重启 `ollama serve`；切云端 API |
| Dify 容器崩了 | `docker compose restart`；查日志 `docker logs` |
| Cloudflare Tunnel 断了 | 重启 cloudflared；子域名临时走 localhost |
| OpenAI API 超预算 | 切 Claude / DeepSeek / 本地 |
| 知识库索引坏了 | 重新跑分块 + 嵌入；不要在生产库上直接修 |
| Mac mini 内存满 | 关不用的工作台；重启 Ollama |
| 误删文件 | 从 `.bak` 备份 / git 历史恢复 |
