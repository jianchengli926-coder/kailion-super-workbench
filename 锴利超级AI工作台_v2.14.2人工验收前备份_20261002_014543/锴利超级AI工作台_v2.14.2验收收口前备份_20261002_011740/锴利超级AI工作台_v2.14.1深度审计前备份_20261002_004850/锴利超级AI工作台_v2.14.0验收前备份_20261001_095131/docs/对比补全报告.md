## 二、超级工作台遗漏功能清单（对比前）

经过逐文件深度对比，超级工作台在整合三平台后仍遗漏以下功能：

### 🔴 高价值遗漏（必须补全）

| # | 功能 | 来源 | 遗漏原因 | 价值 |
|---|---|---|---|---|
| 1 | **imagetools.js 图片处理工具集** | KaiLionCreator | 整合时只搬了ooxml/zip/blobstore，漏了imagetools | SVG→PNG光栅化、图片压缩、宫格分割、多图合并PDF、统一下载工具 |
| 2 | **水印节点** | KaiLionCrafts | 节点定义和实现均未移植 | 外贸主图刚需，品牌水印保护 |
| 3 | **HTTP请求节点** | KaiLionCrafts | 节点定义遗漏 | 任意REST API调用，扩展能力外挂 |
| 4 | **节点角标系统** | KaiLionCreator | 画布体验差异未移植 | 一眼区分真实产出vs本地推演vs失败，建立信任 |
| 5 | **Electron桌面打包层** | 利建成AI | 整合时未复制electron/目录 | 打包成Mac/Windows可安装App |

### 🟡 中价值遗漏（尽量补全）

| # | 功能 | 来源 | 遗漏原因 | 价值 |
|---|---|---|---|---|
| 6 | **连通性逐项诊断** | KaiLionCreator | api.js只有简单testConnection | 不是一句"失败"，而是逐项报告网络/模型/对话/流式/生图 |
| 7 | **种子数据共享机制** | KaiLionCreator | store.js的loadSeedIfFirstRun未移植 | 拷文件夹给朋友=对方打开就是你配置好的样子 |
| 8 | **LOD缩放折叠 + 流式输出贴节点** | KaiLionCreator | 画布体验优化未移植 | 大画布总览可读；模型逐字返回时实时显示在节点上 |

### 🟢 低价值/已有替代（不补全）

| 功能 | 来源 | 不补全原因 |
|---|---|---|
| 本地网桥proxy.mjs | KaiLionCreator | 需要Node.js后端，浏览器版无法直接用；四协议层已处理大部分跨域 |
| 结果预览器6类型重构 | KaiLionCreator | 超级工作台已有export.js+结果预览，重构风险大于收益 |
| store.js订阅者模式 | KaiLionCreator | 超级工作台已有成熟的状态管理，替换成本高 |
| 50+工作流模板 | KaiLionCreator | 超级工作台已有workflow-templates.js+marketplace，模板内容需按业务定制 |
| CLI节点 | KaiLionCrafts | 浏览器无法执行本地命令行，安全限制 |

## 三、已补全功能清单（本次完成）

### ✅ 功能1：imagetools.js 图片处理工具集

- **文件**：`assets/js/imagetools.js`（新建，14KB）
- **来源**：KaiLionCreator `js/core/imagetools.js` → ES Module转IIFE全局模式
- **暴露**：`window.ImageTools`
- **包含函数**：
  - `svgToPng(svgStr, scale)` — SVG光栅化为PNG
  - `compressImage(blob, maxKB)` — 图片压缩
  - `convertImage(blob, fmt)` — PNG/JPG/WEBP格式互转
  - `cropGrid(blob, cols, rows)` — 宫格分割
  - `mergeImagesToPdf(images)` — 多图合并PDF（A4自动横竖）
  - `downloadBytes/downloadBlob/downloadZip` — 统一下载工具
  - `fmtSize(n)` — 文件大小格式化
- **接入**：index.html在zip.js后、ooxml.js前插入引用

### ✅ 功能2：水印节点 watermarkNode

- **节点定义**：nodes-data.js「文件处理」分类新增
- **参数面板**：水印文字（默认"锴利KaiLion"）、九宫格位置、字号12-72、透明度0.1-1.0、颜色、旋转0-360°
- **执行逻辑**：engine.js用Canvas API真实绘制水印，输出dataURL
- **来源**：KaiLionCrafts `addWatermark` 函数

### ✅ 功能3：HTTP请求节点 httpRequestNode

- **节点定义**：nodes-data.js「连接器」分类新增（默认隐藏）
- **参数面板**：方法（GET/POST/PUT/DELETE）、URL、Headers（JSON）、Body（JSON）
- **执行逻辑**：engine.js真实fetch，返回HTTP状态码+响应体预览
- **来源**：KaiLionCrafts `httpRequest` 函数

### ✅ 功能4：节点角标系统

- **引擎层**：engine.js执行后写入 `node._meta = {real, simulated, failed, pending, model, provider}`
- **渲染层**：canvas.js节点右上角渲染 `.node-badge`
  - 🟢 绿色 = 真实模型产出（显示模型名）
  - 🟡 黄色 = 本地推演
  - 🔴 红色 = 执行失败
  - ⚪ 灰色 = 待接（未配置供应商）
- **API**：`Canvas.setNodeBadge(nodeId, meta)` 导出
- **样式**：canvas-ext.css新增角标/LOD/流式预览样式

### ✅ 功能5：Electron桌面打包层

- **复制**：`electron/`目录（main.js/preload.js/build图标/generate-icons.sh）+ package.json + package-lock.json
- **品牌改造**：
  - package.json: `name: kailion-super-workbench`, `productName: 锴利超级AI工作台`, `version: 2.0.0`
  - main.js: 窗口标题统一为"锴利超级AI工作台"
- **保留**：全部IPC桥接（selectFile/saveFile/writeFile/menu-action）、单实例锁、原生菜单
- **打包命令**：`npm run build:mac`（需先 `npm install`）

### ✅ 功能6：连通性逐项诊断

- **模块**：`window.ProviderDiagnostic.diagnose(provider)`（providers-data.js末尾追加）
- **检查项**：
  1. 网络可达性（fetch baseUrl）
  2. 模型清单拉取（/v1/models）
  3. 对话连通（发"hi" max_tokens=5）
  4. 流式支持（stream:true测试）
  5. 生图权限（如配置了imageModel）
- **UI入口**：设置面板供应商卡片新增紫色「🩺诊断」按钮，点击显示逐项✅/❌明细
- **来源**：KaiLionCreator `providers.js diagnose` 函数

### ✅ 功能7：种子数据共享机制

- **文件**：`data/初始数据.json`（新建，`{}`占位）
- **逻辑**：app.js `loadSeedIfFirstRun()`
  - 检查 `localStorage.kailion_seed_loaded` 标记
  - 首次运行时fetch `data/初始数据.json`
  - 非空则导入工作流/供应商/资源库数据
  - 空文件或失败静默跳过
- **用途**：导出你的配置覆盖此文件 → 拷文件夹给朋友 → 对方首次打开自动载入你的配置

### ✅ 功能8：LOD缩放折叠 + 流式输出贴节点

- **LOD折叠**：canvas.js `applyView` 中
  - scale < 0.66 → 加 `.lod-collapsed`（隐藏参数预览/结果/流式区，只显示标题）
  - scale < 0.4 → 加 `.lod-minimal`（进一步压缩角标字号）
- **流式输出**：
  - engine.js LLM流式回调派发 `klc:streaming` 自定义事件
  - canvas.js监听事件，在对应节点底部 `.node-stream-preview` 实时更新文本
- **样式**：canvas-ext.css新增LOD和流式预览规则

## 八、后续建议

1. **Electron打包测试**：运行 `cd electron && npm install && npm run build:mac` 生成Mac安装包，验证桌面端功能
2. **水印节点实测**：在画布中拖入水印节点，连接图片输入，验证水印位置/透明度/旋转效果
3. **HTTP节点安全**：生产环境考虑限制可请求的域名（CSP策略），防止SSRF
4. **种子数据导出**：在设置面板的"数据备份"区添加"导出为种子数据"按钮，一键生成初始数据.json
5. **角标系统完善**：为所有占位节点（3D/供应链等）统一标记simulated，避免用户误以为是真实产出
6. **流式输出扩展**：目前仅LLM节点派发流式事件，可扩展到图片生成（进度百分比）和视频生成（轮询状态）
