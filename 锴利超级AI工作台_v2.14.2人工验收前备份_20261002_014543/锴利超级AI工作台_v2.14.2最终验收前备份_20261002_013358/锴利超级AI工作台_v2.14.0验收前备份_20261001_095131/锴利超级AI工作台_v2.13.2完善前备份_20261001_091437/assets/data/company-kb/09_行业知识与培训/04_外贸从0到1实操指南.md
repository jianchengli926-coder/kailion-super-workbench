# 外贸从 0 到 1 实操指南

## 一、完整链路

```
注册公司 → 开户 → 建站 → 选品 → 获客 → 报价 → 成交 → 交付
```

| 环节 | 要点 |
|------|------|
| 注册公司 | 阳江市锴利国际贸易有限公司（B2B 外贸） |
| 开户 | 对公账户 + 跨境收款（PayPal/西联/XTransfer） |
| 建站 | WordPress + WooCommerce 独立站 |
| 选品 | 四大品类：厨房刀/剪刀/户外刀/厨房用品 |
| 获客 | TikTok/Facebook/Ins 社媒 + 独立站 SEO + Import Genius/Panjiva/Rocket Reach |
| 报价 | 报价反筛法、整数/凑九定价 |
| 成交 | 样品→询盘→报价→订单 |
| 交付 | 海外仓/物流、质保售后 |

## 二、口语沟通三法则

1. 关键词+短句："Yangjiang factory! 304 steel! Price lower 30%!"
2. 简单词+素材辅助（手势+工厂视频）。
3. 真诚纠错+补充。
核心：客户买的是产品不是英语。

## 三、销售四技巧

1. 开放式问题挖痛点。
2. 特性转价值（304 钢→3 年防锈省成本）。
3. 建信任（工厂素材背书）。
4. 市场调研（知己知彼）。

## 四、报价反筛法

不直接报价，用 3 个反问过滤比价党：目标价位 + 采购量 + 定制需求。

## 五、新人入门

- **客户数量 > 一切技巧**。
- 放弃国际站/展会，聚焦 TikTok/Facebook/Ins 社媒。
- 接受小订单练手。
- 每日开发 5-10 精准客户。

## 六、注意事项

- 公司事实以全局指令为准（英文名、四大品类、战略合作工厂）。
- 收款/开户具体操作见 `05_获客渠道与工具.md`。

## 补充内容：贸易条款、付款、认证与物流

> 提炼自公司资料源合集"一站式出口服务"章节。对外承诺前须与实际开户/资质一致。

### 七、贸易条款（Incoterms）

公司支持全条款，与长期合作货代配合：

| 条款 | 含义 | 责任划分 |
|------|------|---------|
| EXW 工厂交货 | 买方自提 | 卖方责任最小，买方承担全程 |
| FOB 船上交货 | 货物越过船舷为界 | 卖方负责到起运港装船 |
| CIF 成本+保险+运费 | 卖方付主运费和保险 | 到目的港 |
| DDP 完税后交货 | 卖方送货上门含清关关税 | 卖方责任最大，买方最省心 |

- 物流方式：海运 / 空运 / 国际快递（DHL / FedEx / UPS）。
- 拥有完整进出口经营权，私人/长期合作货代，全套出口单证。

### 八、付款方式与节点

- **标准条款**：30% 定金 + 70% 发货前结清（尾款到账才放提单/放货）。
- 收款工具：PayPal（小单 ≤$5000）/ 西联汇款（中小单不退税）/ XTransfer（大额退税首选，费率 0.5%-1%）。
- 订单财务中心支持 T/T、西联、信用证（L/C）三种方式登记，手动折汇率。

### 九、认证与合规出口

- 支持 **CE / FDA / LFGB / RoHS / ISO 9001** 认证。
- 每把刀出口前在公安局（PSB）备案，100% 合法合规。
- ⚠️ 认证仅用真实持有项，对外宣传前 Leo 复核。

### 十、MOQ 与交期分级（对客报价口径）

| 订单类型 | MOQ | 交期 | 适用客户 |
|---------|-----|------|---------|
| 现货 | 无最低 | 7 天 | 试单/测款 |
| 轻定制（Logo） | 50-150 件 | 约 15 天 | 小品牌/试单 |
| 全 ODM | ≥500 件 | 约 30 天 | 品牌商/Private Label |

### 十一、客户痛点与对应卖点（销售话术库）

| 客户痛点 | 我们的答案 |
|---------|-----------|
| 品质忽好忽坏、交期总拖 | 创始人亲督三道 QC + 发货前视频确认，现货 7 天发 |
| 大工厂拒小单 | 灵活起订量，50 件起接小品牌试单 |
| 中间商层层加价 | 源头直供，价格透明，比市场价低 20%+ |
| 沟通不透明、业务员无决策权 | 直接对接创始人 Leo，零审批链条 |
| 质量不可预测 | 三道 QC + 完整检验报告 + 视频验厂 |

> 价值理念：Trust First · Value Second · Price Last。
