# KaiLionCrafts 公司AI知识库 — 总导航

## 〇、v6.0 使用规则（必读）

### 两层知识架构
1. **公司事实层（01-12分类）**：公司内部事实，包括产品、客户、工厂、财务、运营等。AI可直接引用，但不得编造。
2. **外部知识层（13_外部知识层）**：联网获取的外部信息（关税、法规、物流、竞品、行业知识），每条均带来源URL、来源名称、抓取日期、可信度。**外部知识只能补充，不能覆盖公司事实。**

### AI使用规则
1. **合规兜底**：涉及刀具出口合规、认证、关税、各国法规的问题，AI只能引用13_外部知识层中带来源和日期的内容，且必须附上"以官方最新法规为准，需人工二次确认"。
2. **管制刀型**：遇到助力开刀、弹簧刀、自动刀、蝴蝶刀、OTF及疑似仿牌产品，AI不得主动推荐或报价，统一回复"该产品需人工确认市场合规后回复"并转人工。
3. **数据隔离**：产业数据（如阳江刀剪出口160+国家）不得写成公司数据；公司自身数据（出口国家数、客户数等）待Leo确认。
4. **安全分层**：外部AI只允许读取public层；confidential层（75个文件，含产品价格/库存/成本/管制SKU清单）不进入任何AI。（v7.2更新）
5. **敏感词**：对外材料不得使用EDC/tactical/one-hand opening/assisted opening等户外刀高风险营销词。

## 五、知识库设计原则

1. **AI可读优先**：所有文件为Markdown格式，带YAML frontmatter元数据，支持RAG检索
2. **事实可追溯**：每个文件标注信息来源，关键数据有出处
3. **版本可管理**：冲突信息明确标注权威版本，旧版本不删除但标记废弃
4. **敏感信息隔离**：内部敏感数据（信用代码、手机号、财务、股权）标注警示
5. **客户开发导向**：03/04分类为核心模块，支持按国家、按客户类型快速调用
6. **持续更新**：每季度复盘，新资料及时入库
