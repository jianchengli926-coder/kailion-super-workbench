# 团队协作流程与工具

> ⚠️ **重要声明**：本文件为**建议方案，需根据公司实际调整**。
>
> 锴利国际目前为 OPC 一人公司 + 兼职模式，尚无成熟的团队协作流程。下文所列晨会/周报/月度复盘机制与工具栈推荐为**未来 5–10 人小团队的轻量级协作蓝图**，优先选择免费/低成本工具，避免过度工程化。

---

## 一、日常协作节奏

### 1.1 晨会（每日，15 分钟）

| 项目 | 内容 |
|---|---|
| 时间 | 每天上午 9:30–9:45（阳东本地团队）；远程成员异步文字打卡 |
| 形式 | 飞书/钉钉群语音站会，或腾讯会议 |
| 议程 | ① 每人说 3 件事：昨天完成了什么 / 今天计划做什么 / 有什么卡点 |
| 红线 | 不超过 15 分钟，不展开讨论，复杂问题会后单独拉会 |

> 早期 OPC 阶段，晨会即 CEO 自己列当日 TODO；团队到位后再拉通。

### 1.2 周报（每周五下班前）

每人在飞书多维表格/Notion 提交：

| 栏目 | 内容 |
|---|---|
| 本周完成 | 量化数据（开发客户数/发素材条数/订单数/广告花费） |
| 下周计划 | 3–5 件重点事 |
| 卡点求助 | 需要谁配合、什么资源 |
| 行业观察 | 本周看到的竞品/客户/行业动态（鼓励分享） |

### 1.3 月度复盘会（每月最后一个周五，2 小时）

| 议程 | 时长 |
|---|---|
| 数据回顾（销售额/询盘量/广告 ROAS/交付率） | 30 分钟 |
| 本月 Top 3 亮点 & Top 3 问题 | 30 分钟 |
| 下月目标与责任人 | 30 分钟 |
| 自由讨论与流程改进建议 | 30 分钟 |

### 1.4 季度战略会（每季度，半天）

- CEO 主持，全体参与；
- 回顾季度 OKR 达成情况；
- 调整下季度重点方向（如从"打基础"转向"放量"、从"独立站"扩展到"Amazon"）；
- 复盘团队协作问题与工具效率。

## 二、推荐工具栈

> 原则：**免费优先、集成优先、不超过 5 个工具**。早期团队不要同时上飞书+钉钉+Slack+Notion+Asana，工具碎片化比没有工具更伤。

### 2.1 内部沟通与文档

| 工具 | 用途 | 推荐理由 | 成本 |
|---|---|---|---|
| **飞书（Lark）** | 内部沟通 + 文档 + 多维表格 + 日历 | 国产免费、文档协同强、多维表格可做轻量 CRM；公司已在用飞书知识库 | 免费版足够 |
| 备选：钉钉 | 如团队更习惯阿里系 | 考勤/审批强 | 免费版 |
| 备选：Slack | 如全员海外时区 | 海外团队习惯 | 免费版有限 |

> 公司当前已有飞书知识库，建议**主用飞书**，不再引入 Slack/钉钉。

### 2.2 客户管理（CRM）

| 工具 | 用途 | 推荐理由 |
|---|---|---|
| **飞书多维表格**（早期） | 客户档案、跟进记录、订单台账 | 零成本、与飞书打通、自定义字段灵活；见 `03_客户开发与CRM/16_CRM字段定义与数据规范.md` |
| GoodJob CRM（公司已有） | 轻量 CRM 工作台 | 见 `08_AI工作流与工具/04_企业CRM工作台_GoodJob.md` |
| 进阶：HubSpot Free / Zoho CRM | 客户多了之后迁移 | B2B 专业 CRM，但学习成本高 |

> 早期不建议上 Salesforce 等重型 CRM，飞书多维表格 + 规范字段足够用。

### 2.3 项目与任务管理

| 工具 | 用途 |
|---|---|
| **飞书任务/多维表格看板** | 每日 TODO、订单跟进、素材需求单 |
| 备选：Notion | 知识库 + 任务（如团队偏英文环境） |
| 备选：Trello | 简单看板 |

### 2.4 财务与订单

| 工具 | 用途 |
|---|---|
| **XTransfer** | 大额收款（退税首选），见 `11_订单与财务/05_付款条款详解.md` |
| PayPal Business | 样品单/小单收款 |
| 飞书多维表格 / Excel | 订单台账、PI、发票记录 |
| 银行对公户 | 定金/尾款 T/T 收款 |

### 2.5 设计与素材

| 工具 | 用途 |
|---|---|
| Google Drive / 飞书云盘 | 产品图、视频素材归档（按 SKU 命名） |
| Photoshop / Lightroom | 产品图精修 |
| 剪映专业版 / CapCut | 视频剪辑（国内初剪 + 海外二渲） |
| Canva Pro | 快速出社媒图 |
| Midjourney / Gemini | AI 辅助出图（仅作灵感，不替代实拍） |

### 2.6 AI 工作流

| 工具 | 用途 |
|---|---|
| ChatGPT / Claude | 英文开发信、报价邮件、SEO 文案 |
| 豆包企业版 | 中文文档、PPT、资料整理 |
| Codex / Cursor | 独立站代码修改 |
| Dify | 公司内部 AI 工作流编排（见 `08_AI工作流与工具/Dify工作流/`） |
| 本地 Mac mini + 外置 SSD | AI 引擎与知识库数据存储（见 `09_行业知识与培训/06_培训课程体系.md` 模块 2） |

### 2.7 社媒与广告

| 工具 | 用途 |
|---|---|
| Meta Business Suite | Facebook/Instagram 发布与广告 |
| TikTok Ads Manager | TikTok 广告 |
| Google Search Console + GA4 | 独立站流量分析 |
| LinkedIn Sales Navigator | B2B 客户开发（进阶） |
| 静态住宅 IP + 多浏览器指纹 | 账号防封（见 `03_客户开发与CRM/09_跨境网络与基础设施SOP.md`） |

## 三、客户分配与跟进机制

### 3.1 客户分配原则

1. **CEO 统一分配**：早期客户资源不私有化，所有新询盘由 CEO 在每日晨会后分配；
2. **按行业/地区分工**（客户多了之后）：
   - 业务员 A：北美 Amazon/Shopify 卖家
   - 业务员 B：欧洲批发商/品牌商
   - 业务员 C：中东/东南亚新兴市场
3. **独立站询盘默认归分配业务员**，但客户档案必须进 CRM，不能只存在个人邮箱；
4. **禁止反跳单**：任何人不得将公司客户引导至私人账户，详见 `11_订单与财务/03_禁止反跳单协议.md`。

### 3.2 客户跟进 SOP

| 客户级别 | 跟进频率 | 负责人 |
|---|---|---|
| A 级（已成交/高潜） | 每周至少 1 次 | 业务员 |
| B 级（有意向/已寄样） | 每两周 1 次 | 业务员 |
| C 级（询盘过未回） | 每月 1 次，连续 3 个月无回应降级 | 业务员 |
| D 级（无效/同行/骗子） | 标记归档，不再跟进 | 业务员 |

> 详见 `03_客户开发与CRM/02_客户分级管理_ABCD.md`、`13_客户分级管理体系.md`。

## 四、跨部门协作流程

### 4.1 业务 → 供应链（订单交付流）

```
业务员拿到客户 PO
  → 在 CRM 创建订单（填写产品/数量/交期/包装要求）
  → 供应链对接工厂排产
  → 供应链中期 QC（拍照）
  → 业务员跟客户确认产前样（如需要）
  → 供应链尾期 QC（全检/抽检）
  → 业务员收尾款
  → 供应链订舱发货
  → 业务员交单给客户
```

### 4.2 业务/运营 → 设计（素材需求流）

```
需求方在飞书多维表格提需求单
  （类型：产品图/社媒图/视频/包装；SKU；截止时间；参考链接）
  → 设计师每日 10:00 / 16:00 集中处理需求
  → 初稿交付到云盘，需求方在线反馈
  → 最多 2 轮修改，超出需升级 CEO
  → 终稿归档，按 SKU 命名
```

### 4.3 客服 → 供应链（投诉处理流）

```
客服收到客户投诉（质量/物流/错发）
  → 24h 内先安抚客户，登记工单
  → 同步供应链核查工厂/货代责任
  → 48h 内给出方案（补发/折扣/退款）
  → 方案报 CEO 审批后执行
  → 客服跟进客户确认满意
  → 月度复盘投诉 Top3，反馈供应链改进
```

### 4.4 新媒体 → 设计 → 业务（内容获客流）

```
新媒体排期下周内容选题
  → 提素材需求给设计（产品场景图/工厂视频素材）
  → 设计交付素材
  → 新媒体剪辑/配文发布
  → 独立站/社媒带来新询盘
  → 询盘回流业务部分配跟进
```

### 5.2 文档命名规范

- 文件名格式：`序号_主题_关键词.md`（如 `09_组织架构与岗位职责.md`）
- 所有 .md 文件带 YAML frontmatter（title/type/category/tags/status/source/last_updated）
- 图片素材按 SKU 命名，详见 `KaiLionCrafts_公司工厂图片SEO命名超级指令_V2融合终极版.md`

### 5.3 知识贡献机制

- 任何人在客户沟通中发现新 FAQ → 补录到 `03_客户开发与CRM/11_通用客户FAQ.md`；
- 任何人发现工厂质量问题 → 反馈到 `01_公司与品牌/工厂与供应链/08_供应链风险识别与应对.md`；
- 新开发的 AI 提示词 → 沉淀到 `08_AI工作流与工具/AI提示词库/`；
- 每月评选"最佳知识库贡献者"，奖励 $50。

## 六、远程与混合办公

- 早期团队可接受混合办公（阳东本地 + 远程），但**供应链/设计岗位建议驻阳东**（便于工厂实拍与验货）；
- 远程成员必须：
  1. 工作日对应时段在线（欧美客户沟通时段需值班）；
  2. 所有客户沟通走企业邮箱/CRM，不走私人微信；
  3. 每周至少 1 次同步会议开摄像头；
- 跨境网络：所有海外社媒/Google/AI 工具必须走公司统一静态住宅 IP，禁止个人 VPN，详见 `03_客户开发与CRM/09_跨境网络与基础设施SOP.md`。
