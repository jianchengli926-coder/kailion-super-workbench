# 原产地证 Certificate of Origin 模板

> **使用说明**：原产地证（COO）证明货物"中国制造"，是进口国海关征收关税的依据。
> 优惠原产地证可帮客户减免进口关税，是重要的客户增值服务。
> 出货前根据目的国选择对应 Form，向贸促会（CCPIT）或海关（GACC）申请。

## 二、优惠原产地证对比一览

| Form 名称 | 全称 | 适用国家/地区 | 关税优惠 | 签发机构 |
|-----------|------|-------------|---------|---------|
| **Form A** | 普惠制原产地证 | 已不再适用（中国2021年毕业，欧盟等不再给惠） | ~~普惠制关税减免~~（已终止） | — |
| **Form E** | 中国-东盟自贸区原产地证 | 东盟10国：泰国、越南、马来西亚、印尼、菲律宾、新加坡、文莱、缅甸、老挝、柬埔寨 | 自贸协定税率（0%–5%） | 海关 GACC |
| **Form F** | 中国-智利自贸区原产地证 | 智利 | 中智自贸协定税率（多数产品0%） | 海关 GACC |
| **Form CP** | 中国-巴基斯坦自贸区原产地证 | 巴基斯坦 | 中巴自贸协定税率（多数产品0%） | 海关 GACC |
| **Form RCEP** | 区域全面经济伙伴关系协定原产地证 | 东盟10国+日本+韩国+澳大利亚+新西兰 | RCEP协定税率（逐年降税至0%） | 海关 GACC / 贸促会 |
| **Form FTA** | 中国-韩国/澳大利亚/瑞士/冰岛等 | 对应自贸伙伴国 | 双边自贸协定税率 | 海关 GACC |
| **一般 CO** | 非优惠原产地证 | 全球通用 | 无优惠（最惠国税率） | 贸促会 CCPIT / 海关 |

### 各 Form 适用场景速查

| 目的国 | 推荐 Form | 说明 |
|--------|----------|------|
| 美国 | 一般 CO | 美国不给中国普惠制待遇，无优惠 Form |
| 欧盟（德/法/意等） | 一般 CO | 中国已从欧盟普惠制毕业，Form A 失效 |
| 英国 | 一般 CO | 同欧盟 |
| 日本 | **Form RCEP** | RCEP 项下关税逐年递减 |
| 韩国 | **Form RCEP** 或中韩 FTA | RCEP 与中韩 FTA 择优选用 |
| 澳大利亚/新西兰 | **Form RCEP** 或中澳/中新 FTA | 多数刀剪产品已0%关税 |
| 泰国/越南/马来/印尼 | **Form E** 或 Form RCEP | 东盟国家，Form E 税率通常更优 |
| 智利 | **Form F** | 中智自贸，多数产品0% |
| 巴基斯坦 | **Form CP** | 中巴自贸，多数产品0% |
| 俄罗斯/CIS | 一般 CO | 暂无优惠自贸安排 |
| 印度 | 一般 CO | 中印无优惠自贸安排 |
| 中东（沙特/阿联酋等） | 一般 CO | 暂无优惠自贸安排 |

## 三、Form E（中国-东盟）填制要点

> 东盟订单最常用的优惠产地证。

| Box | 填写要求 |
|-----|---------|
| Box 1 Exporter | 本公司完整名称地址 |
| Box 2 Consignee | 东盟买方完整名称地址（与 CI 一致） |
| Box 3 Means of Transport | 如 "By Sea from Yantian to Bangkok" |
| Box 5 Items | 项号 1, 2, 3... |
| Box 6 Marks | 与唛头一致 |
| Box 7 Packages & Description | `[XXX] Cartons of [Product]` |
| Box 8 Origin Criterion | **"WO"**（完全原产）或 **"PE"**（含进口成分但符合区域价值成分） |
| Box 9 Gross Weight | 总毛重 KGS |
| Box 10 Invoice No. & Date | 与 CI 一致 |
| Box 12 Declaration by Exporter | 出口商声明+签字 |
| Box 13 Certification | 海关签章 |

> **Origin Criterion 选择**：
> - `WO` = Wholly Obtained（完全在中国获得/生产）——金属制品如在中国完整加工，可填 WO
> - `PE` = Produced Entirely / Substantial Transformation（区域价值成分≥40%）——如进口钢材加工后出口
> - 刀具用进口钢材（如日本 VG10），通常填 PE，需保留原材料采购凭证备查

## 四、Form RCEP 填制要点

> RCEP 覆盖15国，是目前最通用的优惠产地证。

| 要点 | 说明 |
|------|------|
| **原产地标准** | "WO" 完全获得 / "RVC" 区域价值成分≥40% / "CTC" 税则归类改变 |
| **背书规则** | 可在 RCEP 成员国之间流转（背对背原产地证明） |
| **关税减让** | 各成员国承诺不同，刀剪类多数在第11年降为0% |
| **签发机构** | 海关（GACC）或贸促会（CCPIT）均可签发 |
| **背对背证明** | 如经新加坡/韩国转运，可申请中转国签发背对背产地证 |

## 申领流程

```
出货前 3–5 天
  ↓
准备资料：CI 草稿、PL 草稿、合同、产品 HS Code、原材料采购发票
  ↓
在单一窗口（国际贸易单一窗口）在线申报
  ↓
审核通过（通常 1 个工作日）
  ↓
领取纸质证书（海关/贸促会窗口自取或邮寄）
  ↓
出货后将证书副本寄给客户（客户凭此清关享优惠税率）
```

### 申领所需材料

| 材料 | 说明 |
|------|------|
| 商业发票 CI 草稿 | 含货物描述、数量、金额 |
| 装箱单 PL 草稿 | 含件重尺 |
| 外贸合同/PI | 证明贸易真实性 |
| 产品 HS Code | 与报关一致 |
| 原材料采购发票 | 如适用 PE/RVC 原产地标准，需证明国内增值比例 |
| 产品照片/工艺流程 | 如签证机构审核需要 |

### 费用

| 项目 | 费用 |
|------|------|
| 一般 CO（贸促会） | RMB 50–100/份 |
| 优惠 Form E/RCEP（海关） | 免费（无纸化） |
| 加急 | 加 RMB 50–200 |
| 邮寄 | 到付或顺丰到付 |

## 填写说明

1. **所有单证信息一致**：产地证上的 Exporter、Consignee、货物描述、件数、重量、发票号必须与 CI/PL 完全一致
2. **货物描述**：用大类名称（如 "Stainless Steel Kitchen Knives"），不可写客户品牌名
3. **Country of Origin**：一律填 "P.R. China" 或 "China"
4. **日期逻辑**：产地证签发日期不得早于发票日期，不得晚于提单日期
5. **第三方发票**：如发票由香港/新加坡贸易商开具，需在产地证上注明第三方发票信息

## 常见错误

1. **选错 Form**：出口日本用 Form E 无效，必须用 RCEP 或中日韩相关 Form
2. **货物描述与 CI 不一致**：一个单词不同都可能被目的国海关拒认优惠
3. **Origin Criterion 填错**：进口钢材加工的产品填 WO 会被海关核查，需填 PE/RVC
4. **漏盖签证章**：产地证必须有签证机构签字+公章才有效
5. **日期逻辑错误**：签发日期早于发票日期 = 无效证书
6. **买方信息错误**：Consignee 必须与清关一致，不可填货代
7. **Form E 后发**：Form E 必须在装船前或装船后3天内申请，逾期无法签发
8. **忘记寄正本**：客户需要**正本**产地证才能享优惠税率，副本不行

## 注意事项

- **客户主动要求**：很多客户会在 L/C 或合同中明确要求提供某种 Form，务必提前确认
- **客户省钱就是卖点**：Form E/RCEP 可帮客户省 5%–15% 进口关税，主动询问客户目的国并推荐对应 Form
- **后发证书**：如出货后忘记申请，部分 Form 可在装船后1年内申请"后发证书"（Issued Retrospectively），但需标注
- **更改重发**：如证书有误，需退回原证后重发，不可自行涂改
- **电子原产地证**：目前 RCEP 等已支持电子证书（e-CO），客户可在目的国海关系统直接查验
- **刀具管制**：刀具出口需 PSB 备案，产地证申请不影响 PSB 流程，两者独立办理
