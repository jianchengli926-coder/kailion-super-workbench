# 供应链风险识别与应对

> 本文件归档供应链全链路风险分类、应对策略与预警机制，供运营/跟单/创始人决策使用。
> ⚠️ 数据边界：风险应对策略结合公司已有真实能力（三道 QC、30 分钟半径、双供应链、海外仓）设计；具体风险发生概率、影响金额、对冲成本原始资料未提供，标注「⚠️待确认」。
> 业务背景：阳江刀剪产业带，30 分钟供应链半径；4 家家族股权工厂 + 36 家归档工厂；美国三仓现货（NJ/TX/CA）；80% B2B + 20% B2C。

## 一、风险分类矩阵（发生概率 × 影响程度）

> 概率与影响评级为定性判断（高/中/低），基于业务结构推断；⚠️ 具体数值化评分待运营数据积累后校准。

| 风险类别 | 发生概率 | 影响程度 | 风险等级 | 现有缓解基础 |
|---|---|---|---|---|
| 原材料涨价（钢材/塑料粒/木材） | 中-高 | 中 | 🟡 高 | 天澳/广和/Outokumpu 已有渠道；垂直整合 |
| 旺季产能不足 | 中 | 中 | 🟡 高 | 股权方优先排产权；36 家归档工厂备份 |
| 质量波动/客户索赔 | 中 | 高 | 🔴 极高 | 三道 QC + 7 项测试 + 创始人亲审 + 终身质保 |

## 二、原材料涨价风险

### 2.1 风险描述

刀剪产品成本结构中，钢材（天澳钢板/Outokumpu 进口不锈钢）、塑料粒（广和 ABS/POM）、木材（Homeful FSC 木盒）、包装材料占主要变动成本。钢材为大宗商品，价格随铁矿石/镍/铬等大宗商品周期波动；进口不锈钢（Outokumpu）叠加汇率与海运波动。

### 2.2 影响传导

```
钢材/塑料粒/木材涨价
  → 工厂材料成本上升
  → 报价有效期缩短（当前 PI 报价有效期 15–30 天）
  → 若签约时锁价、交货时涨价，吃掉毛利
  → 海外售价若无法同步上调，利润率压缩
```

### 2.3 应对策略

| 策略 | 具体动作 | 当前状态 |
|---|---|---|
| **长期协议** | 与天澳钢板、广和塑料签订年度框架协议，锁定基准价+调价机制 | ⚠️待确认（是否已签年度协议资料未提供） |
| **套期保值/批量锁价** | 钢材价格高位时按需批量锁价；⚠️具体套期保值工具公司未开展 | ⚠️待确认 |
| **替代材料** | 多钢材等级备选（5Cr15MoV / 3Cr13 / VG10 / 9Cr18MoV / 1.4116），客户可接受时切换性价比更高的钢种；手柄多材质（POM/ABS/G10/Micarta/木材）可替代 | ✅ 已有多材料清单（见 `02_生产工艺与质量控制.md`） |
| **报价有效期管理** | PI 报价有效期 15–30 天，材料剧烈波动时缩短至 7–15 天；大单约定材料调价联动条款 | ✅ 已有报价有效期机制 |
| **垂直整合对冲** | 4 家股权工厂直供，压缩中间环节，吸收部分材料涨价 | ✅ 家族股权直供模式 |
| **汇率对冲** | 进口 Outokumpu 不锈钢涉及欧元/美元结算；⚠️具体结汇策略待确认 | ⚠️待确认 |

## 三、产能不足风险

### 3.1 风险描述

- 旺季（Q3-Q4 礼品季/黑五/圣诞）订单集中爆发，4 家股权工厂产线排满。
- 单一工厂（如 Amber 厨刀主力）同时接多个大客户订单时产能瓶颈。
- Keenhope 羽毛纹大马士革为高端手工线，产能天然有限。

### 3.2 应对策略

| 策略 | 具体动作 | 当前状态 |
|---|---|---|
| **提前排产** | 股权方享有优先排产权，核心客户旺季不排队；旺季前 60 天锁定排产计划 | ✅ 已成文（`06_供应链管理SOP.md`） |
| **多厂分配** | 按品类分工派单（厨刀→Amber、全工艺→YeYu、包装→Homeful、高端→Keenhope），不跨品类混派；非核心订单分流至 36 家 A 级归档工厂 | ✅ 已有订单分配矩阵 |
| **备选厂应急切换** | 旺季主供排满时，从 36 家归档库启用备选厂打样/小批量承接 | ⚠️ 具体备选厂名单待 Leo 指定（见 `07_供应商评估与管理.md` 第四节） |
| **扩产计划** | 股权工厂根据年度订单增长评估增设备/增工人 | ⚠️待确认（具体扩产计划资料未提供） |
| **小单柔性承接** | 大厂不接的 50–150pcs 小单走股权工厂柔性产线 + 协会资源 | ✅ MOQ 50pcs 起 |
| **海外仓前置备货** | 旺季热销 SKU 提前海运备入美国三仓，降低对国内即时产能的依赖 | ✅ 美国三仓现货体系 |

## 四、质量波动风险

### 4.1 风险描述

- 不同批次钢材硬度/成分波动 → HRC 不稳定 → 锋利度/耐久下降。
- 热处理（菜刀炉淬火+氮化）工艺波动 → 刃口开裂/崩口。
- 手柄装配不良 → 拉力测试不达标（汇达厂第⑦项测试）。
- 抛光/开刃一致性差 → 客户投诉。

### 4.2 应对策略（已有真实能力）

| 策略 | 具体动作 | 当前状态 |
|---|---|---|
| **三道 QC** | ①来料检验（钢材硬度/成分不合格不投产）②过程中检（一排质检员逐件检查，不合格不流入下道）③出厂终检（强光台戴无尘手套逐把全检） | ✅ 已成文（`02_生产工艺与质量控制.md` 第三节） |
| **7 项极限测试** | 汇达厂外协：HRC 硬度 / 刀刃角度 / 锋利度（240fps）/ 洗碗机 / 盐水浸泡 / 盐雾防锈 / 拉力抗弯 | ✅ 已成文 |
| **产前 QC 视频** | 工厂拍材料/工艺/外观视频，创始人复核 → 客户确认后再批量 | ✅ 已成文 |
| **发货前视频验货** | 创始人亲自审验货视频（包装/标签/锋利度/装配）→ 客户批准后发货，**无客户批准不发货** | ✅ 已成文 |
| **供应商质量协议** | 与工厂约定质量标准、不良品责任、退换条款 | ⚠️ 是否已签正式质量协议待确认（NDA/防规避协议已有） |
| **终身质保兜底** | 产品材料工艺问题终身质保；刃口 10 年；手柄/刀身装配 2 年；不达标准全额退换 | ✅ 四级质保已成文 |
| **测试数据真实可追溯** | 所有对外测试数据真实，不虚构；数据弹窗须工厂确认 | ✅ 已成文 |

### 4.3 质量异常响应

```
客户投诉/退货
  → 问题直达创始人（不经过多层中转）
  → 调取该批次三道 QC 记录 + 7 项测试报告 + 钢材材质证明（Outokumpu EN 10204-3.1）
  → 定位根因（来料/工艺/运输）
  → 快速公平透明处理（退换/退款/补样）
  → 整改项反馈工厂，纳入下次飞行检查
```

## 五、交期延误风险

### 5.1 风险描述

- 原材料缺货（天澳钢板/广和塑料粒断供）→ 投产延迟。
- 热处理/开刃等瓶颈工序排队 → 生产周期拉长。
- 海运旺季舱位紧张/港口拥堵 → 头程延误。
- 美国仓补货不及时 → 现货断货。

### 5.2 应对策略

| 策略 | 具体动作 | 当前状态 |
|---|---|---|
| **三级交期管理** | 现货 ≤7 天 / 定制 Logo ≤15 天 / 全 ODM ≤30 天；对外口径以报价单为准 | ✅ 已成文 |
| **安全库存** | 海外仓热销 SKU 设安全库存阈值，≤阈值触发补货 | ✅ P0-P3 补货优先级已成文（`12_库存周转与滞销品处理.md`） |
| **多供应商/多物流通道** | 海运（20-35 天）/空运（7-15 天）/国际快递（3-7 天）/海外仓现货（1-3 天）四通道备选；紧急走空运 | ✅ 四通道已成文 |
| **缓冲期** | 对外交期预留缓冲；大货 PI 约定延期罚则（⚠️具体罚则条款待确认） | ⚠️待确认 |
| **30 分钟半径现场处理** | 办公室位于阳江制造核心区，异常直接下车间，不等远程邮件 | ✅ 已成文 |
| **旺季提前备货** | 热销 SKU 旺季前海运备入美国三仓，降低国内即时交付压力 | ✅ Test-Scale-Brand 路径 |

## 六、地缘政治风险

### 6.1 风险描述

- **中美贸易摩擦/关税**：美国对华刀剪产品加征关税；DDP 报价需覆盖目的国关税。
- **制裁/出口管制**：俄罗斯/CIS 方向受制裁需人民币结算；⚠️ 具体制裁清单待按市场确认。
- **仿牌合规风险**：已有 11 个仿牌 SKU（如 KL-OD-SS-029 仿 SOG），出口目标国知识产权诉讼风险。
- **刀具出口管制**：每把刀出口前公安备案；不同国家对户外刀/折叠刀进口法规不同。

### 6.2 应对策略

| 策略 | 具体动作 | 当前状态 |
|---|---|---|
| **海外仓本地化** | 美国三仓（NJ/TX/CA）现货 1-3 天达，部分规避直邮关税时效敏感度；本地发货 B2C 体验 | ✅ 已成文 |
| **原产地多元化** | 目前 100% 阳江制造；⚠️ 是否评估东南亚/其他产地备原产地待确认 | ⚠️待确认 |
| **多市场分散** | 客户覆盖 130+ 国家和地区，不过度依赖单一市场；80% B2B 稳定基本盘 + 20% B2C | ✅ 已成文 |
| **DDP 双清到门** | 无进口经验的小买家走 DDP，关税由卖家核算；提前核算目的国关税（印度高关税、俄罗斯制裁人民币结算） | ✅ 已成文 |
| **出口合规** | 每把刀出口前公安备案；刀具走有资质专线；100% 合法合规 | ✅ 已成文（`06_供应链管理SOP.md` 第六节） |
| **仿牌 SKU 清理** | 11 个仿牌 SKU 不对外推广（KL-OD-SS-029 已标注"不建议对外推广"）；逐步替换为自有品牌 | ✅ 已有决策记录（`02_产品知识库/户外刀具/仿牌SKU处理决策.md`） |
| **NDA + 防规避** | 与工厂/客户签 NDA + anti-circumvention，保护客户不被工厂绕单 | ✅ 已成文 |

## 七、自然灾害/疫情/突发停工风险

### 7.1 风险描述

- 阳江地区台风/暴雨/停电 → 工厂停工。
- 疫情/公共卫生事件 → 工人到岗率下降、物流中断。
- 单厂火灾/设备事故 → 该品类短期断供。

### 7.2 业务连续性计划（BCP）框架

> ⚠️ 公司尚未成文正式 BCP 文件；以下为基于现有多厂布局设计的 BCP 框架，待 Leo 确认后细化。

| 恢复阶段 | 动作 | 现有基础 |
|---|---|---|
| **T+0（事件发生）** | 创始人 30 分钟半径内现场评估各厂受损情况；通知在途客户预期影响 | ✅ 30 分钟半径 |
| **T+1~3 天** | 受损品类订单分流至同品类其他工厂（厨刀→Amber 受损则⚠️待备选厂）；海外仓现货订单不受影响继续履约 | ⚠️ 备选厂名单待补 |
| **T+1~2 周** | 启动未受损工厂优先排产；交期与客户重新协商 | ✅ 股权方优先排产权 |
| **T+2~4 周** | 受损工厂恢复后回切；复盘事故，更新 BCP | — |
| **长期** | 关键品类至少 2 地工厂可生产；避免单厂单点故障 | ⚠️ 当前 4 家均在阳江，地理集中度高 |

- ⚠️ **地理集中度风险**：4 家股权工厂 + 36 家归档厂均在阳江/阳东地区，台风/区域性灾害可能同时影响多家工厂。这是当前 BCP 的最大结构性短板。
- 保险：⚠️ 工厂财产险/营业中断险（BI）投保情况待确认。

## 八、其他风险（认证/库存/物流/合规）

### 8.1 认证失效风险

- BSCI C 评级（YeYu，2027-04 到期）——若不升级，大客户审计扣分。
- FSC（Homeful，2029-04 到期）——木盒包装合规依赖此证。
- 应对：认证到期前 60 天启动续证；台账见 `07_供应商评估与管理.md` 第 6.2 节。

### 8.2 海外仓滞销风险

- 库存 >180 天未动销 → 滞销；占仓租 + 资金占用。
- 应对：Test-Scale-Brand 测款机制（新品小批试仓，动销好再追加）；滞销四方式处理（打折/捆绑/退回阳江/捐赠）。详见 `06_海外仓与订单物流/12_库存周转与滞销品处理.md`。

### 8.3 物流中断风险

- 海运旺季舱位紧张/苏伊士运河/港口拥堵。
- 应对：四通道备选（海运/空运/快递/海外仓）；长期合作私人货代签约舱位；⚠️ 货代备选待确认。

### 8.4 知识产权/仿牌风险

- 11 个仿牌 SKU 潜在侵权诉讼。
- 应对：不对外推广仿牌；逐步替换；NDA + 防规避保护客户资源。

## 九、风险监测与预警机制

### 9.1 预警指标看板（建议）

| 监测项 | 预警阈值（建议） | 数据来源 | 频次 |
|---|---|---|---|
| 钢材/塑料粒价格波动 | ⚠️待确认（如月涨幅 >5% 预警） | 材料供应商报价 | 月度 |
| 关键 SKU 库存 | 库存 ≤ 安全库存阈值 | 海外仓库存表 | 每日 |
| 滞销 SKU | >180 天未动销 | 库存周转分析 | 每周 |
| 准时交付率（OTD） | ⚠️待确认（如 <95% 预警） | 订单跟踪 | 月度 |
| 出厂不良率 | ⚠️待确认 | 三道 QC 记录 | 每批 |
| 客户退货/索赔率 | ⚠️待确认 | 售后记录 | 月度 |
| 认证到期 | 到期前 180 天黄色预警 / 60 天红色预警 | 认证台账 | 季度 |
| BSCI 评级改进 | C→B 升级进度跟踪 | YeYu 工厂 | 季度 |
| 关税/政策变动 | 美国/欧盟/目标市场关税新政 | Google 资讯/货代通知 | 持续 |
| 台风/恶劣天气 | 气象预警（阳江 6-10 月台风季） | 气象局 | 台风季每日 |

### 9.2 风险响应分级

| 级别 | 定义 | 响应人 | 响应时限 |
|---|---|---|---|
| 🔴 P0 紧急 | 断供/质量事故/认证吊销/重大客户索赔 | 创始人直接 | 24 小时内启动 |
| 🟡 P1 高 | 交期延误/库存告急/材料涨价超阈值 | 跟单 + 采购 | 3 个工作日内方案 |
| 🟢 P2 中 | 认证续证/备选厂打样/流程优化 | 采购/运营 | 月度计划内 |

### 9.3 复盘机制

- 每起 P0/P1 事件后输出《风险事件复盘报告》：根因、应对动作、改进项、更新 BCP。
- 每季度更新本风险矩阵，校准概率/影响评级。
- 每年全面审视供应链韧性（多源率、地理分散度、BCP 演练）。
