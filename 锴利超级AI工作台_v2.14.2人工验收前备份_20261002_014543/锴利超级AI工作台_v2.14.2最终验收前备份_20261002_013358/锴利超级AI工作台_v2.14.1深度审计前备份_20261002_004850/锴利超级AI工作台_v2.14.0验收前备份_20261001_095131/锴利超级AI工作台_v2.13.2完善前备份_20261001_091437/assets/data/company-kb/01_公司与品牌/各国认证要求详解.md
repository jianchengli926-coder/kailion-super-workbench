# 各国认证要求详解

> 本文件是 `产品认证标准库.md` 的**逐国深度补充**：按国家列出每个认证的测试项目、费用区间、周期、发证机构、有效期。
> ⚠️ 费用为 2025–2026 年第三方实验室（SGS/BV/Intertek/TÜV）市场参考区间，实际以报价为准。法规更新频繁，发货前与目的国报关行/CAB 确认。
> 已有23组工厂认证清单见 `04_产品合规认证体系.md`。

## 一、美国 USA

### 1.1 FDA 21 CFR（食品接触材料）
| 项目 | 内容 |
|---|---|
| 法规依据 | 21 CFR Part 174–199（间接食品添加剂）；21 CFR 109.6 铅 |
| 适用产品 | 厨刀、厨房剪、削皮器、食品夹铲等一切接触食品的金属/塑料件 |
| 测试项目 | ①不锈钢成分合规（耐蚀无毒）；②铅迁移（≤0.005 µg/mL，AOAC 973.32 ICP-MS）；③重金属溶出（镉/铬/镍）；④橡胶/塑料手柄按对应聚合物法规 |
| 费用 | $500–2,000/材质 |
| 周期 | 1–2 周 |
| 发证机构 | FDA **不发证书**；第三方实验室（SGS/BV/Intertek）出测试报告，制造商自行合规 |
| 有效期 | 无固定期；材料/工艺变更重测 |
| 来源 | https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfcfr/cfrsearch.cfm |

### 1.2 CPSIA（消费品安全改进法）
| 项目 | 内容 |
|---|---|
| 法规依据 | Consumer Product Safety Improvement Act 2008；CPSC 16 CFR Parts 1303/1307 |
| 适用产品 | ⚠️ **12岁以下儿童产品**；成人厨刀/户外刀不适用 |
| 测试项目 | ①总铅（表面涂层≤90ppm、基材≤100ppm）；②邻苯二甲酸酯（DEHP/DBP/BBP/DINP/DIDP/DnOP ≤0.1%）；③需 CPSC 认可第三方实验室 |
| 费用 | $1,000–3,000/款 |
| 周期 | 3–5 周 |
| 发证机构 | CPSC-accepted Third-Party Lab；出具 Children's Product Certificate (CPC) |
| 有效期 | 无固定期；材料变更重测 |
| 对刀剪影响 | 仅儿童安全剪刀、儿童厨房套装触发；成人刀剪无需 |
| 来源 | https://www.cpsc.gov/Regulations-Laws--Standards/CPSIA |

### 1.3 加州 Proposition 65
| 项目 | 内容 |
|---|---|
| 法规依据 | California Safe Drinking Water and Toxic Enforcement Act of 1986 |
| 适用产品 | 所有在加州销售的产品（电商卖到加州即触发） |
| 重点物质 | 铅（黄铜手柄/焊点）、镉、镍（不锈钢析出） |
| 测试项目 | 可浸出铅/镉总量测试；总含量测试 |
| 费用 | $300–1,500/材质 |
| 周期 | 1–2 周 |
| 发证机构 | 第三方实验室测试报告；警告标签自行加贴 |
| 有效期 | 无固定期；新物质列入需重评 |
| 执法特点 | **私人执法**（bounty hunter 律所），和解金 $2,500–$50,000+；标签格式有严格要求 |
| 来源 | https://www.p65warnings.ca.gov/ |

### 1.4 加州 AB 1200 / 刀具零售相关
| 项目 | 内容 |
|---|---|
| 法规依据 | California AB 1200（刀具零售与配送相关）；各州 knife law |
| 要点 | 加州禁止向18岁以下销售刀具；自动刀≥2英寸禁售；网上销售须年龄验证 |
| 对出口影响 | B2C 直邮加州须遵守年龄验证配送；B2B 批发不受影响 |
| 来源 | https://leginfo.legislature.ca.gov/ |

### 1.5 原产国标记（19 U.S.C. 1304）
| 项目 | 内容 |
|---|---|
| 要求 | 每件产品须英文永久标注 "Made in China"；刀身/手柄可见处 |
| 关税 | HTSUS 8211 系列；中国原产加征 301 关税（具体税率以 USTR 最新清单为准） |

## 二、欧盟 EU

### 2.1 Regulation (EC) 1935/2004（食品接触框架法规）
| 项目 | 内容 |
|---|---|
| 法规依据 | (EC) No 1935/2004 框架；(EC) No 2023/2006 GMP 良好生产规范 |
| 适用产品 | 所有预期与食品接触的材料和制品 |
| 核心要求 | ①不释放危害健康成分；②不导致食品组成不可接受变化；③不损害感官特性 |
| 测试项目 | 总迁移量（10 dm²接触面）；特定重金属迁移；感官 |
| 费用 | $1,000–3,000/材质 |
| 周期 | 2–4 周 |
| 发证机构 | 公告机构(Notified Body)出报告；制造商签 DoC |
| 有效期 | 无固定期；标准更新重评 |
| 来源 | https://food.ec.europa.eu/safety/chemical-safety/food-contact-materials/legislation_en |

### 2.2 LFGB（德国食品和饲料法典）
| 项目 | 内容 |
|---|---|
| 法规依据 | LFGB；BfR Recommendations；DIN 10955 感官测试 |
| 适用产品 | 德国市场食品接触金属厨具；比 EU 1935/2004 更严 |
| 测试项目 | ①感官（气味/味道迁移 DIN 10955）；②总迁移；③重金属溶出（铅/镉/铬/镍）；④不锈钢成分 |
| 费用 | $1,500–4,000/材质 |
| 周期 | 3–5 周 |
| 发证机构 | SGS/TÜV Rheinland/TÜV SÜD |
| 有效期 | 材料变更重测；欧盟认可度高 |
| KaiLionCrafts | ✅ cert-07 SGS LFGB DMS-052 PASS；cert-10 感官 DIN 10955 PASS |
| 来源 | https://www.bfr.bund.de/en/service/databases/bfr-recommendations-on-food-contact-materials/ |

### 2.3 REACH（EC 1907/2006）
| 项目 | 内容 |
|---|---|
| 适用 | 所有出口欧盟产品 |
| 核心 | SVHC（高度关注物质）>0.1%(w/w) 须通报消费者/下游；每半年 ECHA 更新清单（目前 240+ 项） |
| 刀剪关注 | 镍（致敏）、铬、铅；塑料手柄邻苯二甲酸酯 |
| 费用 | $500–2,000 |
| 周期 | 2–4 周 |
| 来源 | https://echa.europa.eu/candidate-list-table |

### 2.4 RoHS 2011/65/EU + (EU) 2015/863
| 项目 | 内容 |
|---|---|
| 限制物质 | 铅/汞/镉/六价铬/PBB/PBDE/DEHP/BBP/DBP/DIBP（共10项） |
| 适用 | ⚠️ 仅电子电气设备；纯手动刀剪**不适用**；电动磨刀器/切片器适用 |
| 费用 | $300–1,000/材质 |
| 来源 | https://environment.ec.europa.eu/topics/waste-and-recycling/rohs-directive_en |

### 2.5 ⭐ GPSR (EU) 2023/988（通用产品安全法规，2024-12-13 生效）
| 项目 | 内容 |
|---|---|
| 法规依据 | Regulation (EU) 2023/988，**2024年12月13日起强制** |
| 适用产品 | 所有消费产品（含刀剪），取代旧 GPSD 2001/95/EC |
| 核心要求 | ①**欧盟境内必须有 Responsible Person（责任人）**——进口商、授权代表或履约服务商；制造商在欧盟境外时必须指定；②产品/包装/线上 listing 须标注制造商名称+地址+责任人联系方式；③附安全警告和使用说明；④线上 marketplace 卖家在范围内；⑤危险产品须通过 Safety Gate 通报 |
| 对刀剪影响 | 纯手动刀剪虽无 CE 强制，但**受 GPSR 管辖**：须有 EU Responsible Person、安全警告（"Keep away from children"等）、技术文档留存10年 |
| 费用 | 自行合规 $0–$500；委托 EU Rep 约 €300–1,000/年 |
| 周期 | 责任人指定 1–2 周 |
| 来源 | https://commission.europa.eu/business-economy-euro/product-safety-requirements/eu-general-product-safety-regulation_en ；欧盟委员会 Guidelines |

## 三、英国 UK

### 3.1 UKCA 标志
| 项目 | 内容 |
|---|---|
| 法规依据 | UK Product Safety Regulations；脱欧后替代 CE |
| 适用 | 英格兰/苏格兰/威尔士（GB）；北爱仍走 EU CE 规则 |
| 要点 | 纯手动刀剪无对应产品法规，不强制 UKCA；电动类需 UKCA |
| ⚠️ 过渡期 | 英国政府已宣布 **2027年12月31日前继续接受 CE 标志** |
| 费用 | $500–3,000（视产品类别） |
| 来源 | https://www.gov.uk/guidance/placing-ukca-or-ce-marked-products-on-the-market-in-great-britain |

### 3.2 英国食品接触材料法规
| 项目 | 内容 |
|---|---|
| 要点 | 脱欧后沿用 EU 1935/2004 规则；UK 实验室出具测试报告 |
| 来源 | https://www.gov.uk/government/publications/general-product-safety-regulations-northern-ireland |

### 3.3 英国刀具销售法规（2025–2026 重大更新）
| 项目 | 内容 |
|---|---|
| Crime and Policing Act 2026 | ①线上销售刀具**两步年龄验证**（下单时证件+人脸验证，配送时再核验）；②批量/可疑销售报告义务；③非锁定≤3英寸折刀豁免年龄验证 |
| 2025-08-01 起 | 禁止 ninja sword（忍者刀/长武士刀风格） |
| 2024-09 起 | 禁止 zombie knife（僵尸刀） |
| 来源 | https://www.gov.uk/government/publications/crime-and-policing-act-2026-factsheets/crime-and-policing-act-2026-knife-crime-and-crossbows-factsheet |

## 四、日本 Japan

### 4.1 食品衛生法（厚生劳动省告示第370号）
| 项目 | 内容 |
|---|---|
| 适用 | 食品接触金属器具 |
| 测试项目 | 重金属溶出（铅/镉/铬）；不锈钢成分 |
| 费用 | $500–1,500/材质 |
| 周期 | 2–3 周 |
| 发证机构 | 日本厚劳省登录检查机关；进口时日本检疫所查验 |
| 来源 | https://www.mhlw.go.jp/ |

### 4.2 PSE（电気用品安全法）
| 项目 | 内容 |
|---|---|
| 适用 | ⚠️ 仅电气用品；纯手动刀剪**不适用**；电动磨刀器适用 |
| 分类 | 特定电气用品（菱形PSE，需第三方+工厂检查）；非特定（圆形PSE，自行确认） |
| 费用 | 菱形 $5,000–6,500/6–8周；圆形 $700–2,000/1–3周 |
| 来源 | https://www.jetro.go.jp/world/qa/04M-010965.html |

### 4.3 日本刀具持有管制
| 项目 | 内容 |
|---|---|
| 法律 | 铳砲刀剣類所持等取締法 |
| 要点 | 刃长≥15cm 直刀需公安委员会登录；≥5.5cm 锁定折刀=刀剣类需许可；飛び出しナイフ（自动刀）不论刃长禁止 |
| 对出口影响 | B2B 厨刀不受影响；户外刀出口日本须选短刃/非锁定 |
