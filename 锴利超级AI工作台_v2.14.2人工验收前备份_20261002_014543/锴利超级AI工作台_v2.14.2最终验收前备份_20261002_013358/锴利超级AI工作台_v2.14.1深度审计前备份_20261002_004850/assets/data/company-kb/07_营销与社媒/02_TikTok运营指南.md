# TikTok 运营指南

## 一、平台定位

短视频带货 + 工厂过程化展示。短、直观、现场感强，是五金刀剪工厂实力外化的核心阵地。

## 二、账号搭建

- 纳入 4 品类 × 12 平台 ≈ 48 账号矩阵。
- 硬件：4 台美版刷机 iPhone + 自建洛杉矶静态住宅 IP，养号半年+。
- 1 主号 + 2-3 辅号矩阵结构，辅号用于测试与激活。

## 三、内容类型

| 类型 | 说明 |
|------|------|
| 产品展示 | 刀具切材顺滑度、锋利度实测 |
| 工艺过程 | 锻打火光、淬火、砂轮磨刃、开刃 |
| 工厂实拍 | 生产线、质检、包装、出货 |
| 使用场景 | 厨房/户外/专业场景痛点解决 |

- 时长：30-60 秒；**前 3 秒必须抓眼球**。
- 三方向：产品实力类 / 服务流程类 / 客户案例类。

## 四、发布节奏与「已读不回」激活策略

- 每日 2 条，10 点 / 15 点发布（对应欧美上班时间）。
- 加精准标签（#CNCmachining 等行业标签）。
- 针对沉睡/已读不回客户：分步发测试视频 + 精准私信激活，用短视频内容破冰而非硬广。

## 五、广告投放

- TikTok 广告投放细节 🚧 规划中，待结合 FB 广告素材复用。

## 六、风险提示（刀具内容审核红线）

- 刀具/户外刀具属受限品类，发布前必须检查平台政策与当地法规。
- 避免暴力、危险操作演示导向；聚焦工艺与实用场景。
- 多账号防封：独立设备指纹、静态住宅 IP、养号期不操作。
- 禁止编造客户案例/评价。

### 八、三段式爆款视频结构

```
开篇 3 秒（钩子）→ 中段展示（核心竞争力）→ 结尾引导（商务咨询）
```

- **开篇 3 秒**：直击海外采购痛点，如 "This knife cuts 1000 A4 sheets"。前 3 秒留存率需 >45% 才能进初级流量池。
- **中段**：集中展示工厂产能、定制加工能力、热处理工艺。
- **结尾**：清晰预留商务咨询渠道（Bio 链接、评论区引导）。

### 九、视频规格与关键指标

| 项目 | 建议 |
|------|------|
| 画幅 | 竖屏 9:16（1080×1920） |
| 最佳时长 | 7-15 秒（保完播率）；B2B 工厂内容可 15-30 秒 |
| 完播率基准 | 15-30 秒视频完播率 30% 是基础线，50%+ 结构健康 |
| 发布频率 | 初期每天至少 1 条；成熟后稳定节奏比高频更重要 |
| 最佳发布时间（北京时间，美区） | 工作日中午 12:00 / 晚 19-21:00；周末上午 10:00 / 晚 20-22:00 |

**流量池递进机制**：初级池（200-500 播放）→ 中级池（3000-5000）→ 高级池（1 万-10 万）→ 爆款池（10 万+）。考核指标按权重：完播率 > 互动率 > 关注转化率 > 负反馈。新号次均播放 500-1000 属正常；长期低于 200 需排查账号关联/环境异常。

### 十、广告投放要点（2026 政策）

- **开户**：个人开户通道已停审，必须通过企业主体 + 官方认证一级代理商开户；需营业执照、法人身份证、广告落地页。
- **计费模式**：oCPM（优化千次展示，欧美 $6-10 / 东南亚 $4-7）为主，适合 B2B 线索收集。
- **广告目标**：优先"线索收集"或"网站访问"，不要选直接转化。
- **素材**：工厂生产线、产品暴力测试视频，前 3 秒必须有视觉冲击。
- **落地页**：为每个广告做视频承接页（顶部视频+产品规格+询盘表单），路径不超过 3 步。

### 十一、避坑十条（封号/限流原因）

IP 不干净频繁切换 / 多账号共用设备 IP / 用国内邮箱注册美区号（须用 Gmail/Outlook）/ 内容搬运重复（须视频洗码）/ 买号租号 / 越狱 ROOT 设备 / 引导站外联系方式 / 未授权音乐（用平台正版库）/ 新号批量操作 / 被封后换设备不换网络。

> 询盘钩子：评论区/私信设计"免费获取 2026 五金刀剪采购白皮书""留邮箱发产品手册及出厂价"，公域转邮箱/WhatsApp 分层跟进（A 类即时报价、B 类发 catalog、C 类定期发新品）。
