# 外贸全流程知识链（From Inquiry to Repeat Order）

> 从询盘到售后的完整链路；每环节列关键知识点、常见问题、英文术语。
> 已有 SOP：`11_订单与财务/01_订单处理全流程.md`、`06_订单全流程SOP.md`、`09_出口报关与退税流程.md`。本文件补全订舱/提单/保险/目的港清关等细节。

---

## 一、全流程总览

```
询盘 Inquiry → 快速回复 → 需求确认 → 报价 Quotation → 谈判 Negotiation
→ PI 形式发票 → 定金 Deposit → 生产 Production → 质检 QC
→ 尾款 Balance → 订舱 Booking → 报关 Customs → 装船 Loading
→ 提单 B/L → 客户清关 Customs Clearance → 收货 Delivery → 售后 After-sales → 复购 Repeat Order
```

---

## 二、逐环节拆解

### 环节1：询盘接收与分类（Inquiry）
| 项 | 内容 |
|---|---|
| 英文 | Inquiry / RFQ (Request for Quotation) |
| 关键动作 | 1个工作日内首次响应；反筛3问（目标价/数量/定制需求） |
| 客户分级 | A(KA)/B(成长)/C(比价)/D(风险)；见 `03_客户开发与CRM/02_客户分级管理_ABCD.md` |
| 常见坑 | 只问 "best price" 不答其他 = C类比价党，标准价回复 |

### 环节2：需求确认（Requirements）
| 项 | 内容 |
|---|---|
| 确认点 | 型号/SKU、钢材、尺寸、表面处理、手柄材质、包装、Logo定制、数量、目的港、贸易术语 |
| 文件 | Specification Sheet、产品图 |

### 环节3：报价（Quotation / PI）
| 项 | 内容 |
|---|---|
| 英文 | Proforma Invoice (PI) |
| 构成 | 产品价 + 包装费 + Logo费 + 国内运费 + 海运费(若CIF/DDP) |
| 有效期 | 15–30天；汇率/原材料波动缩至7天 |
| 见 | `11_订单与财务/04_报价体系与价格策略.md`、`各国报价习惯与议价文化.md` |

### 环节4：谈判与定金（Negotiation & Deposit）
| 项 | 内容 |
|---|---|
| 英文 | Deposit / Down payment |
| 标准 | T/T 30% 定金 + 70% 出货前见提单副本 |
| 高风险客户 | 50%+ 预付，款到发货；非洲/新客户 100% 前 T/T |
| 见 | `11_订单与财务/05_付款条款详解.md` |

### 环节5：生产与质检（Production & QC）
| 项 | 内容 |
|---|---|
| 英文 | Lead time / QC (Quality Control) / Pre-shipment Inspection |
| 三道QC | 来料检 → 过程巡检 → 出货前全检（视频/照片确认） |
| 验货标准 | AQL 抽样 |
| 交期 | 现货7天/轻定制15天/全ODM 30–45天 |

### 环节6：尾款（Balance Payment）
| 项 | 内容 |
|---|---|
| 英文 | Balance / Balance payment |
| 动作 | 出货前收 70% 尾款；收款后放单/安排装船 |

### 环节7：订舱（Shipping Booking）
| 项 | 内容 |
|---|---|
| 英文 | Booking / Space booking / FCL / LCL |
| 关键动作 | ①货代/船公司订舱；②确认 FCL(整柜)或 LCL(拼柜)；③柜型 20GP/40GP/40HQ；④对齐船期 |
| 旺季 | 提前2–4周订舱，舱位紧张 |
| 文件 | Booking Note、SI (Shipping Instruction 货物信息)、VGM (Verified Gross Mass 核实总重，集装箱称重强制) |
| 常见坑 | VGM 未提交无法上船；SI 数据错误导致提单改单费 |
| 见 | `11_订单与财务/10_物流费用结构与渠道对比.md` |

### 环节8：内陆运输与装柜（Inland & Stuffing）
| 项 | 内容 |
|---|---|
| 英文 | Inland trucking / Stuffing / Container loading |
| 动作 | 工厂/仓 → 港；监装、拍照、封条(Seal No.) |
| 记录 | 过磅单、EIR (设备交接单)、封条号 |

### 环节9：出口报关（Export Customs Declaration）
| 项 | 内容 |
|---|---|
| 英文 | Customs declaration / Export declaration |
| 单证 | 商业发票(Commercial Invoice)、装箱单(Packing List)、合同、报关单、HS Code、原产地证(CO) |
| HS | 厨刀 8211.91/92；折刀 8211.93；套刀 8211.10；剪刀 8213.00 |
| 常见坑 | HS编码归类错误导致退税差异/查验；单证不一致被退单 |
| 退税 | 出口退税流程见 `09_出口报关与退税流程.md` |

### 环节10：提单确认（Bill of Lading, B/L）
| 项 | 内容 |
|---|---|
| 英文 | Bill of Lading (B/L) / Telex release / Sea waybill |
| 作用 | 海运物权凭证 + 运输合同证明；**凭正本提单提货** |
| 关键 | 开船后核对提单草稿(B/L Draft)：发货人/收货人/通知方/货描/件重尺/唛头；**确认无误再签正本**，改单费昂贵 |
| 电放 | Telex Release（近洋/老客户常用，无需寄正本） |
| 常见坑 | 收货人信息错误；货描与发票不一致导致客户目的港清关被扣 |

### 环节11：货运保险（Cargo Insurance）
| 项 | 内容 |
|---|---|
| 英文 | Cargo insurance / Marine insurance |
| 投保 | CIF 术语卖方投；保额 = 货值 ×110%；一切险(All Risks) |
| 理赔 | 货损/货差：①到货即报保险公司+船公司；②保留货损照片、提单、发票、装箱单；③向代理报案；④索赔时效通常2年 |
| 常见坑 | 未投保一切险只投平安险(FPA)，部分损不赔 |

### 环节12：目的港清关（Destination Customs Clearance）
| 项 | 内容 |
|---|---|
| 英文 | Import customs clearance / Bill of Entry |
| 动作 | 收货人(或其报关行)凭 B/L + 发票 + 装箱单 + CO + 进口许可证报关；缴关税/增值税；查验放行 |
| 特殊认证 | 尼日利亚 SONCAP、肯尼亚 PVoC、沙特 SABER PCoC+SCoC、巴西 INMETRO——**未办会被扣货** |
| 常见坑 | ①目的港费用(DTHC/demurrage)未预算；②HS归类不同导致关税差异；③认证缺失扣货；④免费期(Free Time)超期产生滞港费 |
| 滞箱/滞港 | Demurrage(柜超期)/Detention(柜还超期)——到港后免费期通常7–14天，超期日费高 |

### 环节13：收货与售后（Delivery & After-sales）
| 项 | 内容 |
|---|---|
| 英文 | Delivery / After-sales / Claim |
| 动作 | 客户收货验收；客诉处理（损坏/短缺/质量）；提供保养说明 |
| 客诉应对 | ①让客户提供照片/视频；②判定责任（运输/工厂/客户使用）；③补货/折扣/下次订单抵扣 |
| 保养资料 | 附 `产品保养维护指南.md` 英文版，减少不当使用客诉 |

### 环节14：复购（Repeat Order）
| 项 | 内容 |
|---|---|
| 动作 | 到货后2周回访满意度；节日问候；推新品；年度框架价 |
| 见 | `07_营销与社媒/各国节日与营销问候时机.md` |

## 四、常见风险与应对

| 风险 | 应对 |
|---|---|
| 客户付定金后消失 | 定金已覆盖成本；不影响 |
| 尾款拖延不付 | 出货前坚持收齐尾款再放单；不接受"见副本"新客户 |
| 提单信息错误 | 开船后第一时间核对 B/L Draft，确认后再签 |
| 目的港认证缺失扣货 | 报价阶段即告知 SONCAP/PVoC/SABER 要求，费用买家承担 |
| 货损 | 投一切险；装柜拍照留证；客诉走保险 |
| 汇率波动 | 报价有效期15–30天；见 `11_汇率风险管理.md` |
| 客人弃货 | 新客户30%定金覆盖头程；高风险市场款到发货 |
