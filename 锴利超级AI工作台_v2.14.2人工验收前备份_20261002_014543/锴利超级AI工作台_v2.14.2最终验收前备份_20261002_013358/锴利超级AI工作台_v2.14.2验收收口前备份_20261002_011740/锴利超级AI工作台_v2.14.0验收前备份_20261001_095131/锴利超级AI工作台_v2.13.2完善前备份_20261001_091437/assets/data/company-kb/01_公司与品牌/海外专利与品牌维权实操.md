# 海外专利与品牌维权实操

> **核心定位**：本文件是 KaiLionCrafts 产品出海过程中，**如何在海外申请专利/外观设计、如何在 Amazon 和独立站打击假货和跟卖、如何监测侵权、如何走法律流程**的实操手册。
>
> ⚠️ **重要声明**：
> 1. 本公司目前**没有任何海外专利记录**（原始资料核查未发现）。
> 2. 文中所有"KaiLionCrafts 已有专利/备案"栏目均标注 **⚠️待Leo确认**，**不得编造**。
> 3. 费用数据来自 WIPO/USPTO/EUIPO/Amazon 官网公开标准，**检索日期 2026-09-28**。
> 4. 法律诉讼类事项务必委托当地专利律师/商标律师，**不要自行诉讼**。

## 一、专利海外申请

### 1.1 PCT 途径（专利合作条约）

| 项目 | 内容 |
|------|------|
| **定义** | 通过 WIPO《专利合作条约》（PCT）提交一份国际专利申请，在**优先权日起 30 个月内**（部分国家 31 个月）进入各指定国家阶段。 |
| **适用** | 想在多个国家（≥3 个）申请发明专利，且产品尚在研发/市场验证期。 |
| **流程** | ① 中国首次申请（优先权日）→ ② 12 个月内提交 PCT 国际申请 → ③ WIPO 国际检索 + 国际公布（18 个月）→ ④ 优先权日起 30 个月内进入美/欧/日/韩等国家阶段 → ⑤ 各国实质审查 → ⑥ 授权 |
| **费用** | 国际阶段官费约 CHF 4,000–6,000（含检索费、基本费、传送费），加上代理费；**国家阶段每国另付 $3,000–10,000**（含翻译、当地律师费）。 |
| **优点** | 一次申请、延迟 30 个月进入各国、有国际检索报告评估专利性。 |
| **缺点** | 总费用高（多国累计 $20K–50K+）、周期长（5–7 年）。 |
| **KaiLionCrafts 适用性** | ❌ 公司是贸易型，产品多为通用刀剪，发明专利空间小。**仅当有独创功能（如特殊开合机构、新型刀刃结构）时考虑。** |

### 1.2 巴黎公约途径（直接申请）

| 项目 | 内容 |
|------|------|
| **定义** | 在中国首次申请后 **12 个月内**，直接向目标国家专利局提交申请，要求优先权。 |
| **适用** | 目标国家少（1–3 个）、产品已确定上市。 |
| **流程** | ① 中国首次申请 → ② 12 个月内向 USPTO/EUIPO/JPO 直接提交 → ③ 各国实质审查 → 授权 |
| **优点** | 比 PCT 快、费用低（少了国际阶段费用）。 |
| **缺点** | 必须在 12 个月内决定所有目标国，无法延迟决策。 |
| **KaiLionCrafts 适用性** | ⚠️ 若有独创设计，优先走这条。 |

### 1.3 美国设计专利（US Design Patent）

| 项目 | 内容 |
|------|------|
| **保护对象** | 产品的**外观设计**（形状、图案、装饰），不保护功能。 |
| **保护期** | **15 年**（自授权日起，2015 年 5 月 13 日后申请的） |
| **申请费** | USPTO 官费小实体（Small Entity）约 **$900–1,800**（含申请、检索、审查、授权）；加美国专利律师代理费 **$2,000–5,000**，合计约 **$3,000–7,000**。 |
| **审查** | 实质审查（新颖性、非显而易见性），但比发明专利宽松。 |
| **下证周期** | 12–24 个月。 |
| **申请文件** | 六面视图（前/后/左/右/顶/底）+ 立体图 + 简要说明。 |
| **KaiLionCrafts 适用** | ✅ **推荐**——对自有品牌独家刀型（独特手柄造型、刀身曲线、大马士革纹理处理）申请美国设计专利，防止竞品抄袭外观。 |

### 1.4 欧盟注册外观设计（RCD, Registered Community Design）

| 项目 | 内容 |
|------|------|
| **保护对象** | 产品外观设计。 |
| **保护范围** | 一次注册覆盖全部 **27 个欧盟成员国**。 |
| **保护期** | 最长 **25 年**（自注册日起，每 5 年续展一次：0–5 年、5–10 年、10–15 年、15–20 年、20–25 年）。 |
| **申请费（EUIPO 在线）** | **€350**（含申请费 €200 + 续展前 5 年费 €150）；加急费另加 €120。 |
| **审查** | **不实质审查**新颖性，只查形式要件。下证快（数日–数周）。 |
| **新颖性宽限期** | **12 个月**（申请人自己公开后 12 个月内仍可申请）。 |
| **KaiLionCrafts 适用** | ✅ **强烈推荐**——费用低（€350）、下证快、覆盖 27 国。对畅销款外观设计优先申请 RCD。 |

### 1.5 外观设计 vs 发明专利选择

| 维度 | 外观设计（Design Patent / RCD） | 发明专利（Utility Patent / PCT） |
|------|-------------------------------|-------------------------------|
| **保护对象** | 产品长什么样 | 产品怎么工作 |
| **申请成本** | $1,000–7,000 | $10,000–50,000+ |
| **下证周期** | 6–24 个月 | 3–7 年 |
| **审查严格度** | 宽松 | 严格 |
| **适合刀剪产品？** | ✅ 外观是核心差异化 | ❌ 功能改进空间小 |

> 💡 **KaiLionCrafts 策略**：
> - **外观设计优先**：对自有品牌独家刀型、特色包装申请美国 Design Patent + 欧盟 RCD。
> - **发明专利暂缓**：除非有独创功能（如自磨刀结构、新型开合机构）。
> - **海牙体系（Hague System）**：若想多国注册外观设计，可通过 WIPO 海牙体系一次指定多国，基础费 + 各国指定费。

## 二、亚马逊品牌备案和维权

### 2.1 Brand Registry 品牌备案

| 项目 | 内容 |
|------|------|
| **注册条件** | ① 持有**已注册成功**的商标（不是 pending）；② 商标是文字商标或含文字的图形商标；③ 有官网；④ 有与商标对应的企业邮箱；⑤ 是商标所有人或授权代理人。 |
| **费用** | **免费**。 |
| **申请入口** | https://brandservices.amazon.com/ |
| **所需材料** | 商标注册号/申请号、商标图、品牌官网、产品清单、品牌联系信息。 |
| **审核时间** | 通常 1–5 个工作日。 |

> 来源：Amazon Brand Registry 官方页
> https://sell.amazon.com/zh/programs/our-brands （检索日期 2026-09-28）

### 2.2 备案后核心权益

| 权益 | 说明 |
|------|------|
| **A+ 页面（A+ Content）** | 产品详情页可上传图文模块、品牌故事、对比表，转化率提升。 |
| **品牌旗舰店（Brand Store）** | Amazon 上的免费品牌专属店面。 |
| **Brand Analytics** | 品牌搜索词、重复购买率、购物篮分析等数据。 |
| **Sponsored Brands 广告** | 品牌头条视频广告、品牌旗舰店广告。 |
| **Project Zero** | 自助移除假冒 listing（见 2.4）。 |
| **Transparency 透明计划** | 产品级防伪序列化（见 2.3）。 |
| **Report a Violation (RAV)** | 侵权举报工具（见 2.5）。 |

### 2.3 Transparency 透明计划（产品级防伪）

| 项目 | 内容 |
|------|------|
| **原理** | 为每件产品生成唯一的 Transparency 二维码（序列化码），贴在包装上。Amazon 仓库发货前扫码验证，**只有真品才能入库发货**。跟卖者无法复制唯一码，自动被拦截。 |
| **加入条件** | ① 已是 Brand Registry 权利所有者；② 持有有效注册商标；③ 每件产品有 GTIN（UPC/EAN）；④ 能在产品包装上贴码。 |
| **费用** | **无注册费、无订阅费、无最低量**。按生成的码数付费，每个码约 **$0.01–$0.05**（按量折扣，量大更低）。 |
| **流程** | ① Amazon 发放 Transparency 码 → ② 在工厂包装时贴码 → ③ Amazon 仓库扫码验证 → ④ 消费者可扫码验真。 |
| **适合** | 高客单价、被跟卖严重的产品。 |

> 来源：Amazon Transparency 官方页
> https://sell.amazon.com/brand-registry/transparency?lang=zh-CN （检索日期 2026-09-28）

### 2.4 Project Zero（自助打假）

| 项目 | 内容 |
|------|------|
| **功能** | ① **自助移除假冒 listing**（Self-Service Counterfeit Removal）：品牌方发现假冒 listing 可自行删除，无需等 Amazon 审核；② **自动化保护（Automated Protections）**：Amazon 用 ML 自动扫描并阻止疑似假冒 listing；③ **序列化（Serialization）**：与 Transparency 联动。 |
| **加入条件** | ① Brand Registry 权利所有者；② **过去 6 个月内使用 RAV 举报过商标侵权，且举报批准率 >90%**；③ 有良好的 Brand Registry 使用记录。 |
| **费用** | **免费**（自助移除工具和自动化保护都免费）。若使用 Transparency 序列化，按码付费（见 2.3）。 |
| **流程** | ① 满足条件后在 Project Zero 页面申请 → ② 完成 10 分钟培训 → ③ 获得自助移除权限。 |

> 来源：Amazon Project Zero 官方页
> https://sell.amazon.com/brand-registry/project-zero?lang=zh-CN （检索日期 2026-09-28）

### 2.5 侵权举报流程（Report a Violation, RAV）

```
Step 1  发现侵权
        ├─ 在 Amazon 搜索品牌名/产品 ASIN
        ├─ 截图保存侵权 listing URL、卖家名、产品图
        └─ 记录侵权类型：商标侵权 / 版权侵权 / 专利侵权 / 假冒

Step 2  进入 RAV 工具
        └─ Brand Registry → Report a Violation

Step 3  选择被侵权商标/专利
        └─ 选择对应的注册商标号/专利号

Step 4  填写侵权举报
        ├─ 上传侵权 listing 链接
        ├─ 说明侵权理由
        ├─ 提交权利声明（电子签名）
        └─ Amazon 审核（通常 1–5 个工作日）

Step 5  处理结果
        ├─ 成功 → listing 被下架
        └─ 驳回 → 补充证据再举报
```

> ⚠️ **举报成功率关键**：证据要充分、权利证明要清晰、不要恶意举报竞争对手（会被取消 RAV 权限）。

## 三、侵权监测和维权流程

### 3.1 监测方法

| 监测渠道 | 监测方法 | 频率 |
|---------|---------|------|
| **Amazon** | 搜索 "KaiLionCrafts"、核心关键词（如 "damascus chef knife"），看是否有假货/跟卖 | 每周 1 次 |
| **速卖通（AliExpress）** | 搜索品牌名 + 产品关键词 | 每月 1 次 |
| **eBay** | 搜索品牌名 | 每月 1 次 |
| **Shopify/独立站** | Google 搜索 `site:myshopify.com kailioncrafts` 或 `kailioncrafts* -kailioncrafts.com` | 每月 1 次 |
| **Google Alerts** | 设置关键词 "KaiLionCrafts"、"Kailion knife"，新网页提及自动邮件提醒 | 实时自动 |
| **图片反向搜索** | 用 Google Images / TinEye 上传产品图，看是否被盗图 | 每季度 1 次 |
| **1688/阿里巴巴** | 搜索品牌名，看国内工厂是否冒用 | 每月 1 次 |
| **社交媒体** | Instagram/TikTok/YouTube 搜索品牌名，看是否有假冒账号 | 每月 1 次 |

### 3.2 维权四步流程

```
发现侵权
    │
    ├─ Step 1  证据固定（最重要！）
    │   ├─ 截图：listing URL、卖家信息、产品图、价格、评论
    │   ├─ 录屏：从搜索到产品页的完整操作录屏
    │   ├─ 保留网页快照（web.archive.org 存档）
    │   └─ 必要时购买样品（公证购买，固定侵权实物）
    │
    ├─ Step 2  发 Cease & Desist 律师函
    │   ├─ 委托当地律师（美国/欧盟）发停止侵权函
    │   ├─ 内容：注册商标号/专利号、侵权事实、要求立即下架、赔偿
    │   └─ 期限：通常 10–14 天内回应
    │
    ├─ Step 3  平台投诉（低成本、快）
    │   ├─ Amazon → RAV 工具
    │   ├─ eBay → VeRO 计划
    │   ├─ 速卖通 → 知识产权保护系统
    │   ├─ Shopify → DMCA 投诉 / 商标投诉
    │   └─ Google → 移除搜索结果（Copyright Removal / Trademark Complaint）
    │
    └─ Step 4  法律诉讼（高成本、高威慑）
        ├─ 美国：TTAB 商标异议/无效，或联邦法院侵权诉讼
        ├─ 欧盟：EUIPO 无效宣告程序
        ├─ 中国：互联网法院/知识产权法院
        └─ 仲裁：域名纠纷走 UDRP 仲裁（见第五节）
```

### 3.3 各平台投诉渠道和处理时间

| 平台 | 投诉渠道 | 处理时间 | 费用 |
|------|---------|---------|------|
| **Amazon** | Brand Registry → RAV | 1–5 个工作日 | 免费 |
| **eBay** | VeRO（Verified Rights Owner）计划 | 5–10 个工作日 | 免费 |
| **AliExpress** | 知识产权保护系统（ipp.alibabagroup.com） | 3–7 个工作日 | 免费 |
| **Shopify** | DMCA 投诉 / 平台内举报 | 3–10 个工作日 | 免费 |
| **Google** | Google Copyright Removal / Trademark Complaint | 数天–数周 | 免费 |
| **Facebook/Instagram** | 知识产权举报工具 | 1–3 个工作日 | 免费 |
| **TikTok** | IP 举报工具 | 1–3 个工作日 | 免费 |
| **中国海关** | 海关总署知识产权备案后查扣 | 依案件 | 备案免费 |
| **美国海关（CBP）** | e-Recordation 备案 | 依案件 | 备案费 $190/类 |

### 3.4 法律诉讼途径

| 法域 | 程序 | 适用 | 成本参考 |
|------|------|------|---------|
| **美国 TTAB** | 商标异议/撤销程序 | 他人抢注/冲突商标 | $10K–50K（律师费） |
| **美国联邦法院** | 商标侵权/专利侵权诉讼 | 大规模假冒、要求赔偿 | $50K–500K+ |
| **欧盟 EUIPO** | 无效宣告程序（Invalidity） | 撤销冲突商标 | €3K–10K |
| **中国互联网法院** | 商标/著作权侵权 | 国内假货 | ¥5K–50K |
| **WIPO 仲裁（UDRP）** | 域名抢注仲裁 | 域名被抢注 | $1,500–5,000/案 |

> ⚠️ **诉讼决策原则**：
> - 先平台投诉（免费、快），再律师函（中等成本），最后才诉讼（高成本）。
> - 诉讼前评估：侵权方规模、赔偿潜力、品牌长期影响。
> - **不要为了 $1,000 的假货去打 $50,000 的官司**。

## 四、外观设计保护要点（刀剪产品）

### 4.1 刀剪外观设计保护什么

| 保护对象 | 说明 | 可保护？ |
|---------|------|---------|
| 刀身曲线、刀刃弧度 | 独特的刀型轮廓 | ✅ 外观设计 |
| 手柄造型、材质纹理 | 手柄的独特形状 | ✅ 外观设计 |
| 大马士革钢纹理 | 钢材本身的花纹（锻造工艺产生） | ⚠️ 天然花纹难垄断，但**独特的纹理处理工艺**可考虑 |
| 刀套/礼盒外观 | 包装造型 | ✅ 外观设计 |
| 产品 logo 位置/装饰 | 表面图案 | ✅ 外观设计 + 商标 |
| 刀刃角度、开合机构 | 功能 | ❌ 外观不保护，需发明专利 |

### 4.2 设计图纸要求

申请外观设计专利（美国 Design Patent / 欧盟 RCD）需要：

- [ ] **六面正投影视图**：前视图（Front）、后视图（Back）、左视图（Left）、右视图（Right）、顶视图（Top）、底视图（Bottom）
- [ ] **立体图（Perspective View）**：直观展示整体外观
- [ ] **变化状态图**：若产品有折叠/开合状态，需展示不同状态
- [ ] **简要说明（Brief Description）**：说明各视图、设计要点
- [ ] 线条图（Line Drawing），黑白线条，不渲染

> 💡 **实操建议**：委托专业产品设计公司出图，费用约 ¥1,000–3,000/款。不要用照片申请（照片容易被要求修改）。

### 4.3 优先权利用

```
中国首次外观设计申请（优先权日 D 日）
    │
    ├─ 6 个月内 → 在美国申请 Design Patent，要求中国优先权
    ├─ 6 个月内 → 在欧盟申请 RCD，要求中国优先权
    └─ 6 个月内 → 通过 WIPO 海牙体系指定多国
```

> ⚠️ **外观设计优先权期只有 6 个月**（发明专利 12 个月），错过就不能要求优先权。

## 五、域名和社交媒体账号保护

### 5.1 域名注册策略

### 5.3 域名仲裁（UDRP）

| 项目 | 内容 |
|------|------|
| **全称** | Uniform Domain-Name Dispute-Resolution Policy（统一域名争议解决政策） |
| **管理机构** | WIPO 仲裁与调解中心、亚洲域名争议解决中心（ADNDRC）等 |
| **适用** | 他人恶意抢注与你商标相同/近似的域名（如 kailioncraftsfake.com） |
| **成功三要件** | ① 域名与你的商标相同/混淆性近似；② 域名持有人对域名无合法权益；③ 域名是恶意注册和使用的。 |
| **费用** | WIPO 仲裁费 **$1,500（一人审）–$3,000（三人审）**，加律师费 |
| **时间** | 45–60 天 |
| **结果** | 胜诉 → 域名转移给商标所有人 |
