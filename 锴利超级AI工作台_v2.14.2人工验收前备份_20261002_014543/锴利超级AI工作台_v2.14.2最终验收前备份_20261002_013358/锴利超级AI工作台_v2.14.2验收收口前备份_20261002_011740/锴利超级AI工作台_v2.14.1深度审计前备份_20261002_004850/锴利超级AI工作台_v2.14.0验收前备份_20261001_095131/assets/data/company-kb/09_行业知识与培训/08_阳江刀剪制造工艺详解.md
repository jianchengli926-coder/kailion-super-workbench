# 阳江刀剪制造工艺详解

> 用途：B2B 买家教育、销售话术、社媒工艺视频脚本的工艺知识库。
> 工厂关系统一表述为**深度战略合作工厂**，不得写自有工厂。

## 一、全工艺流程总览

```
钢材选材 → 锻造/冲压成型 → 真空热处理（淬火+回火）→ 研磨/CNC 开刃
       → 表面处理（抛光/涂层）→ 装配（装手柄）→ 三道 QC → 包装出货
```

## 二、各工序详解

### 1. 钢材选材
- 入门到高端：304 不锈钢 / 3Cr13 / 9Cr18MoV / 德国 1.4116 / 日本 VG-10 / D2 / 440C / 大马士革花纹钢。
- 材质证明随货；高端款可展示钢材原板、产地。

### 2. 锻造/冲压成型
- **锻造**：加热后锻打成型，锻打火光是社媒高燃素材；大马士革钢折叠锻打形成花纹。
- **冲压**：钢卷送进冲压机开料，适合批量标准款。
- 装饰工艺：Tsuchime 手工锤纹。

### 3. 真空热处理（核心，决定硬度与耐用性）
- **淬火**：高温加热后急冷（油淬/气淬），提升硬度——淬火"滋滋"声是 ASMR 素材。
- **回火**：淬火后低温回火，消除内应力，防止崩口。
- 厨刀常用 **HRC 56-58**；硬度越高越锋利但越脆，需平衡保持性与韧性。
- 真空热处理 = 表面无氧化层，变形小，高端款工艺。

### 4. 研磨 / CNC 开刃
- CNC 数控磨床批量开刃，一致性高。
- 手工开刃/水磨抛光：锋利度与顺滑度的关键，匠人操作是"工艺细节类"素材。
- 视频点：砂轮火花飞溅慢动作。

### 5. 表面处理
| 工艺 | 效果 |
|------|------|
| 镜面抛光 mirror polish | 高反光高端感 |
| 缎面 satin | 拉丝哑光，防指纹 |
| 黑色涂层 black coating | 户外刀常用，防锈 |
| 钛涂层 titanium coating | 彩色耐磨 |
| 水洗 stone wash | 做旧质感 |

### 6. 装配（装手柄）
- 手柄材料：玫瑰木 / G10 / 聚合物 / 米卡塔 Micarta / 贝壳 / 不锈钢。
- 刀柄镶嵌、铆钉/螺钉固定；激光雕刻 Logo（OEM 定制素材）。

### 7. 三道 QC 品控
| 环节 | 内容 | 工具/动作 |
|------|------|----------|
| 来料检验 | 钢材/手柄/包装材料进厂 | 材质核对 |
| 过程检验 | 生产中途巡检 | HRC 硬度计、尺寸测量、外观 |
| 出货前检验 | 成品全检 + 视频确认 | 锋利度测试、盐雾防锈测试、客户书面批准 |

### 8. 包装出货
- 内包装、外箱、贴标；定制礼盒（OEM）。
- 成品仓库展示库存与供货能力；40 尺柜装柜延时摄影。

## 三、关键参数与卖点对照

| 参数 | 数值/工艺 | 卖点话术 |
|------|----------|---------|
| 硬度 HRC | 56-58（厨刀） | 精准硬度控制，锋利保持性 3 倍 |
| 防锈 | 304 不锈钢 | 3 年防锈，省售后成本 |
| 交期 | 现货 7 天 / 轻定制 15 天 / 全 ODM 30 天 | 快速抓市场窗口 |
| MOQ | 50 件起 | 低试库存压力 |
| 认证 | CE/FDA/LFGB/RoHS/ISO 9001 | 合规进入欧美主流渠道 |
