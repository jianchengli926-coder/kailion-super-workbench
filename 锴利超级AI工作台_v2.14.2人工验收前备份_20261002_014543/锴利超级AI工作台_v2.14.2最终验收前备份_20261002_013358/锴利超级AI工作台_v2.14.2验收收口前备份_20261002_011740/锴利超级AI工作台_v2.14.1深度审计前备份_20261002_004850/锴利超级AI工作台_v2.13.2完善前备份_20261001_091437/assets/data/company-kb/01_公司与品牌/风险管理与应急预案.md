## 二、供应链中断：工厂产能不足/倒闭

### 2.1 识别信号
- 工厂突然延长交期（PI约定30天→45天+）
- 工厂要求预付大额材料款
- 工厂QC数据异常波动
- 行业/本地新闻：工厂拖欠工资/环保处罚/债务纠纷
- 股权方工厂核心团队人员变动

### 2.2 影响评估
| 影响维度 | 评估 |
|---|---|
| 在手订单 | 多少订单依赖该工厂？交期延迟多久？ |
| 客户关系 | 延迟是否导致客户索赔/取消？ |
| 资金 | 在制品/已付货款是否损失？ |
| 替代产能 | 36家归档工厂中谁能快速承接？ |

### 2.3 应急预案

```
T+0（发现信号/事件发生）
  → 创始人24小时内现场评估（30分钟半径优势）
  → 通知受影响客户预期交期调整
  → 启动备选供应商评估

T+1~3天
  → 从36家A级归档工厂中筛选同品类备选厂
  → 打样/小批量试产（与股权工厂同等规格）
  → 订单分流：非紧急订单转备选厂，紧急订单优先股权厂

T+1~2周
  → 备选厂小批量验证通过后正式切换
  → 与客户重新协商交期（给予折扣/补偿）
  → 财务清算：已付货款、在制品、原材料处理

长期
  → 关键品类至少2地工厂可生产（⚠️当前4家均在阳江，地理集中度高）
  → 建立备选厂年度审核机制
```

### 2.4 预防措施
- 旺季前60天锁定排产计划
- 非核心订单分流至36家归档工厂
- 小单走股权工厂柔性产线
- 海外仓热销SKU提前备货，降低对即时产能依赖
- 每季度更新备选厂名单和产能评估

## 三、客户违约/坏账

### 3.1 识别信号
- 客户首次下单要求超长账期（>30天）
- 客户公司信息模糊（无官网/无LinkedIn/新注册邮箱）
- 客户反复变更付款方式/拖延定金
- 货到港后客户拒绝赎单
- 客户以"质量问题"为由拒付尾款

### 3.2 应急预案

#### 场景A：客户拒付尾款（货已到港）
```
T+0
  → 确认提单状态（是否已电放/客户是否已提货）
  → 联系货代确认货物控制权
  → 若未提货：控制提单，不电放

T+1~3天
  → 书面催款（邮件+WhatsApp），保留证据
  → 了解拒付原因（质量问题？资金问题？市场变化？）
  → 若属质量争议：要求客户提供第三方验货报告（SGS/BV/Intertek）

T+1~2周
  → 若客户破产/恶意拒付：
    ①启动中信保理赔（如有投保）
    ②联系当地律师/追账公司
    ③考虑转卖货物给其他客户/退运
  → 若属质量争议：
    ①对照出货前视频确认记录
    ②提供补货/折扣方案
    ③协商部分付款+后续合作折扣
```

#### 场景B：新客户首单风险
- 首单坚持100% T/T预付或信用证
- 不接受OA账期（无中信保覆盖时）
- 中信保投保：对高风险市场客户投保出口信用保险
- 大单分批发货：30%定金+见提单副本付尾款

### 3.3 预防措施
- 新客户背景调查：官网/LinkedIn/Google Maps/海关数据
- 中信保投保（⚠️当前是否投保待确认）
- 付款条款分级：新客户100%前T/T；老客户30%定金+70%见提单；长期客户可OA 30天（需中信保覆盖）
- 大额订单要求信用证(L/C)
- 保留所有沟通记录和出货前视频确认

## 四、批量质量事故

### 4.1 识别信号
- 同一批次多客户投诉同类问题（刀身断裂/手柄松动/刃口崩口）
- 退货率突然上升（>2%）
- 第三方验货不通过

### 4.2 应急预案

```
T+0（接到质量投诉）
  → 问题直达创始人（不经过多层中转）
  → 调取该批次：三道QC记录 + 7项测试报告 + 钢材材质证明
  → 要求客户提供：清晰照片/视频 + 批次号 + 使用场景
  → 判断是否系统性问题（同一批次多客户投诉=系统性；单个偶发=个案）

T+1~3天
  → 定位根因：
    ①来料问题（钢材硬度/成分异常）→ 锁定同批次原材料
    ②工艺问题（热处理波动/开刃角度偏差）→ 锁定同时间段产线
    ③运输问题（货损）→ 凭开箱照片向保险/承运商索赔
  → 通知所有同批次客户预防性检查

T+1~2周
  → 核实为我方责任：
    ①批量问题：100%整批更换或全额退款（④级零缺陷兜底）
    ②个案：免费补发+承担退货运费（①②③级质保）
    ③提供补发折扣/下批抵扣
  → 工厂整改：根因反馈工厂，纳入下次飞行检查
  → 更新QC标准（如新增检测项）

T+1月
  → 复盘报告：根因/影响范围/处理成本/改进项
  → 更新BOM/工艺文件/SOP
```

### 4.3 召回/赔偿标准

| 情形 | 赔偿方式 |
|---|---|
| 长期客户整批不达标 | 100%整批更换或全额退款（④级零缺陷） |
| 核实制造缺陷（刀身断裂） | 免费补发+我方承担退货运费（①级终身质保） |
| 刃口过早失效（指定钢材） | 免费复磨/维修/更换（②级10年） |
| 手柄装配问题（24个月内） | 免费换件/重装（③级2年） |
| 运输货损 | 凭开箱照片协助向保险/承运商索赔 |
| 定制件与确认样不符 | 对照确认样评估，退换 |

## 五、汇率大幅波动

### 5.1 识别信号
- USD/CNY单月波动>3%
- 央行加息/降息政策突变
- 贸易摩擦导致汇率预期变化

### 5.2 应急预案
| 波动幅度 | 应对动作 |
|---|---|
| ±3%以内 | 正常经营，PI报价有效期15-30天自然吸收 |
| ±3-5% | 新报价缩短有效期至7-15天；大单约定材料调价联动条款 |
| ±5%以上 | ①锁汇（远期结售汇）；②调整报价；③加速应收款回收；④与客户协商汇率分摊条款 |

### 5.3 预防措施
- PI报价有效期15-30天（材料剧烈波动时缩短至7-15天）
- 大单约定材料调价联动条款
- 进口Outokumpu不锈钢涉及欧元结算时考虑远期结售汇
- ⚠️具体锁汇工具和额度待财务确认

## 六、地缘政治/政策变化

### 6.1 场景：美国对华关税升级

```
T+0（关税新政宣布）
  → 核算DDP报价影响幅度
  → 评估对在手订单和意向订单的影响

T+1~2周
  → 通知美国客户新的关税成本
  → 与客户协商：分摊关税/调整价格/延后发货
  → 加速美国三仓现货出货（关税按库存时税率）

长期
  → 评估原产地多元化（⚠️当前100%阳江制造）
  → 加大非美市场开发（130+国家分散）
  → 美国仓本地发货B2C降低直邮关税敏感度
```

### 6.2 场景：目的国进口政策变化
- 日本/澳洲/欧洲突然收紧刀具进口法规
- 应对：立即暂停发往该国的户外刀订单；与目的国报关行确认新规；调整产品规格（刃长/结构）以符合新规
- 沙特SABER/尼日利亚SONCAP等认证新规：提前在SABER平台注册

### 6.3 预防措施
- 客户覆盖130+国家，不过度依赖单一市场
- 美国三仓现货体系部分规避关税时效风险
- DDP双清到门，提前核算目的国关税
- 每把刀出口前公安备案，100%合法合规
- 11个仿牌SKU不对外推广，逐步替换为自有品牌

## 七、法律合规/认证失效

### 7.1 识别信号
- 认证到期前60天（BSCI 2027-04、FSC 2029-04）
- 目的国法规更新（如REACH SVHC清单新增物质）
- 客户审计提出认证缺失

### 7.2 应急预案
| 场景 | 应对 |
|---|---|
| BSCI C评级到期 | 提前60天启动续证；推动工厂C→B升级 |
| FSC认证到期 | 提前60天启动续证；木盒包装合规依赖此证 |
| REACH SVHC新增物质 | 复测新增物质；若超标调整材料 |
| Prop 65诉讼 | 立即加贴警告标签；评估测试证据；和解金额$2,500-$50,000+预算 |
| 目的国要求新认证 | 评估认证成本和周期；必要时暂停该国销售 |

## 八、网络安全/电商账号被封

### 8.1 场景：Amazon账号被封

```
T+0（收到封号通知）
  → 确认封号原因（绩效/侵权/关联/审核）
  → 立即冻结所有广告投放
  → 备份所有listing数据和订单记录

T+1~3天
  → 提交POA（Plan of Action）申诉
  → 准备备用账号（如有）
  → 通知FBA库存状态（是否被冻结）

T+1~2周
  → 申诉失败则启用备用账号
  → 将流量导向独立站
  → 评估财务损失（FBA库存+在途资金）
```

### 8.2 场景：PayPal/Stripe支付账号冻结
```
T+0
  → 确认冻结原因（风控/投诉/合规）
  → 准备交易记录/物流凭证/客户沟通记录
  → 提交申诉

T+1~2周
  → 提供所有发票/提单/ tracking number
  → 启用备用收款渠道（万里汇/Payoneer/对公T/T）
  → 通知客户新的付款方式
```

### 8.3 预防措施
- Amazon备用账号（⚠️是否已有待确认）
- PayPal/Stripe/万里汇/Payoneer多收款渠道分散
- 独立站作为DTC备份流量入口
- 所有客户联系方式（邮箱/WhatsApp）备份，不完全依赖平台站内信
- 不刷单、不侵权、不售仿牌——从源头避免封号

## 十、决策流程

### 10.1 事件分级

| 级别 | 定义 | 响应人 | 响应时限 |
|---|---|---|---|
| 🔴 P0 紧急 | 断供/质量事故/认证吊销/重大客户索赔/账号被封/坏账 | 创始人直接 | 24小时内启动 |
| 🟡 P1 高 | 交期延误/库存告急/材料涨价超阈值/汇率波动>5%/认证续证 | 跟单+采购+财务 | 3个工作日内方案 |
| 🟢 P2 中 | 备选厂打样/流程优化/常规续证 | 采购/运营 | 月度计划内 |

### 10.2 决策树

```
突发事件发生
  → 是否影响客户交付/安全/合规？
    ├─ 是 → P0：创始人直接决策，24h内通知受影响客户
    └─ 否 → 是否影响成本/交期？
      ├─ 是 → P1：跟单+采购3个工作日内出方案
      └─ 否 → P2：月度计划内处理
```

### 10.3 复盘机制
- 每起P0/P1事件后输出《风险事件复盘报告》：根因/应对动作/改进项/更新本预案
- 每季度更新本风险矩阵
- 每年全面审视供应链韧性（多源率/地理分散度/BCP演练）
