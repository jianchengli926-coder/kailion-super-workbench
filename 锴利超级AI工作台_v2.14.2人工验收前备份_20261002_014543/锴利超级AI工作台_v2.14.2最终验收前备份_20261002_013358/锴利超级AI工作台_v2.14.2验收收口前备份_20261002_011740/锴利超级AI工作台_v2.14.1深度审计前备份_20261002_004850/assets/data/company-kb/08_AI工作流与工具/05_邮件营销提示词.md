# 邮件营销提示词库

> 来源：`prompts.py` 跟进信/询盘回复 Prompt + CRM development-email 技能 + Dify 外贸邮件表达库（500+ 商务表达）。
> 适用：独立站 EDM、B2B 客户培育、询盘回复、开发信后续触达。

## 一、邮件分类与用途

| 邮件类型 | 触发时机 | 目标 | 长度 |
|---------|---------|------|------|
| 欢迎邮件 | 新订阅/新询盘 | 建立信任、引导下一步 | 100-150词 |
| 开发信（首封） | 新客户冷联系 | 获取回复 | 120-180词 |
| 跟进序列 | 开发信后未回复 | 持续触达、提供价值 | 80-120词/封 |
| 询盘回复 | 客户来询盘 | 专业应答、推动报价 | 100-150词 |
| 新品通知 | 新品上架 | 通知老客户、推广样品 | 80-120词 |
| 节日问候 | 圣诞/新年/开斋节等 | 维护关系、不硬卖 | 50-80词 |
| Break-up | 21天无回复 | 礼貌收尾、留余地 | 60-80词 |

## 二、欢迎邮件 Prompt

```
请写一封新询盘欢迎邮件（英文）。

客户信息：姓名 / 公司 / 国家 / 感兴趣产品

要求：
1. 主题行："Welcome to KaiLionCrafts - {Name}" 或 "Thanks for your inquiry, {Name}"
2. 第一段：感谢询盘 + 确认收到
3. 第二段：简要介绍 KaiLionCrafts（阳江刀剪 OEM/ODM，4大品类）
4. 第三段：附上产品目录链接 + 建议下一步（视频看厂/样品/报价单）
5. 结尾：签名 Leo Li, Founder & CEO
6. 100-150词，热情但专业
```

## 三、4阶段跟进序列（与客户开发库共用）

| 阶段 | 时间 | 策略 | 主题示例 |
|------|------|------|---------|
| 第1封 | 第3天 | 价值型：发目录/行业报告，不提销售 | "Your Kitchen Knife Catalog - KaiLionCrafts" |
| 第2封 | 第7天 | 案例型：新品推荐/类似客户案例 | "New Arrivals: Damascus Chef Knives Under $5" |
| 第3封 | 第14天 | 激励型：限时优惠/免费样品 | "Free Sample Offer - This Week Only" |
| 第4封 | 第21天 | Break-up：礼貌告别 | "Closing the loop - KaiLionCrafts" |

```
写第{number}封跟进邮件时必须：
1. 不重复第一封内容，每次提供新价值
2. 80-120词
3. 不道歉、不解释为什么跟进
4. 每次有明确CTA
5. Break-up邮件要优雅，让客户感到不回复会错过什么
```

## 四、新品通知邮件 Prompt

```
请写一封新品通知邮件（英文）。

新品信息：
- 产品名：{product_name}
- 核心卖点：{key_features}
- 材质/规格：{specs}
- 目标客户类型：{brand / importer / distributor / e-commerce}

要求：
1. 主题行突出新品+核心卖点，≤60字符
   示例："New: {Product} - {Material}, {MOQ} MOQ"
2. 开头：为什么推出这款新品（市场洞察/客户需求）
3. 正文：3个核心卖点 + 适用场景
4. CTA：索取样品/看完整目录/视频会议
5. 80-120词
6. 不编造未确认的参数/认证
```

## 五、节日问候邮件 Prompt

```
请写一封{holiday}节日问候邮件（英文）。

节日：{Christmas / New Year / Eid al-Fitr / Thanksgiving}
客户国家：{country}

要求：
1. 主题行：节日祝福为主，不硬卖
   示例："Season's Greetings from Yangjiang - KaiLionCrafts"
2. 正文：简短节日祝福 + 一句年度回顾 + 来年展望
3. 不附促销信息（除非客户明确在促销期）
4. 50-80词
5. 尊重客户当地节日文化
```

## 六、询盘回复 Prompt

```
客户通过独立站提交了询盘，请生成回复邮件（英文）。

询盘内容：姓名/邮箱/公司/国家/感兴趣产品/留言

要求：
1. 24小时内回复的语气，热情但专业
2. 回答客户留言中的具体问题
3. 推荐1-2款相关产品（带SKU和简短描述）
4. 提出下一步：发送目录/报价单/安排视频通话
5. 100-150词
6. 主题行：Re: Your inquiry about {product} - KaiLionCrafts
7. 签名：Leo Li, Founder & CEO, KaiLionCrafts
```

## 八、邮件合规与注意事项

- 所有邮件发送前须 Leo 确认（全局指令：外部操作确认机制）。
- B2B 邮件不使用夸张营销词（"the best"/"cheapest"），用事实和数据说话。
- 不编造客户案例/订单金额/客户评价。
- 工厂关系表述为深度战略合作。
- 附件大小控制（目录 PDF ≤5MB），大文件用云盘链接。
- 跟进频率遵循：A 级 3 天、B 级 7 天、C 级 14 天。
- 邮件平台（FluentSMTP/独立站表单）配置见工作台设置中心。
