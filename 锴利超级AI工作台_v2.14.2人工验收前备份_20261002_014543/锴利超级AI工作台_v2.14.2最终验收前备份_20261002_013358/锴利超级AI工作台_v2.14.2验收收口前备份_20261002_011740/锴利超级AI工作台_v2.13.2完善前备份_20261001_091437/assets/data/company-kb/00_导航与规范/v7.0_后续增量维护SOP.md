# v7.0 后续增量维护SOP

> 知识库进入v7.1增量维护阶段后的标准操作流程。

---

## 一、日常维护节奏

### 每周（Leo或AI助手执行）
- [ ] 新增/修改文件后更新 `last_updated` 字段
- [ ] 新增文件必须补全frontmatter（含sensitivity标签）
- [ ] 检查是否有新文件未入 `01_知识库文件全清单.md`
- [ ] 检查AI工作台对话中是否有"待确认"事项累积

### 每月
- [ ] 运行全库扫描脚本：统计文件总数、sensitivity分布、frontmatter完整率
- [ ] 检查 `外部知识过期日历.md` 中本月到期的外部知识
- [ ] 更新文件全清单（补入新增文件）
- [ ] 检查是否有死链（README/导航中引用的路径是否存在）
- [ ] SKU入库：每月入库10-20个READY SKU（与工厂同步核对）

### 每季度
- [ ] 外部知识过期复核：关税税率、各国刀具法规、物流承运商政策是否更新
- [ ] AI检索回归测试：抽20条问题测试检索准确率
- [ ] 敏感信息复查：grep检查public层是否有新的价格/供应商真名/管制刀型泄露
- [ ] 版本changelog更新
- [ ] 知识库整体备份（zip或git tag）

## 二、新SKU入库流程

1. **确认状态**：从 `05_待入库SKU清单.md` 中选READY状态SKU
2. **字段核对**：与工厂确认材质/尺寸/MOQ/认证等缺失字段
3. **创建文件**：在对应品类目录创建SKU参数文件，frontmatter标 `sensitivity:public`（不含价格）
4. **更新正式库索引**：在 `SKU正式库/00_总览.md` 中登记
5. **更新待入库清单**：将该SKU状态改为"已入库v7.x"
6. **安全检查**：确认不含价格/成本；确认非管制/仿牌SKU
7. **入文件全清单**：将新文件路径加入索引

**禁止入库**：REGULATED（13个）和PRIVATE_LABEL_RISK（6个）SKU不得生成对外文案。

## 三、外部知识更新流程

外部知识层（13_外部知识层）内容有保质期，必须定期复核：

| 知识类型 | 复核周期 | 数据源 |
|----------|----------|--------|
| 关税税率（HS 8211） | 每季度 | USITC / TARIC / 海关总署 |
| 各国刀具法规 | 每半年 | gov.uk / 各国执法机构官网 |
| 物流承运商政策 | 每季度 | UPS/FedEx/DHL/USPS官网 |
| 竞品分析 | 每半年 | 竞品官网/亚马逊 |
| 长尾关键词/选题 | 每月 | Google Keyword Planner / Reddit / Alibaba |
| 阳江出口数据 | 每年 | 海关/阳江政府统计 |

**过期处理**：
1. 复核发现过期 → 在文件顶部标注"⚠️ 数据截至YYYY-MM-DD，待更新"
2. 获取新数据 → 更新文件，更新 `last_updated` 和 `fetch_date`
3. 无法获取新数据 → 保留旧数据但标注日期，不得删除

---

## 四、事实核验流程

当AI检索结果涉及以下事实时，必须核验：

1. **公司数据**（出口国家数/团队人数/年销售额/客户数）：Leo拍板前标"待确认"
2. **产品参数**（材质/尺寸/MOQ/认证）：工厂确认前标"待工厂确认"
3. **法规/关税**：以官方来源为准，带source_url和fetch_date
4. **第三方数据**（阳江产业规模/竞品价格）：标注来源和日期

**核验步骤**：
- 发现矛盾 → 在 `05_内外冲突清单` 登记
- 找权威来源（公司官方文件/工厂确认/政府官网）
- 统一口径 → 更新所有相关文件
- 删除旧错误口径，保留冲突解决记录

## 五、备份和版本管理

### 备份
- **当前状态**：无整体备份（P1待补）
- **v7.1起**：每周五执行 `zip -r 知识库_backup_YYYYMMDD.zip 公司知识库/`
- 备份保留最近4周，每月末归档一份

### 版本管理
- 每次重要修改后，在 `v7.0_changelog.md`（新建）追加：
  ```
  ## v7.1.0 - YYYY-MM-DD
  - 新增：xxx
  - 修改：xxx
  - 修复：P0-x xxx
  ```
- 大版本（v7→v8）时打git tag或复制整个目录

- [ ] 文件frontmatter完整（title/type/category/status/last_updated/sensitivity）
- [ ] `01_知识库文件全清单.md` 已更新
- [ ] README导航树是否需要新增条目
- [ ] 场景路由表是否需要更新路由
- [ ] 标准问答库是否需要新增Q&A

- [ ] 如果删除了文件，检查是否有其他文件引用它
