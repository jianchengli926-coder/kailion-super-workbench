# 物流费用结构与渠道对比

> 核心选路逻辑：**大货走海运 FOB/CIF；小批补货走海外仓；样品走快递。**

---

## 一、四大物流渠道总览

| 方式 | 时效 | 适用场景 | 成本等级 | 备注 |
|------|------|---------|---------|------|
| **美国海外仓现货** | **1–3 天**（本地送达） | Amazon/Shopify卖家、零售商小批补货、B2C | 最低履约成本 | 现货售完即止，轻定制当天 |
| **国际快递（DHL/FedEx/UPS）** | 3–7 天 | 样品、急单、小包裹 | 最高 | 适合打样补发 |
| **空运** | 7–15 天 | 紧急补货、高货值 | 高 | — |
| **海运（整柜/拼箱）** | 20–35 天 | 大货批发、整柜 OEM/ODM | 最低单位成本 | 阳江工厂大货主力 |

## 二、各渠道费用构成

### 1. 海运（整柜 FCL / 拼箱 LCL）

```
海运费 = 基本海运费 + 国内费用 + 目的港费用（FOB下买家付）
        ├── 基本海运费（按柜/按体积/按重量）
        ├── 国内段：工厂→港口拖车费 + 报关费 + THC港杂费 + 文件费
        └── 目的港：清关费 + 关税 + 内陆运输（CIF/DDP下卖方付）
```

| 费用项 | FOB | CIF | DDP |
|--------|-----|-----|-----|
| 出厂价 | ✅ 卖方 | ✅ 卖方 | ✅ 卖方 |
| 国内运费（工厂→港口） | ✅ 卖方 | ✅ 卖方 | ✅ 卖方 |
| 报关费/港杂费 | ✅ 卖方 | ✅ 卖方 | ✅ 卖方 |
| 国际海运费 | ❌ 买方 | ✅ 卖方 | ✅ 卖方 |
| 货运保险 | ❌ 买方 | ✅ 卖方 | ✅ 卖方 |
| 目的港清关费 | ❌ 买方 | ❌ 买方 | ✅ 卖方 |
| 进口关税 | ❌ 买方 | ❌ 买方 | ✅ 卖方 |
| 目的国内陆派送 | ❌ 买方 | ❌ 买方 | ✅ 卖方 |

> ⚠️ 待Leo确认：各航线具体海运报价区间（每柜/每立方米）。
> 实际运费随季节、舱位、油价波动，按 PI 实时核算。

### 2. 空运

```
空运费 = 燃油附加费 + 安检费 + 制单费 + 目的地费用
        （按计费重量 W/M：取实际重量与体积重量较大者）
```

- 适合：紧急补货、高货值产品
- 计费：⚠️待Leo确认具体每公斤报价

### 3. 国际快递（DHL/FedEx/UPS）

```
快递费 = 首重 + 续重 + 燃油附加费 + 偏远附加费（如有）
        （按 0.5kg 进位计费）
```

- 适合：样品、急件、补发
- 特点：门到门、最快最贵
- 计费：⚠️待Leo确认具体折扣价（签约账号有折扣）

### 4. 美国海外仓履约

```
海外仓履约费 = 头程运费（阳江→美国仓）+ 仓储费 + 订单处理费 + 尾程派送费
             （已批量备货至海外仓，现货订单只产生尾程费用）
```

| 费用项 | 说明 |
|--------|------|
| 头程（阳江→美国仓） | 海运批量备货，单位成本低 |
| 仓储费 | 按托盘/按体积月计费 |
| 订单处理费 | 每单拣货/打包操作费 |
| 尾程派送 | USPS/UPS/FedEx 本地派送 |

> 海外仓现货报价已含本地履约成本，客户看到的是"一口价"。

## 三、选路决策树（对客话术）

```
客户需求？
├─ 测款 / 小批补货 / B2C 现货 → 美国海外仓现货（1–3 天本地送达）
├─ 样品 / 急件 / 补发        → 国际快递 DHL / FedEx / UPS（3–7 天）
├─ 中等补货 / 高货值         → 空运（7–15 天）
└─ 大货 OEM/ODM 整柜/拼箱   → 海运 FOB/CIF/DDP（20–35 天，单位成本最低）
```

## 四、按业务结构的物流分工（80% B2B + 20% B2C）

| 维度 | 80% B2B 大客户（稳定基本盘） | 20% B2C 小单（曝光/现金流） |
|------|---------------------------|---------------------------|
| 客户类型 | 海外进口商、品牌商、批发商 | 海外社媒引流的零售/小B客户 |
| 订单特点 | 定制化、量大、利润高 | 现货、量小、频率高 |
| 交付方式 | 阳江工厂 OEM/ODM 生产 → 海运 20–35 天 | 海外仓 **1–3 天**发货 |
| 获客渠道 | Google SEO 为主 | TikTok / Instagram 社媒引流 |

## 六、DDP 双清到门说明

- **DDP（Delivered Duty Paid）**：完税后交货到门，双清到门，买家最省心。
- 适合无进口经验的海外小买家、Amazon/Shopify 卖家补货。
- DDP 报价需提前核算目的国关税：
  - 印度关税高 → DDP 报价需加足关税成本
  - 俄罗斯受制裁 → 需人民币结算，DDP 需特殊渠道
  - 美国关税 → 注意 301 关税清单

## 七、服务器与视频托管的"物流"配套

海外客户访问速度本身就是物流体验的一部分：

- **主服务器节点**：Hostinger 美国洛杉矶（Los Angeles），覆盖北美核心市场；欧美访问延迟 <50ms。
- **CDN 加速**：Cloudflare 全球节点——欧洲节点缓存欧洲客户秒开。
- **视频托管**：所有产品/工厂视频上传 YouTube，借 YouTube 全球 CDN 分发，不占 Hostinger 带宽。
- **严禁**把几百兆高清视频直传独立站服务器（加载慢一秒流失约 30% 客户）。
