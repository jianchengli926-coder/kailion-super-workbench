## 补充内容：六大模块详细大纲与教学金句

> 提炼自 `阳江五金刀剪协会讲座内容PPT/课程完整PPT/.../all_pptx_content.txt`（五章逐页内容）。

### 六、模块1 跨境网络合规（地基论）详细大纲

- **核心一句话**：先搭好网络底座，再谈获客、内容与运营。
- 平台如何识别你：IP 地址与归属地 / 地区 & ISP 运营商 / DNS 解析与设备指纹 / 浏览器环境 / 登录行为模式——每一项都可能触发风控。
- 普通 VPN 痛点：机房 IP 直接限流封号、共享 IP 一人违规整段被封、IP 频繁跳动判异常、ChatGPT/Claude/Google 过不了验证。
- 自建静态住宅 IP 四优势：真实家庭宽带属性、100% 独享零关联、固定 IP 不变、AI/社媒免或少验证。
- 工具关系链：买 VPS（房子）→ FinalShell（遥控器）→ x-ui（面板）+ Xray（发动机）→ 导出节点（钥匙）→ v2rayN/手机/软路由（门）。
- 自建 8 步：买 VPS → SSH 连接 → 系统初始化 → 一键装 x-ui/Xray → 建节点导出 → 客户端导入测试 → IP/DNS/IPv6 出口验证 → （可选）软路由分流。
- 软路由是 TK 标配：断网不跳 IP、连 WiFi 自动出海、SK5 分流一机一 IP、7×24 稳定。
- 实测数据：pingip.cn 风控分 100、风险值 8%、伪装度 92%；**15 台设备 / 6 个月 / 0 封号**。

### 七、模块2 AI 赋能详细大纲

- **学习路径**：AI 认知与时代趋势 → 我的 AI 使用方法论 → AI 工具矩阵与智能体 → 8 大五金行业 AI 工具实操。
- **多模型交叉验证法**：不相信任何单一 AI，10 个 AI 同时做、互相评分、人最终判断。
- **两大基石**：知识库（喂给 AI 的资料，Markdown 格式 .md/.txt/.csv/.json，别用 Word/PPT/PDF）+ 提示词（角色设定 + 任务目标 + 输入素材 + 输出格式 + 约束条件）。
- **通用 AI→企业 AI 九步工作流**：收集 → 整理 → 定义 → 分析 → 验证 → 执行 → 决策 → 沉淀 → 再利用。
- **国内 4 大 AI**：豆包（主打，文档/PPT/资料整理）、DeepSeek（中文推理强但视觉弱）、智谱清言（Agent 智能体）、文心一言（综合办公）。
- **国外 4 大 AI**：Claude（综合第一，编程长文本，幻觉率低）、ChatGPT（全能均衡）、Gemini（视觉生图最好，免费每天约 20 张）、Grok（内容创作发散）。
- **3 个 AI 智能体**：Codex（重要项目，多项目并行 + 共同记忆）、WorkBuddy（简单中文任务省钱）、豆包桌面版（国内文档 PPT 免费额度足）。
- **企业 AI 安全部署**：本地 Mac mini 只跑 Agent 引擎，数据存雷电/USB4 40Gbps 外置 SSD（Knowledge_Base_1/2 + Project_Workspace + Company_Backup 四区）；严禁 AI 直连生产独立站。

### 八、模块3 独立站与 SEO 详细大纲

- **六步认知**：认知 → 定位 → 选型 → 实操 → 增长 → 未来。
- **核心一句话**：独立站是「收询盘的机器」，不是「给自己看的作品」。
- WordPress vs Shopify 九维对比：做品牌、做 Google SEO、做 B2B 询盘 → WordPress（Leo 的选择）；快速测品不想碰技术 → Shopify。
- Leo 选 WordPress 三理由：B2B 询盘原生支持（Fluent Forms）、SEO 完全可控（Rank Math）、代码自由度高。
- 技术栈全免费：WordPress + WooCommerce + Astra + Elementor + Rank Math + Fluent Forms。
- 独立站流量真相：每个页面都是入口，不是只有首页；合理范围内页面越多入口越多。
- **SEO 三阶段路线图**：1–3 月地基期（收录，感觉没变化正常）→ 4–6 月萌芽期（长尾词排名、零星询盘，很多人在这里放弃）→ 6 月+ 增长期（核心词+长尾词排名，复利增长）。
- SEO 心法四条：耐心是最大竞争力、内容质量 > 数量、小步快跑持续更新、用 GSC 数据驱动决策。
- **Cloudflare 防护 9 步**：备份 DNS → 注册切 Nameserver → 验证 → Bot Fight Mode + Rate Limiting；免费、全球 CDN、SEO 友好，30–60 分钟部署。

### 九、模块4 本地供应链拍摄剪辑详细大纲

- **七个模块**：为什么拍工厂 → 拍什么（六大板块）→ 怎么拍（方法技巧）→ 拍成什么样（爆款）→ 怎么剪（剪辑版本化）→ 视频本地化 → 怎么转化 + 90 天行动路径。
- **信任破局**：一段 60 秒车间实拍，比十页宣传册都管用。
- **六大内容选题**：工艺锻造类 / 极限测试类 / 应用场景类 / 工厂实力类 / 行业知识类 / 客户见证类。
- **24 道工序全链路**（厨房刀样本）：原材料 → 开料成形 → 热处理 → 打磨精修 → 装配品控 → 测试包装。
- **阳江专属必拍高光五镜头**：① 红热刀胚出炉（全片最炸，120fps 慢动作）② 焊接弧光 ③ 激光火花 ④ 逆光刃口线条 ⑤ 镜面抛光。
- **爆款案例**：江西某刀片企业 TikTok 一条 8 秒视频播放超 2100 万（同行案例，不点名）。
- **多平台版本化**：YouTube 16:9 横屏 4–5 分钟深度片 / TikTok 9:16 竖屏 15–30 秒快剪 / Instagram 1:1 精修图+Reels / Facebook 16:9 30–60 秒（B2B 主打，35–45 岁决策者）。
- **视频"代码洗白"五步**：国内拍摄 → 剪映初剪 → 静态住宅 IP → CapCut 二渲（海外音乐/英文字幕）→ 海外平台发布。
- **90 天路径**：第 1 月素材库 100+ 条；第 2 月四平台稳定周更；第 3 月跑通"内容热度→广告助推→询盘承接"。

### 十、模块5 海外社媒矩阵详细大纲

- **平台月活数据**：Facebook 30 亿+、TikTok 15.9 亿、YouTube 28.5 亿；80%+ B2B 采购决策者通过社媒了解供应商。
- **核心理念**：先社媒后外贸——传统外贸"人找货"，社媒外贸"货找人"。
- **养号四周法**：第 1 周基础建设（前 3 天只浏览点赞）→ 第 2 周轻度互动（每天加 3–5 好友）→ 第 3 周内容沉淀 → 第 4 周商业准备。每号至少养 1 个月。
- **B2B 首选 Facebook**：用户画像 35–45 岁采购决策者，广告系统成熟，转化率最高。
- **赛马机制三阶段**：自然流量测试（发布原创观察数据）→ 低预算加码（自然播放 1k–10k 且互动好时开付费）→ 极速测试收询盘（$10–$100 测试目标市场）。
- **广告健康指标**：CTR 1.5%–3% 正常（<1% 需优化）；CPC $0.5–$2 合理（>$3 需优化）；转化率 5%–10% 优秀。
- **五大合规红线**：① 评论区/私信留联系方式 ② 动态机房 IP 频繁切换 ③ 直接用剪映原视频上传 ④ 个人主页直接跑广告 ⑤ 视频一发就砸钱投流。

### 十二、模块7 销售软实力与客户经营（新增）

- **销售是综合型人才，门槛最低也最高**：入职专业不限（兽医、老师、财务都能做成销冠），但流动性最大；能做满 1-3 年出业绩的人会长期留下来。核心分水岭是**情绪管理与逆商**。
- **销售必备五项能力**：及时复盘、积极工作态度、时间管理、情绪管理、终身学习。
- **情绪管理**：客户压价、催货都是常态，长期吸收负能力不清空会走不远；要学会主动释放负能量，不把情绪发泄到下一个客户身上。
- **长线思维（Long-term thinking）**：
  - 大公司采购要走完六个部门流程，大 B 客户成交周期长。
  - 真实案例：宜家客户谈了 **13 个月、6 次跟进**才下单；另一客户 2016 年接触、**2018 年才量产首单（约 27 个月）**。
  - 即使客户中途消失、打过样又消失，只要他有购买能力和需求，就不应放弃。
  - 真实案例：业务员连续发两年多邮件、客户一封没回，广交会上客户自己按新品找来展位下单。
- **信任思维（Trust thinking）**：先做自我营销，再做产品营销。信任靠点滴建立——报价丢三落四、要东报西、寄样标签混乱分不清谁家，都会让信任破裂。报价、寄样、谈判、纪要、合同每个环节都要细。
- **客户精力分配**：永远不要把有限时间浪费在无下单欲望的客户身上（连续 3-4 次问价不回 = 拿你价格压现有供应链）。
- **老客户经营**：广交会空档期邀约本地短途旅游；发送餐服务；礼物走心不印大 logo（详见 `16_展会参展指南（已归档2026-09-28→主版本 展会参展全流程指南 v4.1）.md`）。
- **新人上手 SOP**：入职第一周做市场洞察+客户背调；每人锁定一个 dream customer 做成亚克力牌贴"梦想墙"，直到拿下为止。
