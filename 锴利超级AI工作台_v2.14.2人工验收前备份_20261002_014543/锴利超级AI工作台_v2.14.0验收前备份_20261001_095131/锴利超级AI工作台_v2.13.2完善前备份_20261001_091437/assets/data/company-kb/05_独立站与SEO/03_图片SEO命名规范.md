# 图片 SEO 命名规范（V3 终极版）

> 来源：`图片命名KaiLionCrafts_图片SEO命名超级指令_V3终极版.md`
> 适用：每 SKU 5–7 张多角度图，四张 SEO 字段（文件名 / Alt / Title / Description）成套输出。

## 一、四项 SEO 字段结构

### 1. 图片文件名 File Name
- 全小写、仅连字符 `-`、`.webp` 结尾
- 结构：`[核心产品关键词]-[关键特征/材质]-[角度标识]-[SKU].webp`
- 4–6 组核心词，禁堆砌；禁 premium/best/high-quality 虚词
- 黑名单：IMG / DSC / WechatIMG / Photo / Picture / Image / Final / New / Copy、中文、空格、括号、下划线
- 示例：`m390-fixed-blade-hunting-knife-blade-detail-kl-od-hc-016.webp`

### 2. 替代文本 Alt Text
- ≤ 125 字符
- 结构 = 产品类型 + 该角度可见特征 + 背景措辞 + 完整 SKU
- 句尾带 SKU；同 SKU 多图 Alt 不得雷同
- 示例：`Damascus nakiri vegetable knife with an iridescent abalone shell handle, isolated on white background. KL-KN-DS-001-01`

### 3. 图片标题 Title
- 5–12 词
- 结构：`[核心产品名] - [角度/卖点] | KaiLionCrafts`
- 示例：`Damascus Nakiri Knife - Iridescent Abalone Shell Handle | KaiLionCrafts`

### 4. 图片描述 Description
- 2–3 句、50–80 词，三段式：
  1. 品类固定开头句
  2. `This image showcases the [Product] from a [angle] perspective, highlighting [feature].`
  3. 目标客群收尾（B2B procurement managers / wholesale distributors / private label brands）

## 二、四大品类固定开头句（一字不差）

| 品类 | 开头句 |
|------|--------|
| 户外刀 | …premier OEM/ODM source manufacturer of professional outdoor knives… |
| 厨房刀 | …professional kitchen knives… |
| 剪刀 | …professional scissors & shears… |
| 厨房用品 | …professional kitchenware & accessories… |

## 三、拍摄角度词库（标准化）

front-view / 45-degree-view / side-view / back-view / top-view / blade-close-up / blade-detail / handle-close-up / handle-detail / logo-detail / folded-view / opened-view / with-sheath / with-accessories / packaging-show / gift-box / outdoor-scene / kitchen-scene / in-use / in-hand / workbench-scene

> 补充常用视角：bolster-detail、display-stand、features-infographic、size-measurement、weight-scale。

## 四、背景 → Alt 措辞对照

| 背景 | Alt 措辞 |
|------|---------|
| 白底 | isolated on white background |
| 木台 | displayed on wooden tabletop |
| 厨房 | in kitchen environment |
| 户外 | outdoor camping scene |
| 礼盒 | in retail packaging |
| 手持 | held in hand for scale |
| 工作台 | on workbench setting |

## 五、多图排序规则（同 SKU 多图顺序）

```
主图(白底) → 45度 → 侧面 → 背面 → 细节特写(刀刃/手柄) → Logo → 配件/刀鞘 → 包装 → 使用场景
```

## 六、三类图片命名规则

### A. 产品图（V3，本规范主体）
按上述四段结构 + 角度词库 + 背景措辞，文件名带 SKU。

### B. 公司/工厂图（V2 融合版）
- 命名：`kailioncrafts-[用途]-[场景]-[细节].webp`，全小写连字符。
- 代表：`cnc-precision-machining-spindle-custom-manufacturing.webp`、`blacksmith-anvil-and-hammer-artisan-forging.webp`。

### C. 独立站大屏图（V1）
- 首页/Hero 级大图，命名见 `独立站新seo大图/独立站大图.txt`。

## 七、SEO 检查清单

- [ ] 文件名全小写连字符、.webp、含 SKU
- [ ] 无 IMG/DSC/中文/空格/下划线
- [ ] Alt ≤125 字符、句尾带 SKU、多图不雷同
- [ ] Title 5–12 词、结尾 `| KaiLionCrafts`
- [ ] Description 三段式、含品类固定开头句
- [ ] 角度词来自标准词库
- [ ] 背景措辞与实际场景一致
