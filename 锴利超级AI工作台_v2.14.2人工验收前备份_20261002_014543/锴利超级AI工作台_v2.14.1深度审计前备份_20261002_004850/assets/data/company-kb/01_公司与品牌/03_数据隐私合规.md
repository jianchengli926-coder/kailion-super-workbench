# 数据隐私合规

> 本文件覆盖外贸独立站必须遵守的主要数据隐私法规：欧盟GDPR、加州CCPA/CPRA、中国PIPL，以及隐私政策/Cookie政策英文模板。
> ⚠️ 原始资料中未发现独立站已部署的隐私政策/Cookie政策HTML文件，以下模板为**新建参考模板**，上线前需由律师审核。

## 一、GDPR 欧盟数据保护条例（外贸网站必守要点）

### 1.1 适用范围

GDPR（General Data Protection Regulation, EU 2016/679）适用于：
- 任何向欧盟境内用户提供商品或服务的企业（无论企业注册在哪个国家）
- 即使没有欧盟实体，只要网站有欧盟访客并收集其个人数据，即受GDPR管辖

> **来源**：EUR-Lex GDPR: https://eur-lex.europa.eu/legal-content/EN/ALL/?uri=legissum%3A310401_2 （检索日期：2026-09-27）

### 1.2 核心合规要点

| 要点 | 要求 | KaiLionCrafts落地措施 |
|---|---|---|
| **法律基础** | 处理个人数据必须有合法依据（同意/合同履行/合法利益） | 购物订单=合同履行；营销邮件=明示同意；Cookie=分类同意 |
| **透明度** | 隐私政策必须清晰告知：数据收集者身份、收集目的、数据类别、接收方、存储期限、用户权利 | 网站底部链接Privacy Policy |
| **用户权利** | 访问权、更正权、删除权（被遗忘权）、数据可携带权、反对权、限制处理权 | 提供privacy@kailioncrafts.com邮箱 |
| **数据最小化** | 只收集必要数据 | 询价表单仅收集：姓名、邮箱、公司、国家、需求描述 |
| **Cookie同意** | 非必要Cookie必须在用户同意前不得加载 | 部署Cookie同意横幅（Cookiebot/Complianz等） |
| **数据跨境传输** | 欧盟数据传出欧盟需有适当保障措施（SCC标准合同条款等） | 网站服务器若在美国，需签署EU-US Data Privacy Framework或SCC |
| **DPO** | 大规模处理特殊类别数据或核心活动涉及大规模监控的企业需指定DPO | 外贸B2C站通常不需要专职DPO，但需指定数据保护联系人 |
| **数据泄露通知** | 72小时内通知监管机构 | 建立内部数据泄露响应流程 |

### 1.3 EDPB 2025年最新建议（电商场景）

EDPB 2025年12月发布建议：电商网站**不应强制要求创建用户账户才能购物**，应提供"访客结账"（guest checkout）选项。

> **来源**：EDPB Recommendations 2/2025: https://www.edpb.europa.eu/news/news/2025/edpb-gives-recommendations-make-online-shopping-more-respectful-users-privacy_de （检索日期：2026-09-27）

## 二、CCPA/CPRA 加州消费者隐私法

### 2.1 适用门槛

CCPA/CPRA适用于满足以下任一条件的企业：
- 年总收入超过 **$25 million**
- 每年购买/出售/共享 **100,000+** 加州消费者或家庭的个人信息
- **50%以上**年收入来自出售消费者个人信息

> **来源**：California OAG: https://www.oag.ca.gov/privacy/ccpa （检索日期：2026-09-27）

### 2.2 加州消费者核心权利（LOCKED）

| 权利 | 英文 | 内容 |
|---|---|---|
| L - 限制权 | Limit | 限制敏感个人信息的使用 |
| O - 退出权 | Opt-Out | 退出个人信息的"出售/共享"（含广告追踪） |
| C - 更正权 | Correct | 要求更正不准确的个人信息 |
| K - 知情权 | Know | 知道收集了什么、为什么、与谁共享 |
| E - 平等权 | Equal Service | 行使权利不得歧视、不得降价/降服务 |
| D - 删除权 | Delete | 要求删除个人信息 |

> **来源**：California Privacy Protection Agency: https://privacy.ca.gov/california-privacy-rights/rights-under-the-california-consumer-privacy-act/ （检索日期：2026-09-27）

### 2.3 外贸网站落地要求

1. 网站底部必须有 **"Do Not Sell or Share My Personal Information"** 链接
2. 隐私政策中需披露收集的数据类别、用途、共享类别
3. 提供消费者权利请求渠道（邮箱/表单）
4. 响应Do Not Track信号/Global Privacy Control (GPC)

## 三、PIPL 中国个人信息保护法

### 3.1 适用范围

PIPL（《个人信息保护法》）自2021年11月1日起施行。境外企业向中国境内个人提供产品/服务，或分析评估境内个人行为，同样适用。

> **来源**：CAC 促进和规范数据跨境流动规定: https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm （检索日期：2026-09-27）

### 3.2 跨境数据传输要求

根据2024年3月《促进和规范数据跨境流动规定》：

| 场景 | 豁免/要求 |
|---|---|
| 跨境购物、跨境寄递、跨境支付等**为订立履行合同所必需** | **免予申报数据出境安全评估**、免订立标准合同、免认证 |
| 非必要的营销/分析数据出境 | 需满足：安全评估 / 标准合同备案 / 保护认证 三者之一 |

> 💡 KaiLionCrafts作为中国出口企业，主要数据流向是**海外客户数据→中国服务器**（即数据入境中国），PIPL主要约束的是**中国境内个人信息出境**。海外客户数据进入中国不涉及PIPL出境问题，但需注意：
> - 中国员工个人信息（HR数据）的处理
> - 若有中国消费者通过独立站购买（反向跨境），需遵守PIPL

## 六、数据处理协议（DPA）要点

### 6.1 什么是DPA

数据处理协议（Data Processing Agreement, DPA）是控制者（Controller）与处理者（Processor）之间的合同，规定处理者如何处理个人数据。GDPR第28条要求。

### 6.2 DPA核心条款

| 条款 | 内容 |
|---|---|
| 处理目的与范围 | 明确处理者只能按控制者指示处理数据 |
| 保密义务 | 处理者授权人员须保密 |
| 安全措施 | 处理者须实施技术和组织安全措施 |
| 分包处理者 | 处理者使用子处理者须经控制者授权 |
| 数据主体权利协助 | 处理者协助控制者响应数据主体请求 |
| 数据泄露通知 | 处理者须在知悉后及时通知控制者 |
| 审计与检查 | 控制者有权审计处理者的数据保护措施 |
| 数据删除/返还 | 合同终止后删除或返还个人数据 |

### 6.3 KaiLionCrafts涉及的DPA场景

| 服务方 | 角色 | 是否需DPA |
|---|---|---|
| Shopify/WooCommerce | 平台（处理订单数据） | ✅ 平台标准DPA |
| Stripe/PayPal | 支付处理 | ✅ 已提供DPA |
| Google Analytics | 数据分析 | ✅ Google Data Processing Amendment |
| Mailchimp/邮件营销 | 营销邮件 | ✅ 需签署DPA |
| 海外仓/物流 | 订单履约 | ✅ 建议签署 |
| 云服务器（AWS/阿里云） | 数据存储 | ✅ 云厂商标准DPA |
