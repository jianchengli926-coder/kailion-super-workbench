# OEM / ODM / Private Label 定制能力

## 一、定制服务总览

公司围绕四大品类面向全球批发商、进口商、品牌商（Private Label）、Amazon/Shopify 卖家、零售连锁提供一站式定制服务：

| 服务类型 | 说明 |
|---|---|
| OEM | 来图来样代工，按客户规格生产 |
| ODM | 基于现有产品选型 + 客户化修改开发 |
| Private Label | 客户品牌贴牌，KaiLionCrafts 提供产品与视觉/包装方案 |
| 自主品牌开发 | 产品开发、多语言资料、独立站/SEO 配套 |

> 定位：用大厂的顶级工艺标准与材料渠道，做大厂因产能饱和不愿接的小批量定制订单。

## 二、定制分级与 MOQ

> 按定制深度分三级，MOQ 与交期逐级递增。

| 级别 | 定制内容 | MOQ | 交期 | 说明 |
|---|---|---|---|---|
| **轻度定制 Light** | Logo 雕刻、手柄选择、包装 | **50–150 pcs 起** | ≤ 15 天（定制 Logo 单） | 小品牌/试单友好 |
| **中度定制 Mid-level** | 定制刀型、手柄成型（开模） | **150 pcs 起** | ≤ 30 天 | 客户化刀型/手柄 |
| **全 ODM 开发 Full ODM** | 概念 → 3D 建模 → 开模 → 量产 | **500 pcs 起** | ≤ 30 天；**7 天内出 3D 建模** | 全新 Private Label 开发 |

> 现货订单：≤ 7 天发货。

## 三、可定制选项明细

| 定制项 | 具体内容 |
|---|---|
| **Logo 雕刻** | 刀身激光雕刻（laser）、丝印（silk screen）；支持刀身、刀背、手柄多位置；电蚀（传统）+ 激光（现代）两种工艺 |
| **手柄 Logo** | 手柄 Logo 压铸 |
| **手柄材质** | 花梨木/彩木（Rosewood）、G10、聚合物/POM/ABS、Micarta 米卡塔、鲍鱼壳；ABS 机打 / 彩木人工 / 空心柄机打多种工艺 |
| **刀身钢材** | VG10、9Cr18MoV、5Cr15MoV、3Cr13、高碳钢复合、大马士革钢、德国 1.4116、Outokumpu 1.4028/Dura 420 |
| **表面处理** | 镜面抛光（mirror）、缎面（satin）、黑色涂层（black coating）、钛涂层（titanium coating）、石洗（stone wash） |
| **刀型** | 主厨刀、三德刀、Nakiri、中式菜刀、尖头刀、套刀/刀架套装；可定制刀型 |
| **包装设计** | 吸塑（blister）、木盒（wooden box，FSC 认证 Homeful）、皮盒（leather case）、礼盒（gift box）、彩盒；可定制品牌包装盒/吸塑托 |
| **产品组合** | 厨房套刀、礼品套装组合、完整厨房品牌捆绑套装 |
| **认证协调** | CE / LFGB / FDA / RoHS 等认证测试与文件协调（第三方实验室） |

## 四、打样流程

```
需求沟通 → 选材/选规格 → 3D 建模（全 ODM 7 天内）→ 打样确认 → 产前 QC 视频 → 批量生产 → 三道 QC → 发货前视频确认 → 发货
```

- 开模打样、手柄材质选择、表面处理均可定制。
- 产前提供 QC 视频确认材料、工艺、外观。
- 发货前创始人亲自审查验货视频（包装、标签、刃口锋利度、手柄装配）→ 客户最终确认后发货。

## 五、商务条款

| 项目 | 政策 |
|---|---|
| 付款方式 | 30% 定金生产 + 70% 发货前付清尾款 ⚠️ 商务条款仅对客户合同 |
| 贸易条款 | EXW / FOB / CIF / DDP |
| 小批量 | MOQ 低至 50 pcs 试单；试单→复购支持 |
| 法律主体 | 阳江市锴利国际贸易有限公司（完整进出口经营权） |
| 知识产权 | 与每家工厂、每位客户签严格 NDA 与防规避协议（anti-circumvention） |

## 六、配套增值服务（每单附赠营销素材）

> 创始人自媒体/摄影背景，自建 4K 摄影棚；每单免费附赠完整媒体包，可直接用于 Amazon/TikTok/Shopify/Instagram。

- 4K 产品摄影：白底图、生活场景图、细节特写
- 生产过程视频：原材料→锻造→热处理→研磨→组装→包装全流程
- 产品展示视频：360° 展示、开箱、功能演示
- 包装展示素材：定制包装开箱体验
- 发货前 QC 视频
- 工厂实地直播 / 实时视频通话（创始人英语直接沟通）
- AI 英文产品详情、多语言资料、独立站产品页/SEO 素材

## 七、目标客户类型

- 进口商、批发商、分销商
- 品牌商（Private Label）
- Amazon / Shopify / TikTok 卖家
- 零售连锁、礼品公司
- 小批量初创品牌（MOQ 50pcs 起友好）
