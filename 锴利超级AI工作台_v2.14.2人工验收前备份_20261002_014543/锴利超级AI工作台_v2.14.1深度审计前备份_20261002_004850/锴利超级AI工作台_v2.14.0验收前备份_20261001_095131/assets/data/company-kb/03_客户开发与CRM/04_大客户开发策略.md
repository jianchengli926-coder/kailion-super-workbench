# 大客户开发策略

> 大客户 = 进口商 / 品牌商 / 连锁批发商 / 大型连锁零售商
> 特点：决策链长、关注稳定供货和认证、首单慢但复购稳、利润高

---

## 一、大客户类型与开发重点

### 1. 进口商（Importer/Distributor）
- **画像**：从中国采购后分销给本地零售商；有仓库、有销售团队
- **关注点**：价格有竞争力、交期稳定、MOQ灵活、能做贴牌
- **开发切入点**：海关数据找现有供应商，打"替代/补充供应商"牌
- **关键人**：Import Manager / Purchasing Director

### 2. 品牌商（Brand Owner）
- **画像**：自有品牌，找工厂OEM/ODM；注重设计和品质
- **关注点**：品质一致性、OEM/ODM能力、认证齐全、保密性
- **开发切入点**：发定制案例（激光LOGO、定制手柄、专属包装）
- **关键人**：Sourcing Manager / Product Developer

### 3. 连锁批发商（Wholesaler/Chain）
- **画像**：多家门店或线上分销网络；走量大
- **关注点**：阶梯价格、稳定供货、包装标准化、交期
- **开发切入点**：发年度框架价方案
- **关键人**：Category Buyer / Procurement Manager

### 4. 连锁零售商（Retail Chain）
- **画像**：线下连锁店（如Williams-Sonoma, Sur La Table）
- **关注点**：验厂通过、BSCI/Sedex社会责任审核、CE/FDA认证齐全
- **开发切入点**：先发BSCI报告+工厂视频，降低验厂顾虑
- **关键人**：Buyer / Vendor Manager

---

## 二、决策链分析

大客户决策链通常包含以下角色，开发时需逐一触达：

| 角色 | 关注点 | 触达方式 |
|---|---|---|
| **CEO/Owner** | 公司战略、合作价值 | 创始人级别对接（Leo亲自） |
| **Purchasing Manager** | 价格、交期、MOQ | 日常主要沟通人 |
| **QC/Quality Manager** | 品质、认证、检测报告 | 技术资料+样品测试 |
| **Product Developer** | 设计、材质、OEM能力 | 发定制案例+打样 |
| **Finance** | 付款条件、信用 | 报价单+付款条款 |

> **策略**：不要只盯采购经理，通过LinkedIn找到QC和产品开发，分别发不同角度的邮件。

---

## 三、关键人触达策略

1. **找到对的人**：用LinkedIn Sales Navigator 搜公司 + 职位
2. **别发info@**：99%石沉大海。直接找到具体人名+邮箱
3. **多维度触达**：
   - 邮件（正式资料）
   - LinkedIn InMail（简短打招呼）
   - WhatsApp（如有手机号）
   - 展会面谈（最佳）
4. **引荐法**：通过共同LinkedIn好友引荐，回复率提升数倍

## 四、样品策略

| 客户阶段 | 样品策略 |
|---|---|
| 首次索样 | 付费样品（样品费可在大货抵扣）；运费到付 |
| 深度谈判 | 免费寄样+DHL预付；附完整检测报告 |
| OEM/ODM | 收取打样费（大货退还）；7-15天打样周期 |
| 验厂前 | 寄全套产品系列样品+工厂视频+产能表 |

### 样品包标准配置
- 样品本体（检查无瑕疵）
- 材质检测报告（SGS/LFGB/FDA）
- 规格表（精确到毫米）
- 包装细节图
- 公司简介PDF
- 手写感谢卡（加分项）

## 五、大客户跟进节奏

| 阶段 | 时间 | 动作 |
|---|---|---|
| 首次接触 | Day 0 | 个性化开发信 |
| 等待回复 | Day 3/7/14/21/30 | 7封跟进序列 |
| 客户回复 | 24小时内 | 需求确认+发资料包 |
| 报价 | 48小时内 | 正式报价单+阶梯价 |
| 样品 | 3天内安排 | 寄样+tracking number |
| 样品反馈 | 收到后3天 | 主动询问+调整方案 |
| 谈判 | 1-4周 | 多轮沟通、视频会议 |
| 首单 | 1-3个月 | PI签订+定金到账 |
| 首单后 | 每2周 | 生产进度汇报 |
| 交付后 | 30天 | 回访+争取复购 |

> **注意**：大客户从接触到首单通常需要1-3个月，日本客户可能3-6个月。耐心是关键。

## 六、大客户资料包标准配置

| 资料 | 用途 |
|---|---|
| 公司简介PDF（中英双语） | 首次接触 |
| 产品目录PDF（四大品类完整） | 需求确认 |
| 工厂宣传视频 | 建立信任 |
| BSCI/Sedex社会责任审核报告 | 欧洲零售商必备 |
| FDA/LFGB/CE/RoHS/FSC证书 | 产品合规 |
| TÜV/SGS第三方检测报告 | 品质证明 |
| 产能表（月产能/年产能） | 供货能力 |
| Outokumpu钢材材质证明EN 10204-3.1 | 高端材质背书 |
| 客户案例/出口记录 | 社会证明 |
