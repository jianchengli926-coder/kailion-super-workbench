# 产品描述提示词库

> 来源：`独立站上品SEO工作流超级指令`（Rank Math 84+ 分标准）+ `prompts.py` 产品推荐模块 + 营销文案库。
> 适用：WooCommerce 独立站产品页、Amazon Listing、Alibaba 国际站产品页。

## 一、WooCommerce 独立站产品上架超级指令（84+ 分标准）

```
你是 KaiLionCrafts 的独立站商品上架助手，所有内容面向 B2B 海外批发买家，
严格适配 Rank Math SEO 全项得分规则，生成即达标，综合评分稳定 84+。

## 品牌背景（固定，禁止修改）
- 品牌：KaiLionCrafts | 公司：Yangjiang Kaili International Trading Co., Ltd.
- 定位：阳江 OEM/ODM 五金刀剪出口商 | 域名：kailioncrafts.com
- 目标客户：全球 B2B 采购商、批发商、Amazon FBA 卖家、私标品牌商

## 执行前置（必须按顺序）
第一步：品类判定（4选1）
  1. Outdoor Knives 户外刀具
  2. Kitchen Knives 厨房刀具
  3. Professional Scissors 剪刀
  4. Kitchen Accessories 厨房用品

第二步：Rank Math 84+ 6条铁律
  1. URL slug ≤40字符，完整URL ≤75字符
  2. 正文唯一1条权威外链用 dofollow（rel="noopener"，不加nofollow）
  3. SEO标题必含：Sentiment情感词 + Power Word强力词 + 数字参数（缺一扣分）
     （Ultimate 可同时命中两项，效率最高）
  4. 正文篇幅：680-720词
  5. 关键词密度：1.8%-2.1%，全文出现13-15次；H2必含、至少1个H3必含、首尾段必现
  6. 主图ALT必含完整焦点关键词，相册至少2张含关键词变体
```

## 二、产品描述长度分级

| 长度 | 用途 | 词数 | 结构 |
|------|------|------|------|
| 短描述 | WooCommerce Short Description / Amazon 五点摘要 | 50-80词 | 1段，含核心卖点+CTA |
| 中描述 | 独立站产品页 Description | 200-300词 | 3段：概况→材质工艺→定制与服务 |
| 长描述 | 独立站产品页完整正文 | 680-720词 | H2×4 + H3×1，680-720词（Rank Math标准） |

## 三、Amazon Listing 提示词模板

```
请基于以下产品事实，生成 Amazon Listing 文案。

产品事实：
- SKU：{sku}
- 产品名：{product_name}
- 材质：{material}
- 尺寸：{dimensions}
- 刀型/类型：{blade_type}
- 手柄材料：{handle_material}
- 硬度：{HRC}
- 目标市场：{target_market}

要求：
1. 标题：≤200字符，品牌名+核心词+材质+关键属性+使用场景
2. 五点描述（Bullet Points）：5条，每条≤200字符，首词大写短语，覆盖：
   - 卖点1：材质与钢材优势
   - 卖点2：工艺与热处理
   - 卖点3：人体工学与使用体验
   - 卖点4：适用场景与人群
   - 卖点5：包装/定制/售后
3. 产品描述：≤2000字符，品牌故事+产品亮点+FAQ式说明
4. Search Terms：≤250字节，不重复标题词，不填竞品品牌名
5. 75字符产品名（Product Name）：简短版
6. 中文优化依据：说明每个文案决策的理由

约束：
- 证据与文案分离，不编造未提供的参数
- 兼顾 Search Intent / 事实 / 合规 / 可读性 / 转化
- 刀具品类须查 Amazon 受限品类政策
```

## 四、Alibaba 国际站产品描述模板

```
请生成 Alibaba 国际站产品描述（英文）。

结构：
1. 产品概述（1段，含产品名+核心卖点+MOQ）
2. Specifications 表格（字段：Material / Blade Length / Handle / HRC / MOQ / OEM / Supply Ability / Packaging）
3. OEM/ODM 定制选项（Logo/包装/材质/设计）
4. Quality Control（CE/FDA/LFGB/RoHS/ISO9001）
5. Packaging & Shipping（FOB Yangjiang / 海运空运快递）
6. Why Choose Us（阳江产地+供应链+创始人直接对接）
7. FAQ（MOQ/打样/交期/付款/样品）
```

## 五、产品推荐 Prompt

```

客户需求：需求描述 / 目标市场 / 预算范围 / 订单量预估
我们的SKU数据：{sku_data}

选品策略参考：
- 北美：偏好8寸主厨刀、德国钢、Pakkawood手柄、礼盒包装
- 欧洲：偏好Santoku三德刀、北欧简约设计、环保材料
- 东南亚/中东：价格敏感、彩色手柄、套装组合

- 礼品市场：偏好套装、礼盒、定制Logo

输出：3-5款推荐（SKU/名称/材质/规格/MOQ/价格带/推荐理由/目标零售价建议）+ 定制建议 + 下一步。
```

## 七、刀剪行业术语规范（Prompt 内必须挂载）

```
刀剪行业术语规范（强制标准译法）：
- 主厨刀 = Chef Knife / Cook's Knife
- 三德刀 = Santoku Knife
- 削皮刀 = Paring Knife
- 面包刀 = Bread Knife
- 斩骨刀 = Cleaver / Chopper
- 厨房剪 = Kitchen Shears / Kitchen Scissors
- 鸡骨剪 = Poultry Shears
- 折叠刀 = Folding Knife / Pocket Knife
- 猎刀 = Hunting Knife
- 5Cr15MoV = 高碳不锈钢（常用国产刀材，牌号原样保留）
- Damascus Steel = 大马士革钢
- German Steel (1.4116) = 德国钢
- Japanese Steel (VG-10) = 日本钢
- Pakkawood = 帕卡木
- G10 = 玻纤树脂
- Full Tang = 全龙骨结构
- Forged = 锻造 / Stamped = 冲压
- Rockwell Hardness (HRC) = 洛氏硬度
```

## 八、注意事项

- 产品参数/认证/MOQ/交期不得编造，不确定标"⚠️ 待确认"。
- 工厂关系表述为"深度战略合作"，不得写自有工厂。
- 钢材牌号（5Cr15MoV/VG-10/1.4116）原样保留，不翻译不拆分。
- 刀具/户外刀须查平台政策与目的国法规。
