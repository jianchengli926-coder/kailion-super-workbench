模型使用逻辑

🔄 默认优先级

在线 GLM 免费 → 其他在线供应商 → Ollama 本地文本 → Ollama 本地视觉。在线全部失败时自动回退到本地 Ollama。

👆 用户手动选择

用户手动选择的供应商/模型优先使用，仅在失败时才触发故障转移。通过 onProviderUsed 回调显示实际使用的模型，不静默换模型。

🛡️ 类型保护

embedding 不用于聊天、纯文本不用于视觉、文本不用于图片、图片不用于 embedding。getModelForType 按能力匹配，无同类型模型时跳过该备用供应商。

⏹️ 停止中断

用户点击停止后，AbortController 立即终止当前请求，故障转移链检测到 signal.aborted 后不再尝试备用模型。

🔁 故障转移配置

支持开关、顺序配置、单次重试上限、失败原因记录、主备模型自动替换。qwen3.5 仅在 Ollama 环境使用，不切换到不支持它的供应商。

📊 实际模型显示

每次调用后通过 onProviderUsed(providerName, modelId) 报告实际使用的供应商和模型，UI 可展示"已切换到备用模型"提示。

知识库功能（586 文档 · 14 分类）

🔍 混合检索

关键词搜索 + 向量搜索（nomic-embed-text:latest，768维）合并去重，按相似度排序。向量不可用时自动回退关键词检索。

📄 资料展示

搜索结果显示资料标题、分类、来源路径、更新时间、相似度百分比。无命中时明确提示"未找到相关资料"，不编造。

💉 LLM 注入

生成内容时自动注入相关资料片段，附"不得编造参数/认证/案例"约束。生成后进行事实核对，提取数字与引用资料比对。

🔄 索引管理

页面加载自动增量索引新文档，支持手动重建索引（带进度条）。向量缓存到 localStorage，索引状态持久化。

登录保护

🔐 界面锁屏

前端密码验证为本地界面锁屏机制，不是企业级认证。sessionStorage 持久化登录状态，关闭浏览器后失效。公网/局域网部署必须启用服务端 ACCESS_TOKEN。

🚫 5次锁定

连续5次密码错误后锁定1分钟，锁定状态持久化到 sessionStorage（跨刷新有效）。锁定期间实时倒计时显示，到期自动解锁。

👁 密码显示切换

密码输入框 type=password，支持显示/隐藏切换按钮。错误提示不泄露正确密码，登录成功后清理敏感输入，退出登录清理会话。

🛡️ 防重复提交

提交中按钮显示加载动画，isSubmitting 标志防止重复点击。未登录不能通过内部 URL 绕过（登录遮罩层高 z-index 覆盖全部内容）。
