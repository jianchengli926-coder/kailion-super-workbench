## 四、遗漏功能补全情况

### 4.1 已补全功能（3项）

#### 🥇 功能1：画布撤销/重做
- **修改文件**：canvas.js
- **实现**：undoStack/redoStack（上限50步），`takeSnapshot()` 深拷贝，`pushHistory()` 在17处 mutating 操作前埋点，`undo()`/`redo()` 互推栈恢复
- **快捷键**：Ctrl/⌘+Z（撤销）、Ctrl/⌘+Shift+Z 或 Ctrl/⌘+Y（重做）
- **按钮**：绑定 index.html 中已有的 btn-undo/btn-redo
- **拖拽优化**：mousedown 记录状态，未真正移动则回退空点击，避免误触污染历史

#### 🥈 功能2：API自动重试 + 错误分类中文提示
- **修改文件**：api.js + i18n.js
- **自动重试**：5xx/网络错误/超时自动重试最多3次，退避 900ms×次数（900/1800/2700）；401/403/404/429/400 立即失败；用户取消立即失败
- **错误分类**：9类（auth/quota/cors/server/network/timeout/model/notfound/badrequest），每类给可执行中文提示
- **接入**：chatCompletion 整体替换为 apiFetch；videoGeneration/model3DGeneration 在 catch 中加 classifyError

#### 🥉 功能3：生图形态自动探测
- **修改文件**：api.js
- **3种形态**：① `/images/generations`（OpenAI标准）② `/v1/images/generations`（带/v1前缀）③ `/chat/completions`（Gemini多模态风格）
- **记忆机制**：第一个成功后写入 `localStorage['ljc_image_form_<providerId>']`，后续直接命中
- **兼容提取**：`extractImageUrls()` 兼容 data.data[]、data.images[]、choices[].message.images[]、content[].image_url、Gemini inlineData、顶层 url

## 七、重要判断说明

### 7.1 localStorage 前缀未从 ljc_ 改为 ljs_
任务要求统一 `ljs_` 前缀，但全项目扫描结果：`ljs_` 出现 **0 次**，`ljc_` 统一使用约 **40 个 key、遍布 21 个文件**。且 ui.js 维护了一份「导出全部数据」的 key 清单。若批量改名会导致：
- 老用户已存数据全部孤立（无法读取）
- 备份/恢复功能漏掉数据
- 需跨21文件迁移工程

故遵循「不重构、增量修复」原则，维持 `ljc_`。如需全库迁移，建议单独立项并做旧 key 兼容迁移。

### 7.2 品牌残留处理
- 活代码中「利建成/小利/网蜂窝/WfwCreator/Wfw3D/lijiancheng」**0 残留**（已全部修复）
- `KaiLionCrafts`/`kailioncrafts.com` 经判定为用户**真实外贸品牌**（占位符示例、官网域名、SKU/品牌种子数据），非工作台品牌残留，正确保留
- `i18n.js.bak` 是含旧品牌的备份文件，未被 index.html 加载，建议手动删除归档
