## 四、Bug 清单（按严重程度排序）

### 🔴 严重（P0）
**无。** 未发现导致页面崩溃、白屏或核心功能不可用的严重 Bug。

### 🟡 中等（P1）

#### Bug #1：语义资源库（semantic）I18N 键缺失
- **严重程度**：P2（轻微，但持续刷警告）
- **分类**：国际化 / 资源库
- **现象**：打开"语义"资源库时，控制台连续输出 15 条警告：
  ```
  [I18N] missing key: res.semTitle
  [I18N] missing key: res.semSub
  [I18N] missing key: res.semSearch
  [I18N] missing key: res.semAdd
  [I18N] missing key: res.semEmpty
  ```
- **复现步骤**：
  1. 打开 index.html
  2. 左侧导航点击"🧠 语义"
  3. 查看 Console
- **预期结果**：语义资源库的标题/副标题/搜索框/添加按钮/空状态应有对应 i18n 键，英文模式下正确翻译。
- **实际结果**：5 个 i18n 键未在 `i18n.js` 中定义，英文模式下回退显示中文键名；每次渲染重复输出警告。
- **影响范围**：仅英文模式下的语义资源库界面文案；中文模式不受影响（中文为默认回退）。
- **建议修复**：在 `i18n.js` 的语言包中补充 `res.semTitle` / `res.semSub` / `res.semSearch` / `res.semAdd` / `res.semEmpty` 的中英文翻译。

### 🟢 轻微（P3 / 观察项）

#### 观察 #1：手册描述"8 个预设供应商" vs 实际 13 个
- **分类**：文档一致性
- **现象**：使用说明书 API 配置指南章节写"🏢 支持的供应商（8个预设）"，但实际设置面板的 `#provider-presets` 渲染了 **13 个**预设按钮。
- **建议**：更新手册文案或确认预设数量。

#### 观察 #2：版本号不一致
- **分类**：元数据
- **现象**：`package.json` 中 version 为 `2.1.2`，但设置面板"关于"区显示 `v2.2.0`。
- **建议**：统一版本号。

#### 观察 #3：启动遮罩淡出时长
- **分类**：体验
- **现象**：启动遮罩 2.2s 后淡出（CSS 控制），无头测试等待 5s 已完全消失，无问题。
