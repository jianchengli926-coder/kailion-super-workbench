| 办公工作流 | HTML、Word、Excel、PPT、PPT内容、PPT组装（6） |
| 生活工具 | 命理玄学（1） |

### 1.2 资源库：14 类
角色、场景、品牌、风格、专家、数字人、技能、商品、知识、素材、提示词、选题、工作流、**语义**。（专家/数字人/选题/风格/角色/场景/品牌/商品出厂默认隐藏）

### 1.3 工作流模板：20 个分类
图像创作、视频创作、故事漫剧、内容创作、PPT制作、图像处理、多模态混合、电商详情页、工业设计、专家协作、专家讨论、品牌运营、商业方案、文旅、社媒运营、翻译本地化、代码开发、数据分析、音频播客（+1 注释称共 20 类）。

### 1.4 画布与交互
拖拽节点、连线串联、滚轮以鼠标为中心缩放、自动布局、撤销/重做(Ctrl+Z)、复制粘贴、Delete 删除、框选多选、分组、便签、小地图（教程/产品页明确写到「撤销/重做、复制粘贴、自动布局」）。

### 1.5 运行引擎
Kahn 拓扑排序、依赖解析、**分层批量并行执行**、环检测告警、停止/中断（AbortController 中止在途请求）、异步任务进度/任务状态、**4 步 stepper 执行面板可视化、可暂停**、节点结果缓存。

### 1.6 API 与集成
- 供应商管理：8 图像模型 + 8 视频模型 + 3 大 LLM 协议（OpenAI / Claude / Gemini），生图节点必须手动选模型。
- SSE 流式对话、生图、视频、3D（GLB/OBJ/STL/PLY/3MF 五格式互转，远程直链转 3MF 打印文件）。
- **MCP 协议**接任意外部工具；**CLI 本地命令行**；**内置 HTTP API 服务器（17 个 REST 端点）**供外部程序调用；**飞书机器人**群聊下达需求。
- 自定义 Skill 创建。

### 1.7 数据持久化
本地 **SQLite**（Tauri）、断网可用、不上传服务器、自动保存、工作流库保存、**数据备份整体导出搬家**、历史记录自动沉淀一键重跑。

### 1.8 UI / 体验
节点搜索、可见性「管理」弹窗、侧边栏 **AI 助手全屏对话**、**提示词独立编辑器**（含提示词库、语义库、模型切换、AI 优化）、快捷键、Toast 通知、主题。

### 1.9 智能进化内核（差异化高价值能力）
1. **UnifiedWorkbench 智能工作台**：一句话 → 意图解析 → 自动建画布 → 直接执行；意图预测引擎、真实置信度评估、**低置信度主动澄清反问**、参数槽位校验、非法参数（比例/时长/页数）生成前自动纠正、画像记忆 + 执行反馈回流。
2. **AI 教练 / 智能分析**：执行完自动检测画布结构（断边/孤立节点自动修复）、Prompt 智能优化、主动提示「要不要我优化这工作流」。
3. **TOOLFORGE AI 工具工厂**：缺口探测 → 生成规格 → 真跑验证 → 注册为可复用技能，跨重启长期保留，默认关闭待人工启用。
4. **AI 智能选 MCP**：说出意图自动匹配并预填 MCP 模板（包名/参数/协议），只向用户索令牌，匹配不到用工具工厂自举兜底。
5. **深度思考模式**：分析 → 规划 → 执行 → 反思四阶段结构化推理，带 critic 自检与子问题分解。
6. **数字人记忆与进化**：持久记忆、能力画像随协作沉淀；开启「自主进化」后以品牌契合度为闸门自我迭代，结构级改动须人工审批。
7. **任务引擎与复盘**：OKR 式大目标拆可验收子任务，每轮对照验收标准复盘，成功即归档案例库，反馈回流调优。
8. **GAP SCANNER 差距自感知**：周期扫描「反复想做但现有节点覆盖不了」的意图簇，聚类计数达阈值自动派单锻造（self-discovered）。
9. **定时任务 cron**、批量并行、**敏感操作人工确认闸门**（询盘外呼须人工点确认，按次扣点不重试不退费）。
10. 30+ 预设专家、多模态内容审查、GEO 生成式引擎优化。

原始 19 类全部保留，**新增「跨境供应链」**类；每类提供 3–6 节点的可加载模板（`workflow-templates.js`）。

### 2.4 画布与交互（`canvas.js`，2018 行）
拖拽、连线、滚轮缩放 30%–200%、拖拽空白平移、**空格临时平移**、多选/框选、分组移动、**便签（v0.9.0）**、**小地图（可折叠）**、自动布局、**撤销/重做（v2.2.0，快照栈）**、复制节点、**保存为节点模板**、对齐辅助线、双击空白加提示词、resetZoom。→ **画布能力比原始更丰富**。

### 2.5 运行引擎（`engine.js`，1633 行）
Kahn 拓扑排序、**拓扑分层并行调度（MAX_CONCURRENCY=3）**、runAll/runSelected（serial/parallel）、**环检测告警**、stop（AbortController 统一中止在途请求）、执行进度条、节点结果缓存、子图环检测。

### 2.6 API 与集成
- 供应商管理（`providers-data.js`）：**13+ 预设**——OpenAI、DeepSeek、豆包/火山、Claude、Gemini、通义千问、智谱GLM、wawapi 中转站、**Ollama 本地模型**、**硅基流动 SiliconFlow**、**Tripo3D / Meshy（3D）**。
- 三协议（openai / anthropic / gemini）、SSE 流式 chat（`api.js`）、生图（/images/generations，base64/url 自动识别）、模型列表 `/v1/models` 拉取、连通测试、默认供应商。
- MCP（`mcp.js`）：前端保存服务器配置，交由 Electron 端启动本地进程。

### 2.7 数据持久化
localStorage（非 SQLite）、断网可用、**全量数据导出/导入（JSON + ZIP 含图片回注，`export.js`/`ui.js`）**、工作流导出 JSON/PNG、**版本历史（20 条 FIFO）**、**运行历史（50 条，快照恢复一键重跑）**、**API 调用日志与费用统计（200 条）**。

### 2.8 UI / 体验
**中英文双语切换（`i18n.js`，2719 行，节点中英名/描述全本地化）**、**6 套预设主题 + 6 色自定义（`theme-manager.js`）**、**全局搜索 Ctrl+K（`search.js`，覆盖节点/模板/市场/资源库/说明书）**、快捷键（`shortcuts.js`）、Toast 通知、节点可见性勾选、小锴助手悬浮面板、**智能工作台意图引擎（`smart.js`：25 条规则 + 槽位抽取 + 置信度 0.55 阈值主动澄清 + 非法参数自动纠正）**、**AI 教练画布体检（`coach.js`：孤立节点/断链/空参数/环/未配供应商 5 项检查）**、**技能库（`skills.js`：从选中节点保存可复用组合）**、**批量并行 + cron 定时任务（`tasks.js`，每分钟 tick 自动触发）**、执行步骤 stepper 可视化（v2.0.0）。

## 四、缺失功能清单（按优先级）

### 🔴 高价值（直接影响开放生态与「越用越聪明」的核心卖点）

| # | 缺失功能 | 说明 |
|---|---|---|
| H1 | **本地 HTTP API 服务器（REST 端点）** | 原始有 17 个 REST 端点供外部程序调用；超级工作台完全没有后端服务能力，外部系统无法触发/读取工作流。 |
| H2 | **飞书机器人群聊协同** | 原始支持飞书群聊直接下达创作需求；超级工作台无任何 IM 机器人接入。 |

## 五、高价值缺失功能补全建议（落到文件）

> 以下为实现路径建议，**未改动任何代码**。按依赖顺序排列。

### H1 本地 HTTP API 服务器
- **落点**：新增 `electron/server.js`，在 `electron/main.js` 里 `app.whenReady()` 时启动（Node 内置 `http`/`express`），通过 `preload.js` 暴露给渲染进程。
- **端点建议**（对齐原始 17 个）：`GET /api/workflows`、`POST /api/workflows`、`POST /api/run`（触发 `window.Engine.runAll`）、`GET /api/nodes`、`POST /api/nodes`、`GET /api/resources/:lib`、`GET /api/status`、`GET /api/history`、`GET /api/providers`、`POST /api/chat` 等。
- **桥接**：渲染进程通过 `IPC` 把 Canvas 状态/Engine 句柄暴露给主进程 HTTP handler。
- **配置**：端口（默认 7878）、Token 鉴权开关放进「设置」。

### H2 飞书机器人
- **落点**：新增 `assets/js/feishu-bridge.js`，复用 H1 的 HTTP server 接飞书事件订阅回调；消息文本转给 `window.Smart.parseIntent()` → `buildWorkflow()` → `Engine.runAll()`，结果回推飞书卡片。
- **依赖**：H1 完成后再加；飞书 App ID/Secret/Verification Token 放供应商管理同级设置项。

### H3/H3b 工具工厂 + 差距自感知
- **落点**：扩展 `assets/js/skills.js`（当前只有 `saveFromSelection/load`）。
- **新增**：
  - `gapScanner.js`：周期扫描 `kailion_smart_history` + 运行历史，对意图关键词做聚类，同类意图 ≥N 次未命中已有技能时弹窗「要不要为你锻造一个技能？」。
  - `toolforge.js`：缺口探测 → 调 LLM 生成节点规格 JSON → 用已有节点类型试跑验证 → 成功后 `Skills.saveFromSelection()` 注册，存 `ljc_skills`。
- **安全**：默认关闭，设置里开关；跨重启保留靠 localStorage。

### H4 深度思考模式
- **落点**：`assets/js/nodes.js` 的 `llmContentNode` 执行分支 + `assets/js/api.js`。
- **做法**：节点参数面板加「深度思考」开关；开启后把单次请求拆为 4 段 system prompt（分析→规划→执行→反思），中间结果写入节点预览区，critic 段对产出做自检后再定稿。复用现有 SSE 流式。

### H5 任务引擎与复盘
- **落点**：扩展 `assets/js/tasks.js`（已有 batch/cron）。
- **新增**：OKR 大目标 → LLM 拆子任务（带验收标准）→ 逐个 `runSelected` → 对照验收标准复盘 → 成功案例存 `ljc_casebook`。失败案例也入库并回流到 H3 差距扫描。

### H6 AI 教练自动修复
- **落点**：`assets/js/coach.js`（已有 5 项 `check`）。
- **新增**：`autoFix()`——孤立节点自动连线到最近提示词节点、断边自动重连或删除、空提示词自动填入推荐 prompt；Prompt 优化调 LLM 改写并 diff 展示，用户确认后写回。主动提示由 `engine.js` run 完成事件触发。

### M1/M3 画像记忆与数字人进化
- **落点**：新增 `assets/js/user-memory.js`，存 `ljc_user_profile`（高频意图、常用供应商、偏好画幅/风格/语言）；数字人协作结束后把「哪次方案被采纳」写回 `ljc_digital_humans` 的能力画像字段，供下次协作加权。

## 七、结论

- **节点覆盖度**：超级工作台已 100% 继承原始 68 节点并扩展到 76 个，资源库 14 类全保留，工作流模板 20 类齐整——**底座无缺口**。
- **画布/引擎/持久化/UI**：超级工作台在多数维度**已追平甚至反超**原始（便签、小地图、双语、主题、搜索、版本/历史/费用统计）。
- **真正的缺口集中在「开放生态」与「智能进化」两条线**：
  - 开放生态：H1 HTTP API 服务器、H2 飞书机器人、M7 真实后端执行（MCP/CLI/供应链）。
  - 智能进化：H3 工具工厂+差距自感知、H4 深度思考、H5 任务复盘、H6 教练自动修复、M1 画像记忆。
- **建议补全顺序**：H1（解锁一切外部集成）→ H3/H6（让工作台自生长）→ H4/H5（深度能力）→ H2/M7（业务落地）。这样既能以最小成本补齐原始的「7×24 开放流水线」卖点，又不会丢掉超级工作台已有的双语+垂直专线+工程化优势。
