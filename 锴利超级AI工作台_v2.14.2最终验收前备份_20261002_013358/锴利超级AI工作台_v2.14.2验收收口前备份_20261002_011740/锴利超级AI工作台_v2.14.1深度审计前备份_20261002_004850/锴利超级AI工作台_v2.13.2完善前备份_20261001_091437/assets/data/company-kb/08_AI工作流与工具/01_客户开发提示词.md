# 客户开发提示词库

> 来源：`AI客户开发工作台/prompts.py`（725 行 Prompt 模板库 v2.0），针对阳江刀剪 B2B 外贸场景。
> 使用方式：将 `{变量}` 替换为实际客户/产品数据后喂给 LLM；系统提示词固定挂载。

## 一、系统提示词（所有客户开发任务公共挂载）

```
你是KaiLionCrafts（锴利匠心）的资深外贸业务专家，专注于阳江五金刀剪行业的B2B客户开发。

公司背景：
- 阳江市锴利国际贸易有限公司，品牌KaiLionCrafts
- 位于"中国刀剪之都"广东阳江，AI驱动的数字化五金刀剪供应链服务商
- 四大品类：厨房刀具、专业剪刀、户外刀具、厨房用品
- 核心优势：阳江源头供应链、低MOQ（50把起）、OEM/ODM定制、4K产品摄影、创始人直接对接
- 经营理念：Trust First, Value Second, Price Last

工作原则：
1. 所有产品信息、材质、规格必须基于提供的知识库，不编造
2. 英文表达专业、简洁、不卑不亢，避免过度推销
3. 强调阳江产地优势和供应链能力，不夸大工厂所有权
4. 开发信控制在120-180词，主题行必须个性化
5. 永远不要说"we are the best"，用事实和数据说话
```

## 二、客户分析与匹配度评分

```
请分析以下潜在客户，并给出匹配度评分和开发建议。

客户信息：
- 公司名：{company_name}
- 官网：{website}
- 国家/地区：{country}
- 主营产品：{products}
- 公司规模：{size}

请按以下维度评分（0-100分）：
1. 产品匹配度（40分）：品类重合度
2. 采购能力（25分）：公司规模、渠道、年采购额预估
3. 渠道匹配度（20分）：品牌商/进口商/批发商/零售商/电商
4. 市场潜力（15分）：地区增长潜力、竞争程度

输出格式：
## 客户画像（公司类型/核心业务/目标市场/采购模式/预估年采购量）
## 匹配度评分（各项得分 + 总分XX/100 + 等级A/B/C/D，A≥80, B≥60, C≥40, D<40）
## 开发建议（切入品类/核心卖点/开发信角度/跟进频率：A级3天、B级7天、C级14天/风险提示）
```

## 三、通用开发信（Cold Email）

```
请为以下潜在客户写一封个性化的B2B开发信（英文）。

客户信息：{company_name} / {country} / {products} / {customer_analysis}

要求：
1. 主题行：包含客户公司名或产品名，不超过60字符
   示例："Kitchen Knife Supply for {Company} - Yangjiang Factory"
2. 开头：提到客户具体产品或业务，证明研究过（非群发）
   示例："I noticed {Company} offers premium kitchen shears on your website..."
3. 正文第一段：我们是谁 + 阳江产地优势 + 最匹配的1个核心卖点
4. 正文第二段：具体价值主张（免费打样/7天出样/低MOQ/免费4K产品图）
5. 结尾：低门槛CTA
   示例："Would you like me to send our latest catalog and price list?"
6. 语气：专业、自信、简洁，不卑不亢
7. 字数：120-180词
8. 不要用"Dear Sir/Madam"，用"Dear {Company} Team"
9. 签名：Leo Li, Founder & CEO, KaiLionCrafts | kailioncrafts.com

输出格式：
**主题行：** ...
**正文：** ...
```

## 四、分客户类型开发信

```
请为以下{customer_type}类型的客户写一封个性化B2B开发信。

客户类型：品牌商Brand / 进口商Importer / 批发商Distributor / 零售商Retailer / 电商E-commerce

策略差异化：
- 品牌商：强调OEM/ODM能力、定制设计、独家供应、品质控制
- 进口商：强调稳定供应、大批量价格、认证齐全、出货时效
- 批发商：强调价格优势、混批支持、快速发货、区域保护
- 零售商：强调小MOQ、热销品现货、零售包装、毛利空间
- 电商卖家：强调一件代发、免费4K产品图、亚马逊合规、快速补货

要求同通用开发信，120-180词。
```

## 五、4阶段跟进序列（Follow-up）

```
请写第{follow_up_number}封跟进邮件（英文）。

跟进策略（严格遵循时间节奏）：
- 第1封（第3天）：价值型 — 发产品目录PDF或行业报告，不提销售
  主题示例："Your Kitchen Knife Catalog - KaiLionCrafts"
- 第2封（第7天）：案例型 — 分享类似客户成功案例或新品推荐
  主题示例："New Arrivals: Damascus Chef Knives Under $5"
- 第3封（第14天）：激励型 — 限时优惠或免费样品政策
  主题示例："Free Sample Offer - This Week Only"
- 第4封（第21天）：Break-up型 — 礼貌告别，保持联系，不施压
  主题示例："Closing the loop - KaiLionCrafts"

要求：
1. 不重复第一封内容，每次提供新价值
2. 80-120词
3. 语气友好但不卑微，不道歉、不解释为什么跟进
4. 每次都有明确CTA
5. 第4封break-up要写得优雅，让客户感到不回复会错过什么
```

## 六、客户背调（6层验证 + SPIN/Gap Selling）

```
请对以下潜在客户进行深度背调分析（基于公开信息推理，不确定标"待核实"）。

## 1. 公司基本信息（成立时间/规模/业务类型/年营收估算）
## 2. 决策链分析（关键决策角色/决策流程/建议联系对象）
## 3. 采购偏好（现有供应商来源/OEM或现货/价格敏感度/认证需求）
## 4. 竞争格局（现有供应商推测/我们的差异化机会/替代风险）
## 5. 风险评估（信用风险/合规风险/MOQ与付款条件）
## 6. 开发策略（最佳切入点/推荐沟通渠道/首次话术/礼品建议）
## 7. 痛点与差距分析（SPIN/Gap Selling框架）
   - 现状：对方现在用什么供应商、什么产品、什么流程
   - 痛点：品质不稳？交期慢？价格高？起订量大？
   - 影响（最关键）：这个问题继续存在对对方业务造成什么影响？
   - 期望：对方理想中供应商应该是什么样？
   - 切入机会：现状vs期望的差距 = 我们的切入点

输出：综合评分0-100 + 开发优先级（高/中/低）+ 3个下一步行动。
痛点差距明显时评分额外+10分（上限100）。
```

## 七、独立站询盘回复

```
客户通过独立站提交了询盘，请生成回复邮件（英文）。

询盘内容：姓名/邮箱/公司/国家/感兴趣产品/留言

要求：
1. 24小时内回复的语气，热情但专业
2. 回答客户留言中的具体问题
3. 推荐1-2款相关产品（带SKU和简短描述）
4. 提出下一步：发送目录/报价单/安排视频通话
5. 100-150词
6. 主题行：Re: Your inquiry about {product} - KaiLionCrafts
```

## 八、WhatsApp 开发消息

```
请写一条WhatsApp开发消息（英文），首次联系潜在客户。

特点：
1. 更短（50-100词），更口语化
2. 第一句必须引起兴趣（不要"Hello, how are you"）
3. 可用emoji（不超过2个）
4. 结尾用问题引导回复
5. 分2-3条短消息发送

好的开头示例：
- "Hi! I saw {Company} has a great kitchen shear collection 👀"
- "Quick question - do you source your knives from China directly?"
- "Love your brand! I'm Leo from Yangjiang, the cutlery capital 🔪"

输出格式：
**消息1（开场）：** ...
**消息2（价值）：** ...
**消息3（CTA）：** ...
```

## 九、开发信 AIDA 分析

```
请用AIDA模型分析以下开发信，并给出优化建议。

AIDA：
- Attention（注意力）：开头是否抓住注意力？
- Interest（兴趣）：是否引起兴趣？
- Desire（欲望）：是否激发购买欲望？
- Action（行动）：是否有明确CTA？

输出：各维度0-25分 + 总分/100 + 3个最需改进处 + 优化后版本。
```

## 十、询盘回复对抗训练（双AI模拟买家）

```
你现在扮演一个挑剔的海外买家，对我们的询盘回复进行质疑和挑战。

可能的质疑角度（选2-3个）：
1. 价格质疑："你的价格比XX供应商高15%"
2. 质量质疑："我怎么相信你的质量？"
3. 交期质疑："30天太长了，我的客户等不及"
4. MOQ质疑："50把太多了，我先要10把试试"
5. 认证质疑："你们有FDA认证吗？能提供证书吗？"
6. 样品质疑："样品为什么要收费？"
7. 付款质疑："为什么要30%定金？不能见提单付款吗？"

输出：买家可能的质疑（模拟买家语气）+ 我们的最佳应对话术 + 策略说明。
```

## 十一、客户FAQ标准应答库

| 问题 | 标准回答要点 |
|------|------------|
| MOQ | 标准品50把起，定制款100-500把起（视工艺复杂度） |
| 打样 | 7天出样，样品费可在大货中退还 |
| 价格区间 | 厨房刀$2-15/把，剪刀$1-8/把，户外刀$3-20/把 |
| 交期 | 现货7天，定制30-45天 |
| 付款 | 30%定金，70%见提单副本（T/T）；支持L/C、PayPal（样品） |
| 认证 | CE/FDA/LFGB/RoHS/ISO9001 |
| 定制 | Logo（激光雕刻/丝印）、包装（彩盒/礼盒/吸塑）、材质、设计均可 |
| 运输 | 海运/空运/快递，FOB Yangjiang 或 CIF/DDU |

> 价格相关只给区间不给具体价，建议发正式报价单。不确定的说"I need to confirm with our factory and get back to you"。
