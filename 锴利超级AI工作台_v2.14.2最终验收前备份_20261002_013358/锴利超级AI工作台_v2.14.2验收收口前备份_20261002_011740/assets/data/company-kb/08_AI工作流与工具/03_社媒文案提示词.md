# 社媒文案提示词库

> 来源：全局指令第18章社媒语气规范 + 锴利超级工作台内容创作节点 + 五金刀剪行业营销文案库。
> 核心原则：不同平台语气差异化；AI 不虚构工厂/客户/认证/数据。

## 一、平台语气规范（全局指令第18章）

| 平台 | 语气定位 | 内容侧重 |
|------|---------|---------|
| **LinkedIn** | B2B 专业、行业洞察 | 供应链趋势、制造工艺、外贸经验、公司里程碑 |
| **Instagram** | 产品工艺视觉、品牌故事 | 高清产品图、工厂工艺特写、匠人精神、生活方式 |
| **TikTok** | 短、直观、现场过程化 | 锻打火花、淬火、磨刃、开箱、 before/after |
| **Facebook** | 社区互动、温和品牌 | 产品使用教程、用户互动、行业新闻 |
| **微信朋友圈** | 真实克制、创业阶段感 | 参展、新品、工厂日常、个人思考 |

## 二、LinkedIn B2B 帖子模板

```
请为 KaiLionCrafts 写一篇 LinkedIn B2B 帖子。

主题：{topic}
（可选：阳江刀剪产业带 / OEM定制流程 / QC质检标准 / 外贸选品趋势 / 展会回顾）

要求：
1. 开头1-2句钩子（行业数据/痛点提问/反常识事实）
2. 正文3-4段：问题 → 我们的做法 → 价值点 → CTA
3. 语气：专业、行业洞察，不硬卖
4. 结尾CTA：邀请连接/评论/私信获取目录
5. 长度：150-250词
6. Hashtag：#Cutlery #KitchenKnives #OEM #Yangjiang #PrivateLabel #B2B + 2个行业标签
7. 不编造客户案例/订单金额/出口国数量
```

**LinkedIn 钩子示例：**
- "Why 8-inch chef knives from Yangjiang cost 40% less than European brands — and what that means for your margin."
- "We audited 12 knife factories last month. Here are the 3 QC red flags every buyer should check."

## 三、Instagram 产品帖模板

```
请为 KaiLionCrafts 写一条 Instagram 产品帖文案。

产品：{product_name}
配图方向：{product_in_hand / flat_lay / factory_process / lifestyle}

要求：
1. 第一行是视觉钩子（emoji + 画面感描述）
2. 正文2-3段：产品亮点 → 使用场景 → 定制信息
3. 语气：美学、工艺感、克制
4. CTA：DM for wholesale / Link in bio
5. Hashtag（8-12个）：#KnifeMaking #ChefKnife #KnifeCommunity #Yangjiang #Cutlery #KitchenTools #DamascusKnife #OEM
6. 不编造材质/参数，只写图片中真实可见的内容
```

## 四、TikTok 短视频脚本模板

```
请为 KaiLionCrafts 写一条 TikTok 短视频脚本（15-30秒）。

主题：{forging_sparks / quenching / grinding_edge / unboxing / before_after / knife_test}
素材：自家工厂实拍

结构：
- 0-3秒 钩子（视觉冲击：火花/慢动作/对比）
- 3-10秒 过程（1-2个核心镜头，配简短旁白或字幕）
- 10-20秒 结果（成品展示/切开番茄/锋利度测试）
- 20-30秒 CTA（"Follow for more knife making" / "DM for OEM"）

要求：
1. 字幕大而醒目，前3秒必须有视觉钩子
2. 旁白简短有力，每句≤8词
3. BGM：热门节奏型
4. 刀具演示注意平台审核红线（不展示伤人/不当使用）
5. 素材必须真实工厂实拍，AI不虚构生产线
```

**TikTok 钩子镜头清单：**
- 锻打火光特写（forging sparks）
- 淬火蒸汽升腾（quenching）
- 砂轮磨刃火花（grinding）
- 一刀切番茄纸（sharpness test）
- 开箱包装（unboxing ASMR）
- 成品排列展示（knife roll layout）

## 五、Facebook 社区互动帖模板

```
请为 KaiLionCrafts 写一条 Facebook 互动帖。

类型选择：
A. 投票互动："Which chef knife do you reach for most? 🔪 A) 8-inch chef B) Santoku C) Paring"
B. 教程分享："How to store your kitchen knives properly (5 mistakes to avoid)"
C. 行业新闻：转发行业趋势 + 我们的评论

要求：
1. 语气比 LinkedIn 轻松，比 TikTok 专业
2. 鼓励评论互动
3. 长度：80-150词
4. Hashtag：3-5个
```

## 七、注意事项

- AI 不得虚构工厂生产线、客户合影、认证标志、产品参数。
- 刀具视频注意各平台审核红线（不展示暴力/伤人/不当使用）。
- 社媒文案中的"我们"指 KaiLionCrafts 品牌，工厂关系表述为深度战略合作。
- 所有对外内容默认 English（面向海外客户）；微信朋友圈用中文。
