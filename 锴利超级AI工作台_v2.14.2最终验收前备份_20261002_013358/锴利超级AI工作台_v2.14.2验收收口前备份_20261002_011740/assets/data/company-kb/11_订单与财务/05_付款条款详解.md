# 付款条款详解

> 核心铁律：**30% 定金到账 + 规格书面批准**才开工；**70% 尾款到账**才放货/放提单。

---

## 一、标准两段式付款（行业基准）

```
① 确认订单（签 PI）
   ↓ 付 30% 定金（Deposit）
收到定金 + 规格书面批准 → 才开工生产
   ↓
② 出货前视频确认（Pre-Shipment Video Inspection）
   ↓ 付 70% 尾款（Balance）
收到尾款 → 安排发货 / 放提单
```

| 节点 | 比例 | 触发条件 | 到账后动作 |
|------|------|---------|-----------|
| **Deposit 定金** | 30% | 签回 PI | 收到 + 规格书面批准 → 下单给工厂生产 |
| **Balance 尾款** | 70% | 出货前视频验货 + 客户书面确认 | 收到尾款 → 放货 / 放正本提单 |

> ⚠️ 待Leo确认：是否所有客户都执行 30/70，还是有例外（如 A 类老客户可谈见提单副本付尾款）。

## 二、各收款方式对比（优劣与风险）

| 方式 | 英文 | 适用场景 | 费率/成本 | 到账时效 | 优点 | 缺点/风险 |
|------|------|---------|----------|---------|------|----------|
| **T/T 银行电汇** | Telegraphic Transfer | **大货定金+尾款主力** | 中间行费用约 $25–$50/笔 | 1–3 个工作日 | 最常用、大额安全、可退税 | 有中间行扣费、需手动核账 |
| **PayPal** | PayPal | 样品费、小单（≤$5,000） | 费率约 4.4% + 固定费 | 即时 | 即时到账、客户体验好 | **费率高**、冻结风险、大额不划算、不可退税 |
| **Western Union 西联汇款** | Western Union | 中小单、紧急款 | 按金额收费，相对低 | 即时–当天 | 快速便捷、手续简单 | **不可退税**、需到银行解付、大额不规范 |
| **L/C 即期信用证** | Letter of Credit (Sight) | 大额信任订单（≥$50K） | 银行费用约 $200–$500/笔 | 单证相符后 5–7 天 | 银行信用背书、买卖双方都有保障 | 流程复杂、单证要求严格、费用高 |
| **XTransfer** | XTransfer | 大额退税首选 | 费率 0.5%–1% | 1–2 个工作日 | 提现快、可退税、适合外贸 SOHO | 需实名认证、有额度限制 |

> 来源：`09_行业知识与培训/04_外贸从0到1实操指南.md`（XTransfer 费率 0.5%–1%）。

## 三、按订单金额分级推荐付款方式

| 订单规模 | 推荐付款方式 | 说明 |
|---------|-------------|------|
| **样品单（<$500）** | PayPal / Western Union | 小额、即时、客户垫付样品费 |
| **小单（$500–$5,000）** | PayPal / Western Union / T/T | 灵活选择，PayPal 客户体验好 |
| **常规 OEM/ODM 大货（$5,000–$50,000）** | **T/T（30% 定金 + 70% 尾款）** | 最常用，主力方式 |
| **大额订单（≥$50,000）** | T/T 或 L/C 即期信用证 | 大额信任客户可谈 L/C |
| **海外仓现货小批** | T/T / PayPal（按约定） | 现货即走 |

## 四、高风险地区付款策略

### 俄罗斯 / CIS 客户

> 受国际制裁影响，美元/欧元结算通道受限。

| 项目 | 要求 |
|------|------|
| **结算货币** | **人民币 CNY 跨境支付**（目前最常用） |
| **预付比例** | 首单 **50%+**（标准 30% 不够） |
| **禁止事项** | 不接受通过可疑第三国公司的付款 |
| **替代方案** | 第三方货币转口（谨慎） |

### 印度 / 南亚客户

| 项目 | 要求 |
|------|------|
| **结算方式** | T/T 为主，也接受 L/C |
| **预付比例** | **最少 20%–30%**（标准 30% 即可） |
| **红线** | **未收到定金前绝不组织生产** |
| **OA 账期** | 高风险，仅对熟悉客户，且必须买中信保 |
| **关税** | 印度关税高，客户常要求 DDP 报价 |

### 澳洲 / 新西兰客户

- OA 赊销仅对熟悉客户，且必须查 **Dun & Bradstreet 信用报告**。

## 七、风险控制红线

1. **不接受**通过可疑第三国公司的付款（尤其俄罗斯方向）。
2. 首单对高风险地区客户**提高预付比例**（俄罗斯最好 50%）。
3. **OA 赊销**仅对熟悉客户，且必须查信用报告（澳新 D&B / 印度中信保）。
4. **未收定金不排产**，未收尾款不放货/放提单。
5. 所有收款必须在工作台 payments 表登记，手动折人民币。
6. 每批出货 **Leo 本人签字放行**。

## 八、收付款登记（工作台口径）

每一笔收付款都进 `payments` 流水表，一条订单可对应多条流水（天然支持 30% 定金 + 70% 尾款分批）：

| 字段 | 说明 |
|------|------|
| 日期 | 收/付发生日 |
| 方向 | 收客户 / 付工厂 |
| 关联订单号 | 下拉选销售订单号 |
| 金额 / 币种 | 原币金额（USD 主力 / EUR / GBP / CNY） |
| 汇率 | **手动填写**，折人民币 |
| 方式 | T/T / 西联 / 信用证 / PayPal / XTransfer |
| 备注 | 如"30% 定金""出货前 70% 尾款" |

**自动计算：**
- 应收 = Σ订单金额 − Σ已收
- 应付 = Σ采购额 − Σ已付工厂
