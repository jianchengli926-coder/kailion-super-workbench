## Master Sheet 建议字段

填完48账号后，用一张表统一管理：

```
Category | Owner | Platform | Display Name | Username/Handle | Public URL | 
Primary Landing URL | Secondary URL | Business Type | Avatar Version | 
Banner Version | Public Email | WhatsApp | Last Profile Update | 
Policy Check | Link Test | Screenshot | Notes
```

**URL提取方法**（各平台）：
- LinkedIn: 个人页→Share/Copy link
- Facebook: Page→About→Copy link
- Instagram: Profile→Share profile→Copy link
- TikTok: Profile→Share→Copy link
- YouTube: Studio/Channel→Share→Copy link
- Pinterest: Profile→Copy link（记录是否Claim root domain）
- X: Profile→Share→Copy link
- WhatsApp: Settings→Business tools→Short link
- Messenger: m.me/{page-username}
- Gmail/Outlook/Zoho: 无公开profile URL，用mailto:
