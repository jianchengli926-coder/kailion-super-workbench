> 本文件是 `09_美国仓选址与布局逻辑.md` 的**运营深化版**：前者讲"为什么选这三州"，本文件讲"每个仓怎么用、三仓怎么配合、单仓多仓怎么算账"。

## 一、三仓总览回顾

| 区位 | 州 | 核心定位 | 覆盖州（对客口径） | 标称时效 |
|------|---|---------|------------------|---------|
| 美西 | California（Fontana） | 现货出库 + 仓内激光/丝印轻定制 | CA, OR, WA, AZ, NV | 1–2 天 |
| 美中 | Texas | 中部枢纽，托盘级大货仓储与分发 | TX, OK, KS, MO, LA | 2–3 天 |
| 美东 | New Jersey | FBA/B2C 专人履约打包 | NY, NJ, PA, MA, CT, FL | 1–2 天 |

> 来源：`09_美国仓选址与布局逻辑.md` 第二节。其余美国本土州统一按"1–3 个工作日"口径。

## 二、美西 CA 仓（Fontana, California）

### 2.1 优势

- **头程最近**：紧邻 LA / Long Beach 港，海运到港后卡车短驳即可入仓，头程尾段成本最低。
- **西海岸消费密集**：加州人口第一大州，LA/SF/SD 都会区订单密度高。
- **华人生态圈**：南加州 Inland Empire 是中国卖家海外仓与 FBA 配套最密集区域，服务商资源丰富。
- **轻定制工位已落地**：仓内激光雕刻/丝印 Logo 加工能力已确认（见 `09_美国仓选址与布局逻辑.md` 第六节）。
- **已有实景素材**：Fontana 仓外景图已备，可用于页面/PPT。

### 2.2 劣势

- **仓租与人工成本最高**：加州地产与人工成本全美前列，长期仓储单位成本三仓最高（具体数字待确认，见 `14_海外仓成本核算与优化.md`）。
- **不覆盖东部**：从 CA 发纽约/佛罗里达 Zone 7-8，尾程费高、时效 3-5 天。
- **Q4 港口拥堵**：LA/LB 港旺季可能拥堵，影响入库时效。
- **加州合规复杂**：California Prop 65 警告、包装法（CalRecycle）等合规要求比其他州多。

### 2.3 适合品类与产品

| 适合 | 说明 |
|------|------|
| 热销 SKU 现货 | 西海岸订单密度高，快周转 |
| 需轻定制（激光/丝印 Logo）的订单 | 工位在 CA |
| 户外刀具/户外用品 | 加州户外文化浓厚，西海岸户外需求大 |
| 小批量 B2B 样品单 | 1-2 天送达西海岸客户 |
| 高价轻小件 | 仓租虽高但周转快可摊薄 |

### 2.4 不适合

- 大托盘级慢周转大货（仓租贵）。
- 发往东部的订单（应路由到 NJ）。

## 三、美中 TX 仓（Texas）

### 3.1 优势

- **仓租与人工成本最低**：德州无州税、地产与人工成本远低于 CA/NJ，适合慢周转品集中存储（具体数字待确认）。
- **地理中心**：向东西南北辐射的地面运输距离相对均衡，是天然中转枢纽。
- **托盘级大货仓储**：定位为托盘级大货仓储与分发中心（见 `09_美国仓选址与布局逻辑.md` 第六节）。
- **南部市场覆盖**：覆盖 TX/OK/KS/MO/LA 中南部，这一区域制造业与油气产业 B2B 需求稳定。

### 3.2 劣势

- **不临海**：头程到港后需内陆卡车转运（LA 或 Houston 港），入库时间略长。
- **人口密度低**：本地终端消费密度不如东西两岸，B2C 直邮订单密度低。
- **夏季高温**：德州夏季极端高温，对包装/产品存储有一定影响（刀剪类金属产品需注意）。
- **轻定制工位待确认**：是否具备激光/丝印能力未明确（见 `09_美国仓选址与布局逻辑.md` 待确认清单）。

### 3.3 适合品类与产品

| 适合 | 说明 |
|------|------|
| 托盘级大货存储 | 中部枢纽定位 |
| 长尾/慢周转 SKU | 仓租最低，集中放这里省钱 |
| 中部 B2B 批发订单 | TX/OK/KS/MO/LA 2-3 天达 |
| 跨仓调拨中转站 | CA/NJ 缺货时从 TX 中转 |
| 大包装/套装组合 | 成本低，适合大货作业 |

### 3.4 不适合

- 需 1-2 天达的东西海岸急单。
- 需轻定制但 TX 无工位的订单（应路由到 CA）。

## 四、美东 NJ 仓（New Jersey）

### 4.1 优势

- **东北走廊人口密集**：NY/NJ/PA/MA/CT 占美国人口约 1/4，订单密度最高。
- **FBA/B2C 专人履约**：定位为 FBA 贴标/混装/B2C 打包履约中心（见 `09_美国仓选址与布局逻辑.md` 第六节）。
- **东海岸时效**：覆盖东北走廊 1-2 天达，FL 等东南州 2-3 天。
- **纽约港便利**：头程到 NY/NJ 港后短驳入仓。
- **Amazon 运营中心集中**：NJ/PA 一带 FBA 仓库密集，转 FBA 入仓距离短。

### 4.2 劣势

- **仓租成本较高**：纽约都会区地产成本高（仅次于 CA）。
- **冬季天气**：冬季暴风雪可能导致派送延误。
- **人工成本高**：东北都会区人工工资高于德州。

### 4.3 适合品类与产品

| 适合 | 说明 |
|------|------|
| FBA 备货贴标/混装 | 专人管理 FBA 履约 |
| B2C 直发订单 | 东北走廊 1-2 天达 |
| 东部零售客户 | NY/PA/MA 零售商补货 |
| 高价/急单 | 时效要求高的东部客户 |
| 套装组合/礼盒 | B2C 打包能力 |

### 4.4 不适合

- 大托盘级慢周转品（仓租贵，应集中 TX）。
- 西海岸订单（应路由到 CA）。

## 五、三仓协同策略

### 5.1 库存分配原则

```
热销 SKU（月动销 > X 件）  → 三仓均匀铺货，每仓保安全库存
常规 SKU                   → 两仓铺（CA + NJ），TX 按需调拨
长尾 SKU（>180天滞销风险） → 集中 TX（仓租最低），另一仓放最小安全库存
新品测款                   → 先放 CA 一仓小批量，跑通后再铺 NJ/TX
```

> ⚠️ 具体动销阈值 X 待运营数据积累后确定；参见 `13_海外仓库存管理实操.md` ABC 分类法。

### 5.2 订单路由规则（自动/人工分仓）

```
客户下单（含目的邮编）
   ↓
WMS/人工判断目的仓
   ├─ 目的邮编在 CA 覆盖区（西部）→ CA 仓有货？→ CA 发货
   │                                → CA 无货？→ 查 TX/NJ 是否有货 → 调拨或退款
   ├─ 目的邮编在 TX 覆盖区（中部）→ TX 仓有货？→ TX 发货
   └─ 目的邮编在 NJ 覆盖区（东部）→ NJ 仓有货？→ NJ 发货
```

**路由优先级：**
1. 首选：目的区域仓库有货 → 最短尾程 + 最低成本。
2. 次选：邻区仓库有货 → 接受多 1 天时效。
3. 末选：跨区调拨 → 只有当客户愿意等/订单利润足够覆盖调拨费时才用。

> ⚠️待确认：是否已实现 WMS 自动按邮编路由，还是人工判断（见 `09_美国仓选址与布局逻辑.md` 第四节）。

### 5.3 调拨规则

| 规则 | 说明 |
|------|------|
| 调拨触发 | 目的仓缺货但有未完成订单，且邻仓有富余库存 |
| 调拨方向 | CA ↔ NJ 跨东西海岸成本高，优先走 TX 中转（TX 在中间） |
| 调拨时效 | 美国本土城际 3–7 天（待确认） |
| 调拨成本权衡 | 调拨费 > 空运补货费 → 不调拨，走空运；详见 `14_海外仓成本核算与优化.md` 第六节成本红线 |
| 调拨记录 | 每次调拨在 WMS 双边调账，见 `13_海外仓库存管理实操.md` 调拨申请表 |

### 5.4 三仓能力分工矩阵（运营视角）

| 作业 | CA | TX | NJ |
|------|----|----|----|
| 现货存储 | ✅ 热销品 | ✅ 长尾/大货 | ✅ 热销品 |
| 激光/丝印轻定制 | ✅ 已确认 | ⚠️待确认 | ⚠️待确认 |
| FBA 贴标/混装 | ⚠️待确认 | ⚠️待确认 | ✅ 专人管理 |
| B2C 打包履约 | ⚠️待确认 | — | ✅ |
| 跨仓调拨中转 | — | ✅ 地理中心 | — |
| 托盘级大货 | ⚠️ | ✅ 主要功能 | ⚠️ |

## 六、单仓 vs 多仓成本与时效对比

> ⚠️ 以下为对比框架，具体节省幅度需用实际运费数据核算。

| 维度 | 单仓（仅 CA） | 三仓（CA+TX+NJ） |
|------|-------------|----------------|
| 尾程时效 | 全美 3–5 天（东西海岸跨区慢） | 全美 1–3 天（就近发货） |
| 尾程运费 | 高（全美都走 Zone 5-8） | 低（大部分订单 Zone 1-4） |
| 仓租成本 | 低（只交一个仓） | 高（三仓仓租叠加） |
| 库存分散风险 | 集中在一个仓，缺货影响全域 | 某仓缺货其他仓可补 |
| 管理复杂度 | 简单 | 高（需库存分配/调拨/对账） |
| 客户体验 | 东部客户等待久 | 全国客户都快 |
| 适合阶段 | 测款期/SKU 少/订单量小 | 成长期/SKU 多/全国订单分散 |

**结论：**
- 初期 SKU 少、订单集中在西海岸 → 单 CA 仓即可。
- 随着东部订单增长 → 加 NJ 仓提升东部时效。
- TX 仓作为大货/长尾/中转仓，最后加。
- 单仓多仓的盈亏平衡点（尾程节省 vs 多仓仓租）待运营数据核算。

## 七、双引擎模式下的三仓运营要点

> 双引擎战略见 `01_海外仓战略与模式.md` 第一节。本节聚焦"阳江工厂 + 美国仓现货"双引擎的运营协同。

### 7.1 库存节奏

```
阳江工厂按预测生产 → 整柜海运发美国（20-35天）
   ↓
到港后按三仓库存分配比例拆柜入仓
   ↓
美国仓现货销售（1-3天达）
   ↓
销售数据回传 → 阳江工厂调整下一批生产计划
```

### 7.2 备货逻辑

- **测款期**：新品先小批量发 CA 一仓（200-500 pcs），看动销。
- **跑通后**：追加海运，按三仓订单密度分配（如 CA 40% / TX 20% / NJ 40%，比例待实际数据调整）。
- **大货深度定制**：不走海外仓，直接阳江发货（见 `01_海外仓战略与模式.md` 双引擎对比表）。
- **紧急补货**：热销品断货走空运（成本高但保订单），见 `12_库存周转与滞销品处理.md` P0-P3 优先级。

### 7.3 数据闭环

- 美国仓 WMS 销售数据 → 每周回传 Leo → 调整阳江工厂生产计划。
- 滞销 SKU（>180天）→ 停止补货，走清仓/捆绑/退运（见 `12_库存周转与滞销品处理.md`）。
- 热销 SKU → 提前安排下一批海运，避免断货。

### 7.4 对客口径统一

- 独立站产品页标注 "Ships from: CA / TX / NJ Warehouse"。
- 所有海外仓订单 24h 内出库，1–3 个工作日全美送达。
- 不公开仓库精确地址，只展示州名（见 `09_美国仓选址与布局逻辑.md` 第五节）。
