# 客户开发全流程SOP（10步标准链路）

> 适用对象：KaiLionCrafts（阳江锴利国际贸易有限公司）B2B五金刀剪外贸业务
> 核心链路：线索获取 → 初步筛选 → 背景调查 → 开发信 → 首次跟进 → 需求确认 → 报价 → 样品 → 谈判 → 成交

---

## 第一步：线索获取（Lead Generation）

### 操作要点
1. **传统渠道**：国际展会（广交会、法兰克福Ambiente、芝加哥Housewares Show）、B2B平台（阿里巴巴国际站、环球资源）
2. **数字渠道**：
   - 独立站SEO/内容营销（kailioncrafts.com）
   - Google高级搜索：`"kitchen knife" importer distributor site:.us`
   - Google Maps 搜 "knife store near [city]"
   - LinkedIn 搜职位：Import Manager / Purchasing Manager / Buyer
   - 社媒：Facebook/Instagram/YouTube 行业账号
   - 海关数据：ImportYeti（免费查美国提单）
3. **线下渠道**：老客户转介绍、阳江本地展会接待、地推拜访

### 工具
- Google Search / Google Maps
- LinkedIn（免费基础版 + Sales Navigator付费版）
- ImportYeti（免费美国海关数据）
- 独立站询盘表单（WordPress + WPForms）

### 时间节点
- 每日固定1-2小时拓客；展会季集中线索入库
- 目标：每周新增50个潜客线索入库

### 检查清单
- [ ] 线索来源已记录（展会/Google/海关数据/转介绍）
- [ ] 客户公司名称、官网、国家已录入CRM
- [ ] 初步判断客户类型（进口商/品牌商/电商/零售商）

---

## 第二步：初步筛选（Lead Qualification）

### 操作要点
1. 从50个潜客中打分筛选，选出10个重点攻克对象
2. 筛选维度：
   - 是否经营五金刀剪/厨房用品品类（看官网产品）
   - 公司规模（员工数、年采购额估算）
   - 是否有进口记录（海关数据验证）
   - 国家/地区是否在目标市场内
3. 排除无效线索：info@邮箱无回复、价格离谱、明显骗子

### 工具
- Google（看官网About Us和产品页）
- ImportYeti（查真实采购记录）
- LinkedIn（看公司规模和组织架构）

### 时间节点
- 线索入库后24小时内完成初筛

### 检查清单
- [ ] 客户类型已判定（进口商/品牌商/电商卖家/零售商）
- [ ] 目标品类匹配度已评估（高/中/低）
- [ ] 是否有真实进口记录已验证
- [ ] 已分配A/B/C/D初步等级

---

## 第三步：背景调查（Due Diligence）

### 操作要点
按《03_客户背景调查SOP与工具.md》执行13步背调Checklist：
1. Google高级搜索公司名
2. 官网分析（About Us、产品、客户案例）
3. 域名注册时间（Whois）
4. Google Maps地址验证
5. LinkedIn员工数量和决策人
6. 社媒活跃度
7. 海关数据查采购记录
8. 资信/诉讼记录
9. 定位决策人（CEO/Import Manager/Purchasing Manager）
10. 邮箱验证（Hunter/RocketReach）
11. 美国上市企业查EDGAR
12. 德国客户查Creditreform
13. 全球商业信息库D&B Hoovers

### 工具
- ImportYeti（免费）/ Panjiva / Volza（付费）
- Hunter.io / RocketReach / Lusha（找邮箱）
- Creditreform（德语区）
- EDGAR sec.gov（美国上市）
- Dun & Bradstreet（全球资信）

### 时间节点
- 重点客户（A/B类）必须在发开发信前完成背调
- C类可简化，仅查官网+海关数据

### 检查清单
- [ ] 客户类型和规模已明确
- [ ] 决策人姓名和职位已定位
- [ ] 决策人邮箱已找到并验证
- [ ] 采购规模和周期已估算
- [ ] 付款风险等级已评估（低/中/高）

---

## 第四步：发送开发信（Cold Outreach）

### 操作要点
1. **个性化开头**：提及客户具体信息（官网产品、参展动态、采购记录），证明不是群发
2. **痛点匹配**：1个核心痛点（成本↓/品质↑/交期↓）+ 1个我们的优势
3. **轻量CTA**：邀请样品测试或15分钟通话，别一上来要大单
4. **发送时间**：按目标国时区定时发送（详见《10_全球时区与最佳联系时间速查表》）
5. **邮件长度**：控制在150词以内，三短段

### 工具
- 企业邮箱（ceo@kailioncrafts.com）
- 邮件追踪工具（Snov.io / Lemlist）
- 定时发送功能

### 时间节点
- 背调完成后24小时内发首封开发信
- 按目标国最佳联系时间定时发送

### 检查清单
- [ ] 开发信模板已按场景选择（通用/进口商/亚马逊卖家/品牌商）
- [ ] 开头已个性化（提及客户具体业务）
- [ ] 邮箱已验证有效
- [ ] 发送时间已按目标时区设定
- [ ] 已附签名（姓名/职位/公司/网站/WhatsApp）

---

## 第五步：首次跟进（Follow-Up Sequence）

### 操作要点
1. **7天规则**：邮件发出后3天无回应发第二封，触达率可提升20%+
2. 按7封跟进序列执行：Day0 → Day3 → Day7 → Day14 → Day21 → Day30 → Breakup
3. 每封邮件换角度：价值提供 → 案例分享 → 限时优惠 → 最后通知
4. 详细模板见《邮件模板/02_跟进邮件序列》

### 工具
- CRM系统自动提醒跟进日期
- 邮件序列工具（Lemlist/Snov.io）

### 时间节点
- Day0：首封开发信发出
- Day3：第二封（简单bump）
- Day7：第三封（附参数表/案例）
- Day14：第四封（行业应用场景）
- Day21：第五封（参数对比/认证）
- Day30：第六封（报价区间/样品）
- Day30+：Breakup邮件（优雅收尾）

### 检查清单
- [ ] 跟进日期已录入CRM提醒
- [ ] 每封跟进邮件角度不同
- [ ] 已读不回时用ABC选项追问话术
- [ ] 连续7封无回复标记为D类，转入季度维护

---

## 第六步：需求确认（Needs Discovery）

### 操作要点
1. 客户回复后，快速判断：
   - 具体需求是什么？（哪个品类？厨房刀/剪刀/户外刀/厨房用品）
   - 目标价位区间？
   - 年采购量/单次订单量？
   - 是否需要OEM/ODM（定制LOGO/包装）？
   - 目标市场在哪里？（影响认证要求）
2. 主动提问清单：
   - "What models are you currently sourcing?"
   - "What is your target price range for this item?"
   - "Do you need custom logo / packaging?"
   - "Which certifications are required in your market?"
3. 24小时内响应（A类客户）

### 工具
- 邮件 / WhatsApp / Zoom视频会议
- 产品参数表PDF（按品类）

### 时间节点
- 客户首次有效回复后24小时内完成需求确认
- 大客户可安排15-30分钟视频会议

### 检查清单
- [ ] 目标品类已确认
- [ ] 规格/材质要求已记录
- [ ] 采购量已估算
- [ ] OEM/ODM需求已确认
- [ ] 认证要求已明确
- [ ] 目标交期已了解

---

## 第七步：报价（Quotation）

### 操作要点
1. 按需求确认结果制作报价单
2. 报价单结构：
   - 公司抬头 + 报价日期 + 有效期
   - 产品型号 + 描述 + 图片
   - 材质/硬度/尺寸/包装规格
   - MOQ
   - FOB单价（深圳/广州/阳江）
   - 阶梯价（不同数量不同价格）
   - 付款条款（30% T/T定金 + 70%见提单副本）
   - 交货期
   - 报价有效期（通常15-30天）
3. 大客户：给年度框架价 + 阶梯价，强调总成本（TCO）
4. 小客户：FOB单价 + MOQ，可小幅起订

### 工具
- 报价单模板（Excel/PDF）
- 产品价格阶梯表

### 时间节点
- 需求确认后48小时内发出正式报价单
- 复杂定制需求72小时内

### 检查清单
- [ ] 报价单已含所有规格参数
- [ ] 阶梯价已列出
- [ ] 贸易条款明确（FOB/CIF/DDP）
- [ ] 付款条款已写明
- [ ] 报价有效期已标注
- [ ] 已附相关认证证书（FDA/LFGB/CE等）

---

## 第八步：样品确认（Sample）

### 操作要点
1. **大客户**：付费样品 + 正式样品单，附检测报告
2. **小客户/电商卖家**：低价或免费样品，快速寄样
3. 样品政策：
   - 样品费可在大货订单中抵扣
   - 运费到付或客户预付
   - OEM样品需收打样费
4. 样品发出后 tracking number 立即发给客户
5. 样品到达后3天主动询问反馈

### 工具
- 样品单（Sample Order PI）
- 国际快递（DHL/FedEx/UPS）

### 时间节点
- 报价确认后3天内安排样品
- 样品发出后tracking number 当天发客户
- 样品预计送达后3天跟进反馈

### 检查清单
- [ ] 样品费政策已说明
- [ ] 样品已按客户要求定制（LOGO/包装）
- [ ] 样品检测报告已随附
- [ ] Tracking number 已发送
- [ ] 样品反馈已记录

---

## 第九步：谈判（Negotiation）

### 操作要点
1. 常见异议处理见《06_谈判话术与异议处理.md》
2. 价格异议：强调TCO（总成本），不只比单价
3. MOQ异议：提供阶梯MOQ，或推荐现有规格现货
4. 交期异议：说明排产周期，承诺提前7天预警
5. 质量疑虑：发第三方检测报告（SGS/TÜV/LFGB/FDA）
6. 付款条款：首单30%定金+70%见提单副本，信用好可谈L/C

### 工具
- 谈判话术手册
- 价格权限表（业务员折扣权限）

### 时间节点
- 客户收到样品后1-2周内进入谈判
- 每个问题24小时内回复

### 检查清单
- [ ] 客户核心异议已识别
- [ ] 已提供折中方案（减包装成本/分批交货/延长账期）
- [ ] 价格底线已守住（不低于成本价）
- [ ] 所有承诺已书面确认

---

## 第十步：成交与订单执行（Closing）

### 操作要点
1. 客户确认后制作PI（形式发票）
2. PI要素：买卖双方信息、产品明细、金额、贸易条款、付款条款、交期、包装
3. 收到30%定金后排产
4. 产前QC视频发给客户确认
5. 生产完成后拍大货照片/视频确认
6. 收尾款后安排发货
7. 发货后给客户发货文件（提单、装箱单、发票、原产地证）
8. 订单完成后30天回访，争取复购

### 工具
- PI模板
- 生产跟单表
- QC检查表

### 时间节点
- 收到定金后24小时内下达生产通知
- 产前样确认后开始大货
- 出货前7天确认尾款安排
- 出货后30天售后回访

### 检查清单
- [ ] PI已双方签字确认
- [ ] 30%定金已到账
- [ ] 产前QC视频已发客户确认
- [ ] 大货QC已完成
- [ ] 70%尾款已到账
- [ ] 发货文件全套已提交
- [ ] 客户已签收确认
- [ ] 已录入CRM客户档案并标记复购跟进日期

## 附：全流程时间总览

| 阶段 | 预计周期 | 关键里程碑 |
|---|---|---|
| 线索获取→初筛 | 1-2天 | 50线索→10重点 |
| 背调→开发信 | 1天 | 发出首封邮件 |
| 跟进序列 | 30天 | Day0-30 七封邮件 |
| 需求确认→报价 | 2-3天 | 正式报价单发出 |
| 样品 | 1-2周 | 样品送达+反馈 |
| 谈判→成交 | 2-4周 | PI签订+定金到账 |
| 生产→交付 | 30-45天 | 尾款到账+发货 |
| 售后→复购 | 30天后 | 复购跟进 |
