## 一、怎么打开

### ✅ 推荐：双击启动

在项目文件夹里双击 **`启动工作台.command`**，会：

1. 启动工作台（本地网站 `:8477`）
2. 启动 API 网桥（`:8787`）
3. **自动打开浏览器**

> 那个黑色终端窗口要**保持开着** —— 关掉它，工作台就停了。
> 不用的时候直接关窗口即可，不会留后台进程。

**第一次双击如果 macOS 提示「无法打开，因为来自身份不明的开发者」：**
右键点这个文件 → 选「打开」→ 再点一次「打开」。之后就能正常双击了。

### 命令行启动（可选）

```bash
cd kailioncreator
./start.sh
```

### 手动启动（想自己控制时用）

```bash
# 终端 1：工作台
python3 -m http.server 8477

# 终端 2：API 网桥（接真实模型 API 才需要）
node tools/proxy.mjs
```

然后浏览器打开 `http://127.0.0.1:8477/index.html`

### ⚠️ 不要直接双击 index.html

这是个 ES Module 项目，浏览器对 `file://` 协议有跨域限制，**双击 html 文件会白屏**。
必须走上面的本地服务方式。

## 二、第一次用：接你自己的模型 API

工作台本身**不带模型**。接上你自己的 Key 之后，节点才会从「本地推演」变成「真实产出」。

**四步：**

| 步骤 | 操作 |
|---|---|
| ① 开网桥 | 双击启动时已自动开了（看终端里有没有「网桥 :8787 已就绪」） |
| ② 加线路 | 右上角 **「线路管理」→「从模板添加」**，选你的服务商（或「+ 添加线路」自己填） |
| ③ 填三样 | **Base URL**（多数要带 `/v1`）、**API Key**、**用途**（文本 / 图像） |
| ④ 测连通 | 点 **「测试连通」** —— 它会逐项告诉你：能不能连、有哪些模型、对话通不通、生图有没有开权限 |

**怎么判断接没接上：** 节点右上角会出角标

- 🟢 **绿色 + 模型名** = 真实模型产出
- 🟡 **黄色「推演」** = 还没接线路，是本地演示结果

## 三、日常怎么用：三种玩法

### 玩法 1：说一句话（最快）

在「智能工作台」输入框直接说话，比如：

- `生成 4 张厨房刀具白底主图，1:1`
- `写一段回复美国买家询盘的英文邮件`
- `做一份 8 页海外招商 PPT`

它会自动：解析意图 → 搭好画布 → 检查前置条件 → 执行 → 归档。
跑完点「去画布看它搭了什么」，还能「保存到工作流库」或「转成定时任务」。

### 玩法 2：画布手搭（最灵活）

在「经典画布」里，从左侧节点库**拖节点到画布**，把上游节点的输出圆点**拖到下游的输入圆点**完成连线，然后点节点上的「▶ 运行」。

常用快捷键：

| 快捷键 | 作用 |
|---|---|
| `Ctrl/⌘ + Z` | 撤销 |
| `Ctrl/⌘ + O` | 自动整理布局 |
| `Ctrl/⌘ + A` | 全选 |
| `Ctrl/⌘ + K` | 全局搜索 |
| `Delete` | 删除选中节点 |
| 滚轮 | 缩放画布 |

### 玩法 3：加载现成工作流

「工作流库」里有 **50 条预设流程**（21 个分类），点一条直接加载到画布，改改参数就能跑。
其中 **6 条「锴利专线」** 是为你业务定制的：产品图精修、规格参数表、询盘邮件、出口合规包、独立站文案、供应商评分。

## 四、产出的东西在哪

| 产出 | 在哪 |
|---|---|
| 图 / 视频 | 自动进 **「素材」** 库（图片存 IndexedDB，刷新不丢） |
| Word / Excel / PPT / PDF | 点节点 → 「查看运行结果」→ **下载**（是真文件，Office 能打开） |
| 整套流程 | 画布工具栏「保存为工作流」，下次直接加载 |

导出完整备份（**含图片**）：设置 → 数据与存储 → **导出完整备份（ZIP）**。
⚠️ 备份文件里有明文 API Key，别放公开仓库或云同步目录。

## 五、常见问题

**Q：点运行没反应？**
先查**连线** —— 节点之间没连线，上游的提示词根本传不到下游。再查提示词节点是不是空的。这两条覆盖九成情况。画布工具栏的「盾牌」图标是结构体检，点一下能自动列出来。

**Q：填了 Key 还是走「推演」？**
查三件事：① 网桥开了吗（终端里看 `:8787`）② 线路启用了吗 ③ Key 填在**文本**类线路而不是图像类。都对还不行就点「测试连通」，它会直接告诉你是哪一环断了。

**Q：生图提示 403 未开通权限？**
这是**你的 Key 所在分组没有生图权限**，不是工作台的问题。多数中转站按分组计费，文本和生图是两套独立权限。去中转站后台开通，或换一个支持生图的 Key。

**Q：浏览器报 CORS 错误？**
那就是网桥没开。中转站几乎都不返回跨域头，浏览器直连必被拦。执行 `node tools/proxy.mjs` 或双击 `启动工作台.command`。

**Q：数据存在哪？会上传吗？**
全部在你本机浏览器（localStorage + IndexedDB），**不上传任何服务器**。换电脑就用「导出完整备份（ZIP）」搬走。
