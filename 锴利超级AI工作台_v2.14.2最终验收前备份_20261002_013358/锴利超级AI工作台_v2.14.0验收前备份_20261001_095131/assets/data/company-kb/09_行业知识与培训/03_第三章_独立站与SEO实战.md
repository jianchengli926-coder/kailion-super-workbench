## 二、核心观点

1. **阳江 = 中国刀剪之都，这五个字就是最大的天然信任资产**：海外客户搜"Yangjiang knife"就能找到你。背靠产业带优势，用独立站把名声打出去。〔A级，P2——Leo 实地观察〕

2. **独立站三大核心价值**：① 客户数据自有（每一个询盘/访问/行为数据归你，平台拿不走）；② 资产持续增值（SEO 权重随时间积累，像买房越久越有价值）；③ 规则完全自主（无封店风险、无佣金抽成、无比价骚扰）。〔B级，P3〕

3. **短期跑量选平台，长期品牌做独立站**：更聪明的做法是分阶段布局——平台养当下，独立站攒未来。〔B级，P4〕

4. **我选 WordPress 不选 Shopify 的三个理由**：① B2B 询盘原生支持（Shopify 连询盘表单、阶梯价都没有）；② SEO 完全可控（URL/元标签/Schema/速度全可控）；③ 代码自由度高（Shopify 要付费 App 才能实现的功能，用代码免费做）。〔A级，P7——Leo 真实技术栈选择〕

5. **每个页面都是入口，不是只有首页**：客户可能从产品页/服务页/关于页/文章页任何一页进入；合理范围内页面越多，被搜索到的入口越多；每个页面都要独立做 SEO。〔B级，P10〕

6. **B2B 独立站 ≠ B2C 商城**：B2B 核心路径是搜索→看产品/工厂/认证→提出规格/MOQ/定制→提交询盘→报价→打样→订单。CTA 是 "Get a Quote"，不是 "Buy Now"。〔B级，P15〕

7. **80% 精力做 B2B 大客户，20% 做 B2C 小单**：大客户养活公司（稳定基本盘、高利润），小客户打开市场（品牌曝光、市场测试、现金流）。Trust First, Value Second, Price Last。〔B级，P16〕

8. **不做 SEO 的独立站只有你自己能看到**：AI 可以搭一个酷炫网站，但没有 SEO = 没有询盘 = 白做。〔B级，P17〕

9. **SEO 就像种树，6 个月才见效**：1-3 月地基期（谷歌认识你）、4-6 月萌芽期（长尾词开始排名，很多人在这里放弃）、6 月+增长期（核心词+长尾词排名上来，流量稳定增长）。能坚持 6 个月就赢了 90% 的人。〔B级，P24〕

10. **双环流量闭环**：内环 = 独立站 SEO 自然流量（精准/免费/长期/复利）；外环 = 海外社媒引流（TikTok/YouTube/Instagram/Facebook/LinkedIn，曝光大/起势快）。社媒做曝光和信任，独立站做深度和转化，双向引流正向循环。〔B级，P25/P29〕

## 三、方法与步骤

### 3.1 从 0 到 1 搭建 WordPress 独立站（P8）

1. **基础环境**：域名(.com) + 海外服务器 + 安装 WordPress
2. **主题选择**：推荐 Astra / GeneratePress 轻量主题，响应式设计
3. **必备插件**（四大类）：
   - SEO：Yoast SEO / Rank Math
   - 页面构建：Elementor（可视化拖拽）
   - 安全：Wordfence Security
   - 缓存：WP Rocket（提升速度）
4. **代码能力**：HTML=骨架、CSS=样式、JS=交互——AI 帮你写
5. **实操上手**：边做边学

> 域名注册不要只是公司拼音，在国外没有记忆点。（P8）

### 3.2 Leo 的真实技术栈（P7，A级）

| 组件 | 选型 |
|------|------|
| 建站系统 | WordPress + WooCommerce |
| 页面构建 | Elementor + Astra 主题 |
| 服务器 | Hostinger VPS（海外节点，主节点美国洛杉矶） |
| SEO 插件 | Rank Math（评分 80 分+ 体系） |
| 表单插件 | Fluent Forms（询盘表单） |

> 全部免费版够用；想进阶再用代码实现，不用每个功能都开会员。

### 3.4 产品页与分类页结构（P11-P12）

**产品页**：
- 首屏：产品图片背景 + 产品大标题
- 下方三个跳转卡片（关键设计）：查看所有产品 / 产品视频 / 产品工厂
- 作用：延长停留时间，提升询盘概率

**分类页**：
- 左侧侧边栏四大品类：户外刀 / 剪刀 / 厨房用品 / 厨房刀
- 四大品类共 **23 个细分类目**（户外刀 5 类 · 剪刀 6 类 · 厨房用品 6 类 · 厨房刀 6 类）
- 每行 3 个产品卡片，底部"查看更多"按钮

**内链原则**：每个页面都要有"下一步"指引；底部统一放联系/获取报价按钮；FAQ 用 JS 手风琴；博客文章关联产品页。

### 3.5 联系页 + 博客页设计（P13）

**联系页（询盘收口）**：
- 顶部直接放邮箱/WhatsApp/电话，点击直达
- 询盘表单是核心：字段简洁（姓名/邮箱/国家/需求）
- 购物车一键提交：客户选的产品自动带入表单
- 谷歌地图定位：提升真实感与信任度
- 每页底部「获取报价」入口

**博客页（长尾流量金矿）六大分类**：
1. B2B 采购指南
2. 金属工艺知识
3. OEM / ODM 流程
4. 质量与出口认证
5. 刀具保养与使用
6. 阳江优势与品牌文化

> 每个分类持续更新 10-20 篇深度文章。

### 3.6 图片 SEO 四要素（P18）

| 要素 | 说明 | 错误示范 |
|------|------|----------|
| 文件名 | SEO 友好命名，英文小写+连字符，含关键词 | IMG_20240101_12345.jpg（微信默认名） |
| Alt 文本 | 用关键词或一句话描述图片内容 | 留空或写"图片1""product" |
| Title 标题 | 图片标题，含关键词，鼠标悬停显示 | 留空 |
| Description | 一句话描述，含关键词，补充 Alt | 留空 |

> 上传图片前必须先把微信下载的长串代码文件名改成 SEO 命名。

### 3.7 关键词四类布局与内容三层金字塔（P21）

**四类关键词**：
| 类型 | 示例 |
|------|------|
| 产品关键词 | wholesale kitchen knives, OEM kitchen knives |
| 行业关键词 | Yangjiang knife manufacturer, China knife factory |
| 解决方案关键词 | private label kitchen knives, custom knife manufacturer |
| 内容关键词 | How are kitchen knives manufactured? |

**内容三层金字塔**：
- **流量层**：How knives are made 等科普内容 → 社媒曝光
- **专业层**：HRC 硬度指南、材料对比等深度内容 → 建立权威，SEO 长期流量
- **成交层**：Looking for manufacturer 等采购意向内容 → 直接引导询盘

### 3.8 SEO 三阶段路线图（P24）

| 阶段 | 时间 | 状态 | 目标 | 心态 |
|------|------|------|------|------|
| 地基期 | 1-3 月 | 谷歌认识你、收录页面 | 打好技术基础，上满内容 | 感觉没变化很正常 |
| 萌芽期 | 4-6 月 | 长尾词开始排名，零星询盘 | 持续更新内容+完善产品 | 很多人在这里放弃，坚持住 |
| 增长期 | 6 月+ | 核心词+大量长尾词排名上来 | 流量稳定增长，询盘规律出现 | 开始享受复利 |

**SEO 心法四条**：① 耐心是最大竞争力；② 内容质量 > 数量；③ 小步快跑持续更新（每周 2-3 篇比一月集中发好）；④ 用数据驱动决策（每周看 GSC）。

### 3.9 服务器与视频托管架构（P20，A级）

- **主节点**：美国洛杉矶（覆盖北美核心市场）
- **CDN 缓存**：立陶宛（欧洲）、新加坡（东南亚）
- **视频托管**：全部上传 YouTube → 代码嵌回独立站产品页
  - 严禁直传高清视频到独立站服务器（占内存、耗尽带宽）
  - 借用 YouTube 全球 CDN，客户看视频零卡顿

### 3.10 Cloudflare 防护 9 步部署（P26-P27）

| 步骤 | 名称 | 关键操作 |
|------|------|----------|
| 第 0 步 | 备份现有配置 | 截图记录所有 DNS 记录（A/CNAME/MX），记录当前 Nameserver |
| 第 1 步 | 注册 Cloudflare | Google 登录，选 Free Plan，添加域名 |
| 第 2 步 | 核对 DNS 记录 | 对照备份截图逐条核对（尤其 MX 邮件记录） |
| 第 3 步 | 修改 Nameserver | 回域名注册商后台，替换为 Cloudflare 提供的两个 ns.cloudflare.com |
| 第 4 步 | 等待生效+验证 | 15-30 分钟生效，验证网站/表单/邮件/后台全部正常 |
| 第 5 步 | 开启 Bot Fight Mode | Security → Bots，打开开关 |
| 第 6 步 | 配置 Rate Limiting | 同 IP 10 秒超 20-30 次请求弹验证码 |
| 第 7 步 | 最终确认+观察 | 重测网站/后台，观察 1-2 周流量日志 |

> 成本：0 元（Cloudflare Free Plan）；部署时间：30-60 分钟（含 DNS 生效等待）。
> 防护原则：拦脚本不拦人——真实客户正常浏览、Google 爬虫正常收录、自己登录后台不被拦截。
