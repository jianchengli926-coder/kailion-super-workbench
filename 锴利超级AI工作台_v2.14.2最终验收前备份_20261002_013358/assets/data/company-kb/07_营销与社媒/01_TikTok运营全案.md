# TikTok运营全案

> 定位："人性化"获客与工厂实拍。用30秒工厂实拍、工艺特写把阳江供应链透明度打出去。新号也有机会爆，是B2B工厂号"去中介化"性价比最高的冷启动渠道。

## 一、平台规范速查

| 字段 | 规范 |
|------|------|
| Bio简介 | **80字符硬限** |
| Username/handle | ≤24字符 |
| 显示名 | ≤30字符 |
| 视频caption | ≤4,000字符（feed只显示前约100，利于埋SEO关键词） |
| 评论 | ≤150字符 |
| 头像 | 200×200（圆形裁切） |
| 视频尺寸 | 1080×1920（9:16竖版） |

## 二、账号类型选择

**4个品类号全部用Business Account（企业号）。**
- 0粉即可挂独立站链接（个人号需≥1,000粉）
- 有Analytics数据后台
- 可投Ads Manager
- 代价：只能用Commercial Music Library（无热门趋势音乐），但B2B工厂号内容本就是实拍，牺牲不大

## 三、链接放置规则（核心）

**整个TikTok账号只有Bio Website一个可点外链位。**

| 位置 | 可点击性 | 说明 |
|------|---------|------|
| Bio Website字段 | ✅ 唯一可点链接 | Business号0粉可挂；品类号挂对应品类页 |
| 视频caption | ❌ 不可点 | 写"Link in bio / DM us for wholesale" |
| 评论区 | ❌ 不可点 | 放多了判spam，重复=风控 |
| 置顶视频 | ⚠️ 引导Bio | 口播"link in bio" |

**Bio里写的网址不可点**，必须用Edit Profile → Website字段。

## 四、四品类Bio模板（已压字符数）

| 品类 | Bio英文（可直接复制） | 字符数 |
|------|---------------------|--------|
| Outdoor | `EDC & camping tools from Yangjiang / OEM/ODM · lawful programs / Catalog ↓` | 72 |
| Kitchen | `Kitchen knives & Damascus steel / OEM/ODM from Yangjiang / Wholesale link ↓` | 75 |

| Accessories | `Food-grade kitchenware & BBQ tools. OEM/ODM private label. Made in Yangjiang.` | 77 |

## 五、养号节奏

### Phase 1（Day 1–3）：只刷不发
- 每天20–30分钟，点赞5–10个同类内容，关注2–3个同类账号
- 头像Bio全空，不发内容

### Phase 2（Day 4–7）：完善资料+低频发布
- 加头像Bio，每2天发1条
- Day 6左右再挂外链
- 每天互动15分钟

### Phase 3（Day 8–14）：稳定发布
- 每天1条（新号应有50–200播放，属正常）
- 测试是否限流

## 六、内容方向

### 内容类型
- 开刃/热处理/激光雕刻微距
- 盐雾/锋利度测试（安全场景：切食物/绳子/木头）
- 装箱发货、露营场景切食物
- 工厂车间横移、钢材微距、EDC携带

### Hashtag方向
`#edc #bushcraft #campinggear #kitchenknife #knifemaker #oem #factorydirect #wholesale`

### 视频规格
- 9:16竖版 ≤60秒
- **前3秒必须有视觉冲击**（完播率命门）
- 字幕必加（英文硬字幕为主）
- 封面统一风格：深色背景+产品特写+大字关键词

### CapCut洗稿六步
1. 剪辑结构重组：裁掉/调换镜头顺序，各平台版开头3秒不同
2. 变速/镜像局部：关键镜头0.9x或1.1x；个别镜头水平翻转
3. 换配乐：每平台版本用不同BGM（Business号只能用商用音乐库）
4. 调色/滤镜微调：暖色版给IG/Pinterest，原色版给YouTube，高对比给TikTok
5. 字幕重做：每平台字号/位置/字体不同
6. 封面各异：不同帧+不同标题字

## 七、合规红线（最高优先级）

### 绝对禁止
- **TikTok Shop全类目禁售刀具**——不要挂任何刀具商品链接
- 禁用词：`kill/murder/fight/blood/weapon/knife crime` 会被AI立即降权删视频
- 用 `slicing/cutting/craftsmanship` 替代
- 不拍刀刃指人/动物、攻击演示、血腥
- **弹簧刀/蝴蝶刀/重力刀连展示都不要**
- 评论区不留联系方式/报价（直接降权限流）

### Outdoor品类特殊红线
- 只做合法非暴力演示；主打outdoor lifestyle/camping/bushcraft/EDC
- 配文 "for lawful outdoor use only"
- 不打tactical/combat/self-defense
- 误判暴力后申诉走craftsmanship路线

### 安全话术替换
| ❌ 禁用 | ✅ 替代 |
|--------|--------|
| weapon | outdoor tool, blade, EDC gear |
| tactical/combat | bushcraft, camping, outdoor |
| attack/fight/kill | slicing, cutting, prep |
| self-defense | everyday carry, hiking, adventure |

## 八、改名频率限制

| 字段 | 频率 |
|------|------|
| Display Name | 每7天1次 |
| Username | **每30天1次（最严）** |

> Username一次定准，不要试错。新号前7天不改资料。

## 九、申诉渠道
- App内封禁提示点"申诉"
- **7天内勿重复提交，间隔10天**
- 申诉窗口约30天
- 封一个号后不要同机同IP立刻重开（连坐）
