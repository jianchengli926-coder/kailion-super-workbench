## 二、商业模式：B2B Inquiry / RFQ（无在线支付）

- 站点为 **B2B 批发询盘型独立站**，**不配置在线购物车/在线支付**。
- 客户动作路径：浏览产品 → 查看详情 → 点击 **Request a Quote / Send Inquiry** → Fluent Forms 提交询盘 → 销售人工报价、跟进、签 PI。
- 表单插件：**Fluent Forms**；邮件发送：**FluentSMTP**（对接 ZOHO 企业邮箱发信）。
- WooCommerce 仅用于产品目录展示、分类/标签体系与 SEO 落地，不开启结账流程。

| `backup_...-uploads.zip` | 418MB | wp-content/uploads（产品图片/媒体库） |
| `backup_...-uploads2.zip` | 130MB | uploads第二卷（分片） |

## 六、页面接入铁律（旧Stage2 SPA vs Elementor — 历史参考，不代表当前生产网站）

> ⚠️ 本节为旧 Stage2 单页 SPA 与 Elementor 混合期的历史接入约束，**当前生产网站为 WordPress 多页面架构，已不涉及 SPA 锚点整合**。以下仅作历史工程记录保留，不代表当前网站事实。

1. 不改动 dropdown 全局点击逻辑。
2. 不把独立 html 锚点导航塞进 SPA 主导航。
3. 整合进 index 时只替换 `#page-overseas-stock` 的 `<main>` 和局部 CSS。
4. Elementor 独立页用 standalone html，不带 SPA 依赖。
5. 视觉沿用现有 `--klc-` 变量体系（见 `02_CSS设计规范.md`）。
