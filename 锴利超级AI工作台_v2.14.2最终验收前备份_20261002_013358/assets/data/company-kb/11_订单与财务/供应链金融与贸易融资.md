# 供应链金融与贸易融资

> **核心定位**：本文件是 KaiLionCrafts（阳江市锴利国际贸易有限公司）作为一人外贸公司，
> 在**不囤货、不压款、轻资产**模式下可使用的贸易融资工具大全。
>
> ⚠️ **重要声明**：
> 1. 本文件中所有利率、费率、保证金比例均来自公开官方来源（银行/中信保/外管局），
>    **检索日期 2026-09-28**，实际办理以开户银行当日报价为准。
> 2. 所有融资建议均为**建议方案，需根据公司实际情况和银行政策调整**。
> 3. 公司当前付款方式以 T/T（30% 定金 + 70% 出货前付清）+ PayPal + 少量 L/C 为主，
>    **不做 OA 赊销**，因此多数贸易融资工具当前用不上——本文件作为未来业务扩张时的工具箱留存。

## 一、出口贸易融资方式

### 1.1 打包贷款（Packing Loan / 备货贷款）

| 项目 | 内容 |
|------|------|
| **定义** | 出口商收到国外开来的**正本信用证（L/C）**后，因备货资金不足，以信用证正本为抵押向银行申请的装船前融资，用于采购、生产、包装出口货物。 |
| **申请条件** | ① 持有以本公司为受益人的正本信用证；② 开证行/保兑行资信良好（在银行白名单内）；③ 信用证中无可由受益人无法自主履行的"软条款"；④ 公司已在银行开立结算账户并有授信额度。 |
| **融资金额** | 通常为信用证金额的 **70%–80%**（中国进出口银行口径：通常为信用证金额的 70%）。 |
| **期限** | 自放款日起至收到开证行货款之日止，一般不超过信用证有效期后 + 一定缓冲期，通常 3–6 个月。 |
| **利率** | 参照银行流动资金贷款利率，通常在 LPR 基础上加点，**小微企业约 3.5%–5%/年**（具体以银行报价为准）。 |
| **还款来源** | 出口交单后，开证行付款直接用于偿还打包贷款本息。 |
| **适用场景** | 收到大额 L/C 订单（≥$50K）但手头没钱向工厂下定金时。 |
| **KaiLionCrafts 适用性** | ⚠️ 当前公司 L/C 订单极少，主要用 T/T 30% 定金。**未来若接到 ≥$100K 的 L/C 订单且工厂要求预付 30%，可考虑。** |

**办理材料（来源：中国工商银行/中国进出口银行）**：
1. 打包贷款书面申请书
2. 国外销售合同 + 国内采购合同
3. **正本信用证**（须留存银行）
4. 营业执照、对外贸易经营者备案、公章、法人身份证
5. 首次申请需提供财务报表、经营情况说明及担保材料

> 来源：中国进出口银行《打包贷款》http://www.eximbank.gov.cn/business/trade/financing/201806/t20180612_3674.html ；
> 中国工商银行安徽分行业务说明 https://www.icbc.com.cn/anhui/page/721852424313929766.html （检索日期 2026-09-28）

### 1.2 出口押汇（Outward Bill Purchased / 议付）

| 项目 | 内容 |
|------|------|
| **定义** | 出口商发运货物后，将全套单据（汇票、提单、发票、保单等）交给银行，银行**扣除利息后先行买入**单据/汇票，提前把货款垫付给出口商，然后银行再向开证行索汇。 |
| **与打包贷款区别** | 打包贷款是**装船前**融资（备货用）；出口押汇是**装船后**融资（交单后即拿钱）。 |
| **流程** | ① 出口商交单 → ② 银行审单"单证相符、单单一致" → ③ 银行扣除押汇利息后垫付货款 → ④ 银行向开证行寄单索汇 → ⑤ 开证行付款后偿还押汇款，余额入出口商账户。 |
| **追索权** | **有追索权**：若开证行拒付，银行可向出口商追索已垫付的款项。 |
| **融资比例** | 通常为汇票金额的 **80%–90%**。 |
| **期限** | 即期 L/C 项下一般 15–30 天；远期 L/C 项下根据承兑期限（如 90 天/180 天）。 |
| **成本** | 押汇利息 = 押汇金额 × 融资利率 × 融资天数/360。利率通常按 LIBOR/SOFR 加点或人民币 LPR 加点，**小微企业约 4%–6%/年**。 |
| **风险** | ① 单证不符被拒付风险；② 开证行信用风险（已有追索权兜底）；③ 汇率风险（已提前结汇则锁定）。 |
| **适用场景** | 即期/远期 L/C 项下，发货后想立刻拿到钱、不想等 1–3 周单证邮寄时间。 |

> 来源：中国工商银行黑龙江分行出口押汇业务说明
> http://www.icbc.com.cn/heilongjiang/column/1438058384883859494.html （检索日期 2026-09-28）

### 1.3 福费廷（Forfaiting）

| 项目 | 内容 |
|------|------|
| **定义** | 出口商将**经过银行承兑/承付/保付**的远期票据（远期 L/C 项下的汇票或本票）**无追索权**地卖断给银行，银行扣除贴息后提前付款。 |
| **核心特点** | **无追索权**：一旦卖断，即使未来开证行不付款，银行也不能回头找出口商要钱——风险完全转移给银行。 |
| **与出口押汇区别** | 出口押汇有追索权；福费廷无追索权。代价是福费廷利率更高。 |
| **适用场景** | 大额（≥$500K）、长期（180 天以上远期）、买方信用风险较高但开证行资信好的订单。 |
| **金额期限** | 短至数十天，长至数年；币种与 L/C 相同（USD/EUR/CNY 等）。 |
| **成本** | 融资利率 = 基础利率 + 浮动点数，浮动点数取决于**国家风险、开证行信用、融资期限**。手续费每笔最低约 $100（中国银行口径）。 |
| **费用构成** | 融资利息 + 手续费（最低 $100/笔）。 |
| **KaiLionCrafts 适用性** | ❌ 当前订单规模用不上。**未来若接到 ≥$500K 的 180 天远期 L/C 大单**，且不想承担开证行拒付风险，可考虑。 |

**办理流程（来源：中国银行）**：
1. 客户与银行签《福费廷业务合同》
2. 客户提交《福费廷业务申请书》
3. 取得对债务人（开证行）的授信额度或确定转卖后，签《福费廷业务确认书》
4. 债权转让：票据背书给银行，或签《债权转让书》
5. 贴现付款：银行取得开证行承兑后，扣除利息将款项付给出口商

> 来源：中国银行《福费廷》https://www.boc.cn/cbservice/cb3/cb35/200806/t20080627_887.html ；
> 中国建设银行福费廷业务说明 https://www3.ccb.com/chn/company/gsjgsy/cpfw/gjyw/gjjshmyrz/fft/index.shtml （检索日期 2026-09-28）

### 1.4 国际保理（Factoring）

| 项目 | 内容 |
|------|------|
| **定义** | 出口商以**赊销（O/A）或承兑交单（D/A）**方式出口货物后，将应收账款**转让**给保理商（银行/保理公司），由保理商提供：① 贸易融资（预付 80% 左右货款）；② 销售分户账管理；③ 应收账款催收；④ 坏账担保（无追索权保理）。 |
| **核心价值** | 让你敢接 OA 赊销订单——买方不付款由保理商赔。 |
| **有追索权 vs 无追索权** | **有追索权保理**：买方不付钱，保理商回头找出口商要；**无追索权保理**：买方因破产/拖欠不付钱，保理商承担坏账风险。 |
| **中国银行费率（2025-11 价格表）** | ① 有追索权保理：按受让应收账款金额的 **0.4%**；② 无追索权保理：**0.8%**；③ 进口保理：**1.0%**；④ **小微企业免收**。 |
| **融资利率** | 在保理费率之外，另收融资利息（预付部分），通常按 LIBOR/SOFR 加点，约 4%–7%/年。 |
| **预付比例** | 通常为发票金额的 **70%–90%**，余款在买方付款后清算。 |
| **适用客户** | 以 OA/D/A 方式出口、买方多为欧美优质企业、年出口额 $50 万–$1000 万的中小出口商。 |
| **KaiLionCrafts 适用性** | ⚠️ 当前**不做 OA**，所以暂时不需要。**未来若美国/欧洲大商超（如 Bed Bath & Beyond 类）要求 OA 60/90 天账期**，可通过无追索权保理接单，把坏账风险转给保理商。 |

> 来源：中国银行《国际结算业务服务价格表》（2025-11）
> https://pic.bankofchina.com/bocappd/pricelist/202511/P020251110646503121588.pdf （检索日期 2026-09-28）

### 1.5 信保融资（基于中信保保单的融资）

| 项目 | 内容 |
|------|------|
| **定义** | 出口商投保了中信保短期出口信用保险后，将保单项下的赔款权益**转让**给银行，银行据此给予出口商融资。 |
| **逻辑** | 中信保保了买方不付款的风险 → 银行拿着保单当还款保障 → 愿意放贷。 |
| **融资比例** | 通常为保单承保金额的 **70%–90%**。 |
| **成本** | 银行融资利息（约 4%–6%/年）+ 中信保保费（见第四节）。 |
| **适用场景** | 做 OA 赊销、又想提前回款的出口商。**与中信保短期险配套使用。** |
| **KaiLionCrafts 适用性** | ⚠️ 当前不做 OA，但**未来若接 OA 订单，建议"中信保短期险 + 信保融资"组合使用**。 |

### 1.6 出口退税账户托管贷款

| 项目 | 内容 |
|------|------|
| **定义** | 出口企业凭应退未退的出口税额，向银行申请的流动资金贷款，贷款额度以应收退税额为限。 |
| **逻辑** | 出口退税从申报到实际到账通常有 1–3 个月滞后期，企业可以先把这部分"未来的退税钱"贷出来用。 |
| **贷款额度** | 一般不超过应收出口退税额的 **70%–90%**。 |
| **期限** | 一般 3–6 个月，退税到账后自动归还。 |
| **利率** | 参照流动资金贷款，小微企业约 3.5%–5%/年。 |
| **适用场景** | 出口量大、退税额高、退税到账慢的企业。 |
| **KaiLionCrafts 适用性** | ⚠️ 公司年出口额尚小，退税额有限。**月退税额 >¥10 万时可考虑。** |

## 二、进口贸易融资

> KaiLionCrafts 是出口商，不直接进口，但**若未来从海外（如日本/德国）采购大马士革钢坯、特殊钢材、包装材料**，会用到以下工具。

### 2.1 信用证（L/C）开证融资

| 项目 | 内容 |
|------|------|
| **定义** | 进口商向银行申请开立 L/C，银行代收进口商保证金（通常 10%–30%）后向出口商开出信用证。 |
| **保证金** | 全额保证金（100%）或部分保证金（10%–30%，占用授信）。 |
| **费用** | 开证手续费通常为开证金额的 **0.05%–0.15%/季度**，最低约 ¥200–500/笔。 |
| **KaiLionCrafts 适用性** | 若未来从日本/德国钢材厂采购，可能用到。当前主要从国内阳江工厂采购，用不上。 |

### 2.2 信托收据（Trust Receipt, T/R）

| 项目 | 内容 |
|------|------|
| **定义** | 进口商在 L/C 项下单据到达后，因资金紧张无法付款赎单，向银行出具信托收据，先借单提货销售，日后再偿还银行垫款。 |
| **本质** | 进口押汇的一种形式——货权归银行，进口商只是"代银行销售"。 |
| **期限** | 通常 30–90 天。 |

### 2.3 进口押汇

| 项目 | 内容 |
|------|------|
| **定义** | 进口商信用证项下单据到后，银行先行垫付货款给出口商，进口商在约定到期日偿还银行本息。 |
| **费用** | 资金安排费通常为单据金额的 **0.5%**（中国银行境外分行口径），另收融资利息。 |
| **期限** | 通常 30–180 天。 |

> 来源：中国银行贸易结算与融资服务费率表
> https://www.bankofchina.com/hu/sub_cn/bocinfo/bi4/201410/t20141031_11637300.html （检索日期 2026-09-28）

## 三、供应链金融平台

### 3.1 主流供应链金融平台

| 平台 | 背景 | 模式 | 适用对象 |
|------|------|------|---------|
| **蚂蚁链（AntChain）** | 阿里巴巴/蚂蚁集团 | 基于核心企业确权的应收账款多级流转 | 核心企业上游供应商 |
| **联易融（Linklogis）** | 腾讯等投资 | 供应链金融科技平台，核心企业 + 多级供应商 | 大型核心企业上下游 |
| **简单汇（Easyhi）** | TCL 集团孵化 | "金单"模式，核心企业应付账款电子凭证化、可拆分流转 | 制造业核心企业供应商 |
| **中企云链** | 中国中车等国企发起 | "云信"应收账款多级流转 | 国企/大型民企供应商 |
| **京东科技供应链金融** | 京东 | 基于京东交易数据的融资 | 京东商家/供应商 |
| **苏宁银行、微众银行** | 互联网银行 | 纯线上、无抵押、基于交易数据 | 小微企业 |

### 3.2 核心企业确权模式（反向保理）

```
核心企业（如沃尔玛/家得宝）
    │ 应付账款 $100K，60 天后付款
    ▼
一级供应商（KaiLionCrafts）
    │ 拿着核心企业的"确权凭证"（电子债权凭证）
    ▼
供应链金融平台/银行
    │ 打折（如 9.5 折）买入这个债权，提前给供应商 $95K
    ▼
60 天后核心企业直接付给平台 $100K
```

**核心要点**：
- 信用基础是**核心企业**的信用（不是供应商的），所以利率低（约 3%–6%/年）。
- 供应商拿到钱提前回笼，核心企业账期不变。
- 电子债权凭证可**拆分、流转**（一级供应商可以再付给二级供应商）。

### 3.3 KaiLionCrafts 适用性分析

| 平台 | 是否适用 | 原因 |
|------|---------|------|
| 蚂蚁链/联易融/简单汇 | ⚠️ 看客户 | 只有当 KaiLionCrafts 的海外客户（如美国大商超）是国内某核心企业的供应商，或 KaiLionCrafts 是某国内核心企业（如阳江十八子作）的上游/下游时才用得上。**目前公司直接对接海外 B 端客户，不经过国内核心企业，暂不适用。** |
| 国内反向保理 | ⚠️ 看工厂 | 若阳江合作工厂（Amber/Keenhope）是某核心企业的一级供应商，KaiLionCrafts 作为其客户可间接参与。**目前未涉及。** |
| 跨境电商平台融资 | ✅ 见第六节 | Amazon Lending、PayPal Working Capital 等。 |

## 四、出口信用保险（中信保 Sinosure）

### 4.1 中信保简介

| 项目 | 内容 |
|------|------|
| **全称** | 中国出口信用保险公司（China Export & Credit Insurance Corporation, Sinosure） |
| **性质** | 国有政策性保险公司（中央金融企业），由国家出资设立。 |
| **主要产品** | 短期出口信用保险（信用期 ≤ 1 年）、中长期出口信用保险（2–15 年）、投资保险、担保业务。 |
| **官网** | https://www.sinosure.com.cn/ |

### 4.2 短期出口信用保险（最常用）

| 项目 | 内容 |
|------|------|
| **承保风险** | ① 商业风险：买方破产无力偿付、买方拖欠货款（通常拖欠 4 个月以上）、买方拒收货物；② 政治风险：买方所在国发生战争/内战/叛乱/外汇管制/进口管制/吊销进口许可证等。 |
| **最高赔付比例** | **最高 90%**（具体由被保险人申请并与保险人协商确定，常见 80%–90%）。 |
| **费率** | 以**出口国别、支付方式、信用期限**为基本因素，根据国别风险等级、支付方式种类、信用期限长短制定费率表；再综合企业投保范围、买方资信、双方交易历史、出口市场风险程度调整。**短期险费率区间通常为出口额的 0.3%–1%**（高风险国别/OA 账期偏高，低风险国别/L/C 偏低）。 |
| **小微企业专属产品** | **"小微企业信保易"**：保单年度保险费 = 上年海关统计出口总金额 × 保险费率；流程简化、索赔条件明确。 |

> 来源：中国信保《短期出口特险简介》
> https://www.sinosure.com.cn/ywjs/myxcp/dqckxybx/mfwybx/tdhtbxabck/index.shtml ；
> 中国信保《短期出口信用保险的费率是如何计算的？》
> https://www.sinosure.com.cn/khfw/wytb/cjwtdy/tbsx/165905.shtml ；

### 4.3 投保流程（5 步）

```
Step 1  投保申请
        ├─ 在线提交投保申请（https://www.sinosure.com.cn/）
        ├─ 填写《投保单》，提供公司基本信息、主要出口国家/买方/支付方式
        └─ 中信保审核企业资质、历史出口数据

Step 2  签单缴费
        ├─ 中信保核定费率、签发《保险单》
        ├─ 提供《保单明细表》《费率表》《国家（地区）分类表》
        └─ 企业按告知函缴纳保费至约定账户

Step 3  申请买方信用限额（关键！）
        ├─ 对保单适用范围内**每一个买方**，填写《买方信用限额申请表》
        ├─ 中信保调查买方资信（通过海外征信机构 D&B/Coface 等）
        ├─ 审批后出具《信用限额审批单》
        └─ 每个买方都有一个"赔付上限"——超过限额的部分不赔

Step 4  出运申报
        ├─ 每出运一批货，填写《出口申报单》
        ├─ 申报内容：买方、金额、支付方式、出运日期
        └─ 中信保根据申报数据核算实际保费

Step 5  理赔/追偿
        ├─ 发生可能损失（买方拖欠/破产/拒收）→ 立即报损
        ├─ 提交《可能损失通知书》
        ├─ 中信保定损核赔（原则上 30 个工作日内）
        ├─ 同意赔付的，收到客户反馈材料后 15 个工作日内支付赔款
        └─ 赔付后代位求偿，向买方追偿
```

> 来源：中国信保投保指南 https://www.sinosure.com.cn/khjl/xbbk/tbzn/290.shtml ；
> "小微企业信保易"索赔说明 https://sol.sinosure.com.cn/biz/solc/esell2/sseManage/subpage2.jsp （检索日期 2026-09-28）

### 4.4 国家风险评级与费率关系

| 风险等级（中信保分类） | 典型国家/地区 | 费率倾向 |
|---------------------|-------------|---------|
| **低风险（A/B 类）** | 美国、德国、英国、法国、日本、澳大利亚、加拿大、新加坡、中国香港 | 费率低（0.2%–0.5%） |

| **高风险（E/F/G/H 类）** | 伊朗、叙利亚、阿富汗、部分非洲国家、委内瑞拉、朝鲜 | 费率高（1%+）或**不予承保** |

> 💡 **实操要点**：费率高低主要看**国别风险 + 支付方式 + 账期**。

> - D/P 付款交单：中等
> - D/A 承兑交单 / O/A 赊销：费率最高（商业信用）

## 五、汇率避险工具

> 本节为**概要**，详细操作流程见《汇率风险管理实操.md》（同目录）。

### 5.1 远期结售汇（Forward）

| 项目 | 内容 |
|------|------|
| **定义** | 与银行签订远期合同，约定未来某日按约定币种、金额、汇率办理结汇/售汇。 |
| **核心作用** | **锁定未来结汇汇率**，不管市场怎么变都按约定汇率交割。 |
| **期限** | 通常 1 个月、3 个月、6 个月、1 年；也可做择期（一段时间内交割）。 |
| **保证金** | 通常按合约金额的 **5%–10%** 缴纳保证金，或占用银行授信额度。符合条件的小微企业可申请减免保证金（地方政府有担保政策时）。 |
| **办理前提** | 必须有**真实贸易背景**（PI/合同/报关单），银行做"客户适合度评估"后签《外汇衍生品交易主协议》。 |
| **KaiLionCrafts 适用场景** | 单笔 ≥$50K、从签 PI 到收汇超过 60 天的订单。建议锁 50%–80%，不全锁。 |

> 来源：国家外汇管理局《汇率避险知识速递》
> https://www.safe.gov.cn/shanghai/2026/0626/2462.html ；
> 商务部《外经贸企业汇率避险业务手册》
> http://images.mofcom.gov.cn/cws/202308/20230801151809608.pdf （检索日期 2026-09-28）

### 5.2 外汇期权（Option）

| 项目 | 内容 |
|------|------|
| **定义** | 付一笔"权利金"，获得按约定汇率结汇/售汇的**权利但不是义务**。 |
| **买入结汇看跌期权（Put）** | 约定按 6.68 结汇的权利。如果市场跌到 6.55 → 行权按 6.68 结；如果市场涨到 6.90 → 放弃期权按 6.90 结。 |
| **卖出期权（Call/Put）** | 收取权利金，但承担按约定汇率被行权的义务。**出口商一般不做卖出期权，风险大。** |
| **权利金** | 通常为合约金额的 **1%–3%**（取决于期限、汇率波动率）。 |
| **适用场景** | 大单（≥$100K）、汇率趋势不明朗、想保留下行收益时。 |
| **KaiLionCrafts 适用性** | ⚠️ 当前阶段建议先用远期结售汇（简单），期权作为成熟后进阶工具。 |

### 5.3 外汇掉期（Swap）

| 项目 | 内容 |
|------|------|
| **定义** | 同时做一笔即期 + 一笔反向远期（或两笔不同期限远期），实质是换币种短期周转。 |
| **适用场景** | 未来既有美元收入又有美元支出，币种/期限错配时。 |
| **KaiLionCrafts 适用性** | ❌ 暂不需要。公司收入美元、成本人民币，不涉及多币种错配。 |

### 5.4 人民币跨境结算（CIPS）

| 项目 | 内容 |
|------|------|
| **全称** | 人民币跨境支付系统（Cross-border Interbank Payment System, CIPS） |
| **运营机构** | 跨境银行间支付清算有限责任公司（CIPS 公司） |
| **作用** | 为人民币跨境贸易和投资提供清算结算服务。 |
| **KaiLionCrafts 适用场景** | ✅ **俄罗斯/CIS 客户**：受制裁环境下美元/欧元通道不稳，坚持用 CNY 跨境人民币结算，零汇率风险。 |

| P1 | **大 L/C 订单用打包贷款备货** | 收到 ≥$100K L/C 时，若手头没钱向工厂下 30% 定金，用打包贷款（L/C 金额 70%）解决备货资金。 |
| P2 | **申请银行信用贷款** | 纳税满 2 年、开票额稳定后，申请农行"外贸贷"/工行"税务贷"，额度约纳税额 3–8 倍，作为备用金。 |
| P2 | **月退税 >¥10 万时申请出口退税托管贷款** | 退税到账滞后期的资金占压可以通过贷款盘活。 |

### 8.3 扩张阶段（月流水 >$100K）建议

| 优先级 | 行动 | 理由 |
|--------|------|------|
| P2 | **大额远期 L/C 用福费廷** | ≥$500K、180 天以上远期 L/C，无追索权卖断给银行，彻底转移开证行信用风险。 |
| P2 | **无追索权国际保理** | 若主要客户是欧美优质企业、稳定 OA 订单，用无追索权保理（费率 0.8%）把坏账风险转给保理商。 |
| P3 | **做 Amazon FBA 后关注 Amazon Lending** | 仅作为短期周转，不作为长期资金来源。 |
| P3 | **评估是否申请政府创业扶持基金/大赛后续扶持** | 公司已获"百千万工程"二等奖，关注团省委/阳江市配套的创业贷款贴息、场地补贴。 |

### 8.4 融资红线

1. ❌ **不做 OA 赊销，除非已投中信保且有信保融资额度。**
2. ❌ **不拿个人房产抵押去做贸易融资**——一人公司风险不可控，房子押进去就回不来了。
3. ❌ **不碰平台高利贷**（Amazon Lending/PayPal Working Capital APR 20%+），除非周转 <1 个月。
4. ❌ **不做外汇投机**——远期结售汇只锁真实贸易背景的敞口，不赌汇率方向。
5. ✅ **融资只用于真实贸易周转**，不用于炒股、买房、借新还旧。
6. ✅ **任何融资决策 Leo 本人核算后再做**，不轻信银行客户经理推销。
