# 供应链成本拆解模板

> ⚠️ **使用说明（必读）**
> 本文件为**成本拆解与报价测算模板**，所有具体金额均为**占位数字/行业参考区间**，标注「待填入实际数据」的位置须由 Leo 或工厂提供真实采购价、加工价、运费后填入。
> 行业参考区间来自公开外贸/五金制造行业资料，**仅供参考，不构成公司实际成本**；实际成本以工厂报价单、货代报价单、PI 为准。
> 本模板用于：① 收到询盘后快速测算 FOB/CIF/DDP 报价底线；② 评估新 SKU 的成本结构与毛利空间；③ 谈判时掌握各成本项的弹性空间。

> 📌 **结构说明**：
> - 钢材通常是单品最大成本项（尤其大马士革/VG10 高端线）。

> - 镜面抛光比拉丝抛光贵 2–4 倍。
> - 包装（尤其 FSC 木盒/皮盒）在高端礼品线占比可升至 10%–15%。

## 二、钢材成本计算

### 2.1 计算公式

```
单把刀钢材成本 = 单把刀实际用钢重量(kg) × 钢材单价(¥/kg) × (1 + 开料损耗率)

其中：
  单把刀实际用钢重量 = 刀胚重量 + 损耗重量（开料边角料）
  开料损耗率 ≈ 15%–25%（异形刀型/小批量更高）
  即：采购钢板重量 = 成品刀胚重量 ÷ (1 - 损耗率)
```

> 💡 **材料利用率参考**：
> - 开料损耗约 **15%–25%**（行业经验值，异形刀型更高）
> - 即一块钢板真正变成刀胚的材料利用率约 **75%–85%**
> - 损耗边角料部分可折价回收（⚠️ 回收折价待确认）

### 2.3 单把刀钢材成本计算示例（占位数字）

> ⚠️ 以下为**示例**，数字为占位演示，非真实成本。

**示例：一把 8 寸主厨刀（5Cr15MoV）**

```
已知：
  刀胚净重 = 0.20 kg（成品刀身钢料）
  钢材单价 = ¥30/kg（5Cr15MoV 参考中值）
  开料损耗率 = 20%

计算：
  实际采购钢板重量 = 0.20 ÷ (1 - 0.20) = 0.25 kg
  单把刀钢材成本 = 0.25 kg × ¥30/kg = ¥7.5 ≈ $1.05

对比：若换 VG10 芯 67 层大马士革
  大马士革钢材成本 = 0.25 kg × ¥800/kg = ¥200 ≈ $28.0
  → 仅钢材一项，大马士革就是 5Cr15MoV 的约 27 倍
```

| 钢材方案 | 刀胚净重 | 损耗后采购量 | 单价(¥/kg) | 单把钢材成本(¥) | 约合(USD) |
|---|---|---|---|---|---|
| 3Cr13（入门） | 0.20 kg | 0.25 kg | ¥20 | ¥5.0 | $0.70 |
| 5Cr15MoV（主力） | 0.20 kg | 0.25 kg | ¥30 | ¥7.5 | $1.05 |
| 9Cr18MoV（高端） | 0.20 kg | 0.25 kg | ¥55 | ¥13.75 | $1.93 |
| VG10（进口高端） | 0.20 kg | 0.25 kg | ¥225 | ¥56.25 | $7.90 |
| Damascus 67层（溢价） | 0.20 kg | 0.25 kg | ¥800 | ¥200.0 | $28.0 |

> 💡 **结论**：钢材选型对成本影响极大。报价前务必先锁定钢材牌号，再测算 BOM。
> ⚠️ 实际刀胚重量、钢材单价、损耗率均**待填入工厂真实数据**。

### 3.2 不同工艺的成本差异对比

> 以同一把厨刀为基准，对比工艺选择对加工费的影响。

| 工艺维度 | 低档方案 | 高档方案 | 成本倍数差异 |
|---|---|---|---|
| **成形工艺** | 冲压（Stamping） | 手工锻造（Forged） | 锻造 ≈ 冲压的 **5–8 倍** |
| **表面抛光** | 拉丝/缎面（Satin） | 镜面抛光（Mirror） | 镜面 ≈ 拉丝的 **3–5 倍** |
| **钢材** | 3Cr13 | 67层大马士革 VG10 | 大马士革 ≈ 入门钢的 **20–40 倍** |
| **手柄** | ABS/POM 注塑 | 花梨木手工/G10/鲍鱼壳 | 高端柄材 ≈ 注塑的 **3–10 倍** |
| **包装** | 白盒/吸塑 | FSC 木盒/皮盒礼盒 | 高端包装 ≈ 吸塑的 **5–15 倍** |
| **热处理** | 普通淬火 | 真空淬火+回火+深冷 | 深冷处理 ≈ 普通的 **2–3 倍** |

> 💡 **成本控制要点**：
> - 同一款刀，冲压+拉丝+3Cr13+ABS 柄+白盒 vs 锻造+镜面+大马士革+鲍鱼壳+木盒，**终端成本可相差 15–30 倍**。
> - 报价前必须确认：成形工艺（冲压/锻造）、表面处理（拉丝/镜面/喷砂）、钢材牌号、手柄材质、包装档次——这五项决定 80% 的加工费差异。
> ⚠️ 以上倍数为行业经验参考，具体单价待填入工厂实际报价。

## 四、物流成本拆解

> 依据 `11_订单与财务/10_物流费用结构与渠道对比.md` 与 `04_报价体系与价格策略.md`。

### 4.1 全链路物流成本结构（DDP 口径）

```
DDP 到门总成本
├── 国内段（工厂→起运港）
│   ├── 工厂→港口拖车/短驳费
│   ├── 报关费
│   ├── THC 港杂费
│   └── 文件费/单证费
├── 国际段
│   ├── 海运费（整柜 FCL / 拼箱 LCL）
│   ├── 空运费（紧急补货，按 kg）
│   └── 国际快递费（DHL/FedEx/UPS，样品）
├── 保险费
│   └── 货运保险 = 货值 × 110% × 保险费率（约 0.1%–0.3%）
├── 目的港段
│   ├── 目的港清关费
│   ├── 进口关税（按 HS 编码税率）
│   └── 代缴税费服务费（DDP）
└── 尾程配送
    ├── 目的国内陆运输（港口→客户仓）
    └── 海外仓尾程（USPS/UPS/FedEx 本地派送）
```

### 4.2 各环节费用参考

| 环节 | 计费方式 | 参考区间 | 备注 |
|---|---|---|---|
| **国内运输**（工厂→港口） | 按车/按柜 | ⚠️ 待填入（阳江→深圳盐田/阳江东平港） | 30 分钟供应链半径，本地拖车 |
| **报关费** | 按票 | ¥150–300/票 | 出口报关，每票固定 |
| **THC 港杂费** | 按柜 | ⚠️ 待填入 | 起运港码头操作费 |
| **海运整柜 FCL** | 按 20GP/40HQ | ⚠️ 待填入（随季节/舱位/油价波动） | 大货主力，单位成本最低 |
| **海运拼箱 LCL** | 按体积(CBM)/重量 | ⚠️ 待填入 | 小批量不足一柜 |
| **空运** | 按计费重量(kg) | ⚠️ 待填入（取实际重与体积重较大者） | 紧急补货/高货值 |
| **国际快递** | 首重+续重(0.5kg进位) | ⚠️ 待填入（签约账号有折扣） | 样品/急件，门到门最贵 |
| **货运保险** | 货值×110%×费率 | 费率约 0.1%–0.3% | CIF/DDP 由卖方付 |
| **目的港清关费** | 按票 | ⚠️ 待填入（各国不同） | DDP 由卖方付 |
| **进口关税** | 货值×关税率 | ⚠️ 待填入（刀具 HS 编码各国税率不同；美国注意 301 关税清单） | DDP 由卖方付 |
| **尾程配送** | 按件/按区 | ⚠️ 待填入（USPS/UPS/FedEx） | 海外仓本地 1–3 天 |

### 4.3 各物流渠道费用占比参考

> 以一票 DDP 到美国的大货为例，费用结构典型占比（行业参考，⚠️ 实际待填入）：

| 费用项 | 占物流总成本比重（参考） | 说明 |
|---|---|---|
| 产品出厂成本（EXW） | 占 FOB 的 70%–85% | 最大头 |
| 国内段（运输+报关+港杂） | 占 FOB 的 3%–8% | 固定支出 |
| 国际海运费 | 占 CIF 的 5%–15%（大货整柜占比低） | 大货摊薄后不高 |
| 货运保险 | 占 CIF 的 0.1%–0.3% | 很小 |
| 目的港清关+关税 | 占 DDP 的 10%–25% | 关税是大头，随 HS 编码 |
| 尾程配送 | 占 DDP 的 5%–15% | 海外仓本地履约 |

> 📌 **渠道选择逻辑**（来自知识库）：
> - 大货 OEM/ODM → 海运 FOB/CIF/DDP（20–35 天，单位成本最低）
> - 紧急补货/高货值 → 空运（7–15 天）
> - 样品/急件 → 国际快递 DHL/FedEx/UPS（3–7 天，最贵）
> - B2C/小批 → 美国海外仓现货（1–3 天本地送达，最低履约成本）

## 五、报价计算公式（Incoterms）

> 依据 `11_订单与财务/04_报价体系与价格策略.md`。

### 5.1 四大贸易术语公式

```
EXW（工厂交货）= 产品成本 + 工厂利润

FOB（装运港船上交货）= EXW + 国内运输(工厂→港口) + 报关费 + 港杂费(THC) + 文件费

CIF（成本+保险+运费）= FOB + 国际海运费 + 货运保险费
                       保险费 = 货值 × 110% × 保险费率

DDP（完税后交货到门）= CIF + 目的港清关费 + 进口关税 + 目的国内陆派送 + 代缴税费服务费
```

### 5.2 计算示例（占位数字，仅演示公式结构）

> ⚠️ 以下数字**全部为示例占位**，非真实报价，仅用于演示公式如何套用。

**基础数据（示例）：**
- 产品成本（EXW 出厂价）= $3.00/把
- 国内运输+报关+港杂分摊 = $0.30/把
- 海运费分摊 = $0.50/把
- 保险费 = $0.05/把
- 目的港清关+关税 = $1.20/把
- 尾程派送 = $0.80/把

```
EXW = $3.00

FOB = EXW $3.00 + 国内段 $0.30 = $3.30

CIF = FOB $3.30 + 海运费 $0.50 + 保险 $0.05 = $3.85

DDP = CIF $3.85 + 清关关税 $1.20 + 尾程 $0.80 = $5.85
```

| 术语 | 示例计算过程 | 示例结果(USD/把) |
|---|---|---|
| EXW | 产品成本 | $3.00 |
| FOB | EXW + 国内段($0.30) | $3.30 |
| CIF | FOB + 海运($0.50) + 保险($0.05) | $3.85 |
| DDP | CIF + 清关关税($1.20) + 尾程($0.80) | $5.85 |

> 💡 **报价原则**（来自知识库）：
> - 多数海外客户更习惯 FOB 术语，**优先报 FOB**。
> - 分项报价（产品价+包装费+Logo 费+运费分列），客户觉得透明。
> - 报价有效期标准 15–30 天（汇率/原材料波动时缩短到 7 天）。
> - DDP 报价需提前核算目的国关税（印度关税高、美国注意 301 清单、俄罗斯需人民币结算）。

## 六、利润测算模板

> ⚠️ 以下所有数字为**模板占位**，需填入实际数据。

### 6.1 成本加成法（Cost-Plus）

```
报价单价 = 单位总成本 × (1 + 目标毛利率)

其中：
  单位总成本 = 单位产品成本 + 分摊运营费用 + 单位物流费
  目标毛利率 = ⚠️ 待填入（建议行业参考 20%–35%）
```

**示例（占位）：**
```
单位总成本 = $3.30（FOB 成本）
目标毛利率 = 25%
报价单价 = $3.30 × (1 + 0.25) = $4.13/把
```

### 6.2 目标利润法（Target Profit）

```
保本单价 = (固定成本 + 目标利润) ÷ 预计销量

其中：
  固定成本 = ⚠️ 待填入（人员工资、独立站年费、邮箱、推广、办公等月度固定支出）
  目标利润 = ⚠️ 待填入（期望赚多少）
  预计销量 = ⚠️ 待填入（预计月/季销量）
```

**示例（占位）：**
```
月度固定成本 = $3,000
月度目标利润 = $2,000
预计月销量 = 1,000 把
保本单价 = ($3,000 + $2,000) ÷ 1,000 = $5.00/把
（即每把至少卖 $5.00 才能覆盖固定成本+达成目标利润）
```

### 6.3 盈亏平衡点（Break-Even Point）

```
盈亏平衡销量 = 固定成本 ÷ (单价 − 单位变动成本)

其中：
  单位变动成本 = 随单量变动的成本（产品成本+物流+包装）
  单价 = 对外售价
```

**示例（占位）：**
```
固定成本 = $3,000/月
单价 = $4.13/把
单位变动成本 = $3.30/把
单位边际贡献 = $4.13 − $3.30 = $0.83/把
盈亏平衡销量 = $3,000 ÷ $0.83 ≈ 3,615 把/月
```

| 指标 | 公式 | 占位示例值 |
|---|---|---|
| 单位边际贡献 | 单价 − 单位变动成本 | $0.83/把 |
| 盈亏平衡销量 | 固定成本 ÷ 单位边际贡献 | ≈ 3,615 把/月 |
| 盈亏平衡销售额 | 盈亏平衡销量 × 单价 | ≈ $14,930/月 |

### 6.4 不同 MOQ 的成本变化（规模效应）

> 依据 `03_OEM_ODM定制能力.md` 与 `04_报价体系与价格策略.md`：MOQ 三级 50/150/500。
> 量越大，模具/开机/损耗分摊越薄，单价越低。

| MOQ 区间 | 定制级别 | 单价系数（相对标准价） | 成本变化逻辑 |
|---|---|---|---|
| 1–49 pcs | 样品/打样 | 标准价 × 2–3 倍 | 打样费、小批量开机成本高 |
| 50–150 pcs | 轻定制（Logo/包装） | 标准价（基准） | 小单柔性产线起步 |
| 150–499 pcs | 中度定制（刀型/手柄开模） | 标准价 × 0.9–0.95 | 开机费摊薄 |
| 500–999 pcs | 全 ODM | 标准价 × 0.8–0.88 | 模具费分摊、批量采购钢材 |
| ≥1000 pcs | 整柜/年度框架 | 标准价 × 0.75–0.85（面议） | 规模效应最大，钢材整板采购议价 |

> 📌 **规模效应来源**：
> 1. **材料采购**：量大可整板/整柜采购钢材、塑料粒，单价更低。
> 2. **模具/开机费**：固定费用分摊到更多件，单件分摊下降。
> 3. **损耗率**：大批量开料利用率更高，损耗率下降。
> 4. **人工效率**：连续生产熟练度提升，单件工时下降。
> 5. **谈判筹码**：量大向货代、工厂争取更低费率。

### 6.5 毛利核算公式（工作台口径）

```
毛利 = 订单金额 − 关联采购成本 − 物流费 − 其他费用
毛利率 = 毛利 ÷ 订单金额 × 100%
```

> ⚠️ 待确认（来自知识库待补数据清单）：
> - 各品类目标毛利率区间
> - 实际平均毛利率
> - 最低可接受毛利率红线（低于此价不接）
> - 固定成本月度总额
> - 各 SKU 实际单位变动成本
