> **使用说明**：商业发票（CI）是出口报关、进口清关、银行结汇的核心单证。

> CI 与 PI 号码规则一致（KL-CI-YYYY-XXX），但金额为实际出货金额。

## 填写说明

| 字段 | 填写要点 |
|------|---------|
| Invoice No. | 格式 KL-CI-YYYY-XXX，与 PI/合同号对应但编号段独立 |
| Invoice Date | 实际开票日期，一般为出货前 3–5 天 |
| Buyer 信息 | 必须与合同/信用证完全一致；含 VAT/EIN 税号（欧洲/澳洲必填） |
| HS Code | 厨刀/剪刀 8214100000；户外刀 8211 项下；厨房用具 8215 项下 |
| Product Description | 与合同/信用证描述一致，不得增减字 |
| Trade Terms | 注明 Incoterms 2020，如 FOB Yantian |
| Amount | 实际出货金额；如有溢短装，按实际数量计算 |
| Bank Info | CIF 条款下保险费单列；FOB 条款下不列运费保费 |

## 常见错误

1. **金额与 PI/合同不符**：CI 金额必须与实际出货一致；溢短装需在合同 +/-5% 范围内
2. **Buyer 名称与信用证不符**：L/C 项下严格按信用证申请人名称填写，一个字母都不能错
3. **HS Code 填错**：厨刀归 8214，户外刀归 8211，厨房用具归 8215——报关前与报关行复核
4. **贸易术语漏写港口**：FOB Yantian ≠ FOB Shenzhen，必须写具体装运港
5. **唛头遗漏**：有指定唛头必须照抄；无指定则用卖方标准唛头
6. **大小写金额不一致**：数字金额与英文大写金额必须一致
7. **漏签字盖章**：CI 必须有出口方签字+公章，否则进口国海关可能拒收
8. **CIF 下不列运费保费**：FOB 成交的 CI 上不应出现 Freight/Insurance 金额

## 注意事项

- **CI 是报关核心单据**：报关单上的商品名称、数量、金额必须与 CI 完全一致
- **进口国清关**：部分国家（如巴西、阿根廷）要求 CI 做领事认证或使馆认证，出货前确认
- **低报货值风险**：切勿应客户要求低报 CI 金额——影响出口退税，且涉嫌逃税
- **多批次出货**：同一合同分批出货时，每批单独出具 CI，注明"Partial Shipment X of Y"
- **金额币种**：与合同一致；如客户要求欧元，CI 上注明 USD/EUR 汇率及折算日
- **退税联**：CI 是出口退税必备单据之一，务必留存电子版+纸质版
