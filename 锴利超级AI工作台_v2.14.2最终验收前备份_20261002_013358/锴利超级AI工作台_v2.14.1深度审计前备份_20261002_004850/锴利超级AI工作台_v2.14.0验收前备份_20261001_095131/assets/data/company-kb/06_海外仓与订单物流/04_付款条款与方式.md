# 付款条款与方式

## 一、两段式付款（行业标准）

> **30% 定金（Deposit）+ 70% 尾款（Balance）**

```
① 确认订单（签 PI）
   ↓ 付 30% 定金
收到定金 + 规格批准 → 才开工生产
   ↓
② 出货前视频确认（Pre-Shipment Video）
   ↓ 付 70% 尾款
收到尾款 → 安排发货
```

- **Deposit 定金**：确认订单后付；收到定金 + 规格批准才开工。
- **Balance 尾款**：出货前视频确认后付；收到尾款才发货。

## 二、付款方式对比

| 方式 | 英文 | 适用场景 | 说明 |
|------|------|---------|------|
| T/T 银行电汇 | Telegraphic Transfer | 大货定金+尾款主力 | 最常用 |
| PayPal | PayPal | 样品费 | 小额、即时 |
| Western Union | 西联汇款 | 小单 | 小额快捷 |
| L/C 信用证 | Letter of Credit (Sight) | 大单 | 即期信用证，大额订单 |

## 三、币种

- **USD**（主力）/ EUR / GBP

## 四、各方式适用场景

| 场景 | 推荐方式 |
|------|---------|
| 样品单 | PayPal / Western Union |
| 常规 OEM/ODM 大货 | T/T（30% 定金 + 70% 尾款） |
| 大额信任订单 | L/C 即期 |
| 海外仓现货小批 | 按约定（T/T / PayPal） |

## 五、风险控制要点

- 收到定金 + 规格书面批准才投产。
- 出货前必须视频验货 + 客户书面批准。
- 收到尾款才放货/放提单。

### 六、收付款在工作台中的登记（payments 流水表）

每一笔收付款都进 `payments` 流水表，一条订单可对应多条流水（天然支持 30% 定金 + 70% 尾款分批）：

| 字段 | 说明 |
|------|------|
| 日期 | 收/付发生日 |
| 方向 | 收客户 / 付工厂 |
| 关联订单号 | 下拉选销售订单号 |
| 金额 / 币种 | 原币金额（USD 主力 / EUR / GBP） |
| 汇率 | **手动填写**，折人民币（汇率 API 后期再接） |
| 方式 | T/T / 西联 / 信用证 / PayPal |
| 备注 | 如"30% 定金""出货前 70% 尾款" |

- **应收** = Σ订单金额 − Σ已收；**应付** = Σ采购额 − Σ已付工厂。
- 这两个数字是首页驾驶舱顶部 4 个数之二（今日待跟进 / 进行中订单 / 应收总额 / 本月毛利）。

### 七、付款方式按订单金额分级

| 订单规模 | 推荐付款方式 | 说明 |
|---------|-------------|------|
| 样品单 | PayPal / Western Union | 小额、即时、客户垫付样品费 |
| 常规 OEM/ODM 大货 | T/T（30% 定金 + 70% 尾款） | 最常用，主力 |
| 大额信任订单 | L/C 即期信用证（Sight L/C） | 大额订单，银行信用背书 |
| 海外仓现货小批 | T/T / PayPal（按约定） | 现货即走 |
| 俄罗斯/CIS 客户 | **人民币 CNY 结算** | 受制裁，美元/欧元通道受限（详见 04 国家指南） |
| 印度/南亚客户 | T/T + 高比例预付（最少 20%–30%） | OA 账期风险高，未收定金不排产 |

### 八、付款铁律（与反跳单协议联动）

1. 收到 **30% 定金 + 规格书面批准** 才开工生产。
2. 出货前必须 **视频验货 + 客户书面批准**。
3. 收到 **70% 尾款** 才放货 / 放提单。
4. 每批出货 **Leo 本人签字放行**。

> ⚠️ 反跳单协议要点：乙方（锴利）自主开发的海外客户为专属客户，专属期自首次接触起 2 年；该客户订单必须由锴利作为唯一对接方与工厂签采购合同，工厂不得私接。详见 `11_订单与财务/03_禁止反跳单协议.md`。

### 九、风险控制红线

- 不接受通过可疑第三国公司的付款（尤其俄罗斯方向）。
- 首单对高风险地区客户建议提高预付比例（俄罗斯最好 50%）。
- OA 赊销仅对熟悉客户、且必须查 Dun & Bradstreet 信用报告（澳新客户）或中信保（印度客户）。
- 所有收款必须在工作台 payments 表登记，手动折人民币，便于月度毛利核算。
