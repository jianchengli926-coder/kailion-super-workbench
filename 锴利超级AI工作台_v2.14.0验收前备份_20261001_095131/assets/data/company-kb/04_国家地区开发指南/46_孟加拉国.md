# 孟加拉国客户开发指南（Bangladesh）

> **战略定位**：约 1.7 亿人口、**全球第二大成衣（RMG）出口国 + 裁缝剪巨大需求 + 低价市场**。孟加拉国出口的 **80% 以上来自服装（RMG）**，达卡周边聚集了约 7,000 家服装厂，对**裁缝剪、缝纫剪刀、修线剪**等工业用剪刀有刚性需求。本国人均收入低（约 2,800 美元），价格敏感，但 RMG 产业带来稳定的工业工具采购。
>
> ⚠️ **本市场付款风险等级：中（但信用证制度下实际风险偏低）。** 孟加拉国外汇管制严格，**商业进口几乎强制使用不可撤销信用证（L/C）**，且进口商须 100% 押金开证——对出口商而言，只要单证相符，收款由孟加拉银行担保，风险反而可控。但清关慢、外汇排队、塔卡波动需关注。

## 二、商务习俗与沟通风格

- **关系导向 + 宗教主导**：孟加拉国约 90% 穆斯林，商务文化偏关系型；先做朋友再做生意。
- **沟通语言**：**英语为商务语言**（曾为英属，教育层英语流利）；开发信英文即可；孟加拉语版报价单加分。
- **价格极度敏感**：本国人均收入低，客户压价厉害；但 RMG 工厂对工具质量有底线（剪刀直接影响生产效率）。
- **宗教禁忌**：
  - 穆斯林为主——斋月白天勿在客户面前饮食；
  - 不送猪/酒精礼品；
  - **周五中午礼拜时间勿安排会议**；
  - 印度教徒约 8%，杜尔迦节（Durga Puja）是大节日。
- **时间观念**：偏宽松，会议可能推迟；耐心比效率重要。
- **决策链**：RMG 大厂采购经理 + 老板；中小进口商老板拍板；决策慢。
- **通讯工具**：邮件 + **WhatsApp**；电话/手机普及率高；达卡拥堵严重，线下见面耗时。
- **基建**：达卡交通拥堵严重、电力短缺；清关效率偏低（吉大港拥堵常见）。

> 来源：Bangladesh Bank – FE Guide Vol.1 Ch.7 https://www.bb.org.bd/aboutus/regulationguideline/foreignexchange/feguidevol1chp/feguidevol1ch7sec2.pdf ；检索日期 2026-09-28。

## 三、采购特点与决策链

- **市场结构**：
  - **RMG 服装厂（核心）**：约 7,000 家服装厂——**裁缝剪（tailors' shears）、修线剪（thread snips）、缝纫工具**是刚需耗材；
  - **成衣辅料/机械进口商**：代理缝纫设备/工具；
  - **本地五金市场**：达卡 Babu Bazar / Islampur 批发市场——厨房刀/家用剪；
  - **连锁零售**：Rangs、Daraz BD（电商）；
  - **食品加工/屠宰**：本地屠宰业——屠刀/砍骨刀；
  - **政府/项目**：达卡基建带来工具需求。
- **决策链**：RMG 大厂采购部（有规范流程）；家族贸易商老板拍板；RMG 工厂常用 **back-to-back L/C**（背对背信用证）采购辅料。
- **辐射效应**：孟加拉本身是低价市场；RMG 产业是核心切入点。

## 四、付款偏好与风险

| 方式 | 接受度 | 说明 |
|---|---|---|
| **不可撤销即期 L/C（Irrevocable Sight L/C）** | **⭐⭐ 绝对主流** | 孟加拉国进口几乎强制 L/C；进口商须 100% 押金开证 |
| T/T 预付 | 低-中 | 外汇管制下 T/T 大额预付少见；样品单可 |
| O/A 赊销 | 🚫 不接受 | 外汇管制 + 信用环境，严禁 O/A |
| D/P / D/A | 低 | 谨慎；不如 L/C 安全 |
| PayPal/西联（样品单） | 中 | 样品单 |

> ⚠️ **风险提示：**
> 1. **外汇管制严格**：孟加拉国央行（Bangladesh Bank）管制外汇；进口须通过 LCA（Letter of Credit Authorization）表格；
> 2. **L/C 是保护出口商的关键**：进口商开证须 100% 押金（银行才受理），因此**只要单证相符，收款风险低**；
> 3. **L/C 条款**：孟加拉 L/C 条款普遍宽松，正常交单很少出现不符点；但仍须严格 UCP 600 单证一致；
> 4. **塔卡波动 + 外汇排队**：近年孟加拉外汇紧张，进口付汇曾出现排队；报价用 USD；
> 5. **强制装船前检验**：部分商品须 PSI（pre-shipment inspection）；
> 6. **清关慢**：吉大港拥堵，建议预留时间。
>
> 来源：Bangladesh Bank – LCs and Remittances against Imports https://www.bb.org.bd/aboutus/regulationguideline/foreignexchange/feguidevol1chp/feguidevol1ch7sec2.pdf ；Bizmend – LC in Bangladesh https://bizmend.com/blog/letter-of-credit-lc-in-bangladesh/ ；连连国际 – 出口孟加拉国实操 https://global.lianlianpay.com/article/MTU1MDM0LDY4Mg.html ；Bangladesh Trade Portal – Import Procedure https://bangladeshtradeportal.gov.bd/?r=site/display&id=303 ；检索日期 2026-09-28。

## 六、刀具进口法规与认证要求（⚠️重点）

### 6.1 关税与税种（HS 8211/8213 刀剪）

| 税费 | 税率（参考 FY2025-26） | 说明 |
|---|---|---|
| **CD（关税 Customs Duty）** | **25%** | HS 8211（刀）/8213（剪刀/裁缝剪）法定进口关税均为 25% |
| **SD（补充关税 Supplementary Duty）** | 0%（刀剪类暂未列征） | 视年度 SRO 调整；其他商品 0–45% 不等 |
| **VAT（增值税）** | **15%** | 标准税率；进口商可抵扣 |
| **AIT（预付所得税 Advance Income Tax）** | **约 5%** | 进口环节预缴 |
| **RD（监管税 Regulatory Duty）** | 视品类 | 刀剪类一般 0 |
| **综合税负（CIF 基础）** | **约 25% CD + 15% VAT + 5% AIT** | 总税负约 40%+（VAT 可抵扣） |

- 即：中国产刀剪出口孟加拉，**关税 25% + VAT 15% + AIT 5%**——税负较高，因此客户极度价格敏感。
- 来源：NBR Bangladesh – Customs Tariff Chapter 82 (PDF) https://nbr.gov.bd/uploads/tariff_schedule/Chapter-821.pdf （8211.10/8211.91/8213.00 法定进口关税 25%）；Bangladesh Trade Portal – Commodity Tariff https://bangladeshtradeportal.gov.bd/index.php?id=6900&r=tradeInfo%2Fview ；NBR – VAT FAQ https://nbr.gov.bd/all-faq/ban/eng ；PwC – Bangladesh Other Taxes https://taxsummaries.pwc.com/bangladesh/corporate/other-taxes ；检索日期 2026-09-28。

### 6.2 认证与市场监督

| 项目 | 规定 |
|---|---|
| LCA 表格 | 所有进口须通过银行填报 LCA（Letter of Credit Authorization）表格 |
| 不可撤销 L/C | 除少数例外，进口须开立不可撤销跟单信用证 |
| 装船前检验（PSI） | 部分商品须装船前检验 |
| 食品接触材料 | 厨刀建议提供食品接触报告；无法定强制孟加拉认证 |
| 标签 | 孟加拉文/英文标签；进口商信息必填 |
| 强制认证 | 刀剪类无强制 BSTI 认证（BSTI 对部分食品/建材强制） |

### 6.3 刀具管制

| 项目 | 规定 |
|---|---|
| 武器/弹药 | 严格管制，须国防部/内政部许可 |
| 🚫 进攻性武器/军火 | 禁止 |
| ✅ **裁缝剪（tailors' shears, HS 8213）** | B2B 自由进口（RMG 刚需） |
| ✅ 厨刀/餐刀/厨房剪/修枝剪 | B2B 可进口，25% 关税 |
| ✅ 屠刀/砍骨刀 | 本地屠宰业需求 |
| 战术刀/自动刀 | 谨慎，不主动推 |

- **对 B2B 出口的含义**：
  - ⭐⭐ **裁缝剪/修线剪（HS 8213）是孟加拉核心切入点**——RMG 工厂约 7,000 家，剪刀是耗材；
  - ✅ **厨刀/厨房剪/修枝剪/砍骨刀**：B2B 可进口，但税负高（约 40%），客户极度压价；
  - ⚠️ 报价须考虑 25% CD + 15% VAT 的高税负——客户会把税负转嫁给出口商压价；
  - 🚫 武器/战术刀不出口。
- 来源：Bangladesh Customs – Harmonised Tariff Chapter 82 https://customs.gov.bd/portal/services/tariff/print.jsf?c=82 ；NBR – Chapter 82 Tariff https://nbr.gov.bd/uploads/tariff_schedule/Chapter-821.pdf ；检索日期 2026-09-28。

### 6.4 清关要点

- 必需文件：商业发票（USD，HS 编码）、装箱单、提单、原产地证、**L/C 项下单证**（严格 UCP 600）、LCA 表格；
- 上海/宁波到吉大港约 12–15 天；
- **吉大港拥堵**：清关常需 7–14 天甚至更长；
- 孟加拉文/英文标签；
- 外汇紧张时付汇可能排队，建议催促客户及时赎单。

> ⚠️ 本指南为公开信息汇编，不构成法律意见。孟加拉国进口法规由 NBR/Customs/Bangladesh Bank 执行，发货前由客户及孟加拉报关行确认。

## 七、推荐品类与开发切入点

| 品类 | 孟加拉市场机会 | 切入点建议 |
|---|---|---|
| **裁缝剪/修线剪（HS 8213）** | **⭐⭐⭐ 核心** | RMG 服装厂刚需耗材；走量；性价比 |
| **缝纫工具/小剪刀** | **中高** | RMG 辅料 |
| **厨房刀/厨用剪（走量）** | 中 | 低价市场；极低价路线 |
| **砍骨刀/屠刀** | 中 | 本地屠宰业 |
| **修枝剪/园艺剪** | 低-中 | 农业（黄麻/茶叶/稻米） |
| **理发剪** | 中 | 本地理发业 |
| **厨房小工具** | 低-中 | 低价市场 |
| 战术刀/自动刀/武器 | 🚫 不推 | |

**开发路径建议：**
1. **英文开发信**——孟加拉商务语言；
2. **付款方式只做不可撤销即期 L/C**——不接受 O/A；这是孟加拉外贸铁律；
3. **瞄准 RMG 服装厂/辅料进口商**——裁缝剪是核心切入点；
4. 报价 USD；考虑 25% CD + 15% VAT 高税负，客户会压价——主推性价比走量款；
5. 工作日**周日至周四**（周五周六周末）；
6. 北京时间**12:00–18:00**发信（孟加拉上午-下午）；
7. 避开开斋节/宰牲节长假；斋月白天勿安排商务午餐；
8. 严格 L/C 单证一致——UCP 600 项下交单；
9. 提醒客户吉大港拥堵，预留清关时间；
10. 不推战术刀/武器。
