# 亚马逊竞品调研方法

## 一、竞品调研资料库架构

竞品调研资料库是飞书多维表格形式的结构化知识库，包含**9张业务表、265个字段**，覆盖从调研立项到证据沉淀的全流程。

### 9张业务表
1. **竞品调研总索引**：调研项目主表
2. **竞品档案表**：单个竞品ASIN的基础信息
3. **Listing对比表**：多竞品Listing字段横向对比
4. **价格监控表**：价格历史与促销记录
5. **评价分析表**：评论主题与根因分析
6. **关键词流量表**：竞品关键词流量结构
7. **证据图片库**：截图、图片证据
8. **差异化机会表**：从竞品弱点中提炼的机会点
9. **复盘结论库**：调研结论与行动记录

### 部署原则
- 以JSON Schema为唯一事实来源创建Base
- Excel仅用于人工审核和备用录入
- 每张表的`fields[0]`是主字段，不得重新排序
- 跨表业务键（调研ID、竞品ID、证据ID）同时保留文本ID和link字段
- 文本ID用于幂等与跨系统追踪，link字段用于飞书内点击关联

## 二、竞品选择标准

### 竞品池构建原则
- 从SellerSprite `product_research`、`competitor_lookup`、关键词相关ASIN和`asin_detail`构建
- 选取**8-12个代表性ASIN**
- 覆盖真实结构、价格水平和成熟度
- 按产品结构和使用场景分层，而非仅按排名

### 竞品分层维度
1. **产品结构**：传统插槽刀座、紧凑刀座、透明刀座、磁吸刀站、精品木座
2. **价格带**：低价段（<$30）、中价段（$30-$60）、高价段（>$100）
3. **成熟度**：新品（<100评论）、成长期（100-1000评论）、成熟品（>1000评论）
4. **变体差异**：颜色、尺寸、套装数量、配件

### 竞品门禁
- 用户提供的竞品ASIN先确认站点和相关性
- AI推荐竞品时，先列出候选ASIN、标题、品牌和推荐理由，等用户确认后再采集
- 未经确认的竞品不得进入最终资产库

## 三、竞品分析维度

### 基础信息
- ASIN、品牌、标题、类目路径
- 价格、评分、评论数、BSR排名
- 上架时间、变体数量
- 主图、A+内容有无

### 价格分析
- 当前价格与历史价格（Keepa）
- 促销频率与幅度
- 价格带分布与均价
- 不同价格带的产品结构对比

### 评价分析
- 总评分与星级分布
- 好评主题（高频正向词）
- 差评主题（1-3星根因）
- 评论增长速度
- Verified Purchase比例

### Listing对比
- Title关键词覆盖对比
- 五点描述结构与卖点对比
- A+内容模块数量与设计
- 主图/副图数量与质量
- Search Terms覆盖

### 关键词流量
- 自然流量词Top 50
- 广告投放词Top 20
- 流量占比与排名
- 与目标ASIN的关键词差距

## 四、差异化机会识别

### 从VOC找机会
- 差评高频根因 → 产品改进方向
- 好评集中点 → 放大优势
- 未满足需求 → 新品概念

### 从价格带找机会
- 低价段质量差 → 中价品质升级
- 高价段价格虚高 → 性价比平替
- 某价格带空白 → 卡位

### 从结构创新找机会
- 传统结构痛点（刀座难清洁、锈蚀） → 新结构
- 功能缺失（无磨刀器、无排水） → 功能整合
- 审美同质化（黑色刀座） → 颜色/材质差异化

### 差异化机会总结
1. **卫生与清洁**：刀座通风排水、可拆洗设计
2. **真实材质**：无涂层钢刃、明确钢材等级和护理边界
3. **颜色差异化**：Cream White、粉色等审美升级
4. **结构创新**：紧凑小空间、磁吸展示（需防滑落测试）
5. **礼品定位**：包装、配件、品牌故事
6. **不做的方向**：不堆牛排刀、不依赖彩色刀刃涂层、不做未经验证的可机洗承诺
