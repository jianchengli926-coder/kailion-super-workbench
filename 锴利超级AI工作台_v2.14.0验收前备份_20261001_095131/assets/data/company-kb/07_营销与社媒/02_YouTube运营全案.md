# YouTube运营全案

> 定位：深度信任与工厂纪录片。一条好的工厂tour可以持续被买家搜索到，是长效资产。YouTube视频是所有平台中SEO长尾价值最高的。

## 一、平台规范速查

| 字段 | 规范 |
|------|------|
| 频道简介About | 无硬限，可放多条链接 |
| 视频描述 | ≤5,000字符；URL自动可点；时间戳行首可跳转 |
| 视频标题 | ≤100字符 |
| 头像 | 800×800（高清PNG） |
| Banner | 2560×1440（安全区1546×423，文案必须压安全区内） |
| 缩略图 | 1280×720 |
| 频道主页链接 | **最多14个**（官方确认） |

## 二、账号类型选择（关键）

**必须用Brand Account，不要用个人频道。**
- Brand Account可多人协作（主所有者/所有者/经理/沟通经理分级权限）
- 与个人Gmail隔离
- 可作为公司资产转让——员工离职带不走频道
- 4个品类号全部挂在公司名下

## 三、链接放置规则

| 位置 | 可点击性 | 说明 |
|------|---------|------|
| 频道About Links | ✅ 最多14条 | 第1条放品类页，第2条OEM页，第3条联系页 |
| 视频描述首行 | ✅ 全可点 | URL自动可点，前150字搜索可见 |
| 置顶评论 | ✅ 可点 | 权重低但安全 |
| 视频卡片/终屏外链 | ⚠️ 需Advanced Features | 手机号验证后开通 |
| Shorts描述/评论 | ❌ 不可点 | Shorts的URL不可点击 |

**最佳实践**：描述首行放品类页+空行+WhatsApp链接+时间戳章节。

## 五、内容策略

### 视频类型
- 工厂参观长视频（3–5分钟完整纪录片）
- 产品对比测评
- 工艺纪录片（锻打火光、淬火、砂轮磨刃、成品开箱、包装、质检）
- Buyer checklist / 采购指南
- Shorts竖版切片（复用长视频素材）

### 发布节奏
- 每周1条长视频（1–3分钟）+ 每周2–3条Shorts
- 起量慢但长尾最高
- 缩略图统一：深色背景+产品特写+大字关键词

### 内容主题方向
| 品类 | 内容主线 |
|------|---------|
| Outdoor | 钢材与热处理、刀型与用途、携带/刀鞘、OEM/ODM、采购清单 |
| Kitchen | 钢材与研磨、Chef/Cleaver/Santoku、刀柄、热处理、套装、QC |
| Scissors | 刀片对齐、张力、材质、握持、应用场景差异、激光刻字 |
| Accessories | 砧板、硅胶厨具、BBQ工具、套装配置、食品接触材料 |

## 六、合规注意

- YouTube政策重锤在枪支；刀具作为户外/厨用工具在有机内容中常见
- **不得链接到武器销售页、不得制作"如何用刀伤人/制作武器"教程**
- Outdoor品类描述加 "for lawful outdoor, camping and bushcraft use"
- 标题不写tactical/combat
- 三级警告制：1级禁传1周、2级2周、3级永久，90天滚动清除
- 可在YouTube Studio内申诉

## 七、改名限制
- Channel/Handle：14天内最多2次
- 旧Handle保留14天
- Brand Account改名走Google审核

## 八、CDN上传建议
- 北美主市场走洛杉矶节点上传
- 视频是长效资产，标题埋SEO关键词（如"OEM kitchen knife manufacturer Yangjiang"）
