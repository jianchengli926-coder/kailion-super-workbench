# 海外仓操作流程 SOP（入库 / 上架 / 拣货 / 打包 / 发货 / 退货）

> 📌 **数据边界说明**：本 SOP 中的**前端销售流程、轻定制边界、出库时效**均来自海外仓战略文档与已上线页面文案；**仓内具体作业细节（入库上架时长、拣货路径、打包耗材标准、退货质检流程）原始资料未成文**，凡未约定处一律标注「⚠️待Leo确认 / 待供应商提供」，不得对客户编造。

## 一、海外仓业务全流程总览

```
【头程入库】阳江工厂备货 → 海运批量发往美国仓（20–35天）
   ↓ 到港清关 → 卡车送仓
【仓内作业】收货 → 质检 → 上架 → 库存数据同步独立站
   ↓
【订单履约】客户下单 → 查实时库存 → 锁库存 → 24h内出库
   ├─ 无需轻定制：直接拣货 → 打包 → 交尾程承运商
   └─ 需要轻定制：仓内激光/丝印 Logo → 换包装/贴标/套装分装 → 拣货打包 → 交承运商
   ↓
【尾程派送】USPS / UPS / FedEx 本地派送 → 1–3个工作日客户签收
   ↓
【售后】如有质量问题 → Leo 24h内响应 → 补发/退款（见 07_售后服务与质保体系）
```

> 来源：综合 `海外仓1.txt`「双渠道流程图」Channel 2（Customer Enquiry → US Warehouse nearest hub → Optional Same-Day Light OEM → Local Delivery 1–3 Days → Customer）与 `11_订单与财务/06_订单全流程SOP.md` 节点⑧物流时效。

## 二、头程入库 SOP（阳江 → 美国仓）

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 备货 | 阳江工厂按海外仓备货清单生产 | 走大货流程，QC 三道关（来料/制程/出货前视频验货），详见 `05_出口流程与单证.md` |
| ② 出口报关 | 刀具 PSB 公安局备案 → 报关行申报 → 装船 | Every Document, Every Time, Zero Delays |
| ③ 国际运输 | **海运为主**（单位成本最低），紧急补货可空运 | 海运 20–35 天；空运 7–15 天；DDP 双清到门 |
| ④ 到港清关 | 目的港清关 + 关税缴纳（DDP 下凯利承担） | ⚠️待Leo确认：美国关税（301清单）核算口径 |
| ⑤ 卡车送仓 | 港口 → CA / TX / NJ 仓库 | ⚠️待供应商提供：国内段派送时长、预约入仓规则 |
| ⑥ 收货清点 | 美国本地团队点收件数 / 外箱状态 | 破损/短装当场拍照反馈，向货代/保险索赔 |
| ⑦ 质检上架 | 抽检外观/功能 → 贴库位标签 → 上架 | ⚠️待供应商提供：抽检比例、AQL 标准、入库到上架时长 |
| ⑧ 库存同步 | WMS 入库数据 → 同步独立站前端 | 售罄 SKU 自动隐藏 / 标记 Out of Stock，避免超卖 |

> 头程备货属于大货物流，费用结构详见 `11_订单与财务/10_物流费用结构与渠道对比.md`。

## 三、仓内轻定制作业 SOP（仓内当天完成）

> 这是海外仓的核心差异化能力。资料中明确列出的可作业项：

### 3.1 可在仓内完成（Same-Day Light OEM）

| 作业项 | 英文 | 说明 |
|--------|------|------|
| 激光雕刻 Logo | Laser Engraving / Laser Marking | 刀身/手柄/剪刀/厨具表面 |
| 丝印 Logo | Silk-Screen Printing | 产品表面品牌标识 |
| 简易彩盒/纸包装更换 | Simple Color Box / Paper Packaging Replacement | 换外盒、贴 hang tag |
| 条码 / UPC / FNSKU 贴标 | Barcode / UPC / FNSKU Labeling | Amazon FBA 入仓标签 |
| 小套装组合分装 | Small Kit Repacking / Bundling | 多件组合、混装、重新打包 |
| 透明袋 / 贴纸 | Custom Poly Bags, Stickers | 包装辅料更换 |

### 3.2 不可在仓内完成（必须回阳江工厂）

- ✗ 刀型 / 尺寸 / 开刃方式改动
- ✗ 手柄材质升级、结构重构
- ✗ 钢材牌号变更（如升级 VG10 / Damascus / D2）
- ✗ 新开模具、大型结构 ODM
- ✗ 专属高端礼盒 / 木盒全案开发

### 3.3 轻定制三步流程（资料原文口径）

```
Step 1: Choose from in-stock items   — 从现货库存中选择产品
Step 2: Request logo / simple repack — 提出 Logo 或简易包装需求（激光/丝印当天完成）
Step 3: Ships within 1–3 days        — 从最近仓库发货，1–3 天送达
```

- 现货 1 件起发；**轻定制 10–50 件起**（资料口径）。
- 多数轻定制**当天或 24h 内**完成（当队列与设备确认时）。
- ⚠️待Leo确认：轻定制加工费率（激光打标 / 丝印 / 换盒 / 贴标分别多少钱/件）。

## 四、订单履约 SOP（前端客户下单 → 出库）

> 资料中上线页面描述的「4 步时间线」：查库存 → 确认数量 → 可选轻定制 → 美国发货。

| 步骤 | 操作 | 时间标准 | 责任人 |
|------|------|---------|--------|
| ① 查库存 | 客户询盘 / 下单后，核对对应 SKU 在哪个仓有货、库存数量 | 即时 | Leo / 值班销售 |
| ② 锁库存 | 确认订单后锁定可用库存，避免超卖 | 下单时 | WMS / 美国团队 |
| ③ 可选轻定制 | 如需 Logo / 换包装 / FNSKU 贴标，转仓内加工工位 | 当天–24h | 美国仓加工团队 |
| ④ 拣货 | 按订单到库位取货 | ⚠️待供应商提供：拣货时长 | 美国仓 |
| ⑤ 打包 | 按品类选包装（刀具需防护鞘/缓冲）→ 核对数量/标签 | ⚠️待供应商提供：打包耗材标准 | 美国仓 |
| ⑥ 交承运商 | 贴运单 → 交 USPS / UPS / FedEx 揽收 | 订单 24h 内出库 | 美国仓 |
| ⑦ 尾程派送 | 本地派送 | **1–3 个工作日** | USPS/UPS/FedEx |

- **出库时效铁律**：所有海外仓订单 **24 小时内出库**（orders ship out within 24h）。
- **库存同步**：售罄 SKU 自动从页面隐藏或标记 Out of Stock；下单时最终确认可用数量。
- **混单规则**：海外仓现货订单与阳江工厂定制订单**不能合并发货**，两套物流独立，需分开下单、分开报价。

## 五、退货 / 售后处理 SOP

> ⚠️ **重要边界**：本站为 B2B 工厂直供，**无 C 端 7/14/30 天无理由退货窗口**；**无标准 RMA 退货授权单号流程**；退货由 Leo 邮件 / WhatsApp 一对一安排。

### 5.1 有资料依据的退货情形

| 情形 | 处理方式 | 运费 |
|------|---------|------|
| 制造缺陷（刀身断裂/结构失效/材料不一致） | 免费补发或全额维修 | **我方承担退货运费**（Return shipping cost covered by us） |
| 刃口保持问题（VG10/9Cr18MoV/Damascus/1.4116） | 免费复磨 / 维修 / 整支更换 | 按质保条款逐案 |
| 手柄/铆钉/销钉装配问题（2年内） | 免费换配件 / 重新装配 | 按质保条款逐案 |
| 长期合作伙伴整批不合格 | 100% 整批更换或全额退款 | 我方承担 |
| 物流货损 | 凭开箱照片协助向保险 / 承运商索赔 | 按保险责任 |

### 5.2 退货处理流程

```
客户反馈（附清晰照片/视频 + 批次号 batch details）
   ↓
Leo 团队 24h 内响应（ceo@kailioncrafts.com / WhatsApp +86 134 2129 5360）
   ↓
判定责任（制造缺陷 / 物流货损 / 客户使用不当）
   ↓
├─ 制造缺陷 → 直接补发，承担退货运费，不要求冗长文件/法律流程
├─ 物流货损 → 凭开箱照片向承运商/保险索赔
└─ 非质量问题 → ⚠️原始资料未约定无理由退货，逐案与 Leo 判定
   ↓
记录批次追溯，反馈工厂/供应商改进
```

### 5.3 刀具退货的特殊限制

- 户外刀等管制刃具退回跨境物流受 **PSB 公安局备案**与**目的国进口法规**双重限制。
- 美国本土退货（从美国消费者退回 NJ/CA/TX 仓）与跨国退回（退回阳江）可行性不同，**实际退货可行性逐案评估**。
- ⚠️待Leo确认：美国仓是否设本地退货地址、退货商品能否二次销售（开箱质检标准）。

## 六、品控与库存数据管理

- 海外仓产品作为 KaiLionCrafts 品牌延伸，**要求供应商提供产品质检报告**，或派本地合作方抽检，确保符合品牌标准。
- 库存数据**定期与供应商 stock sheet 同步**；售罄 SKU 必须隐藏或明确标记 unavailable，防止过度承诺。
- 更新频率（来自 `08_美国仓现货SKU库存清单.md`）：
  - 每日：库存数量变动（出库/入库）
  - 每周：库存盘点、滞销检查
  - 每月：补货计划、周转分析
  - 每季度：仓租核算、SKU 优化
- ⚠️待指定：各更新频率的责任人（资料中列为待指定）。
