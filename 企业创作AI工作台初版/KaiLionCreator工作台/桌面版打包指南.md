# 桌面版打包指南（Tauri v2）

> 目标：把当前 Web 版工作台打包成 **Windows 桌面应用（.exe）**，形态与你参考的那个工作台一致 —— 本地原生、无需浏览器、双击即用、可离线。
>
> 这份指南给的是**可直接执行的步骤**，不是泛泛介绍。

---

## 一、为什么要打包成桌面版

| 能力 | Web 版 | Tauri 桌面版 |
|---|---|---|
| 双击即用 / 离线 | 需本地起服务 | ✅ 原生 |
| 数据存储 | localStorage（约 5MB 上限） | ✅ 真实文件系统，无上限 |
| 大文件（图片 / 视频 / 3D） | 受浏览器限制 | ✅ 本地读写自由 |
| 调用本地命令行（ffmpeg / pandoc / libvips） | ❌ | ✅ 走 CLI 节点 |
| 开机自启 / 系统托盘 / 全局快捷键 | ❌ | ✅ |
| 定时任务 7×24 真实调度 | 仅定义 | ✅ cron + 后台进程 |
| 安装包体积 | — | 约 5~10 MB（NSIS） |


## 三、初始化 Tauri 工程

在 `kailioncreator` **同级目录**下建立 Tauri 外壳工程：

```bash
cd /path/to/where/you/keep/projects
npm create tauri-app@latest kailion-creator-shell
# 交互选项：
#   Project name        → kailion-creator-shell
#   Identifier          → com.kailioncrafts.creator
#   Frontend language   → Vanilla (不用框架)
#   Package manager     → npm
#   UI template         → Vanilla
#   UI flavor           → TypeScript / JavaScript（选 JavaScript 更省事）
```

生成后你会得到：

```
kailion-creator-shell/
├── src/                  前端源码（把我们的前端文件放这里）
├── src-tauri/
│   ├── Cargo.toml
│   ├── tauri.conf.json   ← 主要改这里
│   ├── icons/            ← 图标
│   └── src/
│       ├── main.rs
│       └── lib.rs        ← Rust 侧能力都在这里加
```

## 四、把工作台前端装进去

```bash
# 清掉模板自带的示例前端
rm -rf kailion-creator-shell/src/*
rm -rf kailion-creator-shell/public/*

# 把我们的工作台整体拷进去
cp -R kailioncreator/index.html  kailion-creator-shell/src/
cp -R kailioncreator/css         kailion-creator-shell/src/
cp -R kailioncreator/js          kailion-creator-shell/src/
cp -R kailioncreator/assets      kailion-creator-shell/src/
```

> ⚠️ **关键点**：`js/app.js` 里用的是原生 ES Module + 相对路径 `./data/xxx.js`，Tauri 的 `distDir` 指向 `../src` 时会原样提供静态文件，**不需要任何打包器**。所以 `tauri.conf.json` 里要把 `beforeDevCommand` / `beforeBuildCommand` 留空，`frontendDist` 直接指 `../src`。

## 八、把数据存储从 localStorage 换成真实文件（P1 增强）

当前 `js/core/store.js` 只用了 `localStorage`。桌面版想换成文件系统，只需替换 `Store` 类里的三个方法，其余业务代码**一行都不用动**。

### 8.1 装 Tauri 插件

```bash
cd kailion-creator-shell
npx tauri add fs
npx tauri add dialog
```

`src-tauri/capabilities/default.json` 里加权限：

```json
{
  "identifier": "default",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "fs:default",
    "fs:allow-appdata-read-recursive",
    "fs:allow-appdata-write-recursive",
    "fs:allow-applocaldata-read-recursive",
    "fs:allow-applocaldata-write-recursive",
    "dialog:default"
  ]
}
```

### 8.2 改 `store.js`

把同步的 `localStorage` 读写换成异步文件读写，并加一个内存缓存保证启动速度：

```js
// 顶层
import { readTextFile, writeTextFile, exists, mkdir, BaseDirectory } from '@tauri-apps/plugin-fs';

const FILE = 'wfw-creator-settings.json';   // 沿用你参考过的命名风格
const DIR  = { baseDir: BaseDirectory.AppData };   // %APPDATA%\com.kailioncrafts.creator\

class Store {
  async init() {
    try {
      if (!(await exists(FILE, DIR))) return;
      const raw = await readTextFile(FILE, DIR);
      this.state = JSON.parse(raw);
    } catch (e) { console.warn('[store] 首次启动或读取失败', e); }
  }
  save() {
    // localStorage 同步 → 文件系统异步，用防抖合并写入
    clearTimeout(this._t);
    this._t = setTimeout(async () => {
      try { await writeTextFile(FILE, JSON.stringify(this.state, null, 2), DIR); }
      catch (e) { console.error('[store] 写入失败', e); }
    }, 400);
  }
}

// 启动时改成：await store.init(); store.touch(); app.boot();
```

同理，`exportAll()` / `importAll()` 可以改成用 `@tauri-apps/plugin-dialog` 弹原生文件选择框，走真实的 `.json` 文件。这样 **14 类资源库、画布、工作流就全部落在 `%APPDATA%` 里的真实文件上**，容量无上限，也方便你自己备份和 Git 管理。

### 8.3 让 CLI 节点真的能跑

`js/core/engine.js` 的 `ADAPTERS.cli` 目前只展示命令。桌面版可以接上：

```bash
# Rust 侧引入 shell 插件
npx tauri add shell
```

```js
import { Command } from '@tauri-apps/plugin-shell';

// 替换 ADAPTERS.cli
cli: async (def, p) => {
  const out = await Command.create('run', p.cmd.split(' ')).execute();
  return { type: 'text', text: out.stdout || out.stderr };
}
```

接上之后，「视频组装」节点可以真的调 `ffmpeg` 出片，「文档转换」节点可以真的调 `pandoc` 或 `libreoffice --headless` 转换 12 种格式。

## 十一、常见问题

**Q: 打出来是 CMake / MSVC 报错？**
A: 装 Microsoft C++ Build Tools（`winget install Microsoft.VisualStudio.2022.BuildTools`），勾选「使用 C++ 的桌面开发」。

**Q: 前端页面打开是空白？**
A: 检查 `tauri.conf.json` 的 `frontendDist` 是不是 `../src`，以及 `index.html` 是否在 `src/` 根目录。再用 `npm run tauri dev` 打开开发者工具看控制台报错。

**Q: 安装包体积太大？**
A: 26MB 那种体积通常是没开 LTO。在 `src-tauri/Cargo.toml` 里加：

```toml
[profile.release]
codegen-units = 1
lto = true
opt-level = "s"
panic = "abort"
strip = true
```

一般能压到 5~8 MB。

**Q: 想同时出 macOS / Linux 版？**
A: 在同一台机器上 `npm run tauri build -- --target universal-apple-darwin`（macOS），或 `--bundles deb,appimage`（Linux）。源码不用改。
