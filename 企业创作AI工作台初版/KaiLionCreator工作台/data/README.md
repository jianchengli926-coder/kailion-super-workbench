# data/ — 共享数据目录

这个目录用来放你要**分享给别人**的数据。

## 怎么用（三步）

1. 你在工作台里把东西配置好（自制工作流、资源库内容、画布…）
2. 打开 **设置 → 数据与存储 → 分享给朋友**，点「导出共享数据」
3. 把下载下来的文件放进**这个目录**，改名为 **`初始数据.json`**

完成。之后把整个文件夹拷给朋友，他第一次打开工作台时会**自动载入**这份数据，
看到的就是你配置好的样子 —— 而不是空白的出厂状态。

## 几个要点

- **默认不导出 API Key**。朋友在自己电脑的「线路管理」里填他自己的 Key 即可，
  费用算在他头上。若你就是想共用，用「导出（含我的 Key）」，但别公开发布那个文件。
- **只在本机还没有任何数据时才自动载入**，不会覆盖朋友已有的内容。
- 想再载入一次：设置里点「重新载入共享数据」。
- 目录里默认就带着一个 **`初始数据.json`（空占位文件）** —— 它不含任何数据，
  只是用来避免打开时多一次无谓的 404。你导出自己的数据后**覆盖它**即可，文件名保持 `初始数据.json`。

## 为什么数据平时不在文件夹里？

浏览器里的网页**不能自动写本地文件**（安全沙箱限制）。所以：

- 平时你的改动存在浏览器里（下次打开还在，够自己用）
- 要给别人 → 导出成文件 → 放进这里 → 对方首次打开自动载入

如果要求「数据实时写成文件、多台电脑共享同一个文件夹」，那只有
**桌面版**能做到 —— 见 `桌面版打包指南.md`。
