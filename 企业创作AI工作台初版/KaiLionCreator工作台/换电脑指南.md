# 换电脑 / 拷给别人：完整说明

---

## 一、先搞清楚：这个工作台到底是什么

| 问题 | 答案 |
|---|---|
| 是网页吗？ | **是** —— 纯 HTML + CSS + JavaScript，和你平时上的网站一样在浏览器里跑 |
| 需要联网吗？ | **不需要** —— 网断了照样能打开、能搭流程、能看本地推演结果。只有调真实模型 API 时才联网 |
| 需要安装吗？ | **不需要** —— 不用 `npm install`，不用编译，没有数据库 |
| 数据在哪？ | **只在你这台电脑的浏览器里**（localStorage + IndexedDB）。**不上传任何服务器** |
| 那为什么要开终端？ | 见下面第二节 |

**一句话**：它是一个**装在你本地的网站**。既不是云端 SaaS，也不是要编译的工程。

## 二、为什么不能双击 index.html，非要开终端？

这是唯一需要解释的技术点。

这个项目用了现代 JS 的 **ES Module**（代码里的 `import` / `export`）。
而浏览器有个安全规则：**`file://` 协议（直接双击打开本地文件）不允许加载模块**，会直接报跨域错误、页面白屏。

所以要让它跑起来，必须让它以为自己是"一个网站"——
也就是起一个**本地的小网站服务**，再通过 `http://127.0.0.1:8477` 访问。

> 这个"小网站服务"不是什么服务器，只是你本机上一个几行代码的小程序，
> 不联网、不对外、只有你自己能访问。关掉就没了。

**所以需要终端，但其实只需要一条命令** —— 而我已经把它封装成双击文件了：

| 系统 | 你做什么 |
|---|---|
| **macOS** | 双击 `启动工作台.command` |
| **Windows** | 双击 `启动工作台.bat` |
| Linux / 想手动 | `./start.sh` 或 `python3 -m http.server 8477` |

双击之后**终端窗口保持开着就行**，不用敲任何命令。

## 三、拷到别的电脑，能用吗？

**能用。** 但有 4 件事要知道：

### ① 前置环境（目标电脑需要）

| 需要 | 用途 | 没有会怎样 |
|---|---|---|
| **Python 3** | 起本地网站服务 | ❌ **完全打不开**（必需） |
| **Node.js** | 跑 API 网桥 | ⚠️ 能打开，但**接不了真实 API**，只能本地演示 |
| 浏览器 | Chrome / Edge / Safari 都行 | — |

> 绝大多数开发用电脑两个都有。如果目标电脑是纯办公机，装个 Python 就行（很小）。

### ② 代码直接拷，能跑

整个文件夹复制过去即可，不用改任何配置。

### ③ 数据：默认在浏览器，但可以固化进文件夹一起带走

**先澄清一个误会**：74 个节点、50 条预设工作流、81 条资源库内容
**本来就在代码里**（`js/data/`），所以朋友拿到文件夹**不是空的** ——
他一打开就有这些。浏览器里存的只是你后来**自己加**的东西。

如果你还想把你配置的内容也一起给朋友，用**共享数据**功能：

1. 你在工作台里配置好（自制工作流、资源库内容、画布…）
2. **设置 → 数据与存储 → 分享给朋友 → 导出共享数据**
3. 把下载的文件放进文件夹的 **`data/`** 目录，改名为 **`初始数据.json`**
4. 整个文件夹拷给朋友 —— **他第一次打开会自动载入**，看到的就是你配置好的样子

> 我把这条链路端到端测过：配置 2 条工作流 + 1 条自定义提示词导出，
> 换一台全新电脑打开，自动载入了这 2 条工作流和 1 条提示词，且 **API Key 数为 0**。

要点：
- **默认不带 API Key** —— 朋友填他自己的，费用算在他头上。
  想共用就用「导出（含我的 Key）」，但别公开发布那个文件。
- 只在对方**还没有任何数据**时载入一次，不会覆盖他已有的内容。
- 对方之后的改动存在他本机的浏览器里（他自己下次打开还在）。
- 目录里没有 `初始数据.json` 时完全不影响使用。

**给自己换电脑**（不是给别人）：用「导出完整备份（ZIP）」再导入 ——
那个**连图片一起**搬，比共享数据完整。

### ④ API Key 也不会跟着走

同理，Key 存在浏览器里。要么用备份导入，要么在新电脑上重新填一次。
（这也意味着：**别把整个文件夹直接发给别人**，里面有你的 Key 吗？——
其实 Key 不在文件夹里，在浏览器里。但导出的备份 ZIP 里有明文 Key，那个才要小心。）

## 五、代码是怎么组织的？能只把 index.html 发给朋友吗？

### 不能。只发 index.html 等于发一个空壳。

`index.html` **只有 32 行**，里面没有任何功能，它只做三件事：
引用 3 个 CSS、放一个"正在载入…"的占位图、加载 `js/app.js`。
真正的功能全在 `js/` 下 **19 个模块、12433 行**里。

```
index.html  (32 行，空壳)
   ├── css/theme.css + layout.css + components.css   (3 个 · 2177 行)
   └── js/app.js  (唯一入口)
          ├── js/data/    节点目录 · 工作流模板 · 资源库种子数据
          ├── js/core/    执行引擎 · 存储 · 协议适配 · 文件生成 · 图像处理
          └── js/views/   画布 · 工作台 · 参数面板 · 使用说明书
```

模块之间用 `import` 相互引用，是一张**依赖网** —— 缺任何一个文件，
整条链就断了（浏览器会直接报 404，页面停在加载中）。

### 实测：只放一个 index.html 会怎样

我做过实验（单独一个 html 放进空目录，用 http 服务打开）：

| 检查项 | 结果 |
|---|---|
| 页面文字 | 永远停在「正在载入工作台…」 |
| 顶栏 | ❌ 没有 |
| 节点 | ❌ 0 个 |
| 失败请求 | **10 个 404**（css 和 js 全部找不到） |

所以**必须整个文件夹一起给**。

### 那"整个文件夹 + 双击 index.html"行不行？

也**不行** —— 会白屏（原因见第二节：ES Module 不能用 `file://` 打开）。

**唯一正确的方式：整个文件夹 + 双击启动器。**

| 做法 | 结果 |
|---|---|
| 只发 `index.html` | ❌ 卡在"正在载入…"（找不到 css/js） |
| 整个文件夹 + 双击 `index.html` | ❌ 白屏（ES Module 限制） |
| **整个文件夹 + 双击启动器** | ✅ 正常打开 |

## 六、能不能做成"不用开终端"的版本？

**能。** 这就是 `桌面版打包指南.md` 里讲的事：用 **Tauri** 把它包成一个

好处：

- 拷给别人就是发一个安装包

## 七、常见疑问

**Q：能不能直接把这个文件夹放网盘同步？**
代码可以。但**数据不在这个文件夹里**，同步文件夹不会同步你的工作流。
要同步数据用「导出完整备份 ZIP」。

**Q：能给别人用吗？**
可以，把文件夹给他就行（注意别连备份 ZIP 一起给，那个有你的 Key）。
他自己填自己的 API Key，各用各的，互不影响。

**Q：为什么我关了终端再打开，数据还在？**
因为数据存在浏览器里，跟终端无关。只要**同一个浏览器、同一个网址**（都是 127.0.0.1:8477）就在。

**Q：换浏览器数据会没吗？**
会。数据在浏览器里是按"网站地址 + 浏览器"隔离的。换浏览器等于换了个新环境，
用备份导入即可。
