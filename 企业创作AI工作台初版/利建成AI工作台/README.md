# 利建成AI工作台

> AI 驱动的一站式可视化创作工作台 — 阳江市锴利国际贸易有限公司

**版本：v1.0.0**

---

## 项目简介

**利建成AI工作台** 是一款纯前端可视化 AI 创作编排工具。通过拖拽节点 + 连线的方式，将图像生成、视频生成、LLM 文本、3D 生成等各类 AI 模型串联成自动化工作流，无需编程即可完成电商详情页、短视频、办公文档、品牌方案等全链路创作。

- **68 个 AI 节点**，覆盖 13 大创作分类（输入、图片生成、视频生成、3D、连接器、处理、输出等）
- **20 个工作流模板**，开箱即用
- **8 个 API 供应商预设**，支持 OpenAI 兼容格式的所有中转站
- **纯前端零依赖**，双击即用，无需安装、无需构建
- **深色科技风**，靛蓝→紫→品红渐变主题，6 套预设主题 + 自定义颜色

---

## 快速开始

```bash
# 直接用浏览器打开即可
双击 index.html
```

无需安装 Node.js、无需构建、无需配置环境。推荐使用 Chrome / Edge / Safari 等现代浏览器。

打开后：
1. 进入「设置 → 供应商管理」，添加你的 AI 服务与 API Key
2. 从左侧「节点库」拖拽节点到画布
3. 拖动节点右侧圆点到下一节点左侧圆点建立连线
4. 点击顶部「运行」即可执行工作流

## 功能清单

### 画布编辑器
- 可视化拖拽节点编辑器，支持节点添加、删除、多选移动、框选
- SVG 贝塞尔曲线连线，点击连线可删除
- 画布缩放（30%–200%）、平移、小地图导航
- 分组管理、便签标注、自动布局
- 撤销 / 重做（Ctrl+Z / Ctrl+Y）

### 68 节点库
- 13 大分类：输入、图片生成、视频生成、3D 生成、连接器、处理、输出等
- 出厂默认显示约 30 个常用节点，其余可手动显示/隐藏
- 每个节点配有中文/英文名称与描述，支持中英文切换

### 工作流模板
- 20 套预设工作流模板，按分类组织
- 一键加载模板到画布，快速起步

### 工作流市场
- 内置市场示例工作流，可直接导入画布
- 支持收藏与管理自定义工作流

### 运行引擎
- 支持串行 / 并行两种执行模式
- 节点结果缓存，相同参数自动复用，节省 API 调用
- 实时进度条与节点状态指示
- 运行历史记录（v1.0.0 新增）

### 多 API 供应商管理
- 8 个预设供应商：OpenAI、DeepSeek、豆包/火山引擎、Claude、Gemini、通义千问、智谱GLM、wawapi中转站
- 支持自定义 Base URL 和 API Key
- 模型列表管理（从 API 获取或手动添加）
- 连通性测试

### AI 助手（小利助手）
- 右下角悬浮面板，自然语言指令自动搭建工作流
- 支持意图识别（详情页、短视频、PPT、图文、品牌IP、代码等）
- 最近指令历史记录

### 资源库
- 素材库（生成的图片自动保存）
- 提示词库
- 知识库文档管理

### 使用说明书
- 内嵌交互式使用手册
- 快速开始、界面导览、工作流派方、节点清单、API配置指南、FAQ、快捷键

### 批量 / 定时任务
- 批量并行任务：一次跑多个数据源
- 定时任务：按 cron 表达式周期自动执行

### 数据统计
- 本地使用数据统计（节点运行次数、资源使用等）

### 版本历史
- 工作流快照管理，最多保留 20 个版本
- 随时回滚到历史版本

### 节点缓存
- 相同参数的节点运行结果自动缓存
- 图片/视频/3D 仅缓存 URL 与元数据
- 可查看缓存条目数与占用空间，一键清除

### 主题切换
- 深色 / 浅色 / 跟随系统三种模式
- 6 套预设主题：深空蓝紫、暗夜绿、暖橙、玫瑰粉、科技青、极简灰
- 自定义主色调、强调色、背景色等 6 项颜色

### v1.0.0 新增功能
- **中英文国际化**：设置中一键切换界面语言，节点名称/描述同步本地化
- **运行历史**：记录每次工作流运行详情（节点数、耗时、状态、各节点结果），最多保留 50 条，支持一键重跑
- **API 日志与费用统计**：记录所有 API 调用（供应商、模型、token、耗时、费用估算），最多保留 200 条，支持按类型筛选
- **主题自定义**：6 套预设主题 + 自定义颜色取色器
- **全局搜索**：Ctrl+K（Mac 为 Cmd+K）打开搜索面板，可搜索节点、工作流模板、市场示例、资源库、说明书章节

## 技术栈

- **HTML5 / CSS3 / 原生 JavaScript (ES6+)**
- **无外部依赖**：不使用任何框架（React/Vue/jQuery）、不引入任何 CDN
- **SVG** 用于连线渲染
- **localStorage** 用于全部数据持久化
- **CSS 自定义属性（CSS Variables）** 用于主题系统

## API 配置指南

1. 点击右上角「⚙ 设置」
2. 找到「供应商管理」区域
3. 点击预设按钮（OpenAI / DeepSeek / 豆包等）自动填充地址，或手动填写 Base URL
4. 粘贴你的 API Key
5. 点击「测试」验证连通性
6. 在画布中选中节点后，右侧参数面板选择该供应商和模型

### 支持的接口类型

- **Chat Completions**：LLM 文本生成（流式响应）
- **Image Generations**：图片生成（URL / base64 格式自动检测）
- **Video Generations**：视频生成（异步轮询）
- **3D Generation**：3D 模型生成
- **Model List**：从 `/v1/models` 接口拉取模型列表

### 内置模型定价表（用于费用估算）

| 模型 | 输入价格 ($/1M tokens) | 输出价格 ($/1M tokens) |
|------|------------------------|------------------------|
| gpt-4o | 5.00 | 15.00 |
| gpt-4o-mini | 0.15 | 0.60 |
| deepseek | 0.14 | 0.28 |
| claude | 3.00 | 15.00 |
| 默认 | 2.00 | 6.00 |

## 数据存储说明

所有数据均存储在浏览器 localStorage 中，不上传任何服务器。

| Storage Key | 说明 |

| `ljc_workbench_state` | 画布当前状态（节点、连线、视图） |

| `ljc_workflow_versions` | 工作流版本历史（最多 20 个） |
| `ljc_run_history` | 运行历史记录（最多 50 条） |
| `ljc_api_log` | API 调用日志（最多 200 条） |

| `ljc_node_cache` | 节点结果缓存（最多 50 条） |
| `ljc_image_history` | 图片生成历史 |
| `ljc_favorite_images` | 收藏的图片 |
| `ljc_materials` | 素材库 |
| `ljc_prompts` | 提示词库 |
| `ljc_kb_docs` | 知识库文档 |
| `ljc_market_mine` | 市场收藏的工作流 |
| `ljc_batch_tasks` | 批量任务 |

| `ljc_stats` | 使用统计数据 |
| `ljc_theme` | 主题模式（dark/light/system） |
| `ljc_custom_theme` | 自定义主题颜色 |
| `ljc_lang` | 界面语言（zh/en） |
| `ljc_search_history` | 全局搜索历史 |
| `ljc_smart_history` | AI 助手历史指令 |
