KaiLionCrafts 使用说明书

从装好工作台，到跑出第一条能用的工作流 — 按「先跑通、再理解、最后调优」的顺序，全程不用写代码

四步上手 界面导览 小白工作流 节点库全景 快捷键 技巧分享 常见问题

1四步上手，先出一张图

前两步是「必须做」，不做后面一定失败；第三、四步是「跑一次就会」。

1

下载安装

Windows 10 及以上，安装包 10MB 级，本地原生运行。安装完双击桌面图标，首次启动停在「工作台首页」。

2

配置供应商（必做）

右上角菜单栏 → 供应商管理。导入开发者 config 配置文件或手动添加 API Key。用哪个生成节点，就要配对应的那条线。

3

跑出第一张图

切换到「经典画布」，从节点库拖入「提示词」节点和「Banana Pro」节点，把两个节点的小圆点拖在一起连线，写提示词 → 点运行。

4

把成果留下来

图片自动进入素材库，整套流程存进工作流库，重复性任务可转成定时任务 7×24 自动运转。

好提示词公式：主体 + 场景 + 光线 + 风格 + 画质。缺哪补哪，别只写一个词。
一只戴圆框眼镜的柴犬，坐在木质书桌前敲笔记本电脑， 暖色台灯从左前方打光，背景是洒满便签的软木板， 电影级人像摄影风格，浅景深，高清细节

3小白常见工作流（10 组配方）

1

出一张图（最容易）

链路：提示词 → Banana Pro。拖两个节点、连一条线、写提示词、点运行。画幅比例和分辨率档位必须同属一套协议。

2

图生图 / 换风格

链路：图片 → Banana Pro + 提示词。提示词只写「要变成什么」，产品图要加「严格保持产品外形、颜色、logo 不变」。

3

电商详情页（中等）

链路：图片（产品图）→ 详情页生成 → 素材库。上传清晰产品正面图，节点自动反推品类、按品类套用模块组合逐屏出图。

4

图文笔记（最容易）

链路：图文生成（一个主题）→ 文案 + N 屏配图。内置小红书/电商种草/朋友圈/公众号/抖音五套平台预设，第 k 段正文对应第 k 张图。

5

短视频 / 漫剧（中等）

链路：提示词 → 视频大纲 → 视频分镜 → Seedance → 视频组装。先出大纲定结构，再拆分镜，然后逐个镜头出片段，最后组装导出。

6

带货脚本（中等）

链路：图片（商品图）→ 带货脚本 → 分镜提示词 → Seedance。自动反推卖点，按六维拆解，正交枚举多个变体，每个自带完整分镜。

7

办公四件套（最容易）

链路：提示词 → Word / Excel / PPT / HTML。四个独立节点，各自生成对应格式。说清结构和规模：「8 页 PPT，每页 3 个要点」。

8

一句话让 AI 干活（最容易）

在工作台首页输入自然语言需求，AI 自动解析意图、搭建工作流并执行。需求带上「产出物 + 数量 + 风格」三要素。

9

多角色出方案（中等）

链路：提示词（主题）→ 专家讨论 / 专家协作。专家讨论是各说各话碰撞，专家协作是按阶段分工。先选 2-3 位最相关的。

10

跨境选品到上架（需前置条件）

链路：云牛顿找品 → 批量询盘 → 妙手采集 → 编辑详情 → 多平台发布。需妙手 AppKey/AppSecret 和 1688 账号授权，询盘带人工确认闸门。

6技巧分享

提示词写作五段法

好提示词 = 主体 + 场景 + 光线 + 风格 + 画质。这个五段结构适用于一切出图场景，缺哪补哪。

批量生成策略

先跑通 1 个验证画幅和风格，确认满意后再放大批量。多 SKU 批量前必须先验证，否则整批白烧钱。

智能工作台使用技巧

需求描述带上「产出物 + 数量 + 风格」三要素。信息不够时 AI 会主动反问澄清，认真回答比猜错重跑便宜得多。

工作流复用

跑通的工作流一键保存到工作流库，下次直接加载改参数。重复性任务转成定时任务，设定时让 AI 自己跑。

7常见问题

我的创作数据存在哪里？安全吗？

所有数据（工作流、资源库、生成的作品）都保存在你的电脑本地，不上传任何服务器。断网也能正常使用，创意资产完全私有。

需要注册账号或付费订阅吗？

桌面客户端完全免费。使用 AI 生成功能时，只需在「供应商管理」中配置你自己的 API Key，按你的用量计费，无平台抽成。

不会写代码能用吗？

完全可以。打开「智能工作台」直接说需求，AI 会自动解析意图、搭建工作流并执行。也可以从工作流库加载预设模板，改改参数就能跑。

支持什么电脑系统？

当前版本支持 Windows 10 及以上系统，普通办公电脑即可流畅运行。

API 供应商管理

配置你的 AI 模型 API，支持 OpenAI 兼容协议（豆包 / DeepSeek / GPT 中转站等），密钥仅保存在本地浏览器

MCP 服务器

配置 MCP（Model Context Protocol）服务器，让 AI 节点调用外部工具和数据源。支持 HTTP JSON-RPC 传输。
