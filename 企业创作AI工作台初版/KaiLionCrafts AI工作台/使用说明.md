# KaiLionCrafts AI 创作工作台 — 使用说明

## 📦 这是什么？

**KaiLionCrafts AI工作台**是一个**纯前端单文件HTML应用**。

- 所有代码（界面样式 + 功能逻辑）都写在 **一个 .html 文件** 里
- 不需要安装任何软件、不需要终端、不需要服务器
- 只要有浏览器就能运行（推荐 Chrome / Edge / Safari）
- 数据保存在你自己电脑的浏览器里（localStorage本地存储），不上传任何服务器

## 💻 它是怎么工作的？

```
你双击启动器 → 系统用默认浏览器打开HTML文件 → 浏览器直接渲染运行
```

- **不是代码工具**：不需要写代码，不需要懂编程
- **不是终端工具**：不需要打开终端敲命令
- **不是在线工具**：不需要联网也能用基础功能（AI生图/聊天需要配置API）
- **是本地工具**：所有文件在你电脑上，所有数据在你浏览器里

## 🪟 Windows 系统使用方法

### 方法一：双击启动器（推荐）
1. 双击 **`启动工作台.vbs`** — 无黑框，直接在浏览器打开
2. 或双击 **`启动工作台.bat`** — 有短暂提示窗口

### 方法二：直接打开HTML
双击 **`KaiLionCrafts工作台.html`** 即可。

### 方法三：创建桌面快捷方式
1. 右键 `启动工作台.vbs` → 发送到 → 桌面快捷方式
2. 以后双击桌面图标即可启动

## 🍎 Mac 系统使用方法

### 方法一：双击 .command 脚本
1. 首次使用需要授权：右键 `启动工作台.command` → 打开（或在终端执行）
   ```bash
   chmod +x "启动工作台.command"
   ```
2. 以后双击即可启动

### 方法二：使用 .app 应用包（推荐，像原生应用）
1. 将 **`KaiLionCrafts工作台.app`** 拖到「应用程序」文件夹
2. 首次打开：右键 → 打开（因为未经过Apple公证，需要手动确认）
3. 或在终端执行授权：
   ```bash
   chmod +x "KaiLionCrafts工作台.app/Contents/MacOS/launcher"
   xattr -dr com.apple.quarantine "KaiLionCrafts工作台.app"
   ```
4. 以后从启动台或应用程序双击即可启动

### 方法三：直接打开HTML
双击 `KaiLionCrafts工作台.html`，用 Safari/Chrome 打开。

## 🚀 转移到其他电脑

**完全可以！** 这个工作台是**绿色便携软件**：

1. 把整个文件夹复制到U盘 / 网盘 / 微信传输
2. 在新电脑上解压/复制到任意位置
3. 双击对应系统的启动器即可使用

### ⚠️ 注意事项
- **工作流数据不会自动转移**：因为数据存在浏览器的localStorage里
- **转移数据方法**：在旧电脑的工作台里 → 菜单 → 导出工作流（JSON文件）→ 在新电脑导入
- **API配置不会转移**：需要在新电脑重新配置API供应商（供应商管理页面）
- **Mac的.app需要重新授权**：在新Mac上执行上面的chmod命令

## 🔧 常见问题

**Q: 打开后白屏？**
A: 请用 Chrome 或 Edge 浏览器打开，不要用IE。右键HTML文件 → 打开方式 → 选择Chrome/Edge。

**Q: Mac提示"无法打开，因为无法验证开发者"？**
A: 右键文件 → 打开 → 在弹窗中再次点击"打开"。或执行 `xattr -dr com.apple.quarantine` 命令。

**Q: 数据会丢失吗？**
A: 只要不清理浏览器数据就不会丢。建议定期用"导出工作流"功能备份。

**Q: 需要联网吗？**
A: 基础功能（画布操作、节点管理、工作流编排）不需要联网。AI生图、AI聊天、视频生成需要配置API并联网。

**Q: 可以多人共用吗？**
A: 可以把文件夹共享给别人，但每个人的数据是独立的（存在各自浏览器里）。
