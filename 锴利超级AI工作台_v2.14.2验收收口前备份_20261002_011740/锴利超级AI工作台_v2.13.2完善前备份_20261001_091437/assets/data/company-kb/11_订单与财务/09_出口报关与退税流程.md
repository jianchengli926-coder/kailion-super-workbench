# 出口报关与退税流程

> 刀具属管制刃具，**必须 PSB 公安局备案**才能 100% 合法出口。
> 对外承诺：**Every Document, Every Time, Zero Delays**。

---

## 一、出口全流程（五阶段）

```
① Order Confirmation（确认订单 + 收30%定金）
   ↓
② Production & In-Line QC（生产 + 制程质检）
   ↓
③ Packaging & Labelling（包装 & 贴标）
   ↓
④ Pre-Shipment Inspection（出货前视频检验 + 收70%尾款）
   ↓
⑤ Export & Logistics（出口报关 & 物流发货）
```

---

## 二、报关流程

```
准备全套单证（发票/装箱单/合同/报关单）
   ↓
刀具 PSB 公安局备案（出口许可）
   ↓
报关行申报海关
   ↓
海关查验（如抽中）/ 直接放行
   ↓
装船 / 装机
   ↓
收汇核销
   ↓
出口退税申报
```

### 各步骤详细说明

| 步骤 | 内容 | 责任人 | 时间 |
|------|------|--------|------|
| 1. 准备单证 | 商业发票、装箱单、外贸合同、报关委托书 | Leo | 出货前 3–5 天 |
| 2. PSB 备案 | 刀具公安局出口备案（管制刃具强制） | Leo / 报关行 | 出货前 3–5 天 |
| 3. 报关申报 | 报关行向海关电子申报 | 长期合作货代 | 装船前 1–2 天 |
| 4. 海关放行 | 审单 / 查验 / 放行 | 海关 | 当天–1 天 |
| 5. 装船出运 | 集装箱进场 / 装船 / 开船 | 货代 | 按船期 |
| 6. 收汇核销 | 外汇到账后办理核销 | Leo / 财务 | 收款后 |
| 7. 出口退税 | 申报退税（XTransfer/正规T/T渠道） | Leo / 财务 | 收汇后次月 |

## 五、出口退税流程

```
货物出口报关 → 海关结关 → 取得报关单退税联
   ↓
外汇收汇到账（T/T / XTransfer 正规渠道）
   ↓
增值税专用发票（工厂开具）
   ↓
退税申报（电子税务局 / 退税代理）
   ↓
税务局审核 → 退税款到账
```

### 退税关键条件

| 条件 | 说明 |
|------|------|
| 1. 正规报关 | 必须有出口报关单（退税联） |
| 2. 收汇凭证 | 外汇必须通过正规渠道收汇并核销 |
| 3. 进项发票 | 工厂必须开具增值税专用发票 |
| 4. 公司资质 | 必须有进出口经营权（已具备） |

### 注意事项

- **西联汇款不可退税**：小额西联收汇无法办理出口退税。
- **XTransfer 可退税**：大额订单推荐走 XTransfer（费率 0.5%–1%），正规结汇可退税。
- **PayPal 不可退税**：样品费/小单走 PayPal 不涉及退税。
- 退税周期：⚠️待Leo确认（通常出口后 1–3 个月）。

## 六、PSB 刀具公安局备案（重点）

> 刀具属**管制刃具**，必须经 PSB 公安局备案取得出口许可，才能 100% 合法出口。

| 项目 | 说明 |
|------|------|
| 备案主体 | 出口企业（阳江市锴利国际贸易有限公司） |
| 备案机构 | 阳江市公安局（PSB） |
| 所需材料 | 出口合同、发票、企业资质、产品信息 |
| 频次 | 每批出口前均需备案 |
| 不备案后果 | 无法合法出口、海关扣货 |

> 户外刀出口需额外确认目标国进口法规；网站户外刀标注「18+ adult use only」，不销管制刀具。
