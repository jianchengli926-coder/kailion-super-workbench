# Banner与首屏视觉规范

> 铁律：Banner上只放Logo + Slogan + 品类词 + 角落干净短链。手机号/WA/邮箱放上去=判引流违规、降分发。

## 一、统一品牌资产

| 资产 | 内容 |
|------|------|
| Logo | 狮标（居中） |
| 品牌Slogan | **Forged in Yangjiang. Trusted Worldwide.** |
| 短链 | kailioncrafts.com（右下角小字） |
| 品牌主色 | 深青绿 #1f665a / #134e42 |
| 辅助色 | 金棕 #e0b464 |

## 二、各平台Banner尺寸与安全区

| 平台 | 尺寸 | 安全区 | 内容建议 |
|------|------|--------|---------|
| Facebook Page封面 | 1640×856（出图2x） | 中心约820×312避免手机端裁切 | 品牌横幅+CTA文字 |
| LinkedIn公司页封面 | 1128×191 | 居中全幅 | 工厂全景+Slogan |
| YouTube Banner | 2560×1440 | 1546×423 | 工厂工艺微距+订阅CTA |
| X头图 | 1500×500 | 中心1260×400 | 产品线合集或工厂微距 |
| Pinterest头图 | 1920×1080（或1920×240） | 居中1200×600 | 露营/厨房/剪刀场景横图 |
| TikTok / IG / WA | 不支持Banner | — | 用置顶视频/Highlight/Catalog替代 |

## 四、Banner背景图选择优先级

**内容优先级**：
1. 工厂实拍（热处理炉火光 / CNC磨床火花 / QC检测台）—— 最有信任力
2. 产品全家福（该品类产品线平铺）
3. 锻造/打磨微距特写（火花、钢材纹理）
4. 团队照（慎用，避免暴露真实工厂地址）

**Outdoor品类特殊注意**：
- 背景选露营/户外场景，不选武器展示
- 产品展示用开箱/EDC携带视角，不要刀指向镜头
- 可用：锻造微距、钢材纹理、露营切食物场景
- 不可用：刀指人、刺物、血腥、与枪支同框

## 五、头像规范

### 三类头像

| 类型 | 适用平台 | 设计 |
|------|---------|------|
| 真人职业照 | LinkedIn个人页 / X个人号 / 邮箱 | 深色衬衫、浅灰/深蓝纯色背景、胸像、方形≥400px |
| 品牌Logo | FB/IG/YT/TikTok/Pinterest主号 | 狮标居中，纯白或#143440底 |
| 品类Logo+角标 | 4个品类号 | Logo右下角品类色角标 |

### 各平台头像上传尺寸

| 平台 | 尺寸 |
|------|------|
| LinkedIn个人页 | 400×400 |
| LinkedIn公司页 | 300×300 |
| Facebook Page | 512×512（显示170×170圆形） |
| Instagram | 320×320（圆形） |
| TikTok | 200×200（圆形） |
| X | 400×400 |
| YouTube | 800×800 |
| Pinterest | 280×280 |
| WhatsApp | 640×640 |

## 六、视频缩略图/封面规范

| 平台 | 尺寸 | 设计要求 |
|------|------|---------|
| YouTube缩略图 | 1280×720 | 深色背景+产品特写+大字关键词 |
| TikTok封面 | 9:16竖版 | 统一风格：深色底+产品+品类关键词 |
| Pinterest Pin图 | 1000×1500（2:3） | 产品图+关键词标题+品牌水印 |
| IG Reels封面 | 1080×1920 | 与TikTok封面统一但做差异化 |

## 七、Banner铁律清单

- [ ] Banner上**没有**手机号/WA号码/邮箱（判引流违规）
- [ ] Banner上有Logo + Slogan + 品类词
- [ ] 右下角小字短链 kailioncrafts.com
- [ ] 文案压在安全区内（手机端不被裁切）
- [ ] 背景图优先工厂实拍
- [ ] Outdoor品类无武器化staging
- [ ] 全平台Banner视觉风格统一（同色系、同字体、同Logo位置）
- [ ] 品类号Banner右下角有品类色角标
