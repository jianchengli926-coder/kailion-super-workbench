# 订单财务中心落地方案（摘要）

> 原则：**够用就行、一人可维护、别一步到位**。先把"客户→订单→采购→收付款→毛利"这条链跑通。
> 用户：4 人（Leo / Jason / Owen / Julia），订单按"负责人"区分，不做复杂权限。

## 一、目标（一句话）

在现有工作台把"订单台账"升级成轻量 **订单与财务中心**：一个销售订单进来 → 关联客户、关联工厂采购、登记收付款 → 自动算毛利 → 首页看板看应收/应付/利润。**不做审批流、不做多角色权限、不接物流/支付 API。**

## 二、数据底座：一个 SQLite 文件，4 张表

存 `data/workbench.db`（单文件，以后可迁云数据库）。技术栈：sqlite3 + pandas + 内置 st.data_editor（不用 SQLModel/aggrid）。

| 表 | 关键字段 |
|----|---------|
| **sales_orders 销售订单** | order_no（自动 KL-2026-001）· 负责人(4人下拉) · 客户名 · 国家 · 产品摘要 · 数量 · 金额 · 币种 · 状态(询价/报价/确认/生产/出运/完成) · 下单日 · 预计交期 · 物流费 · 其他费用 · 备注 |
| **purchase_orders 采购订单** | po_no · 关联销售订单号(下拉) · 工厂名 · 采购成本 · 币种 · 付款状态(未付/部分/已付) · 交货状态 · 下单日 · 备注 |
| **payments 收付款流水** | 日期 · 方向(收客户/付工厂) · 关联订单号 · 金额 · 币种 · 汇率(手动折人民币) · 方式(T/T/西联/信用证) · 备注（一订单多条，支持 30% 定金+70% 尾款） |
| **利润（不存表，自动算）** | 毛利 = 订单金额 − 关联采购成本 − 物流费 − 其他费用；应收 = Σ订单金额 − Σ已收；应付 = Σ采购额 − Σ已付 |

## 三、界面（4 个标签页）

| 标签 | 内容 |
|------|------|
| 🧾 销售订单 | 表格增删改查 + 新建订单表单（负责人下拉、状态机） |
| 🏭 采购/工厂 | 选销售订单 → 填工厂/采购成本/付款进度 |
| 💰 收付款流水 | 选订单、选收/付、金额币种汇率，支持分批 |
| 📊 经营看板 | ①订单状态分布 ②应收应付汇总 ③本月销售额/毛利/毛利率 |

**首页驾驶舱顶部 4 个数：** 今日待跟进 / 进行中订单 / **应收总额** / **本月毛利**。

## 四、连客户与工厂

- **连客户**：销售订单"客户名"对应现有客户中心客户（文本+下拉，能选已有客户）。
- **连工厂**：采购订单选工厂名（名称下拉+可新增），36 份工厂资料第二阶段再结构化。

## 五、做 / 不做（够用原则）

✅ 这次做：SQLite 建 4 表+自动建号 / 销售订单 CRUD / 采购订单关联 / 收付款流水（多币种手动汇率分批）/ 自动毛利+应收应付+看板 / 首页 4 个数 / 4 人共用同一库。

⏸️ 这次不做：多用户权限/审批流 / 历史 Excel 导入（从今天开始录）/ QC·物流跟踪·海外仓 / 社媒看板·AI 经营问答 / 接 Stripe·汇率 API。

## 补充内容：核心数据模型、指标公式与分阶段路线

> 提炼自《方案评审_经营中枢vs真实现状_V2路线.md》。核心结论：先跑通"客户→订单→收款→毛利"这条链，不一步到位建 10 个模块。

### 九、核心数据模型（表关系）

```
customers.json   客户：公司/国家/联系人/WhatsApp/客户类型/价值
products.json    SKU：名称/规格/采购成本/建议报价/MOQ/供应商
orders.json      订单：order_no, customer_id, sku_id, qty, amount, currency
                 costs:{product, packing, shipping, platform, other}
                 gross_profit, gross_margin（自动算）
                 status: 待付款/生产中/已出货/已完成
                 milestones: 定金30%已收? 尾款已收?
purchases.json   采购：order_no, 工厂, 采购额, 已付, 待付
transactions.json 资金流水：日期/收或付/客户或工厂/金额/币种/汇率/手续费/关联订单
```

### 十、三个自动算出的经营指标（首页驾驶舱）

- **应收 = Σ订单金额 − Σ已收**（按订单算账期/逾期）
- **应付 = Σ采购额 − Σ已付工厂**
- **毛利 = Σ收款 − Σ产品成本 − Σ运费 − Σ其他费用**
  （细：毛利 = 订单金额 − 关联采购成本 − 物流费 − 其他费用）

> ⚠️ 内部敏感：毛利/应收应付为经营核心数据，仅限 4 人团队可见。

### 十一、分阶段落地路线

| Phase | 目标 | 内容 |
|-------|------|------|
| **Phase 1 经营闭环（现在）** | 客户→产品→订单→收款→毛利跑通 | 订单 OMS（详情+成本+收款节点）、应收应付+资金流水、自动毛利+月度汇总、首页 4 个数（今日询盘/待跟进/进行中订单/应收） |
| Phase 2 履约（数据有了再做） | 工厂库与采购 | 36 家工厂资料结构化入库、采购 PO 自动拆需求、QC/出货先用备注 |
| Phase 3 获客与 AI（最后） | 客户档案与 BI | 客户档案串全（询盘-报价-订单-付款-沟通）、数据报表、AI 经营问答 |

> 不要做：多用户权限/审批流、历史 Excel 导入（从今天开始录）、接 Stripe/汇率 API、社媒看板。广告/汇率 API 留到有数据后。
