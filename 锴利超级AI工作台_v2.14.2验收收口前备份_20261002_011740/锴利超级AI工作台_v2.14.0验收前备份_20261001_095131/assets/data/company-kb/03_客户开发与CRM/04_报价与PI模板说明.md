# 报价单与PI（形式发票）模板说明

> 报价单（Quotation）= 正式报价，无法律效力
> PI（Proforma Invoice）= 形式发票，客户确认后即合同，有法律效力

---

## 一、报价单（Quotation）标准结构

### 1. 抬头信息
- 公司抬头：KaiLionCrafts / Yangjiang Kaili International Trading Co., Ltd.
- 文件类型：QUOTATION
- 报价编号：KLC-Q-YYYY-NNN
- 报价日期
- 报价有效期（通常15-30天）

### 2. 客户信息
- 客户公司名
- 联系人
- 客户地址

### 3. 产品明细（表格）
| 列 | 说明 |
|---|---|
| Item No. | 序号 |
| Model | 产品型号 |
| Description | 产品描述（材质/硬度/尺寸/手柄） |
| Qty | 数量 |
| Unit Price | 单价（注明贸易术语FOB/CIF） |
| Total | 小计 |

### 4. 贸易条款
- **Price Term**: FOB Shenzhen / FOB Guangzhou / CIF [Port] / DDP
- **Payment**: 30% T/T deposit + 70% against B/L copy
- **Lead Time**: 30-35 days after deposit
- **MOQ**: 按各型号
- **Packaging**: 标准出口包装（彩盒/白盒/吸塑）
- **Port**: Shenzhen / Guangzhou, China

### 5. 备注
- 价格有效期
- 认证说明（FDA/LFGB/CE/RoHS/FSC available）
- OEM/ODM说明
- 样品政策

## 三、付款条款说明

| 付款方式 | 说明 | 适用客户 |
|---|---|---|
| **T/T 30%定金 + 70%见提单副本** | 标准条款 | 所有新客户、A/B类客户 |
| **T/T 100%前付** | 小金额样品单 | 小客户、样品单 |
| **L/C at sight** | 即期信用证 | 大客户、首单大额订单 |
| **PayPal / 西联** | 小额样品费 | 小客户、样品费 |
| **OA 30/60/90天** | 赊销 | 仅A类老客户 + 中信保 |

### 付款条款谈判原则
1. 新客户首单：坚持30%定金+70%见提单副本
2. 德国/日本/澳洲客户：可接受L/C at sight
3. 印度/中东/南美客户：提高定金比例至50%
4. 俄罗斯客户：受制裁影响，用人民币/跨境人民币结算，30%+预付
5. 任何OA账期：必须买中信保

## 四、贸易术语（Incoterms 2020）说明

| 术语 | 说明 | 适用场景 |
|---|---|---|
| **EXW** | 工厂交货，客户自提 | 客户有自己货代 |
| **FOB Shenzhen** | 深圳港船上交货 | 最常用，客户指定货代 |
| **CIF [Port]** | 成本+保险+运费到目的港 | 客户要我们安排海运 |
| **DDP** | 完税后交货到客户门口 | 大客户/电商客户，含清关和税 |

---

## 五、发PI后的跟进

1. PI发出后24小时内电话/WhatsApp确认客户收到
2. 催促客户签字回传并安排定金
3. 收到定金后24小时内下达生产通知
4. 定金到账前不安排任何生产
