## 三、身份架构（Identity Architecture）

### 三层身份
1. **Company brand**：KaiLionCrafts用于Facebook Page、Instagram、Pinterest、YouTube、TikTok、X、WhatsApp Business等品牌面。
2. **Real person**：LinkedIn个人页仅使用真实、授权的人员姓名和职业照。除Leo Li外，其他负责人本版一律写为 `Category Specialist - name pending confirmation`，不能冒充真人。
3. **Conversation**：Messenger依附Facebook Page；WhatsApp Business是经同意的询盘入口；企业邮箱用于报价、样品和合同沟通。

### 头像规则
- 真人身份用真实职业照；品牌/品类身份用Logo
- 不要在同一账号长期混用品牌名+真人头像或真人名+Logo
- 产品图适合做内容封面，不适合做长期账号头像

### 统一横幅文字（可选）
- English: `Made in Yangjiang. Connected to Global Buyers.`
- 中文：源自阳江，连接全球采购商。只在横幅空间足够时使用。

## 四、独立站链接放置总地图

> 所有URL使用完整HTTPS链接。不要用短链掩盖目的地。UTM仅用于内部归因。

| 平台 | 优先放置位置 | 视频/帖子内 | 操作结论 |
|------|------------|-----------|---------|
| LinkedIn | 个人Contact info/Featured；公司页Website | 正常帖子可用完整链接 | 链接直接指向对应品类页 |
| Facebook Page | About的Website + Page action button | 正常帖子可加HTTPS链接 | 产品链接不能成为受限商品变相销售通道 |
| Instagram | Profile links/Bio | Feed caption URL通常不作主要入口；Story用Link sticker | 视频口播写"See the category link in our profile." |
| TikTok | Profile的Website字段（仅当后台开放） | 不要把caption/评论URL当可点击主入口 | 无Website字段时不承诺外链能力 |
| YouTube | Channel profile links + channel description | 每个视频描述首段放相关完整链接 | 外部链接资格以YouTube Studio状态为准 |
| Pinterest | 每个Pin的Destination link | Pin标题/描述与页面主题一致 | 需先Claim网站；Rich Pin转化最强 |
| X | Profile Website | 可在相关帖子使用完整链接 | 不把"放首评规避降权"当规则 |
| WhatsApp/Messenger | Business profile Website / FB Page消息入口 | 客户主动询问后发送相关页面 | 不群发、不自动发送无关产品页 |
| 邮箱 | 企业邮箱签名 | 报价邮件中按客户需求使用 | 邮件签名是正式来源 |

## 六、Facebook/Instagram/Messenger/WhatsApp真实分工

### 免费有机路径
FB Page或IG主页 → 对应品类页；客户自主点击Website/Profile link/Page button/wa.me入口。不需要广告账户，但不等于受限商品都可推广。Messenger/WA仅在客户先联系或明确同意后做一对一跟进。

### 付费Click-to-WhatsApp
需Meta Business Portfolio + 广告账户 + 付款方式 + FB Page + 已连接合格的WA Business资产 + 广告政策审核通过。不是"个人FB账号点一下就能投"。

### 户外刀广告结论
**不为Outdoor Knives创建Meta广告或以WA广告形式导流。** 是否可发布有机内容取决于内容、页面、当地法律和当时政策。若平台提示受限/拒登/要求审核，应停止该素材并按平台流程申诉。

## 七、执行路线：可审计的变更批次

> 平台不会公开可依赖的"每天能改几个账号"安全数字。用静态IP/错峰/设备隔离来规避检测不是正规运营策略。本路线目标是减少人为填错、重复改名和不一致资料。

| 批次 | 执行内容 | 范围 | 完成标准 |
|------|---------|------|---------|
| 0.准备 | 建立资产登记表：平台、所有者、登录恢复方式、真实业务号码、现有URL、最终handle、落地页、截图证据 | 四类全部 | 不做公开变更；资料无冲突 |
| 1.母数据 | 确认4品类名称、Logo文件、横幅素材、落地页、对外邮箱、是否有授权真人出镜 | 四类全部 | 每项有一份最终文件 |
| 2.优先公开面 | 先完善LinkedIn(Leo/公司)、FB Page、IG、YouTube、Pinterest的名称/头像/About/网站字段 | 一次只完成一个品类的一个平台 | 预览正确、链接打开、无私人资料曝光 |
| 3.会话和邮箱 | 设置WA Business资料、Messenger人工回复流程、邮箱发件人和签名；启用2FA与恢复码离线保存 | 四类逐一完成 | 用内部测试联系人验证一条询盘的人工回复和链接 |
| 4.内容首发 | 每个公开主页先发布1条真实/同品类/合规的介绍内容 | 先低敏感三类；户外品类经单独合规复核 | 视频/图片版权清楚，文案、链接与落地页一致 |
| 5.官网互链 | 记录每个公开主页最终canonical URL，逐个打开验证后回填WordPress/Elementor社媒图标 | 只填已公开且公司控制的页面 | 官网外链无404、无登录邮箱、无未确认个人页 |

### 发生验证/限制/拒绝时
停止重复修改；保留截图与页面链接；检查姓名、企业、素材、页面内容和链接是否真实且符合政策；从账户内官方帮助入口提交申诉。不要立刻换设备、IP、重开号或批量转移内容。

## 八、社媒URL收集与独立站回填

### 每个平台主页URL怎么取
1. 以未登录/隐身窗口打开该主页，确认访客可见
2. 复制浏览器地址栏中的公开URL；不要用登录邮箱/App深链/后台编辑URL
3. 在资产表登记：平台、品类、公开URL、handle、页面管理员、验证日期、截图
