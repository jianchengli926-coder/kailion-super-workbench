# 客户背景调查SOP与工具

> 收到询盘后别急着报价！按本Checklist完成背调，再决定报价策略和付款条件。
> 目标：判断客户类型、规模、付款风险、找到决策人。

---

## 一、13步背调Checklist

### Step 1：Google高级搜索
- 搜索指令：
  - `"公司名" + importer / distributor / buyer / wholesale`
  - `"公司名" + site:*.us`（看本地域名）
  - `"公司名" + review / scam / fraud`（查负面）
- 目的：初步判断公司业务和口碑

### Step 2：官网分析
- 重点看：
  - **About Us**：成立年份、规模、使命、品牌故事
  - **产品类目**：是否经营五金刀剪/厨房用品？产品线宽度？
  - **客户案例/合作伙伴**：服务过哪些知名品牌？
  - **联系页面**：办公地址、电话、邮箱
- 目的：判断是工厂/进口商/品牌商/中间商

### Step 3：域名注册时间（Whois / ICANN Lookup）
- 工具：https://lookup.icann.org/
- 域名注册越久公司越稳
- **新域名（<1年）需警惕**，可能是新贸易公司或骗子

### Step 4：Google Maps地址验证
- 搜公司地址，看街景：
  - 是真实办公室/仓库/店铺？
  - 还是虚拟地址/住宅？
- 目的：验证公司实体真实性

### Step 5：LinkedIn公司主页
- 看：
  - 员工数量（5人以下=小公司；100+=中大型）
  - 组织架构（采购部门有多少人）
  - 近期动态（招聘=扩张；发新品=活跃）
  - 决策人是谁
- 目的：定位关键人、判断公司规模

### Step 6：社媒活跃度
- 检查 Facebook / Instagram / YouTube：
  - 最近是否更新（3个月内活跃=真实运营）
  - 粉丝数和互动量
  - 是否参加展会、有无新品发布
- 目的：判断客户活跃度和真实性

### Step 7：海关数据查真实采购记录
- **免费工具：ImportYeti**（https://importyeti.com/）
  - 输入客户公司名，查美国提单数据
  - 看：从哪国买、买多少、采购周期、现有供应商是谁、单次货值
- 付费工具：Panjiva、Volza、特易资讯GT6.0
- 目的：推算年采购额，对应A/B/C分级

### Step 8：资信/诉讼记录
- 查客户所在国法院诉讼记录、商业信用记录
- 目的：决定付款方式（资信差→高比例预付款）

### Step 9：定位决策人
- 找：CEO / Owner / Import Manager / Purchasing Manager / Sourcing Manager
- **别发info@邮箱**（99%石沉大海）
- 通过LinkedIn搜公司+职位

### Step 10：找邮箱并验证
- 工具：
  - **Hunter.io**（域名邮箱搜索+验证）
  - **RocketReach**（找人邮箱）
  - **Lusha**（LinkedIn插件）
  - **Apollo.io**（联系人数据库）
- 验证邮箱有效性后再发开发信

### Step 11：美国上市企业查EDGAR
- 工具：https://www.sec.gov/edgar
- 美国上市公司必须公开财报、内部人交易
- 数据具法律效力，可查公司真实营收和财务状况

### Step 12：德国客户查Creditreform
- 德语区（德国/奥地利/瑞士）最权威信用评级机构
- 查客户信用等级、付款记录、破产风险

### Step 13：全球商业信息库D&B Hoovers
- Dun & Bradstreet 付费数据库
- 买家画像、财务状况、行业地位
- 大客户/新市场客户建议购买

## 四、背调后决策指引

| 背调结果 | 客户类型 | 报价策略 | 付款策略 |
|---|---|---|---|
| 有真实进口记录+规模大+信用好 | 进口商/品牌商 | 年度框架价+阶梯价 | T/T或L/C |
| 有进口记录但量小 | 批发商/小进口商 | FOB单价+MOQ | T/T定金+尾款 |
| 无进口记录但官网专业 | 新品牌/新贸易商 | 标准报价 | 高比例预付(50%+) |
| 无海关数据+新域名+信息模糊 | 风险客户 | 谨慎报价 | 100%前T/T |
| 索要免费样品不留真实信息 | D类/骗子 | 不报价 | 放弃 |
