# 五金刀剪制造工艺

```
锻造/冲压 → 热处理 → 开刃 → 表面处理 → 装配 → 检验 → 包装
```

| 工序 | 说明 | 视频素材点 |
|------|------|-----------|
| 锻造/冲压 | 成型，锻打火光 | 锻打火光 |
| 热处理 | 淬火，提升硬度 | 淬火 |
| 开刃 | 手工开刃，锋利顺滑 | 砂轮磨刃 |
| 表面处理 | 防锈/外观处理 | — |

## 补充内容：钢材牌号、表面处理与三道 QC

> 提炼自公司资料源合集及社媒研究报告"材料科普"章节。用于 B2B 买家教育与社媒内容生产。

### 六、钢材牌号库（从入门到高端）

| 钢材 | 定位/特点 | 社媒话术示例 |
|------|----------|-------------|
| 304 不锈钢 | 基础款，核心卖点 3 年防锈 | "304 stainless steel, 3-year rust resistance" |
| 3Cr13 | 入门马氏体不锈钢，日常厨刀 | entry-level stainless |
| 9Cr18MoV | 高端国产钢，高硬度高耐磨 | from 3Cr13 to 9Cr18MoV |
| 德国 1.4116 | 德国进口厨刀钢，耐腐蚀适合食品接触 | German 1.4116 steel |
| 日本 VG-10 | 高端复合钢，硬度保持性好 | Japanese VG-10 |
| D2 | 高碳高铬工具钢，户外刀常用 | D2 tool steel |
| 440C | 经典高端不锈钢 | 440C stainless |
| 大马士革 Damascus | 花纹钢，手工锻打，收藏/高端厨刀 | Damascus pattern, hand-forged |

- **热处理**：真空热处理（vacuum heat treatment）提升硬度；HRC 控制在 **56-58** 为厨刀常用区间。
- **工艺装饰**：Tsuchime 锤纹（手工锤击表面纹理）、镜面抛光、缎面、黑色涂层、钛涂层、水洗（stone wash）。

### 七、手柄材料

- 玫瑰木 rosewood、G10、聚合物 polymer、米卡塔 Micarta、贝壳 abalone shell、不锈钢。
- 可定制：刀刃雕刻（laser engraving）、手柄材质选择、表面处理、定制礼盒包装。

### 八、三道 QC 品控流程

| 环节 | 内容 |
|------|------|
| 来料检验 Incoming material | 钢材/手柄/包装材料进厂检验 |
| 过程检验 In-process | 生产中途巡检，硬度/尺寸/外观 |
| 出货前检验 Pre-shipment | **视频确认 + 客户书面批准**，出货前放行 |

- 创始人亲自监督三道 QC；提供完整检验报告；长期客户零缺陷承诺。
- 检测设备素材：HRC 硬度计、锋利度测试仪、盐雾测试箱（防锈测试）。
