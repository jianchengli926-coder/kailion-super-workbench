# KaiLionCreator · 功能框架

> 锴利匠心 AI 工作台 · KaiLionCrafts 专属创作工作台
> 版本 v0.1.0 · 数据本地优先 · 品牌：KaiLionCrafts（阳江市锴利国际贸易有限公司）

本文档是整个工作台的**功能框架总览**，包含：产品定位 → 分层架构 → 功能模块树 → 数据模型 → 节点体系 → 与原产品的对照关系。

---

## 一、产品定位

| 项目 | 内容 |
|---|---|
| 一句话定位 | 一个人，就是一支 AI 团队 |
| 服务对象 | CEO 本人 + 未来 1~3 人小团队 |
| 核心场景 | 五金刀剪 / 厨房用品 **跨境 B2B 出海**：产品图 → 详情页 → 询盘应答 → 合规 → 独立站 → 多平台铺货 |
| 与通用工作台的区别 | 内建 **6 条「锴利专线」节点**，把阳江刀剪行业知识（钢材牌号、HRC、FDA/LFGB、FOB 报价、买家类型）直接编译成节点参数 |
| 数据策略 | 全部本地存储，不上传任何服务器；只有主动调用 AI 接口时才联网 |
| 交付形态 | 当前为 Web 版（零依赖，双击可跑）→ 可打包为 Tauri 桌面应用（见《桌面版打包指南》） |

## 三、功能模块树

### 3.1 智能工作台（一句话干活）

```
智能工作台
├── 顶部胶囊（9 个）          决定下方能力标签的显示范围
│   └── 全部能力 / 锴利专线 / 电商 / 图片 / 视频 / 文案 / 办公 / 品牌 IP / 供应链
├── 能力标签（22 条）          点一下写入输入框，作为自然语言起点
├── 输入框（Composer）
│   ├── Enter 立即运行
│   ├── Shift+Enter 换行
│   ├── @文件名 引用已上传文件
│   └── /技能名 调用内置技能
├── 意图引擎（Intent Engine）
│   ├── 24 条关键词规则 + 优先级打分
│   ├── 槽位抽取：数量 / 页数 / 屏数 / 镜头数 / 变体数 / 画幅 / 分辨率 / 时长 / 风格 / 平台 / 语言
│   ├── 真实置信度评估（0.2 ~ 0.97）
│   ├── 非法参数生成前自动纠正（画幅非法 / 数量超限 / 时长超模型上限）
│   └── 低置信度（<55%）主动澄清反问 + 建议选项
├── 4 步执行面板（Stepper）
│   ① 解析意图 → ② 搭建画布 → ③ 校验前置条件 → ④ 执行并归档
├── 执行后动作
│   ├── 去画布看它搭了什么
│   ├── 保存到工作流库
│   ├── 转成定时任务
│   └── 再跑一次
└── 历史面板
    └── 最近 80 条记录，点一下回到当时的画布
```

### 3.2 经典画布（可视化节点编辑器）

```
经典画布
├── 视图操作
│   ├── 滚轮缩放（25% ~ 240%）
│   ├── 中键 / 右键拖拽平移
│   ├── 框选多选 / Ctrl+单击追加选择
│   ├── 小地图导航（实时显示节点分布 + 视口框，可点击跳转）
│   ├── LOD 分级渲染（<66% 折叠节点内容，<40% 只留标题）
│   └── 适应画布（含缩放下限保护：宁可溢出也不缩到文字不可读）
├── 节点操作
│   ├── 从节点库拖拽落到画布 / 双击添加 / 右键菜单添加
│   ├── 拖拽移动（多选一起移动）
│   ├── 端口连线（输出口 → 输入口，自动替换同输入口的旧连线）
│   ├── 参数即时生效（节点内联编辑 + 右侧参数面板编辑）
│   ├── 长文本独立编辑器（提示词库插入 / 结构模板补全）
│   ├── 多选编辑器（模块勾选 / 专家名单）
│   └── 右键菜单：运行 / 复制 / 创建副本 / 断开全部连线 / 配置供应商 / 删除
├── 编辑历史
│   ├── 撤销 Ctrl+Z（60 步）
│   ├── 重做 Ctrl+Shift+Z
│   ├── 复制 Ctrl+C / 粘贴 Ctrl+V / 创建副本 Ctrl+D
│   ├── 全选 Ctrl+A / 取消选择 Esc / 删除 Delete
│   └── 自动整理布局 Ctrl+O（按拓扑层级分列排布）
├── 执行
│   ├── 单节点运行（节点上 ▶ 按钮）
│   ├── 整图运行（工具栏 ▶）
│   ├── 结果预览（图像组 / 视频片段 / 文档预览 / 文本）
│   └── 节点状态：待运行 / 运行中 / 完成 / 失败
└── 结构体检（AI 教练）
    ├── 孤立节点检测
    ├── 生成节点缺上游检测
    ├── 供应商未配置检测
    ├── 画幅协议冲突检测（档位 vs 像素串）
    ├── 敏感操作闸门提示
    └── 输出健康度评分（0~100）+ 优化建议
```

```
State

├── settings                    主题 / 品牌 / 运行偏好 / 助手名称
├── sidebar                     { 资源库 key: 是否显示 }
├── nodeVisibility              { 节点 id: 是否显示 }（自定义模式覆盖）
├── customMode                  节点库自定义模式开关
├── providers[]                 供应商线路
├── nodeProviders               { 节点类型 id: 供应商 id } 绑定表
├── canvases[]                  保存的画布
│   └── { id, name, nodes[], wires[], updatedAt }
├── workflows[]                 我保存的工作流
├── libraries{}                 14 类资源库数据
├── scheduledTasks[]            定时任务定义
├── history[]                   工作台运行历史（最多 80 条）
└── runs[]                      节点执行记录

画布节点实例
├── id            实例唯一 id
├── type          节点类型 id（对应节点目录）
├── x, y          画布坐标
├── params{}      参数（用节点定义的字段默认值补齐）
└── _st/_msg/_out 运行时状态（不落盘）

连线
└── [源节点id, 源端口id, 目标节点id, 目标端口id]
```

## 五、执行引擎

```
执行引擎
├── 拓扑排序 topoSort(nodes, wires)
│   ├── Kahn 算法，环检测
│   └── 检测到环 → 降级按原顺序执行 + 告警，不阻塞
├── 输入传递
│   └── 按连线把上游输出（text / file / images / filename）投递到下游对应端口
├── 适配器注册表（14 类 engine）
│   ├── text / asset / image / video / llm / doc
│   ├── ecom / ip / collab / convert / review / search
│   └── mcp / cli / 3d / assemble / batch / supply / external
├── 双模运行
│   ├── 真实模式：供应商有 Key → 调 /chat/completions 或 /images/generations
│   └── 推演模式：无 Key → 产出结构化、可交付的占位结果（14 种结果渲染器）
│       失败自动降级，不中断整图执行
├── 单节点运行 / 整图运行 / 批量并行（runParallel）
└── 执行日志流（klc:log 事件 → 可挂到 UI 面板）
```
