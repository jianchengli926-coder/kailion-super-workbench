# 博客 SEO 元数据表（7 篇文章）

> **用途**：为 7 篇已上线博客文章逐篇补 Focus Keyword / Meta Title / Meta Description / H1 / 内链建议。
> **填写位置**：WordPress 后台 → Posts → 编辑对应文章 → 底部 RankMath meta box → Edit Snippet。
> **字符规范**：Title ≤ 60 字符，Description 150–160 字符。
> **全局兜底模板**（RankMath → Titles & Metas → Posts）：Title = `%title% %sep% %sitename%`；Description = 手动填（不要依赖 `%excerpt%`，多数文章未写摘要）。
>
> **内链原则**：每篇博客文末至少 2 条内链——1 条到对应品类页（商业转化），1 条到相关服务页（OEM/Quality）。博客是 B2B 获客入口，内链把信息型流量导给交易型页面。

## 填写检查清单

- [ ] 每篇文章 RankMath → Snippet 编辑器填入 Title / Description / Focus Keyword。
- [ ] 确认文章 Featured Image 已设置（用于 Open Graph 与 Article Schema）。
- [ ] 每篇文末加 2–3 条内链（见上表"内链建议"），锚文本用关键词而非"click here"。
- [ ] 博客间互相内链（相关阅读模块），形成主题集群（topic cluster）。
- [ ] RankMath → Titles & Metas → Posts 把默认 Description 从 `%excerpt%` 改为留空手动填，或至少在每篇文章 Excerpt 字段补 155 字摘要。
