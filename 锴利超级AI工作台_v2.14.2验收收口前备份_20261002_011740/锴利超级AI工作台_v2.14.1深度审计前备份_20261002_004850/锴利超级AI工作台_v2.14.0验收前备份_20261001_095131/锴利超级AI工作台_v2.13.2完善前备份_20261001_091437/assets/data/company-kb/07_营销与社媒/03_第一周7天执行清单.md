# 第一周7天执行清单

> 把这份当成项目甘特图来执行。完善账号最忌讳"东改一下西改一下"，正确顺序是先定身份、再填主页、最后互链。

## 一、14天上线路线图总览

| 阶段 | 时间 | 任务 |
|------|------|------|
| 基建 | Day 1–2 | 注册/锁定4品类Handle，公司主号上线；4台手机各自养号（只刷不发） |
| 静默养号 | Day 3–6 | 继续养号，不改资料；拍摄15条母版素材，CapCut洗稿剪辑 |
| 分批改名 | Day 7–10 | 按排期表每天改1台手机3批平台，间隔2小时；改完静默72小时 |
| 邮箱与IM | Day 11 | 设置4品类邮箱签名；WA Business欢迎语/离开消息/快捷回复；Messenger Greeting |
| 发首三条 | Day 12 | 每个账号发布该品类母版的前3条内容；带UTM链接 |
| 独立站回填 | Day 13 | 验证所有社媒URL可打开；把链接填入独立站团队页；配置页脚和品类页CTA |
| 互链与复盘 | Day 14 | 社媒之间互相@、Bio互链；检查每个账号通过清单；备份所有账号截图 |

## 二、7天详细执行清单（Day 12起冷启动周）

### Day 12 · 发布首三条

**上午（洛杉矶时间各品类窗口）**
- [ ] Phone1 Outdoor：发布3条母版内容（EDC folding knife anatomy / Factory heat-treat process / How to specify an outdoor knife program）
- [ ] Phone2 Kitchen：发布3条（Damascus pattern close-up / How a chef knife is heat-treated / Pick the right knife）
- [ ] Phone3 Scissors：发布3条（CNC grinding close-up / Kitchen vs tailor vs garden shears / Laser engraving & private label）
- [ ] Phone4 Accessories：发布3条（Bamboo board vs plastic board / Silicone utensil heat-safe test / Retail bundle ideas）

**每条内容检查**
- [ ] 前3秒有视觉冲击
- [ ] 英文字幕
- [ ] 标题含品类关键词
- [ ] CTA写"Link in bio"
- [ ] 无禁用词（Outdoor品类特别检查）

### Day 13 · 独立站回填

- [ ] 用手机无痕模式验证所有社媒URL可公网打开
- [ ] 把4位负责人社媒链接填入独立站团队页
- [ ] 配置首页Footer公司主号社媒图标
- [ ] 品类产品页底部加"联系品类负责人"模块（WA按钮+Email+LinkedIn头像）
- [ ] 联系我们页挂WA Business悬浮按钮
- [ ] 检查UTM参数在GA中可见

### Day 14 · 互链与复盘

- [ ] 社媒之间互相@（公司主号@品类号）
- [ ] Bio互链完成
- [ ] 每个账号通过上线前检查清单（见下方）
- [ ] 备份所有账号截图到云文件夹
- [ ] 记录Handle列表单独存档
- [ ] 复盘第一周数据：播放量、主页访问、网站点击、询盘数

## 三、每个账号上线前检查清单

### 通用检查项（每个账号都要过）
- [ ] 头像已上传（正确尺寸）
- [ ] 横幅/背景图已设置（正确尺寸，文案压安全区）
- [ ] Display Name符合命名策略
- [ ] Username/Handle已锁定，全平台尽量同名
- [ ] Bio已填写（控制在字符限内），无敏感词
- [ ] 网站字段已填对应品类产品页URL（带UTM），不是首页
- [ ] 账号类型已切换为Business/Brand/Professional
- [ ] 邮箱签名已设置（去掉未证实的CE/FDA/LFGB）
- [ ] WhatsApp Business已配置欢迎语/离开消息/快捷回复
- [ ] Messenger已配置欢迎语
- [ ] 至少3条内容已发布
- [ ] 账号公开可访问（非私密）
- [ ] Outdoor品类：Bio和内容无tactical/weapon/self-defense/kill等敏感词

## 四、首周运营节奏（Day 12起）

### 每天发什么
- 每平台每天1条（TikTok/IG），内容按60/20/20配比
- 首发全是教育/信任类（工艺、工厂、材料）

### 互动多少
- 每天花20分钟刷同niche内容
- 点赞5–10个
- 关注2–3个同行/目标买家账号
- 真诚评论2–3条

### 关注多少
- 每天主动关注≤15个
- 优先关注海外刀具批发商、进口商、品牌买手账号

## 五、首月运营节奏

### 内容日历框架
- 每周一规划下周内容
- 60%教育 + 20%幕后 + 20%产品转化轮换

### 数据观察指标
- 每条内容看：播放/触达、主页访问、网站点击（UTM）、询盘数
- 新号TikTok单条50–200播放属正常，不要因前几条数据差就删视频重发

### 调整策略
- 哪类内容播放高，下周就加量
- 连续2周数据差的平台降低投入，把精力转移到主力平台

## 六、各平台运营优先级（三分法）

| 优先级 | 平台 | 投入节奏 |
|--------|------|---------|
| **主力（每天）** | LinkedIn（创始人个人Profile）+ Instagram + YouTube | 每天维护，B2B获客主阵地 |
| **次主力（每周）** | Facebook Page + Pinterest + TikTok | 每周固定频次发布，Pinterest每天Pin |
| **基础维护** | X + WhatsApp Business + 邮箱签名 | 每周看一眼、回私信即可，不追求高频 |

## 七、三个北极星KPI

1. **Follower growth** across 4 category accounts（四个品类号的粉丝增长）
2. **Website clicks from social**（tracked via UTM）（社媒带来的网站点击）
3. **Inbound inquiries** via WhatsApp / Messenger / email（通过WA/Messenger/邮箱进来的询盘数）

> 点赞这种虚荣指标是次要的——B2B要的是询盘，不是点赞。

## 八、发布时间建议

### 面向美国买家（LinkedIn/FB/IG/TikTok）
- 工作日太平洋时间 **12:00–15:00**（午休）或 **18:00–21:00**（晚间）
- 对应北京时间次日凌晨

### 面向欧洲买家
- CET时区上午9–11点 = 洛杉矶凌晨0–2点
- 可安排定时发布

### Pinterest/YouTube
- 不那么挑时间，但工作日上午发布初始推流更稳

### 定时发布工具
由于人在阳江、账号在洛杉矶，建议用平台自带定时发布：
- Meta Business Suite
- TikTok Scheduler
- Pinterest scheduler

按洛杉矶时区排期，不要在北京时间白天手动发。
