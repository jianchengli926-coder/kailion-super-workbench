# 报价计算实操手册

> **定位**：这是一份"拿到询盘就能照着算"的操作手册，不是理论文章。
> 财务/业务人员收到客户询盘后，按本手册步骤 1→7 走，30 分钟内可出第一版 FOB 报价。
>
> ⚠️ **重要声明**：本手册中所有具体金额（除已注明"公司基准价"外）均为**示例计算，非公司实际定价**。
> 实际报价以工厂最新采购价、货代当周报价、当日结汇汇率为准。

## 一、报价流程全图解（7 步闭环）

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1  收到询盘                                            │
│  ├─ 客户是谁？（进口商/品牌商/Amazon卖家/批发商/小客户）       │
│  ├─ 买什么？（SKU、数量、定制要求、目标市场）                   │
│  └─ 什么时候要？（交期敏感度）                                │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 2  反筛 3 问（不直接报价）                              │
│  ① What's your target price range?                          │
│  ② What's your estimated quantity?                          │
│  ③ Do you need OEM/ODM customization?                       │
│  → 不答的 = C类比价党，用标准报价表应付                        │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 3  成本核算（本手册第二节）                              │
│  ├─ 从工厂拿到 EXW 含税价（人民币）                            │
│  ├─ 加国内段费用 → FOB 成本                                  │
│  ├─ 加海运费+保险 → CIF 成本                                 │
│  └─ 加目的港费用+关税 → DDP 成本                            │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 4  确定加价率（本手册第三节）                            │
│  ├─ 按客户类型选加价区间                                      │
│  ├─ 按订单数量选阶梯系数                                      │
│  └─ 汇率缓冲 2%–3% 已含在加价里                               │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 5  核算底线价（不能低于此价）                            │
│  底线价 = FOB成本 ÷ (1 - 目标最低毛利率) ÷ 汇率缓冲系数        │
│  → 客户还价低于底线价 → 放弃或降配置                          │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 6  出具 PI（本手册第七节模板）                           │
│  ├─ 分项列价（产品/包装/Logo/运费）                           │
│  ├─ 标注有效期 15–30 天                                      │
│  └─ 附产品图、规格表、认证文件                                │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 7  报价后复盘                                           │
│  ├─ 客户接受？→ 签 PI + 收 30% 定金                          │
│  ├─ 客户还价？→ 对照底线价，能让多少让多少                    │
│  └─ 客户消失？→ 7 天后跟进一次，记录到 CRM                     │
└─────────────────────────────────────────────────────────────┘
```

**时间节点 SLA**：
| 节点 | 响应时限 | 责任人 |
|------|---------|--------|
| 收到询盘首次回复（确认需求） | 1 个工作日内 | 业务 |
| 出具第一版 PI | 确认需求后 1–2 个工作日 | Leo |
| 客户还价后再报价 | 24 小时内 | Leo |
| 报价后主动跟进 | 发出后 7 天、14 天各一次 | 业务 |

## 二、成本核算公式详解（EXW / FOB / CIF / DDP）

### 2.1 通用换算公式

```
人民币成本(¥)  ÷  结汇汇率  =  美元成本($)
美元报价($)   ×  结汇汇率  =  人民币收入(¥)
```

> 💡 **报价用汇率 ≠ 当天即期汇率**。报价时应按**保守汇率**核算（比当日中间价低 2%–3%），
> 留出人民币升值的安全垫。详见《汇率风险管理实操》。
>
> **示例**（非实际）：当日中间价 6.75，报价时按 6.60 核算（预留 2.2% 缓冲）。

### 2.2 EXW（工厂交货）成本构成

```
EXW 成本价 = 产品出厂含税价(¥)
           + 内包装费(¥)          ← 彩盒/白盒/吸塑，按把计
           + 厂内装卸费(¥)        ← 叉车装柜/短驳到厂门口
           + 工厂到外贸仓库短驳费(¥) ← 如需集中验货
```

**适用**：客户有自己的货代、长期合作客户、极度价格敏感的进口商。
**卖方责任**：最小——在工厂门口把货交给客户指定货代即可。

**示例计算**（⚠️ 示例数字，非公司实际成本）：
```
某 8" 主厨刀工厂含税出厂价 = ¥28.00/把
内包装彩盒费              = ¥2.50/把
厂内装卸分摊              = ¥0.30/把
─────────────────────────────────────
EXW 人民币成本            = ¥30.80/把
按报价汇率 6.60 折算       = $4.67/把
```

### 2.3 FOB（装运港船上交货）成本构成 ★最常用★

```
FOB 成本价 = EXW 成本(¥)
           + 国内段运费(¥)        ← 工厂→深圳盐田港/阳江港拖车
           + 出口报关费(¥)        ← 固定 ¥200–500/票
           + 港杂费 THC(¥)        ← 按柜分摊，小批量按体积
           + 文件费/订舱费(¥)     ← B/L 费、DOC 费
           + 商检/产地证费(¥)     ← 如客户需要 CO/FORM A
           + 外贸公司运营分摊(¥) ← 人员、邮箱、独立站、推广
```

**常用港口参考**（广东出口）：
| 起运港 | 适合货物 | 特点 |
|--------|---------|------|
| 深圳盐田港 Yantian | 大批量整柜（FCL） | 航线最多、美西/欧洲基本港齐全 |
| 深圳蛇口 Shekou | 拼柜（LCL）、东南亚 | 近、拖车便宜 |
| 阳江港 / 广州南沙 | 本地出货、华南点 | 拖车短但航线少 |

**国内段费用分摊计算**（⚠️ 示例数字）：
```
假设：一个 20GP 柜可装 1,200 把该款厨刀
  工厂→盐田拖车费        = ¥2,800/柜
  报关费                 = ¥300/票
  THC 港杂费             = ¥850/柜
  文件费 DOC             = ¥450/票
  ─────────────────────────────────
  国内固定费用合计       = ¥4,400/柜
  每把分摊 = ¥4,400 ÷ 1,200 = ¥3.67/把
```

```
FOB 人民币成本 = EXW ¥30.80 + 国内分摊 ¥3.67 = ¥34.47/把
按报价汇率 6.60 折算 = $5.22/把
```

### 2.4 CIF（成本+保险+运费）成本构成

```
CIF 成本价 = FOB 成本($)
           + 国际海运费($)         ← 按柜或按体积(CBM)
           + 货运保险费($)         ← 货值 × 110% × 保险费率
```

**海运费计算要点**：
- **整柜 FCL**：20GP / 40HQ 按柜报价，直接问货代当周价格。
- **拼柜 LCL**：按 W/M（重量吨 vs 体积吨，取大者）计费，通常 $50–$150/CBM。
- **航线参考价**（⚠️ 2026 年示例区间，波动大，必问货代）：

| 航线 | 20GP 海运费($) | 40HQ 海运费($) | 航程 |
|------|---------------|---------------|------|
| 盐田→洛杉矶 LAX | $1,500–$3,000 | $2,500–$4,500 | 12–16 天 |
| 盐田→纽约 NYC | $2,500–$4,500 | $4,000–$7,000 | 28–35 天 |
| 盐田→汉堡 Hamburg | $2,000–$4,000 | $3,500–$6,500 | 28–35 天 |
| 盐田→悉尼 Sydney | $1,500–$2,800 | $2,500–$4,500 | 14–20 天 |
| 盐田→迪拜 Jebel Ali | $1,200–$2,500 | $2,000–$4,000 | 18–25 天 |

**保险费公式**：
```
货运保险费 = CIF 货值 × 110% × 保险费率
保险费率 ≈ 0.08%–0.2%（普通货物；易碎品/战争险另计）

实务简化：保险费 ≈ FOB 货值 × 1.1 × 0.1%
```

**示例计算**（⚠️ 示例数字）：
```
订单 1,200 把，FOB 货值 = 1,200 × $5.22 = $6,264
走盐田→洛杉矶 20GP，海运费 = $2,000
每把海运费分摊 = $2,000 ÷ 1,200 = $1.67/把
保险费 = $6,264 × 1.1 × 0.1% = $6.89 → $0.006/把（极小）

CIF 成本 = $5.22 + $1.67 + $0.01 = $6.90/把
```

### 2.5 DDP（完税后交货）成本构成

```
DDP 成本价 = CIF 成本($)
           + 目的港清关费($)       ← 客户国家报关行费用
           + 进口关税($)           ← 按 HS Code 税率 × 货值
           + 进口增值税($)         ← 美国无 VAT；欧洲 19%–21%；英国 20%
           + 目的国内陆派送($)     ← 港口→客户仓库卡车/快递
           + 代缴税费服务费($)     ← 货代或清关行加点
```

**⚠️ DDP 报价三大坑**：
1. **关税税率必须查 HS Code**。厨刀 HS Code 多为 8211.92（其他菜刀）或 8211.93。
   - 美国：对中国刀具加征 25% 301 关税 + 最惠国税率约 0%–7.2% → **实际综合税率可达 25%–32%**
   - 欧盟：最惠国税率约 8.8%，另加 VAT 19%–21%（VAT 可由进口商抵扣）
2. **DDP 不建议报小单**（<500kg）——清关费固定 $150–$300 摊到每把刀上极不划算。
3. **DDP 报价有效期必须更短**（7–15 天），因为目的国关税/派送费也会变。

**示例计算**（⚠️ 示例数字，美国 DDP）：
```
CIF 洛杉矶成本 = $6.90/把（见上）
美国清关费    = $200/票 → 1,200 把分摊 $0.17/把
301 关税 25%  = $6.90 × 25% = $1.73/把
内陆派送      = 港口→洛杉矶本地仓 $0.50/把
代缴服务费    = $0.20/把
─────────────────────────────────
DDP 成本 ≈ $6.90 + $0.17 + $1.73 + $0.50 + $0.20 = $9.50/把
```

## 三、加价策略（按客户类型选加价率）

> **核心原则**：加价率不是拍脑袋，是"覆盖固定成本 + 目标利润"的结果。
> 下面给出**行业参考加价区间**，公司实际加价率需 Leo 根据固定成本测算后确定。
>
> ⚠️ 以下加价率为行业参考区间，需填入公司实际数据。

### 3.1 五类客户的加价率参考

| 客户类型 | 加价率（在 FOB 成本之上） | 目标毛利率 | 谈判空间 | 理由 |
|---------|------------------------|-----------|---------|------|
| **大型进口商/连锁商超** | 15%–25% | 15%–20% | 留 3%–5% 可让 | 量大、复购稳、对价格极敏感 |
| **品牌商/Private Label** | 25%–40% | 25%–35% | 留 5%–8% 可让 | 要 ODM 开发、模具费、独家性 |
| **Amazon/Shopify 卖家** | 35%–60% | 30%–45% | 留 5%–10% 可让 | 量小、要 FBA 贴标、要快反、对价格不敏感 |
| **批发商/分销商** | 20%–30% | 18%–25% | 留 5% 可让 | 比价狠、要阶梯价 |
| **小客户/样品单/电商散客** | 60%–100%+ | 50%–60% | 几乎不让 | 服务成本高、量小、不指望复购 |

### 3.2 加价率计算公式

```
FOB 报价 = FOB 成本 ÷ (1 - 目标毛利率)

例：FOB 成本 $5.22，目标毛利率 30%
   FOB 报价 = $5.22 ÷ (1 - 0.30) = $5.22 ÷ 0.70 = $7.46/把
```

> ⚠️ 注意区分"成本加成"和"毛利率"：
> - **成本加成率** = 利润 ÷ 成本。成本 × (1+加成率) = 售价。
> - **毛利率** = 利润 ÷ 售价。成本 ÷ (1-毛利率) = 售价。
> - 两者数字接近但算法不同，**报价时统一用毛利率口径**（因为财务报表也是毛利率口径）。

### 3.3 汇率缓冲已含在加价里

```
报价用汇率 = 当日中间价 × (1 - 汇率缓冲系数)
汇率缓冲系数：常规 2%；汇率剧烈波动期 3%–5%

例：2026-09-24 中间价 6.7489
   常规报价汇率 = 6.7489 × 0.98 = 6.61
   波动期报价汇率 = 6.7489 × 0.95 = 6.41
```

## 四、阶梯报价计算示例（KL-KN-SS-012 基准价 $13）

> **SKU 信息**：KL-KN-SS-012，8" Chef Knife，5Cr15MoV，HRC 56-58，黑檀 Pakkawood 全柄。
> **公司 SKU 表基准价**：$13.00（⚠️ 这是 SKU 表的参考挂牌价，非 FOB 实际成交价）。
>
> ⚠️ 以下阶梯价为**示例计算，非公司实际定价**，用于演示阶梯报价的计算方法。
> 实际定价需根据工厂最新含税价、当前运费、目标毛利率重新核算。

### 4.1 示例假设条件（全部为示例）

| 项目 | 示例值 | 说明 |
|------|--------|------|
| 工厂含税出厂价 | ¥28.00/把 | 示例，需向工厂核实 |
| 内包装彩盒 | ¥2.50/把 | 示例 |
| 国内段费用分摊 | ¥3.67/把（整柜）/ ¥8.00/把（拼柜小单） | 量小分摊高 |
| 报价汇率 | 6.61（当日 6.75 × 0.98 缓冲） | 保守汇率 |
| 工厂→外贸公司加价前 FOB 成本 | 见下表逐档计算 | |

### 4.2 五档阶梯报价计算过程

#### 第 1 档：50 pcs（轻定制起订）
```
国内段费用：小批量走拼柜或快递样品级，分摊高 ≈ ¥8.00/把
EXW 成本 = ¥28.00 + ¥2.50 + ¥0.30 = ¥30.80
FOB 人民币成本 = ¥30.80 + ¥8.00 = ¥38.80
折美元 = ¥38.80 ÷ 6.61 = $5.87（成本）

客户类型：小客户/测款 → 加价率 60%–80%，取 70% 毛利率
FOB 报价 = $5.87 ÷ (1 - 0.70) = $5.87 ÷ 0.30 = $19.57
凑整报价 = $19.80/把 （或样品价 $22–25，含打样/Logo 费）

订单金额 = 50 × $19.80 = $990
```

#### 第 2 档：200 pcs（小批量 OEM）
```
国内段费用：200 把约 0.8 CBM，拼柜分摊 ≈ ¥6.00/把
FOB 人民币成本 = ¥30.80 + ¥6.00 = ¥36.80
折美元 = ¥36.80 ÷ 6.61 = $5.57

客户类型：Amazon 卖家/小品牌 → 目标毛利率 40%
FOB 报价 = $5.57 ÷ (1 - 0.40) = $9.28
凑整报价 = $9.50/把

订单金额 = 200 × $9.50 = $1,900
```

#### 第 3 档：500 pcs（中批量 OEM）
```
国内段费用：500 把约 2 CBM，可拼小柜或凑整柜分摊 ≈ ¥4.50/把
FOB 人民币成本 = ¥30.80 + ¥4.50 = ¥35.30
折美元 = ¥35.30 ÷ 6.61 = $5.34

客户类型：品牌商/批发商 → 目标毛利率 30%
FOB 报价 = $5.34 ÷ (1 - 0.30) = $7.63
凑整报价 = $7.80/把

订单金额 = 500 × $7.80 = $3,900
```

#### 第 4 档：1,000 pcs（整柜起点）
```
国内段费用：1,000 把近 20GP 满载，分摊 ¥3.67/把
FOB 人民币成本 = ¥30.80 + ¥3.67 = ¥34.47
折美元 = ¥34.47 ÷ 6.61 = $5.22

客户类型：进口商/连锁 → 目标毛利率 22%
FOB 报价 = $5.22 ÷ (1 - 0.22) = $6.69
凑整报价 = $6.90/把

订单金额 = 1,000 × $6.90 = $6,900
```

#### 第 5 档：≥5,000 pcs（年度框架/整柜多柜）
```
国内段费用：5,000 把可走 40HQ 或多柜，分摊进一步降至 ¥3.00/把
工厂端量大还可降价 5%–8%（示例工厂含税价降至 ¥26.00）
EXW 成本 = ¥26.00 + ¥2.50 + ¥0.30 = ¥28.80
FOB 人民币成本 = ¥28.80 + ¥3.00 = ¥31.80
折美元 = ¥31.80 ÷ 6.61 = $4.81

客户类型：大型进口商 KA → 目标毛利率 15%
FOB 报价 = $4.81 ÷ (1 - 0.15) = $5.66
凑整报价 = $5.80/把

订单金额 = 5,000 × $5.80 = $29,000
```

### 4.3 阶梯报价汇总表（示例）

| 数量档 | FOB 成本($/把) | 目标毛利率 | 报价($/把) | 订单总额($) | 客户画像 |
|--------|---------------|-----------|-----------|------------|---------|
| 50 pcs | $5.87 | 70% | **$19.80** | $990 | 测款/小客户 |
| 200 pcs | $5.57 | 40% | **$9.50** | $1,900 | Amazon 卖家 |
| 500 pcs | $5.34 | 30% | **$7.80** | $3,900 | 品牌商/批发商 |
| 1,000 pcs | $5.22 | 22% | **$6.90** | $6,900 | 进口商 |
| 5,000 pcs | $4.81 | 15% | **$5.80** | $29,000 | KA 年度框架 |

> 📌 **报价展示技巧**：给客户看阶梯价时，从高到低排（500/1000/2000），
> 让客户觉得"加量立刻省 X%"。例如 500→1000 档单价降 $0.90（-11.5%），
> 引导客户从 500 加量到 1000。

## 五、报价有效期管理

### 5.1 有效期策略表

| 场景 | 有效期 | PI 备注话术 |
|------|--------|------------|
| 常规市场、汇率平稳 | **30 天** | "This PI is valid for 30 days." |
| 汇率波动 >1%（一周内） | **7–15 天** | "Due to FX fluctuation, this offer is valid for 7 days." |
| 原材料涨价周期（钢材大涨） | **7 天** | "Raw material prices rising, valid 7 days only." |
| 大额订单 ≥$50,000 | **7–15 天** | 敞口大，缩短有效期 |
| 海外仓现货（已备货） | **30–60 天** | 成本已锁定，可放长 |
| DDP 报价 | **7–15 天** | 目的国关税/运费波动大 |

### 5.2 PI 中必须写明的价格保护条款

```
Validity: This Proforma Invoice is valid for 15 days from the date of issue.
Prices are based on USD/CNY exchange rate at the time of quotation.
Should the exchange rate fluctuate by more than ±3% from the quoted rate,
prices are subject to renegotiation.
Should raw material (stainless steel) prices rise by more than 5%,
prices are subject to adjustment.
```

### 5.3 有效期内客户迟迟不下单怎么办

1. **第 7 天**：发一封跟进邮件，附产品图/案例，不催价。
2. **第 14 天**：提醒"本周价格仍有效，下周三起可能调整"。
3. **第 21 天**：如客户仍犹豫，重新核价——要么给"锁价定金"方案（$500 不可退定金锁定当前价 30 天），要么礼貌更新报价。

## 六、常见报价错误与避坑指南

| # | 错误做法 | 后果 | 正确做法 |
|---|---------|------|---------|
| 1 | **用当天即期汇率直接报价，不留缓冲** | 人民币一升值，利润被吃掉 | 报价汇率 = 中间价 × 0.98，留 2%–3% 安全垫 |
| 2 | **忘了算港杂费/文件费** | FOB 报价亏损 | FOB 成本必须含 THC、报关、DOC、订舱 |
| 3 | **CIF 只算海运费，忘算保险** | 差一点小钱但累积 | 保险费 = 货值 × 110% × 0.1%，虽小但要列 |
| 4 | **DDP 没查 HS Code 关税** | 美国 301 关税 25% 直接吃掉利润 | DDP 前必查 HS Code + 目的国税率 |
| 5 | **报 EXW 价给不懂货代的客户** | 客户以为全包，收货后怒投诉 | 不懂进口的客户一律报 FOB 或 CIF/DDP |
| 6 | **一个价报所有客户** | Amazon 卖家嫌贵走了，进口商嫌赚多了 | 按客户类型选加价率，不一个价打天下 |
| 7 | **样品价和大货价一样** | 小单亏服务费 | 样品价 = 大货价 × 2–3 倍，或单独收打样费 |
| 8 | **报价有效期写"长期有效"** | 半年后客户拿旧 PI 回来下单，按旧价亏 | 必写 15–30 天 + 汇率波动重议条款 |
| 9 | **人民币成本÷汇率时用银行买入价** | 结汇时才发现少了 1% | 用结汇中间价再打 2% 缓冲，不要用银行现汇买入价 |
| 10 | **没算外贸公司运营分摊** | 看似有毛利，实际覆盖不了工资/服务器/推广 | FOB 成本里必须含 3%–8% 运营分摊 |
| 11 | **报价只报一个总价，不分项** | 客户砍价时无处让，显得不透明 | 产品价 / 包装 / Logo / 运费分开列 |
| 12 | **忘了报 MOQ** | 客户要 10 把，工厂起订 50 把，尴尬 | PI 里写明 MOQ，样品单单独报价 |
| 13 | **PayPal 收大货款不扣手续费** | 4.4% 手续费吃掉一半毛利 | PayPal 订单单价加 5% 手续费，或大额要求 T/T |
| 14 | **把退税忘了算进利润** | 实际利润比账面高，但定价时不知道空间 | 退税（13% 增值税退税）可作为降价空间或额外利润，单独核算 |

### 6.1 出口退税速算（重要利润来源）

```
出口退税额 = 不含税采购成本 × 退税率

刀具类出口退税率：通常 13%（以最新税务局编码为准，⚠️ 需向财务确认）

示例（⚠️ 示例数字）：
  工厂含税采购价 ¥28.00（含 13% 增值税）
  不含税价 = ¥28.00 ÷ 1.13 = ¥24.78
  退税额 = ¥24.78 × 13% = ¥3.22/把

💡 这 ¥3.22 就是每把刀的额外利润空间！
   谈判时最多可让 ¥3.22/把（约 $0.49/把）而不亏本金。
```

## 八、报价自查清单（发 PI 前过一遍）

- [ ] 客户类型判断正确？（进口商/品牌商/Amazon/批发/小客户）
- [ ] 用的是保守报价汇率（中间价 × 0.98）？
- [ ] FOB 成本含国内运费、报关、THC、文件费？
- [ ] CIF 已加海运费 + 保险？
- [ ] DDP 已查 HS Code 关税 + 增值税 + 派送？
- [ ] 加价率符合客户类型？
- [ ] 报价高于底线价（成本 ÷ 0.7）？
- [ ] 阶梯价从高到低排列，引导加量？
- [ ] 有效期写了 15–30 天（波动期 7 天）？
- [ ] PI 里有汇率波动 ±3% 重议条款？
- [ ] 分项列价（产品/包装/Logo/运费）？
- [ ] MOQ 写清楚了？
- [ ] 付款条款是 30% 定金 + 70% 尾款？
