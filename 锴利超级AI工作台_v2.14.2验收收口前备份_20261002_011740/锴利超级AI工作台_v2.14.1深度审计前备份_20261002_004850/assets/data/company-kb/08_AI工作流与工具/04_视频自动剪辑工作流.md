# 视频自动剪辑工作流

> 用途：豆包 + 剪映 Skill 自动剪辑工厂短视频，降本提效。

## 一、三层原理

1. **豆包 / WorkBuddy** = 能操作电脑的 AI（读写文件、控制剪映）。
2. **剪映** = 被操作对象（草稿是结构化工程文件）。
3. **Skill** = 操作手册 / 剪辑 SOP。

## 二、五金刀剪 5 步生产线

```
找爆款 → 反推分镜表 → 拍自己工厂素材 → 豆包+剪映Skill自动粗剪 → 人工微调导出
```

1. **找爆款**：抖音/TikTok 搜 knife making / forging。
2. **反推分镜表**：用爆款反推工作台。
3. **拍自己工厂素材**：对齐分镜表实拍。
4. **自动粗剪**：豆包+剪映 Skill 完成粗剪/卡点/字幕/BGM/转场。
5. **人工微调导出**：人工复核后导出。
