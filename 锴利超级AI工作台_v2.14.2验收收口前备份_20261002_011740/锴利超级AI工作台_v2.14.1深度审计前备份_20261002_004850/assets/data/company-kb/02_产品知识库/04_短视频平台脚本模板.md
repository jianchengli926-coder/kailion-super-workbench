# 短视频平台脚本模板（TikTok / Reels / Shorts）

> 本文件是 KaiLionCrafts 在三大短视频平台的爆款脚本母版，含通用结构、5 个可直接拍摄的完整脚本、音乐与标签建议。
>
> **脚本语言为英文（面向海外用户），说明文字为中文。**

---

## 一、三大平台通用爆款结构

### 1.1 TikTok 爆款公式（3-15-5 Rule）

| 段落 | 时长 | 任务 | 常见错误 |
|---|---|---|---|
| **HOOK（钩子）** | 0–3s | 第一帧必须是最冲击力画面 + 第一句话制造反差/好奇 | 用 logo 动画开头；开头 3 秒无信息量 |
| **VALUE（价值）** | 3–18s | 展示产品 + 解决一个具体痛点 + 真实演示 | 只讲参数不演示；镜头超过 3 秒不切 |
| **CTA（行动号召）** | 18–25s | 折扣码 + 链接 + 明确指令 | 只说 "link in bio" 不读折扣码 |

### 1.2 Instagram Reels 差异点

- **前 3 秒**：竖屏 9:16，字幕必须居中（IG 用户常静音刷）；
- **音乐**：用 Instagram 热门 Commercial Music Library（商用授权曲库）；
- **节奏**：比 TikTok 稍慢，偏美学/生活方式；
- **文案**：第一行必须 hook（不要把钩子放"展开更多"后面）。

### 1.3 YouTube Shorts 差异点

- **时长**：60 秒内（最长 3 分钟，但 30–45 秒完播率最高）；
- **标题**：SEO 重要，写 "I tested a $X chef knife for 30 days" 这类搜索词；
- **结尾**：引导订阅（"Subscribe for more knife tests"）；
- **复用**：TikTok 原片可直接上传，但前 3 秒字幕要更大。

## 二、5 个可直接拍摄的脚本示例

### 脚本 1 · 厨刀爆款（Chef Knife · 25s TikTok/Reels）

**主题**：痛点对比——"我把 $200 的刀扔了"

| 时间 | 画面 | VO / Text on Screen | 字幕 |
|---|---|---|---|
| 0–3s | 主播对着镜头，手里举一把明显钝的超市刀 | (主播口播) *"I've been cooking with a $20 dull knife for 5 years. Then I tried this."* | **I wasted $200 on fancy knives.** |
| 3–8s | 切番茄：旧刀压出水；新刀干净切开（分屏） | *"Watch the difference. Tomato, old knife vs. this one."* | Old knife vs. factory-direct |
| 8–15s | 切纸超慢动作 + 切洋葱透光片 | *"15-degree edge. Paper-thin slices, zero effort."* | 15° V-edge · HRC 56–58 |
| 15–20s | 手指弹刀身，听清脆声；展示 G10 手柄 | *"Full-tang G10 handle. Balanced. Doesn't slip."* | Full-tang G10 |
| 20–25s | 产品立在黑背景前，弹出折扣码 | *"20% off with code KAILION20 — link in bio."* | **20% OFF · KAILION20** 🔗 |

**Hashtags**：`#chefknife #knifetok #kitchenhacks #foodtok #cooking #knifereview #tiktokmademebuyit`

## 三、音乐 / 标签 / 字幕风格建议

### 3.1 热门音乐方向（2026 TikTok/Reels）

| 内容类型 | 音乐风格 | 参考方向 |
|---|---|---|
| **切菜 ASMR / 锋利展示** | 无 BGM，纯同期声 + 低沉鼓点 | 切菜声、磨刀声放大 |
| **工厂揭秘 / 火花** | 工业电子 / Epic Cinematic | 重低音鼓点 + 上升音效 |
| **厨房 hack / 小工具** | TikTok 热门轻快 Pop / Trend Sound | 用 Creative Center 当周热门 |
| **户外 EDC / Bushcraft** | 民谣吉他 / Lo-fi | 自然风声 + 吉他 |
| **高端大马士革** | 古典钢琴 / 电影感弦乐 | 慢、高级、留白 |

> **工具**：TikTok Creative Center（creativecenter.tiktok.com）→ Songs → 选 "Kitchen" / "Outdoors" 类目当周上升音乐。

### 3.2 Hashtag 策略（每条 5–8 个，不要 20 个）

| 类型 | 用法 | 例子 |
|---|---|---|
| **大流量标签（1–2 个）** | 泛流量，蹭推荐池 | `#tiktokmademebuyit`、`#foodtok` |
| **垂类标签（2–3 个）** | 精准受众 | `#chefknife`、`#knifetok`、`#bushcraft` |
| **品类标签（1–2 个）** | 转化向 | `#kitchengadgets`、`#bbqtools` |
| **品牌标签（1 个）** | 沉淀品牌搜索 | `#KaiLionCrafts` |

### 3.3 字幕风格

| 项目 | 规范 |
|---|---|
| 字体 | Montserrat / Bebas Neue / Luckiest Guy（TikTok 感） |
| 大小 | 占屏宽 80%，手机小屏必须看得清 |
| 颜色 | 白字 + 黑色描边（任何背景都清晰）；关键词用品牌色（橙/红）高亮 |
| 位置 | 画面中下 1/3，不要挡产品 |
| 动效 | 关键词逐字弹出（Pop），不要花哨飞入飞出 |
| 语言 | 全英文；不要中英双语（海外用户看不懂中文） |

## 四、发布节奏建议

| 平台 | 频率 | 最佳发布时间（美东） |
|---|---|---|
| TikTok | 每天 1 条，至少 5 条/周 | 周三–周日 11am / 7pm |
| Instagram Reels | 每周 3–4 条 | 周二–周四 12pm / 6pm |
| YouTube Shorts | 每周 3 条 | 周四–周六 3pm |

> 同一套素材：横屏拍工厂/产品，竖屏剪 TikTok/Reels/Shorts，一鱼三吃。
