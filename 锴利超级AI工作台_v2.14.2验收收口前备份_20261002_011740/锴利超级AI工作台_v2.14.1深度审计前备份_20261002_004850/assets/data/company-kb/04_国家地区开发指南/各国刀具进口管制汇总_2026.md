# 各国刀具进口管制汇总（2026 更新版）

> ⚠️ **法律免责声明**：本文件为业务参考汇编，不构成法律意见。各国刀具法频繁更新（欧洲2025–2026持续收紧），发货前必须与目的国报关行/清关代理逐票确认。
> 核心红线：**自动刀(OTF/switchblade)、蝴蝶刀(balisong)、重力刀(gravity knife)、僵尸刀(zombie knife)在全球绝大多数市场禁止进口/销售**。KaiLionCrafts 产品矩阵聚焦手动折刀与固定刃厨刀/户外刀，不做自动刀。
> 已有逐国市场文件：`04_国家地区开发指南/01_北美_美国加拿大.md` 等。

## 二、重点国家详解

### 2.1 美国（联邦 + 各州）
| 项目 | 内容 |
|---|---|
| 联邦法律 | Federal Switchblade Act 1958 (15 U.S.C. §§1241-1245)；19 CFR §12.97 |
| 禁止进口 | Switchblade（按钮/弹簧自动）、gravity knife、ballistic knife、balisong/butterfly |
| 允许进口 | 普通折刀(pocketknife)、直刀/sheath knife、猎刀、machete、厨刀 |
| 州法差异 | 加州：≥2"自动刀禁售；纽约市：携带刃≥4"违法；德州 2017 HB1935 全面合法化自动刀 |
| 年龄 | 18+（多数州） |
| 原产国标记 | 19 U.S.C. 1304 英文永久 "Made in China" |
| 关税 | HTSUS 8211；中国原产加征 301 关税 |
| 来源 | https://www.govinfo.gov/content/pkg/CFR-2022-title19-vol1/pdf/CFR-2022-title19-vol1-sec12-97.pdf |

### 2.2 英国（2025–2026 重大更新）
| 项目 | 内容 |
|---|---|
| 法律 | Restriction of Offensive Weapons Act 1959；CJA 1988 §139；Offensive Weapons Act 2019；**Crime and Policing Act 2026** |
| 禁止进口/销售 | flick knife/switchblade、butterfly、gravity、stiletto、push dagger、knuckle knife、伪装刀；**2024-09 起 zombie knife；2025-08-01 起 ninja sword** |
| 豁免 | "Folding pocket knife"：刃≤3英寸(7.62cm)且**无锁定装置**；锁定折刀即使短也不豁免公共携带 |
| 2026 新法 | 线上销售**两步年龄验证**（下单证件+人脸，配送再核验）；批量销售报告义务；非锁定≤3"折刀豁免年龄验证 |
| 年龄 | 18+；网上销售须年龄验证+本人签收 |
| 来源 | https://www.gov.uk/government/publications/crime-and-policing-act-2026-factsheets/crime-and-policing-act-2026-knife-crime-and-crossbows-factsheet |

### 2.3 德国
| 项目 | 内容 |
|---|---|
| 法律 | Waffengesetz (WaffG) §42a；2024-10-30 安全包进一步收紧 |
| 绝对禁止 | Butterflymesser、Fallmesser（重力刀）、Springmesser（弹簧刀）、Faustmesser（拳套刀） |
| 携带禁令 | ①双刃匕首；②单手可开并锁定折刀(Einhandmesser)；③固定刃>12cm |
| 例外 | 职业/狩猎/体育用途；运输须封闭容器 |
| 建议出口规格 | 非锁定折刀、直刀≤12cm |
| 来源 | https://www.gesetze-im-internet.de/waffg_2002/BJNR397010002.html |

### 2.4 法国（2025 持续收紧）
| 项目 | 内容 |
|---|---|
| 法律 | Code de la sécurité intérieure R.311-2；Arrêté 4 juil 2025；Décret 2025-894 |
| 分类 | A类(禁)/B类(许可)/C类(登记)/D类(自由购买，携带需理由) |
| 2025-07 新增 D a类 | 蝴蝶刀、自动开启锁定折刀、手里剑——商店须省级授权，过渡期至 2026-03-07 |
| 2025-09 新增 A1类 | "Zombie knives"（固定刃+单面刃+尖端+锯齿+多孔装饰）——禁制造/进口/销售/持有 |
| 普通折刀 | D类：可自由购买，公共携带需"正当理由"(port licite) |
| 来源 | https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000051849523 |

### 2.5 日本
| 项目 | 内容 |
|---|---|
| 法律 | 銃砲刀剣類所持等取締法（铳刀法） |
| 禁止 | 飛び出しナイフ（自动刀）不论刃长 |
| 锁定折刀 | ≥5.5cm 锁定刀 = 刀剣类，需公安委员会登录 |
| 直刀 | ≥15cm 需公安委员会登录 |
| 建议出口 | 厨刀不受影响；户外刀选非锁定折刀或短刃 |

### 2.6 澳大利亚
| 项目 | 内容 |
|---|---|
| 法律 | Customs (Prohibited Imports) Regulations 1956 Schedule 13 |
| 禁止进口 | automatic/flick/assisted opening、dagger、ceramic knife、throwing knife、balisong、knuckle knife |
| 允许进口 | 手动单刃折刀（联邦层面）、厨刀、猎刀（手动） |
| 注意 | 各州持有/携带法不同；维州/新州较严 |
| 来源 | https://www.abf.gov.au/ |

### 2.7 加拿大
| 项目 | 内容 |
|---|---|
| 法律 | Criminal Code s.84(1)；C-46 法案 |
| 禁止 | 重力刀(gravity)、离心刀、按钮自动刀 = prohibited weapon |
| 允许 | 手动折刀、手动直刀（联邦无刃长上限） |
| 注意 | 2022 年起禁止销售 26 种"assault-style"枪支，刀具未跟进；但弹簧辅助折刀灰色 |

### 2.8 意大利（2026 新法）
| 项目 | 内容 |
|---|---|
| 法律 | Legge 110/1975；DL 23/2026 安全法令 |
| 要点 | snap/switchblade ≥5cm 刑事罪；≥5cm 带锁/单手开折刀需正当理由；>8cm 直刀携带需理由 |
| 建议出口 | ≤5cm 非锁定折刀、≤8cm 直刀 |

### 2.9 西班牙
| 项目 | 内容 |
|---|---|
| 法律 | RD 137/1993 Art.4-5 |
| 禁止 | 自动 navaja 任何长度；匕首类 |
| 限制 | 非自动 navaja >11cm 禁售 |

### 2.10 荷兰/比利时/瑞典/波兰/捷克/匈牙利/葡萄牙/希腊

|---|---|
| 荷兰 | 折叠刀公共场合原则禁（除非工具理由）；自动/蝴蝶禁 |
| 比利时 | >10cm 折刀公共携带禁；双刃/匕首禁；https://justice.belgium.be/ |
| 瑞典 | 购刀年龄 21+；公共携带需理由 |
| 波兰 | 折刀视为工具但公共携带需理由；自动禁 |
| 捷克 | 2023-01 起折叠刀公共携带禁（除非职业理由）——欧洲最严之一 |
| 匈牙利 | 匕首/双刃禁；折刀携带需理由 |
| 葡萄牙 | >11cm 折刀公共携带禁；匕首禁 |
| 希腊 | 自动/蝴蝶禁；公共携带需理由 |

| 国家 | 要点 |
|---|---|
| 阿联酋 | 厨刀可进口；户外刀需证明户外用途；自动刀禁；进口需许可 |

### 2.12 新加坡/香港
| 地区 | 要点 |
|---|---|

## 三、KaiLionCrafts 合规产品策略

1. **红线品类（不做）**：OTF、switchblade、gravity knife、balisong/butterfly、knuckle knife、伪装刀、zombie knife、ninja sword、双刃匕首。
2. **欧洲客户首选规格**：
   - 厨刀：全合规（食品接触 + GPSR）。
   - 户外/折刀：**非锁定**、手动开启、刃长 ≤8cm（意/西/葡更友好）；德国客户避免单手开锁定折刀。
3. **B2C 直邮**：
   - 英国/欧洲：18+ 年龄验证配送；英国须两步年龄验证（2026 新法）。
   - 文案避免 "tactical/combat/self-defense/fighting"，改用 "outdoor/camping/hunting/kitchen/BBQ"。
4. **HS 编码**：厨刀 8211.91/92；折刀 8211.93；套刀 8211.10；剪刀 8213.00。
5. **发货前检查清单**：
   - [ ] 目的国是否禁止该刀型？
   - [ ] 刃长是否超当地携带阈值？
   - [ ] 是否锁定？单手开？（欧洲敏感）
   - [ ] 是否需装运前认证（SONCAP/PVoC/SABER）？
   - [ ] B2C 直邮年龄验证是否配置？
