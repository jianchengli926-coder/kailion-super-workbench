### 1. 完整意图引擎升级（8→25条规则）

**文件**: `assets/js/smart.js` (141→568行), `assets/js/ui.js`

**升级内容**:
- **25条意图规则**: 覆盖产品图精修、询盘回复、规格表/合规、独立站SEO、供应商比价、电商详情页、带货脚本、图文笔记、AI出图、图生图、视频生成、漫剧分镜、PPT、Word文档、Excel表格、HTML网页、品牌IP全案、个人IP、专家讨论、专家协作、选品到上架、内容合规审查、数据洞察报告、播客脚本
- **槽位抽取**: 数量(count)、页数(pages)、屏数(screens)、镜头数(shots)、变体数(variants)、画幅(ratio)、时长(duration)、风格(style)、平台(platform)、语言(lang)、分辨率档位(tier)、像素串(pixels)
- **中文数字解析**: 支持「三张」「两页」「十个」等中文数量词

- **AI助手集成**: ui.js的小锴助手respond()优先调用意图引擎，保留画布操作指令

**使用方式**: 在智能工作台或小锴助手中输入自然语言，如「生成3张白底产品图，横屏」「做一份8页海外招商PPT」「写回复询盘的英文邮件」

### 2. 本地CORS网桥

**文件**: `cors-proxy/server.js` (222行), `cors-proxy/server.py` (206行), `cors-proxy/README.md` (161行)

**功能**:
- 零依赖Node.js版本（仅用内置http/https模块）
- 零依赖Python版本（仅用内置http.server/urllib）
- 默认监听8787端口，支持自定义端口
- 支持HTTP和HTTPS目标转发
- 三种目标URL指定方式：
  - 请求头 `X-Target-URL: https://api.example.com/v1/chat`
  - 路径 `/proxy?url=https://api.example.com/v1/chat`
  - 路径形式 `/https://api.example.com/v1/chat`
- 自动添加CORS响应头（Access-Control-Allow-Origin: *等）
- OPTIONS预检请求直接返回204
- Node.js版流式pipe转发，Python版分块flush兼容SSE
- 目标不可达返回502友好错误，进程不崩溃

**工作台集成**: 设置页→CORS代理→启用开关+地址配置，开启后api.js所有请求自动通过代理转发

**启动方法**:
```bash
node cors-proxy/server.js
# 或
python3 cors-proxy/server.py
# 自定义端口
node cors-proxy/server.js --port=9000
```

## 中优先级功能详情

### 3. 模型自动发现 ensureModels

**文件**: `assets/js/providers-data.js` (348→543行)

**功能**:
- 点击供应商管理页的「🌐 从API获取」按钮，自动调用 `GET {baseUrl}/models`
- 10秒超时，按钮显示加载状态
- 兼容多种API返回格式：
  - OpenAI标准：`{ data: [{ id: "gpt-4o" }] }`
  - Gemini：`{ models: [{ name: "models/gemini-1.5-pro" }] }`（自动去掉models/前缀）
  - 通用：`items` 数组或裸数组
- 获取到的模型自动去重并填充到模型列表
- 失败时友好toast提示（401未授权/404接口不存在/超时/网络错误）
- `Providers.ensureModels(provider)` 函数可在添加供应商后自动调用

**新增供应商预设**:
- **Ollama 本地模型**: `http://localhost:11434/v1`，预设6个模型（llama3.1/qwen2.5/mistral/gemma2/phi3/nomic-embed-text）
- **硅基流动 SiliconFlow**: `https://api.siliconflow.cn/v1`，预设4个模型（Qwen2.5-7B/DeepSeek-V3/GLM-4-9B/Qwen2-VL-7B）

### 5. localStorage配额自愈

**文件**: `assets/js/app.js`

**功能**:
- 全局 `safeSetItem(key, value)` 函数，monkey-patch `localStorage.setItem`
- 捕获 `QuotaExceededError` 后自动执行清理策略：
  1. 清理最旧的运行历史（保留最新10条）
  2. 清理API调用日志（保留最新50条）
  3. 清理节点结果缓存（保留最新10条）
  4. 扫描所有localStorage，删除>100KB的base64图片大值（转存BlobStore）
  5. 重试写入
- 清理成功后toast提示「存储空间不足，已自动清理旧数据」
- 仍失败时提示「存储空间严重不足，请手动清理数据」
- 所有模块的localStorage写入自动受益，无需逐个修改

### 8. 多模态图片预处理

**文件**: `assets/js/imagetools.js` (378→862行)

**功能**:
- `ImageTools.openPreprocessor(imageSource, onApply?)` 打开预处理模态框
- 模态框布局：左侧原图/处理后预览双栏，右侧参数面板，底部操作栏
- **图片压缩**: 质量滑块0.1-1.0（步长0.05，默认0.92），实时显示文件大小
- **格式转换**: PNG/JPEG/WebP三种格式
- **尺寸调整**: 宽高输入框+锁定比例开关+25%/50%/75%/100%/200%预设
- **裁剪**: X/Y/W/H输入框+自由/1:1/4:3/16:9/9:16居中预设
- **旋转**: ↺左转90° / ↻右转90°（可叠加，自动交换宽高）
- **翻转**: ⇋水平翻转 / ⇵垂直翻转
- **实时预览**: 参数变更后300ms防抖重新渲染
- **操作按钮**: 下载、重置、关闭、应用（传入回调时）
- 兼容输入：dataURL/Blob URL/Blob/File/HTMLImageElement
- 两阶段Canvas管线：裁剪+翻转 → 旋转+缩放，JPEG自动铺白底

### 11. pruneBlobs孤儿二进制清理

**文件**: `assets/js/blobstore.js`, `assets/js/app.js`, `index.html`

**功能**:
- `BlobStore.pruneBlobs(extraKeepIds)` 函数
- 遍历IndexedDB中所有存储的blob
- 对比当前工作流状态和localStorage中的blob引用
- 找出未被任何地方引用的孤儿blob并删除
- 返回 `{ removed: count, freedBytes: totalSize }`
- 设置页→数据备份区→「🧹 清理孤儿文件」按钮
- 点击后显示「已清理 N 个文件，释放 X KB空间」

## 使用指南

## 已知限制

1. MCP服务器管理为纯前端配置管理，实际执行需在Electron桌面端加载配置
2. 图片预处理的裁剪功能使用输入框方式，未实现拖拽选框（简化实现）
3. CORS代理需用户手动启动本地脚本，未集成到Electron主进程
4. localStorage自愈的图片转存BlobStore功能依赖BlobStore模块可用性
5. 语义资源库数据存储在localStorage中，大量数据可能触发配额自愈
