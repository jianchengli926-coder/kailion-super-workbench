# 各国产品认证要求矩阵（Country × Category Certification Matrix）

> **用途**：客户开发/报价/接单时快速查询目的国认证与刀具管制要求。
> **覆盖**：60个国家/地区 × 4大品类（厨刀/户外刀/剪刀/厨房用品）。
> ⚠️ **免责声明**：本矩阵为业务参考汇编，不构成法律意见。法规更新频繁，发货前必须与目的国报关行/清关代理书面确认。不确定项标注"待确认"。

---

## 一、使用说明

### 1.1 如何使用本矩阵

1. **客户询盘时**：先查"目的国"行，确认该国有无强制认证、刀具管制红线。
2. **报价时**：将强制认证费用和周期纳入报价；推荐认证作为增值服务告知客户。
3. **接单前**：对照"出货前认证检查清单"（本文末节）逐项确认。
4. **发货前**：将品名、刃长、刀型、HS Code发给目的国报关行，取得书面放行确认。

### 1.2 图例说明

| 标记 | 含义 |
|---|---|
| ✅ 强制 | 法律要求必须办理，无证不得清关/销售 |
| 🟡 推荐 | 非法律强制，但客户/渠道/零售商普遍要求 |
| ⬜ 不适用 | 该品类不需要此认证 |
| ⚠️ 受限 | 有刃长/结构/年龄/许可证限制 |
| 🚫 禁止 | 该刀型/品类禁止进口 |
| ❓ 待确认 | 信息不足，出货前必须与客户/报关行确认 |
| 🔍 信息有限 | 小市场，建议出货前与客户确认 |

## 二、国家×品类认证矩阵

### 2.1 北美（3国）

#### 🇺🇸 美国（United States）—— 重点市场

| 维度 | 要求 |
|---|---|
| **厨刀认证** | ✅ FDA 21 CFR Part 170-199（食品接触，事实强制，无预批准，第三方测试报告即可）；🟡 ASTM F2210自愿性质量标准 |
| **户外刀认证** | ⬜ 无法定强制认证；✅ 联邦Switchblade Act禁止进口自动刀/OTF/蝴蝶刀；🟡 Prop 65（加州，含铅/镉/镍须警告标签） |
| **剪刀认证** | ✅ FDA（厨房剪接触食品）；🟡 Prop 65（加州）；⬜ CPSIA仅儿童安全剪刀适用 |
| **厨房用品认证** | ✅ FDA 21 CFR（食品接触）；🟡 Prop 65（加州）；电动款需UL/ETL（非手动） |
| **食品接触要求** | 21 CFR 170-199；铅迁移<0.005 µg/mL；不锈钢耐腐蚀无毒；制造商自行合规，FDA不发证书 |
| **刀具管制** | 🚫 联邦禁止switchblade/OTF/gravity/ballistic/butterfly进口；✅ 手动直刀/手动折刀/猎刀联邦可进；州法差异大：加州≥2"自动刀禁售、NYC市内携带≥4"违法、德州2017年全面合法化自动刀 |
| **标签/包装** | ✅ 19 U.S.C. 1304强制英文永久标注"Made in China"；🟡 加州Prop 65警告标签（如适用）；英文说明书；电动款需UL/ETL标志 |

> **KaiLionCrafts状态**：FDA铅迁移测试已通过（cert-14）；Prop 65专项待确认。

### 2.2 欧洲（25国）

> **欧盟通用框架**：以下22个欧盟成员国（除英国外）适用统一规则——CE标志（纯手动刀剪不强制）、REACH SVHC（所有出口欧盟产品）、RoHS（仅电子电气）、EU 1935/2004食品接触、GPSD通用产品安全。各国差异主要在**国内刀具持有/携带法**和**本地语言标签**。

#### 🇩🇪 德国（Germany）—— 重点市场

| 维度 | 要求 |
|---|---|
| **厨刀认证** | ✅ EU 1935/2004食品接触（强制）；✅ **LFGB**（德国市场事实门槛，比EU更严，含感官测试DIN 10955）；🟡 CE（手动刀剪不强制） |
| **户外刀认证** | ✅ REACH SVHC；⬜ 无食品接触要求；⚠️ 刀具管制极严 |
| **剪刀认证** | ✅ EU 1935/2004（厨房剪）；✅ LFGB（德国客户普遍要求）；🟡 EN 12506家用剪刀安全标准 |
| **厨房用品认证** | ✅ EU 1935/2004；✅ LFGB（德国客户）；🟡 FSC（木/竹柄） |
| **食品接触要求** | LFGB + BfR Recommendations；总迁移量+重金属溶出+感官测试；德国零售商几乎必看LFGB报告 |
| **刀具管制** | 🚫 Springmesser（弹簧刀）/Butterflymesser（蝴蝶刀）/Fallmesser（重力刀）/Faustmesser（拳套刀）绝对禁止进口销售；⚠️ 单手开启并锁定的折刀（Einhandmesser）禁止公开携带；⚠️ 固定刃>12cm禁止公开携带；双手开启非锁定折刀不受限 |
| **标签/包装** | ✅ 德语标签/说明书；EU 1935/2004 Article 15要求："for food contact"标识+制造商名称地址+安全使用说明；原产国标记 |

> **KaiLionCrafts状态**：LFGB已通过（cert-07 SGS DMS-052双项PASS）；REACH SVHC待确认。

## 四、常见问题FAQ

### Q1：客户问"这个国家需要什么认证？"怎么快速回答？

**回答模板：**
> "根据我们的合规数据库，出口【国家名】需要：①【强制认证A】（必须，费用约$X，周期X周）；②【推荐认证B】（客户常要求但非法律强制）；③食品接触材料需符合【标准名】。我们已有【现有证书名】覆盖了其中X项。请问您那边对认证有具体要求吗？我们可以根据您的清关要求定制方案。"

### Q2：客户只做B2B批发，还需要办目的国认证吗？

**答：** 需要。B2B进口同样受目的国海关监管。特别是：
- 沙特SABER、尼日利亚SONCAP、肯尼亚PVoC、埃及GOEIC——**每批出货都需要**，与B2B/B2C无关。
- 欧盟REACH/FDA——B2B也需要，客户会在合同里要求提供测试报告。
- 美国原产国标记"Made in China"——B2B必须。

### Q3：一把刀剪产品能覆盖多少个国家？

**答：** 一份SGS LFGB食品接触报告在全球认可度最高——可同时覆盖德国LFGB、欧盟1935/2004、英国UK FCM、法国DGCCRF、北欧国家、澳洲FSANZ参考。加上FDA 21 CFR报告覆盖美国。**已有LFGB+FDA两份报告，可覆盖约40+个国家的食品接触要求**，剩下的是各国装运前COC认证（SABER/SONCAP/PVoC等）。

### Q4：客户说"我们那边不用认证，你直接发货就行"，能信吗？

**答：** 不能全信。分两种情况：
- **小批量样品/快递**：可能确实不查验，但大货到港被扣风险极高。
- **B2B大货**：客户可能是进口商，他自己清楚需要什么认证但想让你承担成本。务必让客户**书面邮件确认**"该国不需要XX认证即可清关"，并留存记录。

### Q5：自动刀/OTF/蝴蝶刀能出口吗？

**答：** **不要尝试。** 除美国德州（2017年合法化）外，几乎所有主要市场（美联邦、加、澳、日、英、德、法、荷、新、菲）都禁止进口或销售自动刀/蝴蝶刀。KaiLionCrafts产品矩阵聚焦手动折刀和固定刃，不做自动刀。

### Q6：欧洲客户要什么刀型最安全？

**答：** 给欧洲客户推荐：
- **直刀**：刃长≤8cm（意大利阈值），优先≤12cm（德国阈值）
- **折刀**：非锁定、双手开启、刃长≤5cm（意大利带锁阈值）或≤7.62cm（英国豁免阈值）
- **避免**：单手开启（thumb stud + liner lock）、弹簧辅助、双刃、锯齿、战术/Zombie风格

### Q7：中东市场能发户外刀吗？

**答：** 谨慎。沙特必须SABER注册，自锁折刀/长户外刀无资质必扣货；UAE多家物流直接禁运hunting/tactical刀。**中东建议只发家用厨刀/厨房用品类**，户外刀走B2B正式报关+当地持牌进口商。

### Q8：认证报告有效期多久？换材料要重测吗？

**答：** 
- 食品接触报告（FDA/LFGB/EU 1935/2004）：**材料不变则永久有效**；换钢材等级、换手柄材料（POM/G10/木材/Micarta）、换表面处理工艺必须重测。
- REACH SVHC：ECHA每半年更新清单（目前240+项），需持续跟踪。
- 装运前COC（SONCAP/PVoC/SABER SCoC）：**单批有效**，每批出货都要办。
- BIS INMETRO：3-4年，年度监督审核。
